# src/：线程与存储

界面的入口、Worker 与存储。画地图在 [render.md](render.md)，界面在 [ui.md](ui.md)。线程怎样分工见 [开发说明 · 线程与隔离](../开发说明.md#线程与隔离)。

## 线程
- `boot.ts`（第九十六轮，见 [第96轮](history/第96轮.md)）页面最先载入的一小段（`index.html` 里排在 `main.tsx` 前面）：接上全局的兜底（`installCrashHandlers`、`crashHooks.fatal = showRescue`），自救页开着时在捕获阶段拦下键盘；只引用 `crash-host.ts`、`rescue.ts` 和它们用的纯文件
- `mishap.ts`（第九十六轮）没接住的错怎么分，纯规则：`classify`（不管 / 不致命 / 致命；不把扩展、别的来源的 `Script error.`、ResizeObserver 的警告、`AbortError`、隔离探针当成错）、`signatureOf`、`MishapLog`（同一个错不反复刷屏）、`DrawHealth`（地图连着几帧画不出来才算坏了）；`crash-host.ts` 接线：`report`、`reportNoWebgl`、`crashHooks`（界面顶上的一条、整页的自救页、页面里现在的世界、马上写自动保存、要自己重新载入）、`crashState`
- `rescue.ts`（第九十六轮）整页的自救页（只用 DOM，不用 Preact、信号、`components/`）：发生了什么、世界还在不在、导出文件、重新载入、原因；`rescue-doc.ts` 导出从哪里拿世界：`rescueExport`（先页面里现在的，再浏览器里存着的）、`readSavedWorld`（自己读 IndexedDB 的自动保存和 localStorage 的后备，不引用 `autosave-io.ts`）；`crash-text.ts` 这一轮的几组文字（不引用任何东西，`ui/copy.ts` 照旧导出）
- `error-text.ts`（第九十六轮）报错改人话 `humanError`（只在显示的那一层翻，原话留在 `detail`）：命令的格式不对、第几步做不出来、浏览器和运行时的原话；本来就是中文的、脚本出的错原样
- `stall.ts`（第九十六轮）计算程序多久没应答就给“停止”：`Stall`（有带提示的请求在等、连着 `STOP_AFTER_MS` = 5 秒没有回过一条）；`open-guard.ts` 启动时打开上次的世界连着几次没打开成（localStorage 的 `map2.opening`）：`beginOpen` / `endOpen` / `askBeforeOpen`
- `progress.ts`（第九十七轮，见 [第97轮](history/第97轮.md)）久的一步的进度，纯规则：`ProgressTrack`（按时间、按各步耗时加权算画到几成；不倒退、一步里最多走到估的九成、做完之前不到头；重放命令按数的）、`ProgressBook`（每一类请求上一次真实的各步耗时，存在 localStorage 的 `map2.progress`，最多 24 类）、`jobKey`、`defaultProfile`、`SHOW_AFTER_MS` = 1 秒；`progress-defaults.ts` 默认的各步耗时（`tools/progress-weights.ts` 量的）；`state/progress.ts` 接线：`progressView`（不显示时 null）、`cancelling`，`worker-host.ts` 的 `call` 里登记（`jobQueued` / `jobDone` / `jobShowing`）、恢复世界时也有（`recoveryStarted`）；`worker-steps.ts` 计算 Worker 里久的一步怎么走：`runSteps`（半秒以内一口气走完，之后每个阶段的边界让出一次、不要了就往里抛 `Stopped`）、`channelRest`（用 MessageChannel 让出）。`stall.ts` 从这一轮起不管按钮出不出现，管“取消”用哪一种（还有动静：请它自己停；5 秒没动静：结束它）
- `smoke-hooks.ts`（第九十六轮）冒烟要“画界面时抛一个错”用的钩子：只在网址的 `#` 后面是 `#map2-smoke-96` 时才装
- 离线（第一百零一轮，见 [第101轮](history/第101轮.md)）：`sw.ts` service worker，只接线——装（把壳存进这一版自己的缓存，`index.html` 的内容核对过才算装好）、启用（记下这一版、删更早的缓存，不自己顶掉正在用的一版）、答请求、听页面的三句话（`info`、`skip-waiting`、`fill`）；打包时由 `tools/offline-plugin.ts` 打成 `dist/sw.js`，第一行是清单。`offline/sw-core.ts` 规则，都是纯函数：清单 `Precache` / `readPrecache`、一个请求怎么答 `route`（刷新先问网络、程序的文件先看存下的、POST 和别的网站不拦）、启用以后留哪几份缓存 `afterActivate`（现在的一版和上一版）、这个页面是不是那一版的 `pageIsFrom`、在哪里登记 `canRegister`。`offline/register.ts` 页面这一头 `OfflineWatch`：只在打包好的程序、http(s) 下登记（开发服务器上把以前登记的取消掉），新版本装好以后页面是旧的就告诉界面、是新的就马上启用，`apply` 是“重新载入”的那一下；浏览器的几样从外面给（`browserDeps`），测试里是假的。`state/offline.ts` 界面看的两个信号 `offlineReady`、`updateReady`，`startOffline`（`main.tsx` 画出界面以后调）、`reloadForUpdate`（先 `autosaveNow` 再启用、重新载入）
- `main.tsx` 入口（第一次画界面前 `startToolEffects`；第九十六轮：把 `crashHooks` 的几样接上、`RootGuard` 包着 `<App />`、画出来以后 `crashState.rendered`）；`state.ts` 只给界面用的信号（地图模式、季节、开着的面板、悬停……）、脚本出错的“编辑”，并把 `state/` 下给界面用的照旧导出（界面只从它引用；不引用 `ui/`）
- `state/`（第七十轮从 `state.ts` 分出来，原样搬，彼此不绕成圈）：`world.ts` 世界与选中的东西（快照换上时一起改的信号）；`notes.ts` 提示、跳过的步骤、“改了什么”与高亮（`describeChange`）；`options.ts` 工具的选项；`prefs.ts` 偏好（localStorage）与参考图（IndexedDB）
- `state/worker-host.ts` 开计算 Worker、请求排队（`call`、`editsIdle`）、换上快照（`applySnapshot`）、缩略图、页面隐藏时写检查点；第九十六轮：`stalled`（几秒没应答）、`stopBusy`、不死等计算程序的 `docNow`（现在的世界文件，等不到就用命令记录并标 `behind`）、`docTailNow`、`idleWithin`；`state/mishap.ts` 顶上“没接住的错”的那一条（`mishap`、`showToastReason`）；`state/gl.ts` 地图的画面现在怎么样（`glState`）；上层的预览作废、自动保存经 `hostHooks` 接回来；`snapshot-merge.ts` 把只带变了的快照拼到手上的世界上（`mergeSnapshot`、轻快照 `lightWorld`，第八十轮搬出来）；`mesh.ts` 网格的缓存与建网格的 Worker；`cost-gate.ts` 成本闸门；第九十七轮：`stopBusy` 是“取消”（先 `cancelEdits` 请它在阶段之间自己停下，新建 / 打开 / 脚本 / 已经没动静的用 `stopAny`；点过以后才沉默满 5 秒的自动改用 `stopAny`），`stallWait`（测试里改短），`handle` 里说“已取消，世界回到了这一步之前”
- `state/edits.ts` 执行、换掉最后一步、撤销、重做；`exact-preview.ts` 地形预览、命令预览、省份的轻预览、确切预览与调整面板的预览；`open.ts` 新建、打开、继续上次的世界（第九十四轮：没能打开时停在问话上 `RESUME_FAILED`，`openDoc` 另说是取消了还是没能打开）、“再试一次”；`script-trust.ts` 问要不要信任脚本；`ask.ts` 问一句的对话框
- `state/autosave.ts` 自动保存（IndexedDB，退回 localStorage）与连着的“我的地图”（第九十一轮：读、写之前先等 `keepStaleOnce`；后备的位置上压着没能挪走的旧世界时不盖它；第九十四轮：只剩定时、信号、接到 Worker 和页面事件上——写什么、谁写在 `autosave-io.ts`、`autosave-lock.ts`；`takeOverSaving`“在这里接着做”、`flushNow` 关页面的那一下同步写、`noteResumed` / `noteNotResumed`、页面隐藏和 `pagehide` 时马上写、有没存的改动才挂 `beforeunload`、测试换存取的 `useAutosaveIo`）；`state/save-status.ts`（第九十四轮）保存状态的信号 `saveFail`、`saveRole`、`savedState`、`storageTight`、`saveProblem`、`unsaved` 与纯函数 `failWhy`、`saveProblemOf`、`hasUnsaved`；`state/backups.ts`（第九十一轮）留着的旧世界的信号 `backups`、这一次打开页面只挪一次的 `keepStaleOnce`、`deleteBackup`、`dismissBackups`、测试换存取的 `useBackupIo`；`state/versions.ts`（第九十五轮，见 [第95轮](history/第95轮.md)）以前的版本接到世界上：世界的编号 `worldId` / `adoptWorldId`（记在自动保存的头里）、现在是哪一串 `seriesNow` / `currentSeries`、信号 `versions`、留一份 `keepVersion` / `keepText`、自动保存写成之后隔一阵留一份 `versionAfterSave`、键换了 `versionsMoved`、删一张地图 `versionsDropped`、腾地方 `freeVersionRoom`、盖掉“我的地图”里的一张之前 `overwriteLinked`（`noteMapSeen` 记着上一次看到的保存时间）、测试换存取的 `useVersionIo`；`state/file-save.ts`（第九十五轮）存到电脑上的文件接到世界、自动保存、⌘S 上：信号 `fileStatus`，`saveToFile`、`resumeFile`、`stopFile`、`fileAfterSave`、`fileFlush`、`fileMoved`、`useFileIo`；`export-host.ts` 导出 Worker、下载；`tidy.ts` 移出的存进资源库、整理的计划、压缩世界文件
- `notice-timer.ts` 提示条多久消失；`biome-range.ts` 生态范围外怎么说（第六十九轮从 `ui/` 搬来）
- `protocol.ts` 主线程与计算 Worker 之间的消息（第九十轮：新建、打开、撤销、重做的回复带 `regen`——上一次生成时的内容里和现在不一样的项；执行的回复不带）；`transfer.ts` 搬数据不复制
- `worker.ts` 计算 Worker（持有引擎；快照、描好的河、空闲预热）；`worker-snapshot.ts` 快照（`SnapshotSender`，第八十轮搬出来）：推导数组、原因数组（第八十轮）、地物、河都只发与上一次发的不同的，主线程沿用手上的同一个对象；第九十七轮：带提示的一步在做的时候把“走到哪一步了”发给主线程（`StagePing`：`stage`；另自己说 `mesh`、`restore`、`replay` 第几条 / 共几条，重放里面的小步标 `inner`），执行、撤销、重做、换一个经 `worker-steps.ts` 的 `runSteps` 走，`cancel` 请求立即回复、记下“编号不超过几的不要了”
- `regen-track.ts` 上一次生成时世界里的内容，跟着撤销的先后记（第六十二轮，资源库面板的“重新生成”；第八十一轮加省份 `provinces`，`hand` 记上次生成之后手改过的国家、省份；第九十轮：新建、打开时用引擎从命令记录里算的那一份起头（`reset` 的第三个参数，`Response.regen`，`worker-host.ts` 的 `applySnapshot` 拼回来），撤销到这次打开页面之前的位置时也用引擎给的；规则 `scopesOf`、`handOf` 搬到 `core/regen-base.ts`）
- 第九十八轮：`state/notes.ts` 的 `showToast(text, error, 'open')`——和新建、打开世界有关的话带 `about: 'open'`（取消了、没能生成的原因；`state/open.ts`、`worker-host.ts` 的 `handle` / `engineReset` / `thumbnail` 打的），新建向导里只把这样的话再写一遍；`state/worker-host.ts` 的 `commandsNow()`：主线程手上的命令记录（不问计算程序），重新生成之前数手改用
- `content-post.ts` 快照里的 `small.content` 没换时不发，主线程补上手上那一份（第四十七轮）；人口群体 `small.popGroups` 同样（第五十四轮）；第八十轮：小数据的其余各段按 JSON 比、国家一国一国比，没变的不发（`sameSmall`、`sameCountries`，要主线程用上了上一份才拼得起来）；第八十五轮：国家的档案 `small.archive` 按对象比（不可变，不序列化）

## 存储
- `backups.ts`（第九十一轮，见 [第91轮](history/第91轮.md)）留着的旧世界：这一版打不开的自动保存（旧版本的、更新的版本做的；第九十四轮加这一版的但没存完整的 `damaged` / `staleWhy`，和写自动保存那一边盖掉之前挪进来的几种 `BackupWhy`；自动保存的头怎么拆 `splitHead`）启动时原样挪进 `backups` 表（`keepStaleAutosaves`：IndexedDB 的一个事务里挪，localStorage 后备的放进表或换一个键），`listBackups`、`removeBackup`、`markSeen`、导出的字 `backupFileText`、文件名 `backupFileName`；存取经 `BackupIo`（浏览器的 `browserBackupIo`、测试的 `memoryBackupIo`）
- `autosave-io.ts`（第九十四轮，见 [第94轮](history/第94轮.md)）自动保存写什么：头里记谁写的（`writer`）、第几代（`gen`），每次写在同一个事务里先读头——是自己上一次写的那一代才按下标只写变了的，不是就整份重写（有写的权利时）或不写；整份重写盖掉别人写的那一份之前，不是自己打开的那一份、也不是自己世界的开头（`continues`）就先原样挪进留着的旧世界；`AutosaveWriter`（`write`、关页面时不读头的 `blind`、`claim`、`canPromote`）；存取经 `AutosaveIo`（浏览器的 `browserAutosaveIo`：留着一个开着的连接给关页面那一下用；测试的 `memoryAutosaveIo` + `MemoryDisk`）
- `autosave-lock.ts`（第九十四轮）哪个页面写自动保存：`SaveRole`（`navigator.locks` 的 `map2-autosave`，拿到的写；`take` 抢过来并在 `BroadcastChannel` 上说一声；写的那一页关了、能接才接；第九十五轮：不能接时是另一种状态 `stale`——那一页已经关了、这个页面里的是旧的）；锁和频道经 `LockIo`（`browserLockIo`、测试的 `memoryLocks`）；没有锁的环境 `lock` 为 null，靠头里的核对
- `versions.ts`（第九十五轮，见 [第95轮](history/第95轮.md)）以前的版本：一份是整份世界文件的字（`versionDocs` 表）加列表里的一小条（`versions` 表）；留哪些是纯函数——`thin`（按时间稀疏：一小时内 5 分钟一份、一天内每小时、昨天每 6 小时、一周内每天、再早留最新的一份；回去之前留的几种一周内不稀疏）、`planDrop`（没存的旧世界只留最近 6 个、合计超过上限从最旧的丢起）、`versionBudget`（400 MB，不超过浏览器给的四分之一，快满了减半）；`addVersion`（和最新的一字不差不留；满了先丢一半旧的再试）、`makeRoom`、`moveSeries`、`dropSeries`、`removeVersion`；盖掉“我的地图”里的一张之前留一份 `overwriteKeeping`；存取经 `VersionIo`（浏览器的 `browserVersionIo`、测试的 `memoryVersionIo`）
- `doc-text.ts`（第九十五轮）世界文件的字 `docText`：和 `JSON.stringify(doc)` 一字不差，每条命令只转一次（按对象记着），留版本、写文件时在主线程上只要一两毫秒
- `file-save.ts`（第九十五轮）存到电脑上的文件（File System Access API）：`FileSaver`（跟着世界的键 `load` / `rekey`、选文件 `attach`、要重新给权限时“没在写” `resume`、`detach`、自动保存之后节流着写 `noteSaved`、马上写 `flush`；写不成的原因 `fileFailOf` 一直留着）、`FILE_SAVE_MS`；文件和句柄的存取经 `FileIo`（浏览器的 `browserFileIo`：`showSaveFilePicker`、`createWritable`、句柄存在 kv 的 `file:<哪个世界>`；测试的 `memoryFileIo` + `memoryFile`）
- `storage-health.ts`（第九十四轮）申请“持久”的存储只申请一次（结果记在 localStorage 的 `map2.persist`）、用掉九成以上算快满了
- `idb.ts` IndexedDB（第九十一轮是第 7 版，多一张 `backups` 表；第九十五轮是第 8 版，多 `versions`、`versionDocs` 两张；自动保存、检查点、网格、参考图、资源库、我的地图；`kvRequest` kv 表上的一个请求）
- `maps.ts` 我的地图（存、盖掉、改名、删掉，连着哪一张）；`library-edit.ts` 第九十一轮加 `setItems`（一次改几项，一步撤销：把各政体里的一个称号都换掉）
- `library.ts` 资源库（内置的树、我的库、“来自《世界名》”、加进来的；`saveItem`、`keepInLibrary`；第五十九轮：包带版本 `rev`，同一版不再 `parsePack`；第九十二轮：以前叫“我的资源”的那个包键没变 `MY_PACK_KEY`，新建时叫“我的星球形态”，还叫旧名字的读出来显示成“以前存的内容” `shownPack`；世界里的内容不再存进它——存到我的库在 `ui/packs/save-mine.ts`，`saveItem` 只剩星球形态编辑器在用）
- `library-edit.ts` 改我的库（第九十四轮：整个库没写进存储时留着“没写”的记号和日志、说一次 `libStoreFail`、过 `FLUSH_RETRY_MS` 再试；第五十九轮；第六十轮加 `setArrange` 换融入的安排、`applyItems` 几项一步；第六十一轮加 `setPack` 导入时整个换掉，一步撤销，先 `parsePack`）：`setItem` 只查这一项、只换到树根的路、写日志（localStorage），整个库晚一点才写（`FLUSH_MS`、关面板、切换库）；自己的撤销（第八十一轮 `undoLabel`、`redoLabel`：顶栏悬停写哪一步）；`adopt` 读存储时补上日志；`copyLibrary`、`createLibrary`、`deleteLibrary`
- `trust.ts` 信任过的脚本（按源码的 SHA-256；问话的一句 `scriptTrustText`）
- `testing/imports.ts` 测试用：读运行时的引用（`worker-imports.test.ts`、`ui/layering.test.ts`）；`testing/fake-idb.ts` 假的 IndexedDB（第九十四轮从 `autosave-backups.test.ts` 搬出来，加了按范围删、存储满了）；`testing/fake-engine-worker.ts` 带命令记录的假计算 Worker（第九十四轮：自动保存、继续上次的世界的测试）
- `styles.css` 全部样式
