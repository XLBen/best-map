## 金标准与逐值不变的规则

- 提速、重构后结果必须逐值不变：`npm run golden` 必须过，每项提速另加一组新旧对照。
- 没涂成的建议是文字，算在 `derived.conflicts` 的哈希里：第十九轮 C 改字时重录了 `golden-full.json` 的 `derived.conflicts` 两项与 `solver-identity` 的 conflicts、world 两项，核对过清空建议的文字后逐值相同。改界面文字时别的哈希不该变。
- 第九轮去掉旧存档兼容时，金标准和各项逐值测试统一重录了一次；之后的优化必须与它们逐值相同。
- 第二十七轮（二）（地形类别只管起伏）重录了人文的几组金标准：`human/human.test.ts`（自动的类别、资源、山峰，地区与星球）、`population.test.ts`、`countries.test.ts`、`settlements.test.ts`（地区与星球各一组），`raster-identity` 的 terrain.bmp、terrain_class.bmp、terrain_classes.csv、resources.bmp、resources.csv、provinces_summary.csv、README.txt（每种尺寸各一个）；自然的金标准（`golden`、`digestWorld`）不变。同样的世界、同样的时代总人口不变；国家数、城市数大致不变（一块地区的中世纪 15 → 15 国、161 → 169 城，星球 93 → 92 国），有主的陆地在几个时代里多了或少了一些（地区的中世纪 63% → 78%、奇幻 44% → 66%，工业 99.5% → 88%）：人口的分布、通行难度变了，国家的起点与扩张跟着变。
- 第七十三轮（国家格局）只因为小数据里的时代换了样子、多了国家格局重录了含整个小数据的摘要：`libraries-digests` 六个库的 `content`、`origin`，`biome-legacy-digests` 的 `libraries.medieval` 的 `content`、`origin`，`class-only-digests` 的 `region` 的世界摘要（撤销记录不变），`raster-identity` 的 `world.json`（四个，版本 14）。逐项见 [第73轮](history/第73轮.md)。核对过：时代写回旧的 `relations`、去掉国家格局和它的来源（`world.json` 写成第 13 版）时与原来的值逐个相同。`r29-digests`、`countries.test` 的 `RECORDED`、`golden*`、`r31-digests`、`shader-hashes`、`tool-replay` 没动。
- 第五十七轮（水系内容）重录了一次，逐项见 [第57轮](history/第57轮.md)：`golden-full` 只有 `derived.riverType`、`derived.lakeType`、`derived.features`、`small`；`r29-digests` 只有 `resource`（毛皮）；`libraries-digests` 的 `resource`、`content`、`origin`，奇幻另有跟着奇幻生态变的十几项；`r31-digests`；`raster-identity` 的 `world.json` 和星球的 `resources.*`；`human.test` 地区的资源；`ocean-plane` 的 `R45_CURRENTS0`。核对过：去掉这些内容时全部测试对着旧记录通过。`golden-hashes`、`biome-legacy-digests`、`shader-hashes` 没动。
- 第五十一轮（六个库）只因为来源的路径从 `common/…` 换成 `medieval/…` 重录：`golden-full.json` 的 `small`（两项）、`r31-digests.json`（`R31_RECORD`）、`solver-identity` 的 `world`（17 个）、`raster-identity` 的 `world.json`（四个）、`ocean-plane` 的 `R45_CURRENTS0`。核对过：新建时的命令里 `from` 写回 `common`，这些测试不重录全部通过。`r29-digests.json`、`golden-hashes.json`、`shader-hashes.json` 没动。
