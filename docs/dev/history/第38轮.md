# 第三十八轮的设计

从开发说明里搬来（第四十一轮）。这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## 画风（第三十八轮）

以前“图层 → 画风”是一个只在这个浏览器里的开关（`state.ts` 的 `mapStyle` 信号，`'realistic' | 'atlas'`），两种画法写死在合成着色器（`uStyle` 的分支）和画布的几张颜色表里。这一轮画风是资源包里的一种内容，选的那一种记在世界里。

**内容种类 `mapStyle`**（`core/content/kinds.ts` 登记，资源包里的段 `mapStyles`，名字“画风”；`store: 'content'`，放在 `small.content.mapStyle`；`dirty` 总是 `'none'`；登记在自定义点的类型之后，资源库左边的分类里排在最后）：
- 格式（`core/map-style.ts` 的 `mapStyleSchema`）只有两种画风不一样的那几项，都有默认值（`DEFAULT_LOOK`，就是写实）：
  - 陆地：`landTint`（底色）与 `landTintAmount`（0 不混）；`landShade`：`plain`（`col *= mix(1, shade, uShade)`）或 `tinted`（`col *= mix(shadeDark, shadeLight, clamp(shade − 0.3, 0, 1))`，不看“晕渲”的强弱，与以前的地图册一样）。
  - 海：`sea`：`shade`（`col *= mix(1, (1 − seaShade) + seaShade · shade, uShade)`）或 `tiers`（`tier1`–`tier4` 四层，`depth2`–`depth4` 从多深起，等深线 `isobath` 与 `isobathAmount`，分层的海的明暗 `tierShade`）。海面是数据（海水温度底图，`uSeaData`）时分层的画风也按 `seaShade` 画。
  - `glow`（生态发光的强弱）；线条：`coastLine` 与 `coastAmount`、`provinceLine`、`countryLine`；河：`river`、`riverBank`；道路：`road`、`roadMinor`（“道路”工具里）、`quietRoad`、`quietRoadMinor`（平时）；`countryLabel`（国名）。
  - `typeColors`：河湖的种类用 `color` 还是 `atlasColor`（没写时用 `color`）。河湖种类的 `atlasColor` 字段照旧，编辑器里改叫“另一种颜色”。
- 颜色的写法（`styleRgba`）：`#rrggbb`、`#rrggbbaa`、`rgb(r, g, b)`、`rgba(r, g, b, a)`，r、g、b 是 0–255、可以带小数（山影的亮色是乘的系数，可以到 510），a 是 0–1。着色器里的颜色按 r / 255 上传成 float32（不看不透明度，浓淡另有一项）：以前写在着色器里的 `vec3(0.93, 0.87, 0.72)` 在内置的地图册里写成 `rgb(237.15, 221.85, 183.6)`，上传的 float32 与原来的字面常数逐位相同（两位小数 × 255 最多两位小数，读回来 ÷ 255 的双精度与原来的数只差一两个 ulp，转成 float32 一样；测试逐个查）。明暗的两个数 `(1 − k, k)` 在 JS 里按双精度算好再上传，与以前写的 0.86、0.94 一样。画布的颜色原样交给画布（内置的就是以前表里的 rgba 字符串）。
- 编辑器：通用编辑器的字段表，“海”选分层、“山影”选着色时才露出那几项（`when`）；`FieldDesc.default`（新加的一项）让换了“海”“山影”后新露出来的几项从写实补上（以前按类型给 `#888888`）。颜色控件：取色器显示最近的 `#rrggbb`，原来带不透明度的选了颜色后留着不透明度；不是 `#rrggbb` 的写法旁边另有一个框照字改（`fields.ts` 的 `colorHex`、`withHex`、`plainHex`）。资源库的色块左上是陆地（平常的陆地色混上底色）、右下是海（分层的取第二层）。

**内置**（`core/packs/map-styles.ts`，只在主线程）：写实（`realistic`，就是 `DEFAULT_LOOK`）、地图册（`atlas`），数值照第三十七轮的代码搬过来。`builtin-tree.ts` 在 `common` 下加 `styles`（画风）一包，`STYLES_PATH`，`DEFAULT_WORLD_PACKS` 加上它：新世界两种都带，按写实画。`GLOW_GAIN_ATLAS` 去掉了（`GLOW_GAIN` 留给缩略图，缩略图照旧按写实）。格式与默认的画法在 `core/map-style.ts`（命令要用，计算 Worker 里有）；`worker-imports` 照旧查 `core/packs/` 不进计算 Worker。

**选择记在世界里**：
- `small.mapStyle?: string`，命令 `set_map_style {id | null}`（照 `set_name_style`）：只能选世界里有的，`null` 是不选；`Dirty.None`，可以撤销、重放，跟着世界文件。旧的世界文件照旧打得开（没有这条命令、没有画风），`DOC_VERSION` 不变。
- `worldMapStyleId(small)`：选了的（还在世界里）；没选、选的不在了时世界里第一种；一种都没有时 `''`。`worldMapStyle(small)`：照它取，一种都没有时 `FALLBACK_MAP_STYLE`（默认的画法，与写实画出来一样）：没有画风的旧世界照旧按写实画。
- 资源库：世界在用的那一种写“在用”（`RepoStatus.isDefault`）；移出它时一起发 `set_map_style null`（一步）；一个包的“移出没用到的”不移它。
- 整理（`content/unused.ts`）：`TIDY_KINDS` 加 `mapStyle`，世界在用的那一种以外的都是没用到的；没有 `usage` 钩子（在用的也能移出，移出后按剩下的第一种）。压缩世界文件照这一条去掉没用上的画风加进来的那条。
- 界面：`LayersPanel` 的“画风”（`MapStyleSection`）列出世界里的画风，四种以内用分段按钮（悬停是说明），多了用下拉，点了发 `set_map_style`；一种都没有时写一句去资源库添加。

**画法**：
- 合成着色器（平面、星球、投影三份；星球、投影的替换不变，`mustAll` 的 `toScene` 照旧 7 处）：`uStyle` 去掉，换成 `uLandTint`（vec4，a 是比例，0 时跳过）、`uShadeTint`、`uShadeDark`、`uShadeLight`、`uSeaTiers`、`uSeaTier[4]`、`uSeaDepth`、`uIsobath`（a 是浓淡）、`uSeaShade`、`uTierShade`（x + y · 明暗）、`uGlowGain`、`uCoastLine`（a 是浓淡）、`uProvLine`、`uCountryLine`。分支的先后与以前相同：陆地（底色、山影）→ 海按明暗（不分层，或海面是数据）→ 分层的海（16 点平滑的水深、四层、等深线、再涂一次省份着色、分层的明暗）。
- `renderer.ts` 的 `style` 是画风对象（`MapStyle`），`styleUniforms(style)` 按对象记住要上传的数（`WeakMap`），每帧只上传；`composeKey` 与投影的键用 `mapStyleKey(style)`（画出来有关的各项拼成的字符串，也按对象记住，不看名字、说明）。
- 画布：`overlay.ts` 的 `riverStroke(style)` 是 `style.river`，两岸是 `style.riverBank`，`riverTypeColor`、`colors.ts` 的 `lakeTypeColor` 按 `typeColor(t, style)`，国名是 `style.countryLabel`；`settle-draw.ts` 的 `roadStyle(r, style)` 取四种道路颜色（`ROAD_COLOR` 等几张表去掉了）；`overlay-proj.ts` 跟着传。河的缓存键（`riverKey`、叠加层的键、低倍的描线）用 `mapStyleKey`；湖的颜色层 `lakeTintLayer(world, o, style)` 的键（`MapView` 的 `applyTint`）只看 `style.typeColors`。
- `MapView`：`renderer.style = worldMapStyle(shown.small)`（画出来的世界选的那一种：资源库里改着画风、停一下预览时是改好的那份），叠加层、河的图层同一份；`cleanState`、导出（`map/export.ts`）按 `worldMapStyle(w.small)`。“水系”面板列表里的色块照旧按写实。
- 缩略图不变（按写实）。

**测试**：见“测试”的“画风”。另外在无头 Chrome（SwiftShader）里把第三十七轮（ac0d1a3）与这一轮的合成着色器各编译一份，同样的合成输入（随机的场景颜色与海岸线浓淡、起伏的高度与陆海、编号、平涂、省份与国家的分组、花纹与发光、湖的画法、河），写实 / 地图册 × 海面是不是数据 × 一格 12 / 2 像素（平滑的水深开与关）× 平面 / 星球 × 带不带花纹，32 组读回来的像素逐字节相同；投影的两份编译、链接过。

**速度**：只改画法。每帧多上传十几个 uniform（数按画风对象记住）；签名按对象记住，每帧不重算。加工、描河的代码一行没改，新世界多加两项内容。`tools/bench-median.mjs` 在 ac0d1a3 与这一轮之间交替各跑五次（地区）：这一次机器很忙（同时跑着全部测试），各步在 −46% 到 +42% 之间来回跳、两次对照里慢的步骤各不相同（第一次 island −32%、第二次 +26%），看不出高低，如实记下。
