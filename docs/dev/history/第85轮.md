# 第八十五轮的设计

这一轮改了什么见 [更新记录](../../更新记录.md)。目标：给做世界观、写自己的国家和人物的用户一个档案——国家的备注、统治者与家族、
大事年表，和一包能互相点的 Markdown（导出维基）。地图一个像素都没变。

## 数据：`small.archive`

国家的档案放在小数据里单独的一段（类型在 `core/human/archive-types.ts`，`world.ts` 照旧导出）：

```
small.archive = {
  countries: { 国家的编号: { note?, rulers: RulerMeta[], dynasties: DynastyMeta[], edited? } },
  events:    { 编号: { id, year, title, note?, countries: number[], auto? } },
  nextEvent,
}
RulerMeta   = { id, name, orig?, title?, from, to?, dynasty?, parent?, note? }   // 先后就是名单的先后，最后一位是现在的统治者
DynastyMeta = { id, name, orig?, founder? }
```

- 以前的 `CountryMeta.ruler` 去掉了，现在的统治者是名单的最后一位（`currentRuler`）。`set_country` 不再有 `ruler`。世界文件的版本 19 → 20
  （旧的存档不兼容：旧文件里 `set_country` 的 `ruler` 过不了格式）。
- **不放在 `CountryMeta` 上、单独一段、不可变**：每条命令执行前后都把小数据（内容、人口群体以外）序列化一次（`small-copy.ts` 的
  `copySmall`、`sameAsCopy`），发给主线程时结构化克隆一次。中世纪的测速世界（33 国）档案约 26 KB，小数据的其余部分约 160 KB，
  放在国家上每条命令都多序列化 15% 上下（改国家档案 `libCountry`、不重算的编辑 `libEdit`、`libPost` 都会过 +5%）。
  所以和内容（第四十七轮）、人口群体（第五十四轮）一样：档案是不可变的，改档案的命令整个换成新对象（`archive-store.ts` 的 `putLore`、
  `putEvent`，改到的那一国、那一件是新的，别的照旧是原来的对象），`copySmall` 只留一个引用、JSON 里是占位；`postedSmall` 也占位档案，
  快照（`content-post.ts`）按对象比，没换就不发（`sameSmall` 里写 `archive`，主线程补上手上那一个）。预览、快照里内容没换时
  用新的 `withoutContent`（只占位内容）。测试把档案整个冻住执行所有档案的命令（就地改会抛错）。
- 建国、统治者即位**不存成大事**：年表里按建国年份、名单现列（`events.ts` 的 `countryTimeline`），改了名单、年份年表跟着变，不会对不上。
  存的大事只有结盟、开战、成为附庸（生成的，带 `auto`）和自己加的。牵涉几国的一件存一份，`countries` 里的每一国的年表里都有它
  （第一国是写它的那一国，界面上去不掉）。

## 生成

人文生成的最后一步（`generate.ts`：所有的步骤、加的维度之后），只在重新长国家时（`countryMode` 是 generate）：
`archive-keep.ts` 的 `writeArchive`。每个新的国家：

- **统治者**（`rulers.ts` 的 `generateLore`）：3–8 位（2 + 跨度 ÷ 40 年 + 0–2，夹在 3 到 8），从建国到时代的“现在”（`years` 的后一头；
  没写时 1000）。每位在位 8–35 年；加起来放得下时首尾相接、按比例拉开铺满，放不下时第一位是开国的，其余是最近的几位（中间隔着没列出来的年代）。
- **家族**：1–3 个（三位以下最多两个），按先后分成几段，每段的第一位是开创者；名字是文化的地名风格起的地名 + “家”（有原文时带原文）。
- **父母**：同一家族里首尾相接的下一位，多半是上一位的孩子，四分之一是上一位的兄弟姐妹（同一个父母）；有父母时两成沿用父母的名字，
  同一个名字的第二位起写“二世”“三世”（原文写 II、III）。最后一位不沿用，名字和以前的 `ruler` 一样（同一个种子 `mixSeed(countrySeed, 0x7e1)`），
  称号按国家最后的等级（联邦的成员邦也对）。
- **大事**（`events.ts` 的 `generateEvents`）：每一对同盟“A与B结盟”、敌对“A与B开战”，附庸“A成为B的附庸（保护国、殖民地……）”，
  两国都是新的只记一次；年份在两国都建国以后到现在之间（按两国的编号取随机数）。
- 都只用自己的随机流（`mixSeed(seed, hashString('rulers'), id)`、`hashString('event:ally')`……），不碰国家一步共用的流，所以别的结果一个值都不变
  （见“核对”）。新建国家、拆分出来的国家（`newCountry`）也照这样生成统治者。

## 重新生成时留什么（规则）

重新长国家（生成人文、生成国家、重新生成国家、重新生成人文和国家）：

1. **锁定、留下来的国家**（重新生成之前就在、档案对象没换的）：备注、统治者、家族不动，牵涉的大事也留着（生成的只留两头都是这样的国家的）。
2. **别的国家**是新生成的：统治者、家族、生成的大事按新的国家重新生成。**同一个编号**在重新生成之前就有（按编号留下来）时：
   - 备注留着；
   - 统治者、家族自己改过（`edited`：任何一条统治者、家族的命令都会标上）时整份留着，不用生成的。
3. **大事**：自己加的、改过的（没有 `auto`；改生成的大事会去掉 `auto`）留着，去掉已经没有的国家，一国都不剩的去掉；
   生成的（`auto`）除了 1 里的，都去掉、重新生成。
4. **只重新生成人文**（国家的领土不动）、挪发源地：档案一个都不动（同一个对象）。

不留锁定的重新生成国家时编号从 1 起（以前就是这样），所以“同一个编号”可能已经是另一片领土上的国家；想让备注跟着那片领土，先锁定那一国。
条上（资源库面板底下的“重新生成”）有国家时多写一句“手写的档案留着”（`packs/copy.ts` 的 `REGEN_KEEPS_ARCHIVE`）。
删除、合并国家（`tidyArchive`，在 `tidyCountries` 里）：没了的国家的档案去掉，大事里去掉它；合并时大事归并进去的那一国。删除全部国家时档案一起去掉。

## 命令

`baseCommands` 最后加了 11 条（`commands/archive.ts`，都是 `Dirty.None`，不改数组，所以 `touchedArrays` 不用登记）：
`set_country_note`、`add_ruler`、`set_ruler`、`remove_ruler`（孩子的父母改成它的父母）、`move_ruler`（排到第几位）、`add_dynasty`、
`set_dynasty`、`remove_dynasty`（里面的人不再属于家族）、`add_event`、`set_event`、`remove_event`。父母不能是自己的后代，结束不能早于开始，
家族、父母要在这一国里。撤销、重做和别的命令一样（撤销记录里留着改之前的档案对象）。

## 界面

- 概览的最后是“备注”（`NoteSection`，停下一秒、离开框时提交）。
- “历史”页：建国与历史，然后 **统治者**（`archives/country-rulers.tsx`）：按家族一段一段（家族名点了就改），家族里按先后，孩子比父母往里缩一格；
  一行是名字（没有边框的框，点了就改）、在位的两个年份小框（`fields.tsx` 的 `YearBox`：认 `-500`、`前500`，结束空着是至今）、⌄ 展开
  （称号、原文、家族、父母、备注、往前往后、删除），最后“加统治者”（加在最后、上一位在位到它开始，一步）“加家族”。
  然后 **大事年表**（`archives/country-timeline.tsx`）：左边一条竖线，建国是大点、即位是空心的点、大事是小点；大事的标题点了就改，⌄ 展开备注、牵涉、删除；
  最后“加大事”。建国、即位那一行改年份就是改建国年份、那一位的在位。
- “政治”页的统治者只写现在的那一位，点了去“历史”。
- 命令都在 `domain/country-lore.ts`（没变时 null），组件只调它；字在 `copy.ts` 的 `ARCHIVE_TEXT`（测试查着不超过 20 个字）；样式 `archives/lore.css`。
  `LongText` 从 `SettleArchive.tsx` 原样搬进 `archives/fields.tsx`。

## 导出维基

“单独导出”里多了“导出维基”（`wiki.zip`；`core/human/wiki.ts` 的 `wikiFiles` 出每一页，`export.ts` 的 `wikiZip` 用 fflate 打包，
文件时间固定，同一个世界逐字节相同）：`index.md`、`countries/<国名>.md`、`cities/<城名>.md`。国家一页：概览（政体、等级、主流文化、国教、首都、人口、
面积、建国）、备注、历史、统治者（按家族，缩进是父母）、大事年表（牵涉的别国是链接）、关系（宗主、附庸、同盟、敌对、集团）、城市、省份（陆地格最多的那些）；
城市一页：首都 / 等级 · 国家、人口、建城、省份、简介、备注、道路（另一头的城市是链接，接到路网的写“路网”）。链接是相对的（`../cities/X.md`），
文件名去掉 `<>:"/\|?*#%&` 等、空白和括号换成 `_`，保留名（CON、NUL……）前加 `_`，最长 60 个字，同一个文件夹里重名（不分大小写）加 `-2`、`-3`。
测试解开 zip、把每个链接按相对路径解析到包里的文件。
`export.ts` 已经 845 行：道路图（`roadsImage`）原样搬到 `human/roads-image.ts`（照旧导出），现在 802 行。

## 核对与重录

核对“除了国家的档案，别的一个值都没变”（临时的脚本，没进仓库）：六个时代 × {一块地区 1.2 万格、星球 8000 格}，新建、加时代的库、划省份、生成人文（国家、城市、道路），
再改三笔（冷暖、画海、抬山），再重新生成国家一次，每一步之后打出世界的**每一样**的摘要：网格、原因（含人口、国家、地形类别……）、自定义场、推导（含人文的几层）、修正场、
地物（含名字、位置）、冲突、小数据的每一段（`small.countries` 去掉每一国的 `ruler` 以后比；`small.archive` 新的才有，不比）。在 6e91d35 的副本与这一轮上各跑一遍：
36 个世界、4146 项，0 项不同。

## 没做的

- 家族的关系只有父母一条（没有配偶、兄弟姐妹以外的旁支），按家族缩进列出，不画家谱图。
- 统治者的称号是生成时那一国的称号，之后换政体不跟着改（和历史的那几句一样是快照）。
- 不留锁定的重新生成国家时编号从 1 起，“同一个编号”的备注会落到另一片领土上的国家（规则照这一轮的要求写；要跟着领土就锁定）。
- 名单里中间隔着没列出来的年代时，界面上不另外标出来。
