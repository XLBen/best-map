# 第四十三轮的设计

这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## EU4 的文化组、宗教组与政体名（第四十三轮）

用户要的：“按照 eu4 的文化组方案重做所有的资源包……不要架空文化，只有 dnd 和科幻组有架空的设计，但是文字风格还是和 eu4 一样”。定下来的：古代、中世纪与近世、近现代、现代四个历史时代都用 EU4 1.37 的文化组与宗教；一个文化组一种地名风格；奇幻、科幻的种族、宗教第四十四轮再做（这一轮不动它们的组、文化、宗教，只让共用的部分照旧能用）。

### 数据

- **文化**：EU4 1.37 的 71 个文化组、410 个文化（跳过只在 DLC 里合并出来的“斯拉夫”组、亚特兰蒂斯人、扬马延人），按地区放在 `core/packs/eras/cultures/` 的 7 个文件里：`europe`（15 组）、`middle-east`（3）、`africa`（10）、`asia`（16）、`americas`（24）、`oceania`（2）、`lost`（失落的文化，1 组 15 个）。格式 `{ region: {id, name, description}, groups: [{ group, cultures }] }`。以前虚构的 13 个地球文化组、它们的 45 个文化和 15 种宗教全部去掉。
  - 组：`id`（英文，kebab：`east-slavic`、`western-aryan`……；北欧是 EU4 的 `scandinavian`，免得和旧的 `nordic` 混）、`name`（不列颠、东斯拉夫、汉……）、`orig`（EU4 的英文名）、颜色（一组一个色系）、一句说明（仿 EU4 的口吻，自己写的）、喜欢的地方（按真实的家乡：北欧冷的海岸、萨赫勒热的半干草原、安第斯高地、马来热带海岸……，由 30 来种“原型”拼成）、默认的地名风格、倾向。
  - 文化：`id`、`group`、`name`（标准的中文名：卡斯蒂利亚人、英格兰人、江淮人……）、`orig`、颜色，可选的风格、权重，只写与组不同的倾向。EU4 的文化不写说明。
  - 颜色：组的颜色是一个 HSL 色相；组里的文化在色相 ±14° 以内、明暗浓淡拉开（在 Lab 色差上贪心地取离已选的最远的），组里两两 Lab 色差都在 10 以上（汉 20 个文化也是）。同一地区的组两两 8 以上、每个时代默认带的组两两 10 以上。
  - 地名风格：一组一种（第四十三轮前三个提交的 49 种新风格 + 原有的），`eu4-a/b/c.ts` 登记进 `names/index.ts`，`STYLE_REGIONS` 加上（西欧、南欧、北欧与东欧、东亚、西亚与中亚、南亚与东南亚、非洲、北美、中美与南美、大洋洲、幻想）。内置 76 种，每种都有文化或组在用。文化另写风格的（“明显更合适”才写）：荷兰人、佛兰德人、弗里斯兰人用荷兰语；威尔士人、康沃尔人、布列塔尼人用凯尔特；芬兰人、卡累利阿人、萨米人用乌拉尔；阿塞拜疆人、突厥伊朗人、土耳其人用突厥；马尔加什人用马来；满洲人用埃文基；白族人、苗人、彝人用中文；失落的文化各用最近的（雅典人、斯巴达人希腊，腓尼基人、希伯来人、阿拉米人、巴比伦人、古埃及人阿拉伯，帕提亚人、斯基泰人波斯，盎格鲁-撒克逊人英语，斯堪尼亚人北欧，利沃尼亚人、古普鲁士人波罗的）。越南人用孟-高棉（组的风格）。
- **宗教**：EU4 的 28 种分 7 组（基督教 7、伊斯兰教 3、东方宗教 5、达摩宗教 2、原生信仰 9、犹太教、琐罗亚斯德教），古代另有 8 种（希腊、罗马、古埃及、迦南、美索不达米亚、凯尔特、日耳曼的多神教与吠陀教，“古代宗教”一组），现代多一个无宗教（不归组）。颜色大致照 EU4 的地图色，每个时代里两两 Lab 色差 10 以上。EU4 的“异教”组叫“原生信仰”，免得和“异教（不同组）”的关系混。
  - 各时代有的：古代是古代的诸神、琐罗亚斯德、犹太、上座部（早期佛教）、儒、神道、腾格里与各地的原生信仰（印蒂、玛雅、图腾、泛灵、拜物、梦创），没有基督教、伊斯兰教、印度教（吠陀教代替）、锡克教、大乘、金刚乘；中世纪与近世是 EU4 的全部 28 种（这个时代就是 EU4 的 1444–1821，新教、归正宗、圣公会、胡斯派、锡克教都在，倾向里权重小）；近现代去掉胡斯派、纳瓦特尔、印蒂、北欧多神教；现代再加无宗教。
- **政体**（仿 EU4 的君主制、共和制、神权、部落与它们的改革，说明自己写）：古代 10 种（部落专制、部落联盟、部落王国、草原游牧、专制君主制、神圣王权、寡头共和国、贵族共和国、神权统治、原住民议会），中世纪与近世 19 种（封建、专制、行政、选举、绝对君主制，天朝、幕府、伊克塔，商人、寡头、贵族共和国，自由市，神权统治、骑士团，四种部落与原住民议会），近现代 14 种（绝对君主制、君主立宪制、专制君主制、革命帝国、立宪共和国、革命共和国、总统专制、联邦共和国、天朝、幕府、神权统治、部落联盟、草原游牧、原住民议会），现代 12 种（照旧按意识形态，加绝对君主制）。全部 50 种。
- **派系**：古代是贵族、教士、市民、部落（EU4 的阶层），中世纪多一个“异教臣民”（EU4 的迪米：来自信异教的人）；近现代、现代的照旧（教会多一条：信国教的人）。全部 27 个。
- **地标**：金字塔的文化组是黎凡特、失落、苏丹、中美洲、玛雅、安第斯；长城是汉；神庙、城堡、修道院按东亚、东南亚、印度的几组换说法。

### 数据结构

- **文化组是一等内容**（`cultureGroupSchema`）：多了 `nameStyle`（组里文化默认的风格）、`tendencies`（维度 → 取值与权重，政体写 `government`）、`eraTendencies`（时代 id → 维度 → 取值与权重）。文化的 `nameStyle` 可以省略，也有 `eraTendencies`。以前组的倾向只在内置 JSON 里，读的时候合并进每个文化；现在不合并，用的时候查（`era.ts` 的 `cultureTendency(small, culture, dim, era)`）：文化按时代写的 → 文化不分时代的 → 组按时代写的 → 组不分时代的。所以改组的倾向、风格，组里没写自己的文化都跟着变。每个时代只认这个时代有的取值、政体，按时代写是为了同一个取值在不同时代权重不同（不列颠中世纪天主教、近现代圣公会）。风格 `styleOfCulture`（文化的，没有时组的）；`culture-style.ts`、`prune.ts`、`usage.ts`、`import.ts`、`builtin-tree.ts` 都按它算。字段表里加了这几项（`eraTendencies` 是两层的 map），更好用的编辑器在第四十五轮。
- **取值组**（新的内容种类 `valueGroup`，段 `valueGroups`，登记在取值之前，`order` 37.5）：`id`、`dimension`、`name`、`orig`、`color`、`description`。取值多了可选的 `group`（包里组改了 id 时取值跟着改）。时代包里一维的小包带着这一维用到的组；加内容时按规则时代的维度带（同取值）；生成后没有取值属于它的组移出；整理本世界、“用在哪里”都认它。
- **异端与异教**（`faithRelation(small, a, b)`）：一样是 `same`，同组不同派是 `heretic`（异端），不同组或没有组的是 `heathen`（异教）。**国教**是主流文化最典型的宗教（倾向里这个时代权重最大的；不存，现算，没有新的生成数字）。
  - 派系的来源多了 `faith: 'same' | 'heretic' | 'heathen'`（维度省略为 religion）：国家里与国教是这种关系的人占多少。教士 `same` +0.6、`heretic` −0.3，异教臣民 `heathen` +1.5，教会 `same` +0.6。
  - 档案全文多一行“国教：天主教（基督教）；异端 3.2%、异教 10.5%”（`countryFaith`），国家档案的统计里也写；宗教的图例写“天主教（基督教）”。
- **政体的称号按等级**（仿 EU4 的 `government_names`）：`title`、`rulerTitle` 换成 `titles`、`rulers`（一种写法，或“等级 id → 写法”的表，可写 `default`）与 `names`（换说法的几条：`cultures`、`cultureGroups`、`values`、`valueGroups` 几项都满足时起作用，各自是“其中之一”，带 `titles`、`rulers`）。挑法（`govTitles(gov, ctx)`）：国家称号、统治者称号分开挑，按先后看满足的几条里第一条写了这一级（或 `default`、或只写一种）的；都没写这一级时用政体默认的表：有这一级 → `default` → 世界里离这一级最近的一级（`order` 一样近时取低的）→ 表里排在正中的一项。国家没有等级（自己建的）时按世界里排在正中的一级。挑称号时看的（`titleContext`）：国家的等级、主流文化与组、主流文化最典型的各维取值与它们的组。
  - 例：君主制默认 领 / 侯国 / 公国 / 王国 / 帝国（领主、侯爵、公爵、国王、皇帝）；东斯拉夫的基督徒 公国 / 大公国 / 沙皇国；伊朗 汗国 / 沙阿国 / 帝国；草原 伯克领 / 汗国 / 大汗国；印度的穆斯林 纳瓦卜国 / 苏丹国；穆斯林 谢赫国 / 埃米尔国 / 苏丹国 / 帝国；印度教 塔库尔领 / 罗阇国 / 王国 / 帝国（罗阇、摩诃罗阇）；汉 邑 / 侯国 / 国 / 国 / 大某；草原游牧 部落 / 汗国 / 大汗国；神权统治 修道院领 / 主教领 / 大主教领 / 神权国（伊斯兰的是伊玛目国、哈里发国）；商人共和国 城邦 / 共和国 / 至尊共和国。
  - 联邦切出成员邦时首府那一邦的等级会变：统治者的称号跟着重算（`rulerTitleOf`）。档案里换政体、换文化时国名按新的称号（名字锁定的不变）。
  - 编辑器：`titles`、`rulers` 用以前称号的一行一种的编辑器（键写等级 id 或 default），`names` 是一组（文化组、文化、取值组、取值是 tags）。
  - 地标的名字、时代的帝国 / 联邦 / 同盟称号照旧用 `pickTitle`（按文化、文化组）。
- **地名风格的上限**：一个世界、一个包最多 64 种 → 128 种（内置 76 种，勾“通用 ▸ 文化”整个就要七十多种）。

### 内置的树

- **通用 ▸ 文化 ▸ 欧洲 / 中东 / 非洲 / 亚洲 / 美洲 / 大洋洲 / 失落**：一个地区一个小包，放地区里全部的组、文化与它们用的地名风格（包最多两层，地区下面不再分组；勾一个地区时向导按组列出来，可以一组一组勾）。奇幻、科幻的种族只在它们的时代包里。
- **时代包**照旧有 `cultures ▸ <组>`（带默认的权重）：组与文化是“通用 ▸ 文化 ▸ 地区”里的同一份对象（引用，不复制；`builtinItem` 的 paths 有两处）。时代文件的 `pack.cultures` 可以写 `[组, 权重, { except: [文化] }]`：中世纪的不列颠、法兰西、伊比利亚不带殖民地的文化（美利坚人、魁北克人、路易斯安那人、巴西人、墨西哥人、拉普拉塔人），古代的失落不带盎格鲁-撒克逊人等中世纪的、汉不带满洲人和几个“汉-某”、黎凡特不带土耳其人……
- **默认带的组**：古代 15 组（失落、汉、黎凡特、伊朗、印度斯坦、达罗毗荼、凯尔特、日耳曼、阿尔泰、马格里布、苏丹、库希特、日本、安第斯、玛雅），中世纪与近世 18 组（各地区的主要文化组，权重按 1444 年的分量：汉 4、黎凡特 3、日耳曼 3……萨赫勒 1、安第斯 0.8），近现代 17 组（加美洲殖民地的文化），现代 15 组。奇幻暂时带不列颠、拉丁（人类），科幻带汉、不列颠、印度斯坦（第四十四轮再改）；这几组照抄了以前西欧、地中海、东亚、南亚的奇幻、科幻倾向（种族、物种、奇幻的宗教与政体、科幻的意识形态与政体，写在 `eraTendencies.fantasy / scifi` 里）。
  - 取舍：用户说的“中世纪：全部地区的组”没有照字面全带：71 组 410 个文化在一块 4 万格的地区上每组都要一个发源地，大多数组连一个国家都分不到（1.2 万格的地区只有十几国），新手看到的是一片碎片；生成也慢（每个文化一层偏好）。所以时代包默认带各地区主要的十几组，别的在“通用 ▸ 文化”里，一勾就有。这一条是可以改的数据（时代文件的 `pack.cultures`）。

### 奇幻、科幻（第四十四轮前的过渡）

- 组、文化、宗教不动（文件顶上的 `tendencies` 读成组的倾向）。
- 政体的旧称号机械地换成新写法：`default` 成为 `titles` / `rulers`，按奇幻、科幻的组或文化的键成为 `names` 里的一条（先文化后组，与以前一样）；按已经去掉的地球文化写的键丢掉。奇幻用的“帝国”政体从中世纪的文件挪到奇幻的文件；“封建君主制”留在中世纪，带着矮人、兽人、海民的换说法。

### 生成

- 结果变了（内容换了），世界文件第 11 版（`DOC_VERSION`）。
- 有主的陆地：默认的组多了以后，一块小地区上有些组分不到国家，无主地多一些。中世纪 18 组时 1.2 万格的大陆有主 64%（6 组时约 70%），古代 56%、近现代 88%、现代 100%：仍是古代 < 中世纪 < 近现代 < 现代。

### 速度

- `node tools/bench-median.mjs 5 --against 8af35c2`（整个星球 + 奇幻包）：加工各步都在 ±5% 以内（第二次：paintLand +3%、relief −2%、island +2%、humidityPreview +4%……；第一次 paintLand +6%、relief +7%，连没改的 mesh 也 +4%，重跑一次就没有了，是机器的起伏），新建世界 2422 → 2428 ms（+0%：新建时默认加的内容没变）。这一轮没碰地形、气候、渲染。
- 加内容：一块 4 万格的地区上，中世纪包默认的 18 组（144 个文化、22 种地名风格）算计划 6 ms、执行 76 ms；连“通用 ▸ 文化”整个勾上（410 个文化、72 种风格）执行 120 ms。生成人文 + 国家约 0.65 s。生成后照第二十九轮的规则只留用到的（默认 18 组的 144 个文化都有人）。
- `tools/bench.ts --human`、`bench-layers.ts`、`r40-world.ts` 用中世纪包默认的前三组（汉、黎凡特、日耳曼；从包里读，旧的提交上也能跑）。

### 测试与重录

- 改了的：内容的 id、个数（政体 19 种……）、称号的写法、按组的倾向。
- 新加的：EU4 的 71 组 410 个文化、7 个地区；以前虚构的地球文化、宗教一个都没有；宗教各有组、各时代只有那时已有的；组的颜色一个色系、组里分得开；组都有默认的风格、76 种风格都有人用；倾向合 EU4（伊比利亚天主教、东斯拉夫东正教、伊朗什叶派、汉儒教、藏金刚乘、不列颠中世纪天主教近现代圣公会……）；每个历史时代的每种政体给每个 EU4 组、每个默认的等级都有国家称号与统治者称号（一万多种组合）；仿 EU4 的说法（公国 / 王国 / 帝国、大公国 / 沙皇国、埃米尔国 / 苏丹国、汗国 / 沙阿国、罗阇国、大汗国、主教领、哈里发国、大明、幕府……）；北欧住在冷的地方、黎凡特住在干的地方；汉多天朝。

- `country-tiers.test.ts` 看帝国、“混合”的那几个测试换种子 7（种子 3 在新的三组下“混合”有主 62%，不到 70%）。
