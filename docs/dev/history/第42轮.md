# 第四十二轮的设计

这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## 国家等级是内容（第四十二轮）

用户要的：“大国中国小国，改为帝国级行政，王国级行政和侯国级行政（参考 eu4）”，按现有的五档，但**解耦、不写死、可以扩展**。

以前写死的（第二十六轮起在 `countries.ts`、`era.ts`、`blocs.ts`）：五档的 id（`COUNTRY_TIER_IDS`）、面积倍数（`COUNTRY_TIERS`）、名字（`TIER_NAMES`）、相配的政体（`TIER_GOV_SIZE`）、时代没写时的比例（`DEFAULT_TIERS`）、四种格局（`LAYOUT_TIERS`、`LAYOUT_NAMES`），还有几条点名某几档的规则：邦联的中心是 `medium`、成员 35% `city` 其余 `small`；`city`、`small` 当附庸的可能 × 1、别的 × 0.5；只有 `large`、`empire` 能分成联邦；联邦的成员邦 0.7 倍以上 `medium`、0.2 倍以上 `small`、其余 `city`。这些常数全部去掉了。

**两种新内容**（`core/human/tiers.ts` 的格式，`tier-kinds.ts` 登记，`store: 'content'`，`dirty: 'none'`，登记在政体、派系之后）：
- **国家等级** `countryTier`（段 `countryTiers`）：`id`、`name`、`short`（简称）、`description`、`order`（越大越高）、`area`（面积倍数）、`weight`（时代没写比例时占多少，省略为 1）、`govSize`（相配的政体大小）、`vassal`（当附庸的倾向，省略为 0.5）、`federation`（能分成联邦）、`fedMember`（联邦的成员邦面积至少几倍平均时算这一级）、`confedCentre`（邦联的中心）、`confedMember`（邦联成员的比例）、首都的样子 `capitalIcon`、`capitalAlpha`、`capitalLabel`、`capitalBold`。
- **格局** `countryLayout`（段 `countryLayouts`）：`id`、`name`、`description`、`weights`（等级 id → 比例）。“按时代”不是内容（`ERA_LAYOUT = 'era'`，按时代的 `tiers`）。
- 选字段而不是“在排好的列表里第几个”：规则与等级的意思绑在一起，加一级、删一级不会让“邦联的中心”悄悄挪到别的级上。没写的时候才按位置退：中心取排在正中的一级（`tiers[⌊n/2⌋]`，内置五级正好是公国级），成员取最低的一级；联邦成员邦写了 `fedMember` 的几级里取够得上的最高一级，都够不上时取其中最低的一级，一级都没写时最低的一级。

**世界里的列表**：`worldTiers(small)` 按 `order` 从小到大（一样时按 id），按 `small.content.countryTier` 的对象缓存；生成用 `genTiers`，一级都没有时是一档“一般”的（`FALLBACK_TIER`：面积 1、政体 1，id 空，不写进国家的档案；`missingNotes` 写“没有国家等级：国家都按一般的大小”）。`CountryMeta.tier` 是字符串（等级的 id），`CountryRules.layout` 也是字符串（格局的 id 或 'era'），命令里的 `layout` 改成 `typeIdSchema`。时代的 `tiers` 是 `z.record(id, 0–100)`。

**生效的比例** `tierWeights(tiers, era, layout)`：按 `tiers` 的先后各一个数；格局（世界里有、写到的等级有一个大于 0）→ 时代的 `tiers`（同样）→ 各级的 `weight`。没写的等级为 0，世界里没有的 id 不算。

**生成逐值不变**：内置的五级按 `order` 排出来正好是 city、small、medium、large、empire（以前 `pickWeighted` 走的先后），数都照搬。几处要小心的：
- 挑等级：`pickWeighted(tierList, (t) => w[k] × govFit(gov, t))` 与以前的 `(tiers[t] ?? 0) × govFit(gov, t)` 每一项相同。
- 邦联的成员：以前 `rand() < 0.35 ? city : small`；现在 `pickWeighted([city, small], confedMember)`，比例 0.35 + 0.65 按双精度加起来正好是 1，`r = rand() × 1`，`r − 0.35 ≤ 0` 与 `r < 0.35` 只在 `rand()` 正好等于 0.35 时不同（mulberry32 给的是 k / 2³²，碰不上）；不是城邦级时减完 0.65 不一定 ≤ 0，但落到最后一项也是侯国级。邦联的中心不调 `rand()`，与以前一样。
- 附庸：`p = vassals × 同组 × vassalOf(tier) × 层数`，乘的先后不变、值是同样的 1 或 0.5。
- 联邦的成员邦：`a >= fedMember × T` 与以前的 `a >= 0.7 × T` 是同一个式子；城邦级写 0，`a >= 0` 总成立。
- 档案里 `tier` 仍是最后一个键。
- 核对：`r29-digests`（七种设置下生成人文、国家、城市地标，再清理过重新生成国家，摘要里有国家的档案，含 `tier`）一个都没变；`human`、`countries`、`country-tiers` 的测试照旧过。

**内置**（`core/packs/countries/tiers.json`，只在主线程）：在“通用 ▸ 国家等级”（`TIERS_PATH`），`DEFAULT_WORLD_PACKS` 加上它：新世界默认带五级、四种格局。名字：帝国级行政（`empire`）、王国级行政（`large`）、公国级行政（`medium`）、侯国级行政（`small`）、城邦级行政（`city`），简称去掉“行政”。格局的说明改成按等级说（“诸侯林立：低等级的国家为主，几乎没有王国级以上的”）。

**金标准**：新世界的小数据多了这一包、城市等级多了两项（见下），`golden-full.json` 的 `small` 两个值、`r31-digests.json`（整个世界的摘要，每一步都含 `small`）重录；重录前核对过：默认的包里去掉国家等级、城市等级照第四十一轮时，两份都与原来的值逐值相同（别的几十个数组一个没变）。`golden-hashes.json`、`r29-digests.json`、`shader-hashes.json` 没动。

**界面**：
- 国家档案最上面写等级的简称（`tierLabel`，自己建的、等级不在世界里时空着；以前没有等级时写“中等国家”）。
- 格局的下拉（`LayoutPick`）列“按时代”和世界里的格局（`layoutChoices`），说明是格局的 `description`；选着的格局不在世界里时也列上（写 id，说明“按时代”）。
- “分裂 ↔ 统一”的说明改成“往左国家多而小，往右国家少而大”（这个滑块只改平均大小，不改等级的比例；以前写的“小国多 / 大国少”不准）。
- 资源库：两种都在“通用 ▸ 国家等级”，编辑器有字段表（数字、开关、`weights` 是 map）；选这两种时下面有“生成国家… / 重新生成…”（`GOV_KINDS`）。
- 导出的 `countries.csv` 的 `tier` 列照旧写 id。

## 城市与首都分轻重

用户要的：“中级城市在地图内可以渲染得更弱一些，非最大级别国家的首都渲染也能更弱一些”。

- **城市等级**多了三项（`settle-types.ts`）：`alpha`（图标的浓淡）、`iconScale`（图标大小）、`labelAlpha`（名字的浓淡，省略同图标）。内置：首都、大城市不写（照旧），城市 0.7 / 0.85，村镇 0.6 / 0.85。大圆缩到 0.85 半径约 3.7 像素、0.7 的浓淡在浅底上还看得清，大城市的双圈、首都的星相比之下明显突出；白边是图标的一部分，跟着一起缩、一起淡。
- **首都按国家的等级**（`capitalLook`）：等级是世界里**最高的一级**、国家没有等级（自己建的）、等级不在世界里时与以前一模一样；别的级按自己的 `capitalIcon`、`capitalAlpha`、`capitalLabel`、`capitalBold`。内置：王国级 0.9 / 0.95 / 字 0.92，公国级 0.8 / 0.85 / 0.85，侯国级 0.72 / 0.8 / 0.8 不加粗，城邦级 0.65 / 0.75 / 0.75 不加粗。最高一级的这几项不看（写了也照最醒目的画），编辑器的说明里写着。陪都按所属国家的等级。
- **画法**（`src/ui/settlements.ts` 的 `cityLook`、`cityMark`）：`SettleMark` 多了 `alpha`、`scale`、`labelAlpha`、`country`（只有淡、小的点才写，都是 1 的点与以前的对象一样）；字号按 `label × capitalLabel`。排版（`placeSettlements`）按 `iconScale(cellPx) × scale` 算半径与避让；画的时候 `globalAlpha` 按 `alpha`（名字按 `labelAlpha`，在 `save` / `restore` 里）。没有淡、小的点时走以前的那一行（`drawMark` 原样调用，不碰 `globalAlpha`）。
- **照最醒目的画**：叠加层多一项 `settleStrong`（静态的键里按 `join('|')` 比）：鼠标下的点（工具预览的 `Preview.mark`，指针与“城市”一类的工具给）、选中的城市，选中、钉住、指针停着的国家的首都（`country:<编号>`）。只在**画**的时候看：浓淡照 1、图标照原来大小，**不重排**（位置、避让照淡的时候的，字号也不变）——悬停不触发重排，第四十轮的“同一格里不重画、跨国界才重画静态层”照旧。“城市”工具选中的那座在 `cityMark` 里就按最醒目的排（以前就为它写名字、重排）。
- **导出**整张地图按同样的规则（干净的画面没有悬停、选中）。
- 国名没有“按等级加重”的地方（国名的字号按片区的大小与形状），没做。

## 测试

- `core/human/tier-content.test.ts`：内置五级的 id、先后、面积、政体、比例、名字与第四十一轮写死的一样（拷贝的常数，不要改它）；附庸、联邦、邦联的规则与成员邦的门槛逐个比（含门槛两边）；四种格局、六个时代的比例；世界里没有的 id 不算、没写的为 0、全是 0 往下一种退；七级没写邦联、联邦时的退法；按 order 排；三级（中世纪，有邦联）、七级（现代，有联邦，成员邦也在七级里）、一级都没有（照样生成、档案没有等级、写明）都能生成；首都的样子（最高的一级、加一个更高的、不在世界里的）；改名、撤销。
- `src/ui/settlements-ui` 两项：城市、首都的浓淡大小来自数据，选中的照最醒目；档案的等级、格局的选项按数据里的名字，“分裂 ↔ 统一”与格局的说明不提小国、大国。
- `src/render/overlay-static` 一项：淡的点画的时候 `globalAlpha` < 1，`settleStrong` 里的照 1 画、框不变，去掉这几项时一笔都不淡；对照冻结的第三十九轮排法时去掉这几项（两边按同样的图标大小排）。
- 改了的：`content/registry`（种类表）、`pack-tree`（通用的小包）、`era-packs`（新世界默认的包）。

## 速度

只多了几处查表：生成时按等级对象取数（`tierIndex` 一张 Map）、画城市时多一个判断。`node tools/bench-median.mjs 5 --against 8a40b5a`（默认的整个星球 + 奇幻包，旧、新交替各五次的中位数）：加工没有一步比旧的慢 5% 以上——paintLand +4%（328 → 340 ms）、naturalBiome +3%、newWorld +1%，其余持平或快（island −9%、paintLandPreview −10%、openReplay −13%；几毫秒的撤销是噪声）。新建世界多加一包内容，newWorld 2537 → 2567 ms。
