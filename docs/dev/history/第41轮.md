# 第四十一轮的设计：项目结构

目标：以后改代码（尤其是让 AI 改）要读的字少一些；程序的行为一点不变。

## 文档

- 开发说明从 2260 行、约 52 万字节缩成约 130 行的总览与索引（架构、数据流、缓存与性能的摘要、各篇的链接）。
- “文件结构”一节拆成 `docs/dev/core.md`、`core-human.md`、`render.md`、`ui.md`、`src.md`、`tools.md`，每个文件一两行；拆之前的原文（每个文件里有哪些函数、各轮加了什么）原样留在 `history/文件结构（第四十轮）.md`。
- 文件结构下面按轮次写的设计（第二十轮到第三十轮）与第三十二轮起的每一节搬进 `history/第N轮.md`，一轮一个文件；工具怎样组织、界面的样子、文字搬进 `ui-design.md`；测试、速度与测速、和地球比、已知限制与待办各一篇。
- 总览里有一张“节 → 文件”的表：代码注释里写的“见开发说明‘某某’”按它找，注释不用改。
- 根目录新加 `CLAUDE.md`：命令、目录、要改什么看哪里、规矩、写文档与提交的规矩。

## 拆大文件（只搬代码）

- `src/render/renderer.ts` 3757 → 2221 行：着色器源码搬进 `src/render/shaders/`（common、plane、compose、sphere、index）。星球、极地、投影的着色器照旧由平面的按 `must` / `mustAll` 替换出来。搬之前先导出 `SHADER_PROGRAMS`（编译的每个程序与测试用的片段，共 30 项）并记下 sha256（`shaders/shader-hashes.json`），搬之后 `shader-sources.test.ts` 查逐字节相同。
- `src/render/overlay.ts` 2276 → 313 行：拆成 `overlay-base`（类型、画布大小、字宽、测速）、`overlay-rivers`、`overlay-river-layer`、`overlay-static`、`overlay-grid`、`overlay-shapes`、`overlay-labels`、`overlay-country-labels`。`overlay.ts` 照旧导出全部，外面的 import 一个没改。模块里的 `let`（`perf`、`layout`、`gesture`、几张缓存的画布）都与给它赋值的函数在同一个文件（别的文件只读，ES 模块的绑定是活的）。
- `core/commands.ts` 2500 → 327 行：`runOp` 的大 switch 按类别拆成六个函数（`runTerrainOp`、`runNatureOp`、`runProvinceOp`、`runFeatureOp`、`runHumanOp`、`runSettlementOp`），case 的代码原样；`runOp` 先管批量与整理本世界，其余依次问这六个，都不是时与以前一样返回 undefined（命令先过 zod，到不了这里）。命令的格式（`baseCommands`，先后就是 zod 判别联合的先后）原样搬进 `commands/schema.ts`。`commands.ts` 照旧导出全部。
- 拆的办法：一个小脚本按行号把几段原样搬到新文件，按用到的名字补 import、给顶层定义补 export；类型检查报的多余 import（注释里出现的名字）手删。
