# 第四十四轮的设计

这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## 先修第四十三轮的毛病：政体限谁用

用户在中世纪、一块大陆的世界上看到“南野苏丹国 · Sultanate of Minamino”：政体伊克塔，主流文化九州人（26%），国教神道教，异教 70%。

**查到的原因**：国家的主流文化就是起点那一格的文化（`countries.ts` 建档案时 `primaryCulture: culture.id`，`culture` 是起点的文化；之后不会换成长完以后人最多的文化），挑政体（`govWeights`）也按它，所以政体、称号、国教看的是同一个文化——不是“主流文化与挑政体的文化不一致”。毛病在 `govWeights` 的余地：文化的倾向里没写到的政体都乘 0.15 也能挑上。日本组中世纪写了幕府 6、封建 2……合计约 10.8，没写的 14 种政体合起来还有约 2.1，伊克塔在其中约 1%；伊克塔的默认称号按等级是谢赫国 / 埃米尔国 / 苏丹国，于是九州人成了苏丹国。复现：2 万格的一块大陆、中世纪默认 18 组、12 个种子里有 5 国违反（阿瓦德人的伊克塔“派肖苏丹国”、蒙古人的伊克塔、维吾尔人与莫斯科人的幕府、阿拉贡人的“卡莱藩”）。26% 与“异教 70%”是这一国扩张进了别族的地方。

**改法（仿 EU4 的政体限制，数据可改）**：
- 政体多了 `only`：几条，满足其中一条的国家才能用；一条里写了的几项（`cultures`、`cultureGroups`、`values`、`valueGroups`）都要满足，各自是“其中之一”（与换说法 `names` 的一条同样的写法，用同一个 `ruleMatches`）。看的是 `cultureContext`：主流文化、文化组、主流文化最典型的各维取值（中世纪就是国教）与取值组（`titleContext` 从它分出来）。不写时谁都能用。用一组而不是一个对象，是为了“阿尔泰、鞑靼两组，或者斯基泰人、帕提亚人两个文化”这种几条之一的限法。资源库里政体多一栏“限谁用”（`list`，字段同换说法去掉称号两项）。
- 生成：`govWeights` 里这个文化用不了的政体权重是 0（不给 0.15 的余地）；都用不了时 `pickGov` 在不限谁用的里按 `weight` 挑，一个也没有时在全部里挑——国家总有政体。长完、建档案之前再查一遍（`govAllowed`），不合的按主流文化的倾向 × 与等级相配（`govFit`）换一个（随机数 `country:regov` 与编号）。主流文化就是起点的文化，这一遍正常不会换，是防以后主流文化改按长完的结果算。新建国家（工具）的默认政体先在这个文化能用的里挑。手动在档案里换政体不受限。
- 内置的限法（照 EU4）：伊克塔 `valueGroups: muslim`；幕府 日本；天朝 汉（满洲人在汉组里）；骑士团 基督教；草原游牧 阿尔泰、鞑靼两组，或斯基泰人、帕提亚人（古代）；原住民议会 写了它的 29 组（美洲的部落组、埃文基、堪察加、乌戈尔、澳洲原住民、太平洋）；自由市 写了它的 10 个欧洲西部与中部的组（EU4 只给神圣罗马帝国的成员）。草原游牧给萨赫勒的换说法用不上了，去掉。
- 测试 `core/human/gov-only.test.ts`：限法的写法、内置的限法引用的都认得；四个历史时代 × 默认的组 × 三个种子的地区与一个星球，没有一国违反，“苏丹”只出现在国教是伊斯兰教的国家。把 `govRestricted` 改成总是 false（等于以前）时三个时代都报错（“任扎克苏丹国 iqta polish”……）。
- 结果变了：`countries.test.ts`、`settlements.test.ts` 的金标准（地区、星球）与 `r29-digests.json` 重录（国家的政体变了，城市化、扩张性跟着变，人口、城市、道路、地标也变）。只是生成的事，编辑不受影响。

## 奇幻、科幻照 EU4 的写法重做

用户批准的：“DnD：文化组：精灵、矮人、半身人、侏儒、兽人、龙裔等。每组 3–8 个文化……宗教组照 EU4 分组，神名自己起，不用任何现成设定里的专名。政体名按等级。科幻：物种组与文化同理，意识形态保留。地名风格：现有四种架空风格扩成每组一种。写法照 EU4：组名短、文化名照‘地名 + 人’或种族的说法。”

### 数据

- **文件**：`core/packs/eras/cultures/fantasy.json`、`scifi.json`，写法同地区的文件（`{ groups: [{ group, cultures }] }`，组带 `nameStyle`、`tendencies`，文化只写不同的）；去掉了以前一组一个的 10 个文件。`eras/index.ts` 的 `FICTION_FILES`。组与文化都有原文（英文）。
- **奇幻 11 组、52 个文化**：精灵（高等、木、暗、海、雪、野精灵）、矮人（山丘、高山、深地、霜须、熔炉）、半身人（丘居、河居、林居、行商）、侏儒（岩、林、齿轮、深地）、兽人（荒原、山地、雪原、沼地兽人，半兽人）、地精（洞穴、沼泽地精，大地精、熊地精、狗头人）、龙裔（赤、金、青、玄、白鳞）、三组人类——西境（平原的骑士王国：罗维尔人、蒙达尔人、卢韦拉德人、考尔特人、瓦朗塞人）、北境（峡湾：斯科尔德人、赫拉尔德人、雷克沃恩人、卡瓦尔人）、沙海（荒漠绿洲：卡尔塔卜人、沙尔迪兹人、哈贝勒人、米勒索人、灰烬魔裔）——和海民（潮歌人、珊瑚海民、雾岛人、盐港人）。人类的文化名照“地名 + 人”，地名用这一组的地名风格的音。
- **种族**（奇幻的一维）：人类、精灵、矮人、半身人、兽人、侏儒、龙裔、半精灵、地精照旧；“提夫林”是现成设定的专名，换成自己起的“魔裔”（`fiendkin`）；加半兽人、狗头人。
- **奇幻的宗教**：6 个宗教组、21 种（新的取值组写在时代文件的 `valueGroups`，`BUILTIN_VALUE_GROUPS` 把共用的与时代文件的合起来）：光明诸神（晨光教会、银月教团、丰饶之道、守门人教团、誓约派）、自然（林母之道、深潮信仰、四季轮）、祖灵（炉父信仰、石誓、血祖祭、风暴之角）、秘法（秘法之眼、齿轮圣道、诡运之道）、幽暗（契约诸君、影母、无名之饥）、龙（古龙崇拜、余烬圣火、鳞誓）。神名自己起（索雷恩、伊斯薇拉、梅洛娜、薇萝丝、欧瓦隆）；以前的 12 种 id 留着（名字改成宗教的说法：晨光之主 → 晨光教会……）。同组是异端、不同组是异教（第四十三轮的 `faithRelation`）。
- **奇幻的政体**（14 种，仿 EU4 的君主、共和、神权、部落 + 各族的）：封建王国、至高王权、部落酋邦、自由城邦、商会共和国、法师统治、神殿国谁都能用；精灵议会（精灵）、氏族王国（矮人）、兽人部众（兽人、地精）、乡民大会（半身人）、机巧行会（侏儒）、圣武士团（信光明诸神的）、龙主统治（龙裔，或信龙的）用 `only` 限。称号五级都写（城邦级 / 侯国级 / 公国级 / 王国级 / 帝国级），换说法按组（北境的长屋 / 峡湾领 / 海王国、沙海的绿洲领 / 城主国 / 君侯国 / 大君国、精灵的林苑 / 林境、地精的窝、暗精灵的影庭……）与宗教组（神殿国：自然是圣林、祖灵是祖庙、幽暗是影殿、龙是龙殿）。以前中世纪的“封建君主制”带着的海民、矮人、兽人的换说法去掉，它不再放进奇幻；奇幻的“帝国”政体换成至高王权。派系照旧（贵族、法师、教团、公会、氏族长老），教团改按信国教的人，魔裔、血祖祭、石誓、齿轮圣道加进来源。
- **科幻 9 组、35 个文化**：人类四支——地裔（新申洪人、诺瓦齐拉人、苏拉波利斯人、海维尔顿人、金波尔卡人）、远航者（环站人、舰民、带民、漂泊者）、改造人（义体人、基因工匠、冷眠人、荒原改造人）、合成人（初代合成人、节点意识、机仆、漫游体）——与异星的潮裔（深潮、礁歌、雾湾、河口氏族）、晶岩族（石英合唱体、玄武族、晶洞族）、孢生族（菌丝网、花幕族、沼菇族）、甲壳族（卡尔巢、沙丘群、筑丘族、赤甲族）、羽族（新：高崖、风谷、海崖、雪峰羽族；物种多了羽族）。意识形态（阵营）不动。
- **科幻的政体**（新的与改过的 12 种 + 共用的技术官僚制）：星际联邦（殖民站 / 星区 / 星团联合 / 联邦 / 星际联邦）、星际帝国（领地 / 星区侯国 / 星团公国 / 星域王国 / 星际帝国，总督 / 星区侯 / 星团公 / 星王 / 星帝）、企业共和国、殖民地议会、军事政府、灵能神权、自由港（新）谁都能用；蜂巢意志（甲壳族、孢生族；孢生族的称号是菌落 / 菌网）、晶格共识（晶岩族）、机械智能（合成人）、潮汐合唱（潮裔）、巢崖议会（羽族）用 `only` 限。
- **不带地球的组**：奇幻、科幻的包默认只带自己的组（以前过渡用的不列颠、拉丁、汉、印度斯坦去掉）；EU4 组上写的 `race`、`species` 倾向与 `fantasy`、`scifi` 的按时代倾向也去掉（europe.json 的不列颠、拉丁，asia.json 的汉、印度斯坦）。从“通用 ▸ 文化”勾进奇幻世界的地球组，种族、宗教按这一维的第一个取值（人类、晨光教会），政体按政体的 `weight`。
- **颜色**：用脚本挑（Lab 色差）：组的颜色离别的组至少 22、尽量接近这个色相的标准色；组里的文化在色相 ±16° 里贪心地取离已选的最远的（组里两两 23 以上，测试要 18）；宗教在宗教组的色相 ±14° 里挑，两两 23 以上。政体的颜色同一个时代两两 12 以上（留着以前的几种）。

### 地名风格

一组一种：以前的幻想·精灵、矮人、兽人、海民留着，新写 16 种（音译式，自造的音节与音译表）：幻想·半身人、侏儒、地精、龙裔、西境、北境、沙海，科幻·地裔、远航、改造、合成、潮裔、晶岩、孢生、甲壳、羽族。分四批写在 `names/fiction-a / b / c / d.ts`（与第四十三轮的 eu4-a/b/c 一样），在“通用 ▸ 地名 ▸ 幻想 / 科幻”（`STYLE_REGIONS` 加了“科幻”）。各种都过了 `name-styles-builtin` 的几项（每类地物、原文、不碰自己的不许的写法、重名少），不许的写法里另外挡了现成作品的专名与真实的地名（地裔挡了湖南、东京……这些拼音与英文地名）。内置共 92 种（每个世界、每个包上限 128）。

### 内置的树

- 奇幻、科幻的组只在各自的时代包里：`奇幻 ▸ 文化 ▸ 精灵……`、`科幻 ▸ 文化 ▸ 地裔……`（`groupPack`，组、文化、组的地名风格），默认全带；不放进“通用 ▸ 文化”（那里是 EU4 的地球文化，按地区）。这样勾“通用 ▸ 文化”不会把精灵带进历史时代，勾奇幻包就有全部的种族。
- 奇幻的宗教组跟着宗教放在 `奇幻 ▸ 宗教` 小包里（第四十三轮的规则：一维的小包带这一维用到的取值组）。
- 地名风格另外在 `通用 ▸ 地名 ▸ 幻想`（11 种）、`科幻`（9 种）。

### 测试

- 新的 `core/human/fiction-content.test.ts`：奇幻 11 组、科幻 9 组都是默认、没有 EU4 的组；每组 3–8 个文化、每个文化都在组里、组名不超过三个字、有原文；一组一种自己的风格（幻想·… / 科幻·…），文化不另写，EU4 的组不用这些风格；倾向引用的种族、宗教、物种、阵营、政体都在这个时代；JSON 里没有现成设定的专名（提夫林、卓尔、霍比特……）；6 个宗教组、21 种，同组异端、不同组异教；每种政体给本时代每组、每个等级都有称号与统治者称号；奇幻、科幻按默认生成（两个种子的地区与一个星球）没有违反限法的国家、用到 6 种以上政体。
- 改了的：`pack-tree`（奇幻、科幻的组、宗教组、地名的两个小包）、`eras-builtin`（92 种风格；历史上的宗教组另数；各组住在喜欢的地方换成新 id，加沙海在干的地方、北境在冷的地方；兽人 1.3 → 1.15：沙海、龙裔也住荒漠与高地，约 1.2）、`governments-builtin`（奇幻、科幻的称号：战帮 / 部落 / 大部落 / 部众 / 大部众、海王国、大君、薇亚诺尔议会国、影庭、主教领、圣林、龙殿、星区 / 星团联合 / 联邦 / 星际联邦、星区侯 / 星团公 / 星王 / 星帝、巢群、菌网；各族多用自己的政体）、`era-packs` 与 `pack-choice`（组的 id）。
- 重录：`r29-digests.json` 的 fantasy、scifi 两项（内容换了）；第一步重录过的那几项不再动。

### 速度

- 编辑不受影响（只改了生成与内容）。`node tools/bench-median.mjs 5 --against e959db9 -- --globe --pack fantasy`：第一次加工各步在 −3% … +2%，riverPreview +6%（没碰的步骤）；第二次机器忙（连没改的 mesh 也 +11%），paintLand、relief、island 标了出来；第三次全部在 ±5% 以内（paintLand −3%、relief −7%、island −3%、riverPreview −2%），新建世界 2562 → 2462 ms（−4%：新建时默认加的内容没变）。
- 生成：政体限法每个“文化 × 陆块”多算一次主流文化最典型的取值（`typical`，几个数），长完再查一遍各国（正常一国不换）；奇幻默认 11 组 52 个文化，比中世纪默认的 18 组 144 个文化少。
- 测试 169 个文件、1733 个（`npx vitest run` 一次全过）；`npm run build` 通过。
