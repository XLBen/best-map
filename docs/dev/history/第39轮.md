# 第三十九轮的设计

从开发说明里搬来（第四十一轮）。这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## 图层提速（第三十九轮）

用户说选国家图层时很卡，别的图层也有同样的毛病。没有 Worker 往返，时间全花在主线程与 GPU 上。原则：屏幕、导出逐像素相同，只省掉白做的工作；唯一有意的画面变化是“每一维”模式的底子与文化相同（见下）。

**白做了什么**：
- 合成着色器（`src/render/renderer.ts` 的 `FS_COMPOSE`，星球、投影两份由它替换出来）每个像素：
  - 省份格 `pc`（`provCell(seamCell(id, …))`）在每个模式都算，地貌、气温这些用不上；
  - 国界在 1.5、3 像素的两圈上各取 4 个点，每点一次 `provAt`（场景像素、`idAt`、`seamCell`、`provCell`，陆海与格不合时再找最多 16 点）；国界淡的几种模式（同盟、文化、文化组、每一维、人口，`uCountryAlpha` 0.4）外面一圈乘了 0，白取；
  - 帝国的外沿再取 8 个点；省界的 2 个点在省界淡出为 0（缩小看全图）时照取。
- 描格（第三十七轮）的 `focusKey` 在合成的键里：鼠标每跨一格整张重新合成。
- 换模式整份 `cellLayers`、整份重传约 15 张逐格纹理、`layersVersion` 加一、地形层（最重的着色器）整张重画；颜色缓存只有两份；选物种、换季节、开关省界、换工具类别也都整份重算；湖的着色按模式重算。
- 每一维模式走了 `default` 分支：底子没有雪、岛的颜色、干湖，与文化、国家不一致。
- 每次合成调约 70 次 `getUniformLocation`；`MapView` 的 `placeReference` 每帧重写参考图的 `cssText`。

### 合成里先判断再跳过

每一处都只在“跳过与照算画出来一样”时跳过；`tools/compose-ab.mjs` 在无头 Chrome 里与 b4aeaae 逐字节对照（见下）。

- **省份格只在用得上时算**：`needPc = uFlatByGroup || provLines || uHasCountry || (uHasHighlight && uHighlightByGroup)`。别处不读 `pc`（湖的着色读 `id`、`idAt(vUv)`，描格读 `focusAt`，分层的海再涂一次用的 `fc` 来自 `idF`）。地貌、生态、气温等模式没有分组、国界、按省份的平涂，整段不算。
- **省界先算淡出**：`provFade`（原来在省界那一段里算的同一个式子）提到前面，`provFade · uProvAlpha` 为 0 时省界的混合系数是 0，`mix(col, c, 0)` 就是 `col`，不取相邻像素。
- **国界**：浓淡 `k = max(kIn · 0.82, kOut · 0.3 · step(0.999, α)) · …`，`kIn` 只能是 0、0.4、1。近处一圈碰到国界（`kIn ≥ 0.4`）时 `kIn · 0.82 ≥ 0.328 > 0.3 ≥ kOut · 0.3`，外面一圈不影响结果；α < 0.999 时外面一圈乘 0。所以外面一圈只在 `kIn == 0 && α ≥ 0.999` 时取；近处一圈碰到一条非联邦的国界（`kIn` 到 1）就停。α 为 0 时整段不取。取样的位置、先后、算式与原来相同（拆成两个循环）。
- **帝国的外沿**：结果是“远处一圈碰到、近处一圈没碰到”。近处一圈先取，碰到就是“不画”，停；远处一圈碰到一点就是“画”，停。
- **离边界远的格**：下一节。

### 离边界远的格（`src/render/near.ts`）

国家、文化等人文模式里大半个画面离国界、省界很远，每个像素照样在环上取十几个点、每点十几次纹理读取。给每格记“往外几步之内没有会与它连成线的格”，再证明“环上的取样都落在这几步之内”时直接跳过：

- **画出来的格与图 G**：编号层画的是格的多边形（一块地区是网格的 Voronoi 多边形 `mesh.poly`，整个星球是显示用的三角网的 Voronoi 多边形 `viewOf(mesh).polygons()`、左右每 2 再画一份）。G：画出来挨着的两格连一条边（一块地区就是网格的邻接；星球另加显示用的三角网里挨着、网格里不挨着的几对，`nearGraph`）。
- **ρ_h**（`nearRho`，地图单位）：G 上隔 h 步的两格画出来的多边形之间最近的距离，取遍整张网格。一条线段从 c 里的一点走到隔 h 步以上的一格，沿途的格在 G 上一步一步走，一定先经过隔 h 步的一格，所以离 c 不到 ρ_h 的点都落在隔不到 h 步的格里。按多边形算到隔 6 步（`NEAR_EXACT`），再往外按 ρ_(a+b) ≥ ρ_a + ρ_b 推到 12 步（`NEAR_MAX`）。两极的两格（显示用的三角网里是两极一整行影子点，画出来几百块）与画出来比 4 格还宽的高纬的格（`nearFixed`）总算“危险”，不从它们往外数、数到它们就停（这些格附近 H 本来就到不了那么大）。种子 3 的一块地区（4 万格）与类地星球上，ρ_2 = 0（相隔两步的格常碰在一个顶点上），ρ_3 ≈ 0.63 / 0.44 格，ρ_4 ≈ 1.43 / 1.25，ρ_5 ≈ 2.07 / 1.92，ρ_6 ≈ 2.90 / 2.71，ρ_9 ≈ 3.5 / 3.2，ρ_12 ≈ 5.8 / 5.4。算一遍约 0.25 秒（地区）、0.6 秒（星球），渲染器在换网格后空闲时一段段地算（`nearRhoStep`，每段约 6 毫秒），算好之前照取环上的点。
- **H**（`nearLayer`，每格 RGBA 字节，r 省份、g 国家、b 集团）：对值为 A 的一格，“危险”的格是带着同一类里另一个值的格（只有同一类里两个不同的值之间才画线：省界是陆地省 > 0 与别的两类，国界是陆地 ≥ 0 与领海 ≥ 65535.5 两类、不归谁的海 −1 不算，帝国的外沿是 ≥ 0 的一类），或总危险的格（上面的几格、被剪刀切过的格：切线附近会换成另一边的格）。一格带的值是它自己的值；水面格另带它的 `landCellOf` 的值（画成陆地的像素在附近找不到陆地格时取那一格）。H 是在 G 上离最近的危险的格几步：按类各做一遍多源的广度优先，每格记离它最近的两个不同的值与距离（`hopsByValue`）。低四位数全部的格，高四位只数水面格（下面用）；最多记 15。挨着海的陆地格不算挨着危险的格（海与陆地国家连不成线）。
- **跳过的条件**（着色器的 `nearSkip`）：只在像素的省份格就是它扭曲后的格（`pc == id`：陆海与格相同，没按切线换格）时看。环上半径 r 个像素的一个取样（相邻像素的扭曲后的位置 P + o、没扭曲的位置 X + o）取到的格只有几种：扭曲后的那一格与它的 `landCellOf`（离 P 不过 r）；画成陆地、格是水面格时往外找的陆地格（没扭曲的位置再往外 0.3、0.6 格，离 P 不过 |w| + r + 0.6 格）；画成水面、格是陆地格时往外找的水面格（离 P 不过 |w| + r + 1.2 格）。|w| 是这个像素的扭曲（着色器里现成的），再加两次编号层纹素的取整（各约 0.71 个场景像素：停稳 0.71 个画面像素，移动中按场景放大的倍数，投影里按场景的密度）。前两种离 P 不过 rA，比 ρ_(H 的低四位) 近；后一种离 P 不过 rW = rA + 0.6 格，比 ρ_(H 的高四位) 近时，取到的格都是同值、−1，或别的类的值：画不出线。省界 r = 1.5，国界 3（国界淡时 1.5），帝国的外沿 5。ρ 上传前乘 1 − 10⁻⁴（float32 的舍入不会让保证变远）。
- **什么时候算**：H 不在换模式的那一帧里算：`setLayers` 后图层停下 40 毫秒，渲染器在空闲时按这一份图层算（`scheduleNear`，地区约 15–25 毫秒、星球约 30–55 毫秒，分几步、每步几毫秒，见下面的表），按图层对象记住（`MapView` 按模式缓存着拼好的图层，切回来不重算）；编辑时图层每一笔都换，算不上也不耽误。只决定跳不跳过，不进合成的键。
- **什么时候不用**（`uNearOn` 为 0）：ρ、H 还没算好；省份预览、剪刀拖动（显示的分组、切线不是图层里的那一份）；幽灵海岸（改了几格的海岸值、分组）；投影里极地的场景与不到一整圈的场景（经度绕回时场景不连续）。
- **效果**：国界、帝国外沿离边界几格以外的像素一个点都不取；省界只有大的省（多半是海省）的中间跳过。`near.test.ts` 的取样里，地区约 45%、星球约 30% 的有主的像素跳过国界（取样偏向边界附近，全图里更多）。
- **测试**（`src/render/near.test.ts`）：把着色器的 `provAt`、`provCell`、`seamCell`、`landCellOf`、三个环照着写成 JS，编号层用画出来的多边形（`drawnCellAt`）、位置按纹素取整，像素的陆海按位置的哈希故意打乱约 12%（再有 2% 是小湖群，往外找格、`landCellOf` 都走得到），在一块地区与整个星球（人文、国家、帝国、领海、剪刀切线，跨经度接缝）上，国家与文化两种（国界显眼与淡），一格 4、8、16、40 像素，切线、国界、国家深处、领海、离省界最远、帝国深处几处镜头：凡是会跳过的像素，照算也画不出省界、国界、帝国的外沿；跳过的像素不少（不是空对照）。另查 ρ 不减、H 在同值的邻格间至多差 1、两国相邻的格 H ≤ 1、海岸不挡国界的 H。

### 描格那一遍

`focusKey` 不在合成的键（停稳、投影的两个）里。只有描格变了时（鼠标跨格、钉住、取消）：画布上别处与上一次整张合成的一样（`preserveDrawingBuffer`），只在新旧描格的几块里（scissor）照原样再合成一次（`composeFocus`）：同一个着色器、同样的输入，只换了描格的 uniform，每个像素的输出与整张重画逐字节相同（移动中照旧整张合成，停下后整张重画）。几块的范围（`focusRects`）是着色器的 `nearFocus`（离格心 `FOCUS_REACH` = 3.2 格）在画面上的外接矩形，四周多 3 个像素、边落在偶数上（2 × 2 的一组像素整组在里面，`fwidth` 与整张画时相同）：
- 一块地区：格心 ± 3.2 格的方块；
- 整个星球（等距圆柱）：按弦长换成角半径 θ，南北 ± θ / π，东西 ± asin(sin θ / sin 余纬) / π（包着极点时整行），每一份左右的副本各一块；
- 投影：沿球面上的那一圈（角半径大 2%）取 64 个点投到画面上，外接矩形再加相邻两点的间距；有点在球的背面、相邻两点隔得很远（跨过等面积投影的边）时整张。
新旧两块大半重叠时合成一块（`mergeRects`）。没有用合成后再叠一层的画法：画面是 8 位的，在 8 位的结果上再混一次描线与在浮点里混的不逐字节相同。

### 换模式：底子与每种模式的一层

- `colors.ts` 的 `cellLayers` 拆成 `baseLayers`（地形层读的：平滑层、对岸的颜色、岩性、静态层——高程、海岸值、坡度、峡湾……，与晕渲、露岩）与 `modeLayers`（合成读的：平涂、省份的分组与切线、国界的分组、花纹与发光、`landCell`）；`cellLayers` 是两者拼起来（测试、导出照旧用）。
- **键**：`baseKey`：地形类与人文的模式（地貌、主导生态、省份、地形类别、资源、文化、文化组、每一维、国家、同盟）共用 `terrain|季节`；气温、降水、海水温度带季节；“适宜程度”带关注的物种；别的就是模式。`modeKey`：平涂按模式（主导生态、省份、人文的几种），花纹按季节（只在地貌、主导生态、省份），省界开没开，国界开没开（国家模式另带集团）。选物种只进“适宜程度”的底子，季节只进用得上它的，省界、国界、工具类别只进模式的那一层。
- **缓存**（`MapView` 的 `applyColors`）：按世界（用到的数组、小数据的签名）分开，最近两个世界留着；每个世界里底子最多 6 份、模式的那一层最多 10 份、拼好的最多 12 份（先进先出地淘汰，取到的挪到最后）。拼好的按两个键记住，同一个对象：渲染器按对象是不是同一个来上传。第二次以后换模式不算 `cellLayers`。
- **渲染器**（`setLayers`）：每张逐格纹理记着传上去的是哪几个数组（`shownDeps`），同一批对象不重传，也不再每次新建补齐的副本；地形层读的（平滑层、对岸、高程、海岸值、坡度、峡湾、岩性、露岩、海面是数据）变了才加 `layersVersion`（重画地形层），只有合成读的（平涂、分组、国界、`landCell`、合成的海岸值、晕渲的强弱）变了只加 `modeVersion`，它只进合成的键。幽灵海岸、省份预览改过几行的纹理记成对不上（下一次 `setLayers` 整张重传）；花纹与发光按显示着的那一份比，不再每次重传。
- 湖的着色（`applyTint`）的键按“是不是地形类的模式”，不按具体的模式。
- **每一维**：底子改成与文化相同（`baseLayers` 里地形类的分支：雪、岛的颜色、干湖），唯一有意的画面变化。

### 测速开关（`?perf`）

网址带 `?perf`（`render/perf.ts` 的 `perfEnabled`）时 `MapView` 建一个 `Perf`，挂在 `window.__perf`，渲染器拿到同一个：
- 每帧（`draw` 开头 `frame()`）一条记录：主线程的 `draw`（整帧）、`colors`（`applyColors`）、`cellLayers`（这一帧真的算了底子或模式的那一层时）、`overlay`（`drawOverlay`；第四十轮另记 `overlayStatic`、`overlayDynamic`、`layout`，`notes` 里 `overlay:skip` / `shapes` / `direct` / `motion`）、`near`（空闲时算离边界远的格，记在那时的帧上）；GPU 的 `terrain`、`compose`（整张合成）、`focus`（描格那一遍）；`notes` 里记 `compose:full` / `compose:focus` / `compose:none`、`terrain:full` / `terrain:rects`。
- GPU 时间用 `EXT_disjoint_timer_query_webgl2`（`gpuBegin` / `gpuEnd`，结果晚几帧拿到时补进那一帧；GPU 被打断过的那一批不记）；浏览器不给这个扩展时只有主线程的（`summary().gpuTimers` 为 false）。
- `__perf.frames`：最近 300 帧；`__perf.summary(n)`：最近 n 帧每一项的个数、中位数、95 分位、最大、平均，与各种 `notes` 的次数；`__perf.clear()`。
- 不带 `?perf` 时不建对象，代码里只多一次判空。
