# 第二十七轮的设计

从开发说明里搬来（第四十一轮）。这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## 编辑：吸管、橡皮擦、自动的结果（第二十七轮）

- **吸管**：`state.ts` 的 `picking`。底部条第二行末尾的吸管按钮（`shell/ContextBar.tsx` 的 `PickEraseRow`，工具写了 `pick` 才有）、I 键打开；`map/input.ts` 按下时 `e.altKey || picking` 都走 `def.pick`，吸完关上（吸到了也关上橡皮擦）。开着时地图不画笔刷的预览，鼠标旁写“点一下吸取”（`MapView.tsx` 的 `PICK_PREVIEW`）。补上的吸取：陆海 `pickLand`（landMode）、冷暖干湿 `pickClimate`（按这一格的 offset 定更冷 / 更暖与力度，力度 1 = 4 °C、雨水 e^0.5）、自定义场 `pickField`；起伏、打碎、重画没有。
- **橡皮擦**：`state.ts` 的 `erasing`（`'auto' | 'clear' | null`）。工具表的 `eraser: { auto?, clear? }` 是两个工厂函数；`defs/tools.ts` 的 `createTool(id, env)` 在开着橡皮擦、这个工具有这一种时造橡皮擦，否则造工具本身（MapView 换工具、开关橡皮擦时都重建），`eraserModes(id)` 给底部条和 E 键。开着时底部条只剩 `BRUSH` 直径，工具自己的选项收起来，旁边是“恢复自动 / 清空”（只有一种时写一个词）。`setTool` 时吸管、橡皮擦都关上。
  - 地形（陆海、放岛、岛链、堆山、打碎）用原来的 `restoreTool`，冷暖、干湿用 `climateEraseTool`，涂生态、拖动扩张用 `eraseTool`（原来的三个工具 `restore`、`unclimate`、`erase` 从工具表去掉了，backdrop、悬停的“这里：……”照旧）。
  - `tools/erasers.ts` 的 `eraserBrush`：恢复自动只涂得到 `edits.ts` 新的几个掩码里的格（`classMask`、`resourceMask`、`fieldMask`、`popMask`、`countryMask`，按数组缓存），backdrop 画白斜线；清空按 `filter`。类别、资源发 `set_cell_class / set_cell_resource null`，资源清空发 `'none'`；自定义场发 `paint {mode: 'set'}`（值 × (1 − 画笔权重)，中心擦到 0）；人口、文化发 `restore_pop`，清空发 `paint_pop {mode: 'clear'}`；领土发 `restore_country`，清空发 `paint_country null`；省份笔刷的恢复自动是 `provinceRegenTool`（省份没有“生成时的样子”）。
- **自动的结果**（`core/human/auto.ts`）：`generateHuman` 跑完几步、整理群体编号之前 `snapshotPop` 存下 `causes.popAutoTotal / popAutoGroup / popAutoShare`（手改过、这次没重算的格 `keep` 沿用上一份快照；`compactGroups` 多收一个 `extra` 数组，快照里的群体编号跟着一起重新编号，`popGroup` 的编号与以前逐值相同），`snapshotCountries` 在重新长国家（`mode: generate`）时存下 `causes.countryAuto`，用现有的领土时留着上一份，没有国家时清成 −1。`clearPop`（去掉人文、新世界）清空快照。四个数组都进 `HUMAN_ARRAYS`（第一次有时撤销去掉），生成、去掉人文、`set_worldgen` 的 `touchedArrays` 带上它们。
  - `restore_country {cells}`：陆地格里与快照不同的回到快照（那一国已经没了的成无主地），之后照常 `afterCountries`。
  - `restore_pop {cells}`：`popManual` 为 1 的陆地格回到快照里的人数与成分，`popManual` 清掉；快照里没人的清空。
  - `paint_pop` 的 `amount` 可以是 −1–1：负的走 `population.ts` 的 `pushAway`——`share` 这一群体的人里 |a| 按占比让给这一格别的群体（只有它一个时推不动），`value` 有这个取值的人里 |a| 换成这一格最常见的别的取值（没有时：维度可以不写就去掉，否则换成这一维第一个别的取值）。`mode: 'clear'` 是这里没有人（算手改）。
- **人口笔刷**：`options.popPercent`（−0.9–3），`tools/culture.ts` 的 `factorOf(shift)` = 1 + 比例（Shift 取倒数），`amountOf(shift)`（Shift 取负）；滑块 `panels/culture.tsx` 的 `FACTOR` 写成“+50%”（`percentText`）。
- **首都**：`SettleArchive.tsx` 的 `CapitalButton`（城市在这一国的领土上、还不是首都时），`ArchiveBox.tsx` 钉住时 `CountryLine` 的“在这里建首都”，都发 `move_capital`。
- **国家档案**：`CountryArchive.tsx` 的 `COUNTRY_TABS` 与 `countryTab`（模块里的信号：换了国家停在同一页）；`NamePair`（名字、原文两个框一组，焦点离开这一组或回车时用 `namePatch` 一起提交）、`YearField`（数字框加公元前开关）、`flagPartName`（按 `flagSvg` 的画法写每种颜色是哪一块）、`TerritorySection`（涂领土：`setOptions({territory})` 后换到领土笔刷；分成两半：`split_country {id}`；并入：`confirmMerge` 后 `merge_countries {a: 选的那一国, b: 这一国}`；删除）。
- **省份**：`provincePanel.tsx` 的 `ProvinceBar`（色块是 `input[type=color]`、`ProvinceName` 名字与原文一组、无人区、`ProvinceOwner` 整省的陆地 `paint_country`）；多选 `state.ts` 的 `provinceSet`（`tools/provinces.ts` 的 `toggleProvince`，选省份工具 ⇧+点；高亮、Esc、离开类别时清掉），两个以上时 `ProvinceBar` 换成 `ProvinceMulti`（`provinceMultiCommands`：合并是 `merge_province` 的 batch，都并进第一个；划给是 `paint_country`；重新划分是这几个省全部格的 `regenerate_provinces`）；原来的 `pmerge` 工具去掉了。省份笔刷的 `ProvincePick` 与 `brushNew`（“新省份”：只涂陆地省类的格，发 `assign_province 'new'`，涂完选中新的编号 = 涂之前的 `nextProvince`）。
- **省份大小**：`provinceRules.sizeCells`（4–400，按 4 万格的地区标定，有它时不看 `size`，`core/provinces.ts` 的 `provinceSizeCells`）；“省份 ⋯”里 `SizeSlider`（8–200 按对数，写陆地省大约多大）进规则草稿；`CountrySizeBox` 发 `regenerate_provinces {cells: 这一国的格, size}`（这一次按这个大小划，不改规则）。
