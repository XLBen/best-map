# 第六十七轮的设计

这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。第六十六、六十七轮的计划是“看库就是添加”：导入弹窗并进资源库面板。第六十六轮做了逻辑（[第66轮](第66轮.md)），这一轮做界面、删掉弹窗，先修第六十六轮留下的两个问题。

## 先修的两个问题

### 世界用的库里比重 0 的组

第六十六轮：只勾一个文化时组跟着来、比重回来，但组是世界正在用的库里比重 0 的组（中世纪 71 个组里 53 个，“这个时代默认不带”）时，重新生成人文的 `beyondWeights` 只带“别的库加来的组”（`beyondGroups`：这个库不列的），这个组是库里列着的，不参与生成，也不出“添加并重新生成人文”。

现在 `src/ui/packChoice.ts` 加 `revivedGroups`：**世界正在用的库**里比重 0、世界里比重不是 0 的组。`src/ui/human.ts` 的 `beyondWeights`、`retireGroups` 都看 `beyondGroups + revivedGroups`：

- 默认参与：“文化 ⋯”的默认选择、面板顶上的“重新生成”、`addedNeed`（出不出“添加并重新生成人文”）都带上它。
- 用户在“文化 ⋯”里取消：照“本世界加的”组的规矩记下比重 0，下次不再勾上（以前取消一个比重 0 后被勾上的组只是不在 `groups` 里，比重留着没写；现在多一条 `set_content` 写 0，和别的库加来的组一样）。
- 只看世界正在用的库：换库时照旧（不让新库的比重 0 组影响换库的命令）。

生成结果不变：生成人文、新建世界只把选的组加进世界（`humanImportPicks` 的 `groups` 是选的），选了的组在上次生成的 `groups` 里，`beyondWeights` 本来就跳过。会多带组的只有“世界里有、库里比重 0、世界里不是 0、上次没选”的组，只有从资源库面板勾进来（或第六十五轮勾整组）才有。金标准、r29 摘要不走这里，没有重录。

**改了的测试前提**：`page-world.test.ts`、`pick-add.test.ts` 的 `worldOf` 以前把库里**全部**组加进世界（`packImportCommands` 列在 `groups` 里的组比重写成没写，53 个比重 0 的组都成了“世界里不是 0”），再只用 3 个组生成；新规则下重新生成会带上这 53 个组（超过命令的上限，“命令参数无效”）。新建向导、“文化 ⋯”都不会造出这样的世界，所以改成和向导一样只加选的组。这两处的别的断言没改，都过。

测试（`pick-add.test.ts`“世界用的库里默认不带的组”）：用中世纪建世界（只加默认带的组），勾一个比重 0 的组里的文化，出“添加并重新生成人文”，添加并重新生成后有人是这个文化、组在 `human.groups` 里，一次撤销回到原样；只添加、之后点面板顶上的重新生成，也看得到。另一条：没有这样添加过的世界，`regenerateCommand` 和 `withPackImports({ op: 'regenerate_human' })` 一样（不多带组）。把 `revivedGroups` 改成总是空的，第一条不过（核对过）。

### 撤销条写用户点的那一项

第六十六轮的 `importLabel` 写清单里第一个勾的行，变量排在最前，点社会主义共和国时写“添加“意识形态”等 19 项”。

- `core/packs/closure.ts` 的 `importLabel(p, lead?)`、`importCommand` 的 `opts.lead`：给了 `lead` 并且它在清单里时写它，不然照旧。
- `pick-store.ts` 的 `pickLead(state)`：勾的项里第一个不是“为了别人加的”（不在 `added` 的 `need` 里）。`addPicked` 把它传下去；下拉里别的库的项（`addOther`）传选的那一项。
- 加到我的库：`lead` 在清单里时写“添加“X”等 N 项”，不在时（勾的是变量，加到库里时它跟着时代来，清单里没有这一行）写“添加 N 项”，同以前。

### 怎么做的

- **能不能勾**：`pick-store.ts` 的 `destFor(key)`：选的目的地是这个库自己时换成本世界，没有世界时换成别的我的库，都没有时 `null`（不出勾）。`canPick` = 有目的地、来源在。`pickAsk`、`pickPreview`、`addPicked` 默认都用 `destFor`（以前是 `pickDest`，看我的库时“加到”默认是它自己，就勾不了）。
- **一行**：`PickBox` 照 `rowLook` 画，点了走 `pressRow`：勾的、灰了还勾着的取消；子项（`child`）是 ×（`removePickIn`，记进 off）；没勾的、跟着来的勾上；灰的能解时 `pickNeedsIn`，`choices` 不止一个时 `pressRow` 返回 false，界面弹 `ChoiceMenu` 再带着选的那一个调一次；不能解的、✓ 不能点。加到世界时世界里放不进的种类（星球形态）不出勾，留一个空位对齐。
- **全选**：`allLook(refs, look, head)`：变量的取值页（`route.dim`）勾的是变量（同第六十五轮整段勾）；别的勾 `free`、`fixable` 的行；取消时把这一页的（和变量）都取消。
- **右栏**：`openRoute(r)`：能勾的库里一项的页面放进 `side`，左栏的栈不动；别的照旧 `goTo`。列表的行、卡片（时代规则只有一个时是一项）、引用、“谁用到它”、子项的 › 都走它，所以右栏的页面里点引用换右栏，点“组里的文化”这类列表在左栏打开。`livePanel` 在换了来源、那一项没了、不能勾了时去掉 `side`；`goTo`、`goBack` 留着它；`moveToCopy`（复制成我的库）也留着。
- **两栏**：能勾 &&（`side` 或这个库勾了东西）。`libWide`（computed）给 `App` 加 `.lib-wide`，`MapView` 的比例尺抬高缓存跟着它作废（同 `.with-sheet`）。窄窗口用 `matchMedia('(max-width: 900px)')`。
- **清单**：`LibBasket` 用 `pickView` 的 `preview`。“添加并重新生成…”的字是 `addRegenButton(v.ask)`（每次勾选变了算一次 `worldAddCommand`，只在有勾的时候）。底下只留：组的比重是 0（`hasZeroWeightGroup`）、跳过了几项、没有“添加并重新生成”按钮时要重新生成的一句（`regenLine`，比如加变量时“文化、国家、城市都不会变……”）。
- **添加之后**：`addNow` → `addPicked(key, ctx, { regen, look })`。世界里 `queueWorld` 多了第三个参数（做完后顶上那句，make 之后才问），`runTrusted`、`execAdjust` 多一个 `note`，传给 `exec` 的 `action`、`head`：顶上写“已添加“社会主义共和国”等 19 项”（就是撤销条，前面加“已”；跳过了的接在后面），按钮“去看看”和撤销。库里没有世界的撤销：`noteAction` 多一个 `undo`，`changeNote.undo` 有时提示条的“撤销”调它（撤销那个库）。成功后清掉这个库的勾，`flashRows(rows, 'flash')` 让写进去的行闪 1.2 秒（`rowFlash`，行上 `flashClass`）。
- **去看看**：`lookAt(目的地, 行)`：切到那一份，打开第一个新加项所在的列表（`listOf`：变量、取值是那个变量的取值页），`flashRows(rows, 'hl')` 高亮 4 秒。
- **读文件**：标题下拉最后“读文件…”。读得了：`setFileSource` 现在写进 `library.ts` 的 `fileLibrary`（键 `file:文件名`），面板换到它；`sourceKind` 多了 `file`（只读，写“读进来的文件只读”）；下拉里一段“读进来的文件”，写“文件：xxx（没装进资源库）”。“⋯”里“装进资源库…”“不看这个文件”。读不了的走原来的弹窗写原因。面板的 `ctx.lib` 是 `panelLibrary`（资源库 + 文件），资源库别处（新建向导、生成人文）照旧只用 `library`。
- **从库里添加…**：看本世界、我的库时在右上角。点了 `setPickDest`（本世界或这个我的库），切到 `defaultFrom`（上次看过的能勾的库，读进来的文件、我的库不算；没有时目的地用的库以外第一个内置库）。
- **键盘**（`lib-keys.ts`，挂在面板的 `onKeyDown`，处理了的 `stopPropagation`，不到 `window` 的快捷键和地图的空格平移）：行有 `data-pick-row`、`tabIndex=-1`；上下键在行间（右栏的页面里在右栏的行间），搜索框里按下键到第一行；空格点这一行的 `.lp-pick`；回车点 `.lp-row-main`；Esc 先清搜索（写空、发 `input` 事件），再收起右栏；⌘回车添加。能勾的库进列表时搜索框拿到焦点（能勾时总有搜索框）。`shell/keys.ts` 的 Esc 在面板那一层也先收起右栏。
- **提示条、底部条**：`.app.lib-wide` 时（900 px 以上），`.notices` 和 `.bottombar` 的 `left` 是 `(100% + 728px) / 2`（面板右边在 8 + 720），最宽分别是 `min(100% - 768px, 440px)`、`100% - 752px`；右边抽屉也开着时底部条在两者之间。

## 和设计不一样的地方

- **窄窗口**：设计写“右栏盖在左栏上”。勾第一项时就盖上的话每勾一下列表就被盖住，所以只勾了东西时左栏底下一条“已勾 N 项 · 清单 ›”，点它、或者点一行时才盖上来，左上角返回。
- **顶上的提示**：设计写“已添加 4 项 · 去看看 · 撤销”。这一句就是撤销条，按上面第二个问题写用户点的那一项：“已添加“社会主义共和国”等 19 项”。
- **“从库里添加…”**：只在看本世界、我的库时有（看库时已经在库里了）。看我的库时点它，“加到”是这个我的库（原来“导入”到我的库的那条路）。
- **读进来的文件**：多了“⋯”里的“不看这个文件”（从下拉里去掉，勾的一起去掉）。
- **Esc**：焦点不在面板里时（点过地图）也先收起右栏，再一层层返回。
- **我的库的把手**：设计写“勾选框在最左，把手在最右”。不能勾时（没有世界、只有这一个我的库）把手也在最右，不再按能不能勾换位置。
- **清单底下**：设计写只留“里面只有天主教”和跳过了几项。“组的比重是 0”（第六十六轮起只有别的引用带来的组才写）和没有“添加并重新生成”按钮时要重新生成的那句也留着：加了东西地图却不变，也算让人吃惊的。
- **世界用的库里比重 0 的组**：不只“添加并重新生成”时参与，之后点面板顶上、“文化 ⋯”的重新生成也参与；取消时记下比重 0（见上面）。
