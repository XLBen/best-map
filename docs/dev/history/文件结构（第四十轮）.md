# 文件结构（第四十轮时的原文）

第四十一轮把开发说明的“文件结构”一节拆成 docs/dev/ 下的几篇、每个文件一两行；这是拆之前的原文，长的说明（每个文件里有哪些函数、各轮加了什么）都在这里。文件名以第四十一轮为准：`core/commands.ts` 拆成了 `core/commands/`，`src/render/renderer.ts` 的着色器在 `src/render/shaders/`，`src/render/overlay.ts` 拆成了 `overlay-*.ts`，按轮次命名的测试改了名（见 [测试](../tests.md)）。

- `core/`：纯计算，不依赖 DOM，Node 与浏览器共用
  - 网格与几何：`mesh.ts` 网格（平面、球面两种）；`sphere.ts` 球面网格（斐波那契撒点、球面 Delaunay、显示用的三角网、最近格）；`mesh-pack.ts` 网格的打包与拆包；`geo.ts` 整个星球的几何（经度绕回、球面距离、大圆、球面上的圆）
  - 地形：`generate.ts` 随机世界（地壳高度、板块、火山锥；第三十五轮：裂开漂移的大陆块、三角形的半岛、地峡，见“大陆轮廓”）；`outline.ts` 大陆轮廓（第三十五轮：裂开的切口、大陆架、洋中脊、地峡、三角形半岛的式子与常数，地区与星球共用）；`relief.ts` 大格局（第三十二轮：板块的栅格与距离变换、基准面 T、高原、洼地的逐格式子，见“大格局与长河”）；`planet-gen.ts` 整个星球的生成器（球面上的板块、大陆块、热点岛链）；`planet-form.ts` 星球形态的格式；`terrain.ts` 组合地形、画笔、放岛、岛链（`fillSeaPockets`：陆地围住、不挨地图边、不超过 `POCKET_MAX` 格的海块并回陆地，环礁潟湖除外（`lagoonTest`：记着 `LAGOON_BIT` 的海格）；`landAfter` 按同一规则给预览；放岛只添陆地；放岛按种类的形状、高低、岩石长出陆地，并在 `StampResult.types` 里给出要记的种类）；湖里的岛（第十五轮：`placeIsland` 按岛心分海里、湖面、干的陆地；`lakeIslandStamp` 只抬岛心所在的那个湖里不挨岸的格，`keepLakeOpen` 让剩下的湖面连成一片，不改陆度、抬升、岩性，只给出种类与 `StampResult.heights`；`combineStamps`、`chainIslands` 收一个 `LakeSource`，只在有岛心落在陆格上时才取推导里的湖面，整条链都在海上时与以前逐值相同；`islandGeometry` 是从 `islandStamp` 拆出来共用的轮廓）；`island-types.ts` 岛的种类（第十四轮：内置的大陆岛、低平岛、珊瑚岛、小礁与 `small.islandTypes` 里自己的，编号、`provinceLand`——省份按格分陆海时归海省的岛算海，湖里的岛（定了高度的格）算陆地、`lakeSeaIsles`、`landProvinceCells`）；`elevation.ts` 抬升-侵蚀稳态（`finishElevation` 里 `pocketLakes` 三格以上的并回小块挖成湖；第十四轮去掉了 `volcanoes`，`lagoonFloor` 按潟湖的标记挖浅）、海底（`seafloor`：按只走海格的离岸距离给大陆架、坡折、陆坡、陆隆，洋底目标深度来自生成器的 `sea` 分量与 `terrain.ts` 的 `seabedFields`；输入逐字节相同时用上一次的结果，改了一小片海陆只重算离改动约 1500 km 以内的格，与整个重算逐位相同）与湖底（`lakeBedShape`）；第十五轮起最后把 `causes.islandHeight` 定下的高度换上（湖里的岛：湖面 + 按种类算的高出湖面多少，放岛时记进原因；`hydrology.ts` 里这些格永远不是湖面），`placedLakeAnchor` / `placedLakeCell` 是放的湖在水文、湖类型、选湖里认的那一格（湖心放了岛时取碗里最近的水面格）；`plains.ts` 平原与河口（第三十三轮：`solveLand` 最后一遍的冲积平原、冲积扇、三角洲平原，见“平原与河口”）；`glacial.ts` 冰川刻蚀（第三十四轮：冰盖到过哪里、刮的高度上限、按公里定尺度的小洼，`solveLand` 在平原之后按岸取平底挖成湖群，见“湖与海岸”）；`routing.ts` 汇流路由；`stats.ts` 地形统计量（测试与 `tools/terrain-stats.ts` 共用；第三十一轮加和地球比的统计，`tools/realism-report.ts` 用；第三十三轮加低平地、大干流两旁）
  - 气候与水：`climate.ts` 日照温度、风带季风、山挡风、水汽输运；`planet-climate.ts` 整个星球的气候；`sphere-flow.ts` 球面上的输送（绕星球一圈的风带不剪断）；`ocean.ts` 简化洋流与海面温度；`hydrology.ts` 填洼汇流、湖、径流；`rivers.ts` 河流折线（第十二轮：河口在画面上的岸线上，`riverRibbon` 是河画出来的带子：加密、宽度平滑不减、源头收尖、河口张开、画的时候才加的细小弯曲，屏幕与 `rivers.bmp` 共用；第十三轮：`normalMouth` 河口沿岸线法向进水、最后 1.5 格不急转（`maxTurn`），`tidyMouths` 去掉海岸边的源头小河、挤在一起的河口小的沿岸挪开（`shiftMouth`）或接得顺时并进大河（`mergeMouth`），`branchStart` 分出去的一股顺着干流分出来；第三十三轮：`withBranches` 三角洲的分汊）；`delta.ts` 三角洲的画法（第三十三轮：`deltaMouths` 按推导认三角洲的河口，`deltaBulge` 亚格子海岸向海凸出）；`coast-memo.ts` 描河时按画面海岸场的查询跨几次描河记下来（第三十三轮提速：键是参数，按读到的格验过才用）；`coast-style.ts` 海岸类型（第三十四轮：每格峡湾、沙坝、溺谷、小湖群的权重，按生成器与新建时的纬度；着色器海岸值纹理 b、a 的打包与拆法；沙坝、小湖群、岛礁的算式，着色器的 `STYLE_GLSL` 是同一份，见“湖与海岸”“峡湾”）；`fjords.ts` 峡湾（第三十六轮：谷网 `buildFjordNet`（按块建，重画一片只重建碰到的块）、按陆海淹到哪里 `fjordLayer` / `budgets`（按 km 的长度、宽度与支湾）、每格的表与着色器的峡湾纹理、带子的海岸场 `fjordSegField`，见“峡湾（第三十六轮）”）；`river-pack.ts` 地图上的河在计算 Worker 里描好打包（河线与带子几块连续的数组，随快照、预览世界转交，主线程 `overlay.ts` 的 `seedRivers` 拆开直接用，与主线程描的逐位相同；描河读的东西按内容没变时用上一次的）；`display.ts` 画面上的一点画的是哪一格，以及画面上的海岸场（`displayCoast`：湖面取负，着色与河口共用；`shoreCrossing` 找画出来的岸线；第三十四轮带上海岸类型 `style`，`displayCoastAt`、`displayCellAt` 按 `subcell.ts` 的 `styledCoast` 画峡湾、沙坝、小湖群）
  - 水体类型：`water-types.ts` 河流类型、湖泊类型共用的部分（格式里相同的几项、只能有 match 的脚本、改了哪几项从哪一层重算、岸边的远近）；`river-types.ts` 河流类型（每格是哪一种河、河岸场）；`lake-types.ts` 湖泊类型（每个湖是哪一种）；`effects.ts` 生态、河湖对周围冷暖干湿的影响
  - 生态：`species.ts` 生态类型（色块 + 条件 + 耐受曲线）；`vegetation.ts` 适宜度 / 竞争 / 扩散 / 长在哪里（只在某个岛上、圈的范围里、不自然生成）/ 不计水体类型的一遍植被（baseBiomes）；`constraints.ts` 涂生态的反推与“没涂成”的原因、“就这样”；`biome-look.ts` 生态在地图上的样子（颜色脚本、花纹与发光的算式，屏幕与缩略图共用）；`biome-scripts.ts` 生态的脚本在世界上运行
  - 人文（第二十一轮，见“地形类别、资源、格的档案”）：`human/rules.ts` 按格的条件（地形类别的自动规则、资源的分布规则共用）；`human/terrain-class.ts` 地形类别（内置 5 种起伏、世界里的列表、自动分类、画过的；第二十七轮起还有通行难度 `cellMovement`、导出的地形 `paradoxTerrain`、档案的“起伏 · 生态” `terrainLabel`）；`human/resources.ts` 资源（内置通用 18 种、奇幻 5 种、按噪声分布）；`human/peaks.ts` 山峰；`human/cells.ts` 格的小地名与档案；`human/kinds.ts` 两种内容登记进登记表；`human/index.ts` 流水线里的一步 `computeHuman` 与给界面的函数；`human/cell-memo.ts` 自动的类别、资源、宜居度按格记下（第三十五轮提速：只重算输入变了的格）。第二十二轮（见“时代、文化、人口”）：`human/era.ts` 时代、取值、文化组、文化的格式与世界里的列表；`human/pop-kinds.ts` 这四种登记进登记表；`human/habitability.ts` 宜居度与偏好；`human/context.ts` 生成的各步共用的 `GenContext`；`human/generate.ts` 生成（分步、复制内容、重新生成）；`human/cultures.ts` 文化圈；`human/population.ts` 人口、修补、笔刷；`human/groups.ts` 人口群体的编号与每格的成分；`human/layers.ts` 人口的几层、图例、档案的人口一栏、每省的人口；`human/culture-style.ts` 地名跟着文化；`human/space.ts` 面积、距离、噪声、按份额长；`packs/eras/` 内置的 6 个时代（一个 JSON 一个）、几个时代共用的取值（`values/` 下一维一个）与 23 个文化组（`cultures/` 下一个 JSON 一组）。第二十三轮（见“国家与政体”）：`human/government.ts` 政体、派系的格式与世界里的列表、称号；`human/gov-kinds.ts` 这两种登记进登记表；`human/countries.ts` 生成国家（两步）、颜色、名字、历史；`human/country-names.ts` 国名的地名部分、人名；`human/country-edit.ts` 改国家的命令、整理、改地形后的修补；`human/country-layers.ts` 国家的一层、国界的分组、颜色、统计、派系的影响力、国名的位置；`human/flags.ts` 旗帜的规则与 SVG；`packs/governments/` 内置的政体与派系（一个 JSON 一组）。第二十四轮（见“城市、道路、地标、自定义点”）：`human/settle-types.ts` 城市等级、地标类型、点的类型的格式与等级的规则；`human/settle-content.ts` 世界里的列表；`human/settle-kinds.ts` 这三种登记进登记表；`human/settlements.ts` 城市（生成、现算的表与档案、命令、整理、改地形后的修补）；`human/roads.ts` 道路（代价、A* 与最近的路网、生成、画与改走向、修补）；`human/landmarks.ts` 地标（自然的检测器、人造的放法、名字、命令）；`human/points.ts` 自定义点；`human/settle-gen.ts` 一起生成（生成人文的最后一步与命令共用）；`human/archive.ts` 导出的表与档案全文；`packs/settlements/` 内置的城市等级、地标类型、点的类型（三个 JSON）
  - 地名：`features.ts` 地理要素识别（用户圈的地名区块也在这里变成地名，前后地物配对留名字；第十五轮 `lakeIslandInputs`：四周全是湖面的干陆地也是“岛”）；`names.ts` 模板式起名（以前的文字包）；`name-styles.ts` 地名风格（第二十轮：模板式、音译式两种写法，`styleFor` 判断一处地方用哪种，见“地名风格的写法”）；`packs/names/` 内置的地名风格（一个 JSON 一种，共 27 种；`zh-default.json` 就是以前的 `packs/zh.json`）；`name-display.ts` 显示中文 / 原文 / 两者
  - 画风（第三十八轮，见“画风”）：`map-style.ts` 画风的格式（默认的画法 `DEFAULT_LOOK` 就是写实）、颜色的写法 `styleRgba`、世界在用的 `worldMapStyle`、签名 `mapStyleKey`；`packs/map-styles.ts` 内置的写实、地图册
  - 内容：`content/registry.ts` 内容种类的登记表、`content/kinds.ts` 现有的几种登记在这里、`content/refs.ts` 脚本里的引用与改名（见“内容种类的登记表”）
  - 资源包：`packs.ts` 资源包的格式、检查、用到世界（一整步）、从世界导出（各段都由登记表推出）；`packs/fantasy.ts` 内置示例包（生态在 `packs/fantasy-biomes.ts`，河流类型在 `packs/fantasy-rivers.ts`，湖泊类型在 `packs/fantasy-lakes.ts`，星球形态在 `packs/fantasy-forms.ts`）
  - `script.ts` 脚本的运行环境（编译、中英文变量表、辅助函数、出错按没有脚本处理、给看门狗报平安、安全模式）
  - 湖里的岛定下的高度 `causes.islandHeight`（第十五轮）：第一次往湖里放岛时才建，撤销时 `UndoRecord.dropHeights` 去掉它；放岛、画岛链的命令里用 `ensureDerived`
    取这一步之前的湖面（岛心在海里时不取，与以前一样快），所以重放、撤销、检查点逐值一致；批量命令里推导不是最新的：岛心在陆格上的单个岛拒绝，岛链跳过这些岛。
    湖单独成省时，湖里归海省的岛由 `provinces.ts` 的 `lakeCells` 算进湖省；改了一种岛归哪种省、湖里有这种岛时这一步至少重新起名，引擎随后整理湖省
  - 省份与编辑：`provinces.ts` 省份规则、划分、局部重划、修补（格分海、陆地、湖三类，省份不跨类；`lakeProvinceFix` 是推导算好之后湖与陆地之间的整理，由引擎记进命令的 `provinceFix`，重放照用）；`select.ts` 画笔、拖动扩张、画河的路线（汇入、改道、会变干的河段；自定义走向的规划、截走、汇入）、圈一片、剪刀沿线切省；`river-edit.ts` 改一条河（第十一轮：拖控制点、加删弯点、在河上重画一笔，还是同一条河；自然的河第一次改时固定下来）；`seams.ts` 剪刀的切线（切线旁的像素按在线的哪一边分省，屏幕与导出同一条规则）
  - 引擎：`world.ts` 世界的数据；`commands.ts` 命令；`engine.ts` 流水线、历史、预览、文档；`preview-world.ts` 预览世界；`doc-version.ts` 世界文件的版本与打开前的检查；`rng.ts` 随机数与噪声；`heap.ts` 最小堆
  - 输出：`subcell.ts` 格以下的细节（屏幕与导出共用；`shownCoastValues` 是画出来的每格海岸值：`coastValues` 加三角洲的凸出）；`display.ts` 屏幕上的一点画的是哪一格（与着色器同一套规则）；`export.ts` 导出；`thumbnail.ts` 向导缩略图；`presets.ts` 世界大小、星球上的纬度带、星球的格数（`planetCells`：每格约 `PLANET_CELL_KM` = 100 km，按实测的球面格距标定；向导、形态编辑器的“用它新建”、`tools/bench.ts` 都用它）
  - 小文件：`errors.ts`、`type-id.ts`、`world-types.ts` 是为了避免循环引用拆出来的；`testing/fixtures.ts` 测试共用的世界模板（建一次，每个测试拿一份副本）；`golden-full.json`、`golden-hashes.json` 金标准的哈希
- `src/`：界面
  - 线程：`main.tsx` 入口；`state.ts` 主线程状态；`protocol.ts` 主线程与计算 Worker 之间的消息；`worker.ts` 计算 Worker；`engine-spawn.ts`、`engine-source.ts`、`isolation-probe.ts` 开计算 Worker 与隔离；`sandbox.ts` Worker 的看护（看门狗、恢复、安全模式）；`storage-worker.ts` + `checkpoint-store.ts` 存储 Worker 与检查点；`mesh-worker.ts` 建网格；`export-worker.ts` 导出；`transfer.ts` 搬数据不复制
  - 存储：`idb.ts` IndexedDB（自动保存、检查点、网格、参考图、资源库、我的地图）；`maps.ts` 我的地图（存、盖掉、改名、删掉，连着哪一张）；`library.ts` 资源库（装着的包：内置的树，我的资源，“来自《世界名》”，导入的；`saveItem` 把编辑器里的一项存进“我的资源”，`removeItem` 从我的包里删掉一项（分了小包的也行），`keepInLibrary` 把拿掉的、打开的文件里自己做的存进“来自《世界名》”）；`compact-job.ts` 压缩世界文件（在导出 Worker 里）；`trust.ts` 信任过的脚本（按源码的 SHA-256，资源库、内置示例登记为总是信任）
  - `render/`：城市、道路、地标、点的画法（`settle-draw.ts`，第二十四轮：图标、道路、避让用的格子），WebGL 渲染（`renderer.ts`）、整个星球的投影（`projection.ts`：等面积、球形的正反算式与同一套 GLSL、镜头换算、合成要的场景范围与密度；`overlay-proj.ts`：投影时的叠加层）、着色（`colors.ts`）、矢量叠加（`overlay.ts`；第四十轮：底下、图形、上面三段，屏幕上什么都没变时不画 `drawScreen`，排地名按格子查）、画风的 uniform（`renderer.ts` 的 `styleUniforms`，第三十八轮）、风向与洋流流线（`wind.ts`；第四十轮：块的缓存有上限、新的块空闲时算）、导出整张地图的算式（`export-plan.ts`：虚拟镜头、分块、每一块的视图、整个星球自动放分界线 `autoSeam`，不碰 WebGL）、开发用的测速（`bench.ts`）、离边界远的格（`near.ts`，第三十九轮：画出来的格的图、ρ、每格的 H）、测速开关（`perf.ts`，第三十九轮：`?perf`、`window.__perf`）
  - `ui/`：
    - `defs/` 是注册表：`tools.ts`（工具表：每个工具的类别、图标、名字、底部条上的滑块与选项、吸取、光标、离开时清掉什么、地图跟着重画的状态；类别表：每类的“⋯”、离开这一类时清掉什么、地图上多画的高亮；`setTool` 换工具）、`adjustments.ts`（“调整”里的滑块）、`layers.ts`（“图层”里的底图与开关）、`extras.tsx`（注册表里引用的小部件）、`types.ts`。加一个工具、参数或底图只要加一条声明，顶栏、底部工具条、面板、地图上的光标与高亮都由它们生成（见下面的“工具怎样组织”）
