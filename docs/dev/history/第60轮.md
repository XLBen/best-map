# 第六十轮的设计

这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

用户要的：“让一部分内容可以融入一部分内容，比如派系融入到政体里，允许特地资源包融入不同的东西”。

## 安排只改显示

`arrange` 是库的一个可选字段（`core/content/arrange.ts`）：`{ 下级: 上级 }`。写了就是完整的一张，没写到的种类单独成卡；`{}` 是全部单独。没有这个字段时用预设 `PRESET_ARRANGE`。

**谁属于谁一直是内容自己写的**，安排只决定面板上要不要把它们放在一起：

| 下级 → 上级 | 读哪里 | 加 | 移出 |
| --- | --- | --- | --- |
| 文化 → 文化组（预设） | 文化的 `group` | 改文化的 `group` | 文化必须有组，所以是“移到”别的组 |
| 地名风格 → 文化组（预设） | 组的 `nameStyle`，加上组里文化写的 `nameStyle` | 换组的 `nameStyle`（一组只有一个默认的） | 组的默认能移出；文化写的到文化里改 |
| 地标 → 文化组（预设） | 地标的 `cultureGroups` | 加进地标的 `cultureGroups` | 去掉；一个也不写时不限 |
| 地标 → 政体 | 地标的 `governments`（政体的类别） | 加上这个政体的类别 | 去掉这个类别，同一类的政体一起变 |
| 取值 → 取值组（预设） | 取值的 `group` | 改 `group`，只列同一维的 | 去掉 `group` |
| 变量 → 时代（预设） | 时代的 `dimensions` | 时代规则的“变量”一段 | 同左 |
| 格局 → 国家等级（预设） | 格局的 `weights` 里比例大于 0 的等级 | 写这一级比例 1 | 去掉这一级 |
| 派系 → 政体（预设） | 政体的 `factions` | 加进政体的名单 | 从名单去掉，定义还在 |
| 资源 → 地形类别 | 资源的规则写的 `classes` | 只列，在资源的页面上改 | 同左 |

别的组合不接受（`canMerge`）。只有一层：上级不能再融入别的（测试查着），所以不会绕圈，页面也不用嵌套几层。文件里写了讲不通的组合，`parsePack` 报错，和别的不认识的部分一样不悄悄丢掉；写在小包里也报错（只有库的最外层有）。

**内置的包里不写这个字段**：预设是代码里的一张表。所以内置库的摘要、金标准一个都不动。和预设一样的我的库也不写（`withArrange`），文件和以前一模一样。

## 世界用谁的安排

世界没有自己的安排：**看它来自的那个库**（`worldLibrary(small)` 已经记着），那个库不在了用预设。

- 另一条路是新世界记下来源库的安排，要往 `small` 里多写一个字段，`small` 在几处摘要里。这样读一下就行，世界里什么都不记。
- 代价：改了库的安排，用这个库建的世界面板跟着变；库删了回到预设。只是显示，内容不变，可以接受。世界里不能拖。

## 不属于任何上级的

**地标**：用户定的，不属于任何组的在“城市与地标”，所以这张卡片留着，数只算它们（`{ p: 'list', kind, loose }`）。内置的库里大多数地标不属于任何组。`looseCard` 写在关系上。

**别的**（历史库里奇幻、科幻的地名风格没有组用；还没加到政体的派系）：在上级列表的最后一段“不属于文化组的地名风格”。不留卡片：首页要干净，也符合“融入后没有单独的卡片”。

上级的列表最上面有“全部文化 404 ›”这几行，点进去还是第 59 轮的完整列表，新建一个不属于任何组的也从那里。工具里的“从资源库添加…”、缺内容的提示还开这些完整列表，不受安排影响。

## 取值和维度

首页本来有“取值组”一张卡片，和每一维一张（“宗教 7 组”）。取值融入取值组时：取值组那张不列，**每一维的卡片就是这一维的取值组**（点进去本来就按组分段，段的标题去那一组的页面），写“含取值”。拆出来时取值组回到首页，和第 59 轮一样。这一维的卡片作为拖放的目标算取值组（`cardParent`）。`dimensionsOf` 多看取值组写的维度，否则一个还没有取值的组的维度没有卡片，就到不了了。

## 上级页面

几段“下面的”（`childSections`，组件 `PageChildren.tsx`），放在“基本”后面，默认展开：一行一项。

- **点一下就地展开改**：里面就是 `PageItem`（`embedded`：不写标题；删除、移出不返回），改一处就存，同一条路。**› 单独打开**，返回回到上级，面包屑写“本世界 › 文化组 › 汉 › 直隶人”。两个都留着：快改一个数不用换页；字段多的单独打开宽一点。
- **上级自己写着它的字段**（政体的“有哪些派系”、文化组的“地名风格”）融入后不再列，由这一段代替（`parentField`）；空了的一段也不要（文化组的“地名”段）。第 59 轮测的“每个字段在且只在一段里”查的是 `segmentsOf`，它不变；这一步在 `itemPage` 里。
- **政体只列有哪些派系，没有比重**：行上不写分量。
- **加**：下拉里是这一份里还不在这里的（世界里只有世界里的，别的库的等第 61 轮的导入）。**新建**是一步撤销：派系、风格要同时改上级（`applyItems`、世界里一个 batch）；新的格局只写这一级（`fresh`），不带 `blank` 的 `medium`。
- 加和移出都走 `commitItem`：和页面上改字段同一条路，所以校验、撤销、世界的排队都一样。
- 这几段在只读的 `<fieldset>` 外面：内置的库里能点开看（展开的内容自己是只读的），没有加、移出、拆出来。
- 一项的页面上写它在哪几个上级下面（`partOf`），能点过去。
- **一组很多时**：先画 60 行（`CHILD_SHOW`），“还有 N 个”再画，超过 12 个有搜索框（在全部里找）。

## 拖卡片

`page-drag.ts`，鼠标、笔按住拖（`pointer` 事件，不是 HTML5 的拖放）：要一直知道指着哪张卡片、行不行，跟手的小卡片上写“融入政体”“文化只能融入文化组”。动 6 px 才算拖，松手不算点一下；Esc 取消；窗口外松手算取消；靠近上下边自动滚。手指不走这里（按住滑动是滚动面板），触摸时用“⋯”。

- 卡片上的“含”：内置的库是一句话，我的库每种一个能拖的小标签。含两种以上的卡片占两列（一列放不下）。
- 拖到讲得通的上级上：融入（地标在文化组里时拖到政体上是换上级）。拖到别的卡片上：不接受，松手再说一遍（提示条）。拖到空的地方：融入着的拆出来，单独的什么都不做。
- 上级页面、上级列表最上面：抓住标题拖出这一块就拆出来，也有“拆出来”按钮。
- 卡片的“⋯”（我的库、这张卡片能做什么才有）：融入到哪里、拆出来、拆出什么。
- `dropVerdict`（纯函数）算结果，`libEdits.setArrange` 落到库上。撤销和改内容同一个栈，⌘Z 不用分。换安排马上写整个库（和换先后一样，记不成“这一项换成这样”）。

判断逻辑都在 `page-arrange.ts`，测试直接调；组件只把指着哪张卡片传进去。

## 复制和导出

字段在包的最外层，改内容走 `mapNode` / `setAt`，别的字段不碰。

- 复制成我的库：`copiedPack` 展开原来的包，带着。
- 导出文件是整个包，导入 `parsePack` 收下。旧的文件没有这个字段照常。
- `nestByKind` 重新拼最外层，补上了，所以存进我的库（`addToPack`）、导入到库（`importIntoPack`）不丢。
- 刷新页面：写整个库的时候带着；日志只补内容项。

## 世界里的变量（第 59 轮留的）

世界里时代规则的“人口的维度”能直接改，只有一句提示。直接改这张表不分人口，世界的 `popGroups` 就对不上了。这一轮改小了：世界里这一段**只列**（名字、几个取值，点进去是这一维的列表），下面“加变量”走 `add_dimension`（和“文化 ⋯”同一个函数），写一句“文化、国家、城市都不会变”。库里还是字段表，库不带人口。世界里不能在这里改变量的名字了（以前能）：要改名字没有入口，以后要的话加一条只改 `label` 的命令。

## 拆文件

`pages.ts` 已经 703 行，要加逻辑又不能绕圈：`page-source.ts`（来源、`itemsOf`、`rowsOf`）搬出来，`pages.ts` 照旧导出；新的逻辑在 `page-arrange.ts`、`page-children.ts`。`pages.ts` 现在约 700 行。

`linkView` 按内容的树根记“谁属于谁”的表：同一份内容只算一遍。

## 替用户定的

- 世界看来自的库的安排，不记在世界里（上面写了）。
- 安排按**种类**，不按一项：“这种内容融入哪种”。一个文化组下面不能单独关掉文化。
- 只有一层。地名风格不能融入文化（文化自己已经融入文化组）。
- 地名风格、派系不属于任何上级的不留卡片，放在上级列表的最后一段；只有地标留卡片（用户说的）。
- 多给了两种组合，让“不同的库融入不同的东西”有得选：地标 → 政体、资源 → 地形类别。后一种只列，不能在上级页面上加、移出。
- 融入的项点一下就地展开，› 单独打开，两个都有。
- 文化“移出”是“移到”别的组：文化必须有组。
- 手指不能拖，只能用“⋯”（按住滑动是滚动面板）。
- 世界里不能直接改变量表，改名也不行了（上面写了）。

## 坑

- **第 61 轮**：`childSections` 的 `options` 只有这一份里的，从别的库加走导入窗口。导入一个库时要不要带它的 `arrange`：现在 `importIntoPack` 留目的地的，来源的不管。
- **第 61 轮**：列表最上面“全部 X”的列表上还有旧的“添加”“全部添加”。
- **第 62 轮**：`partOf` 是“谁用到它”的一小部分，那一轮可以合起来。`regenNote` 只写在单独的页面和上级页面最上面，就地展开时不重复写。移出、换组改的是内容，世界里同样要重新生成才用到。
- **第 63 轮**：`lp-row` 的旧拖动（换先后）还是 HTML5 的，和 `page-drag.ts` 两套，可以合。
- **`arrange` 只看库**：世界改不了安排。用户想在世界里换，要先换库的。
- **地标 → 政体写的是类别**：一个政体“移出”地标会影响同类的政体，悬停写着。
- **`dimCards` 和 `arrange.popValue`**：拆开取值后每一维的卡片还是这一维的列表，只是取值组多一张卡片。
