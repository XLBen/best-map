# 第九十九轮的设计：简单模式与帮助

这一轮改了什么见 [更新记录](../../更新记录.md)。前提和前几轮一样：用户是对系统完全无知的新手，界面像 Procreate，结果要可以预料。以前一打开，右上角九类工具、每类底部一排、图层里十种底图十二个开关、“调整”九个滑块、资源库首页二十来张卡片全摊着。这一轮：**默认只露常用的，藏着的地方都写着“还有 N 个”**；帮助能搜、一打开先讲手上这个工具；几个看不懂的词在它出现的地方写一行人话。

生成的结果逐值不变：金标准、摘要、着色器的哈希、界面的快照（`tool-replay.json`）、`raster-identity` 一个都没有重录。世界文件的格式没变（`DOC_VERSION` 还是 22），IndexedDB 的库还是第 8 版；localStorage 没有新的键（“完整界面”用的是第九十二轮起的 `map2.lib.allSources`）。没有动引擎的计算、命令、流水线、`src/render/`、计算 Worker、`src/sandbox.ts`；`core/` 里只改了两处给人看的字（见第 4 节）。

## 1. 简单界面 / 完整界面

### 一个偏好（`src/ui/ui-prefs.ts`）

- `fullUi()` / `setFullUi(on)`：整个应用只有这一个偏好、一个信号、一个键（`map2.lib.allSources`）。第九十二、九十三轮的 `showAllSources` / `showAllSettings`（`packs/lib-prefs.ts`）现在就是它（照旧导出，组件不用动）；已经有 `'1'` 的浏览器一打开就是完整界面（那时界面上没有入口，实际上没人有）。
- 开关在“更多 → 偏好 → 完整界面”，下面一行写现在是哪一种（关着：“只露常用的工具、底图和设置；别的在各处末尾的‘还有 N 个’里”）。
- 开着时：全部工具、底图、开关、“调整”的项、资源库的卡片都露着；资源库里一项的“更多设置”都摊开、下拉里带 id、来源下拉里别的库都列着（第九十二、九十三轮定的）。

**底图**（`defs/layers.ts` 的 `VIEWS`）：常用 地貌、生态分区、气温、降水、海拔、海水温度（第十四轮定的：它和气温、降水放在一起，`wizard-terrain.test.ts` 钉着，没有动）；完整 省份、地形类别、资源、抬升。“人文”一组生成过人文时只剩宜居度，它不算常用。自定义场的底图（`场：魔力`）是世界里已经有的东西，有就露着。

**“显示”里的开关**（`OVERLAYS`）：常用 地名、河流、山峰、道路、城市、地标（后三个世界里有才出现，照旧）、比例尺、我改过的地方；完整 省份边界、风向、洋流、纬度刻度 / 经纬网。地图模式、画风、投影、季节、参考图都留着（各只有一样）。

**“调整”**（`defs/adjustments.ts`）：常用 地图在星球上的位置、整体冷暖、整体干湿、河流多少；完整 四季分明、越高越冷、洋流强弱、山挡风、生态边界，两个开关（反向自转、地图外面是海），和下面的“自定义场”一段。

**资源库首页的卡片**（`packs/page-layout.ts` 的 `HOME_MORE_CARDS`）：常用 生成设置、时代（这两张在最上面，总在）、文化组、文化、地名风格、每个变量的卡片（宗教……）、政体、地标、生态与水系、岛、画风；完整 取值组、变量、派系、国家等级、国家格局、城市等级、自定义点、星球形态、地形类别、资源、省份划分。

右上角的类别一类都没藏：每一类都至少露着一个工具，新手找“省份”“文化”时按钮还在原处。

### 简单界面里一项什么时候露着（`defs/simple-ui.ts`，纯函数）

当且仅当有一条成立：

1. 它是常用的；
2. **世界里已经有它对应的东西**——工具写了 `when`（`WORLD_SIGNS` 的一个键）：

   | 键 | 怎么认 |
   | --- | --- |
   | `provinces` 划分过省份 | `small.provinces` 不是空的 |
   | `fields` 有自定义场 | `causes.fields` 不是空的 |
   | `chains` 画过岛链 | 命令记录里有 `add_island_chain`（batch 里的也算）——岛链在世界里没有记号 |
   | `drawnWater` 有画的河或放的湖 | `small.guides`、`small.lakes` |
   | `classPainted` / `resourcePainted` 手画过地形类别、资源 | `causes.terrainClass` / `resource` 里有不是 0 的（按数组对象记着，不重扫） |
   | `hearthMoved` 拖过发源地 | 有 `locked` 的发源地 |
   | `points` 有自定义点 | `small.points` 不是空的 |

   “调整”里是“不在默认值上”（`AdjustmentDef.touched`、`PlanetToggle.touched`：和 `planetSchema.parse({})` 比）；“显示”里是“和一打开页面时不一样”（`state.ts` 的 `OVERLAY_DEFAULTS`）；资源库首页是“挑选时这一类勾了东西”；
3. **它正在用**：正拿着的工具（比如从完整切回简单时正拿着它）、正看着的底图；
4. **这一处点过“还有 N 个”**。

`splitSimple(items, {full, open}, isMore, kept)` 给出 `shown`（声明里的先后）、`hidden`（“还有 N 个”数的）、`foldable`（展开着时能收回几个）；工具用 `shownTools`，接在工具表上的是 `defs/tools/index.ts` 的 `barTools(类, 世界)`。`toolsOf` 没有动（还是这一类在这个世界里的全部工具，已有的测试照旧拿它当“完整的那一排”）。

- 脚本没有对应的工具：它在资源库里一项的“更多设置”里（生态、河湖、星球形态），出错时那一层自己展开（第九十三轮），这一轮没有另加“有脚本就摊开”。
- 命令记录从主线程手上的那一份读（`state.ts` 的 `commandsNow`，第九十八轮重新生成前数手改用的同一份），要用到时才拿、一个世界对象只扫一遍；拿不到时不记、下次再问。撤销了那条岛链，工具就又收回去。
- 新建的世界都划分过省份（生成地形时自动划一次），所以省份画笔、剪刀平时就在；`provinces` 这个记号只在还没生成地形的空白世界里是假的（打开一份没有命令的世界文件时）。冒烟里就是这样做出“没划分过”的世界来对照的。

### 藏了东西的地方怎么提示：在原地展开

**全应用一种做法**（写进了 [ui-design.md](../ui-design.md)）：藏着东西的那一处末尾一句“还有 N 个 / 种 / 项 / 类”，点了**只在这一处展开**，换成“只留常用的”，再点收回。展开过哪几处记在 `ui-prefs.ts` 的 `restOpen`（只到关页面为止，不写进存储）。

| 哪里 | 入口 | 展开以后 |
| --- | --- | --- |
| 底部条每一类的工具 | 那一排末尾、“⋯”之前：`» 还有 4 个`（`button.bb-tool.bb-rest[data-rest]`） | `« 只留常用的`（`.bb-rest.open`） |
| 图层的底图 | “还有 5 种底图”（`button.link-btn.rest-line`） | “只留常用的”，旁边一句“想一直露着：更多 → 偏好 → 完整界面” |
| 图层的“显示” | “还有 4 项” | 同上 |
| 调整 | 最下面“还有 8 项” | 同上 |
| 资源库首页 | 最下面“还有 N 类” | 同上 |
| 资源库一项的页面 | “更多设置”（第九十三轮） | — |
| 资源库标题的来源下拉 | “更多”（第九十二轮） | — |

入口的悬停里写着藏着的是哪几个、怎么一直露着（“画岛链、打碎、重画、地形类别。点了都露出来；想一直露着：更多 → 偏好 → 完整界面”）。面板里的三处是同一个部件 `shell/RestLine.tsx`。

**为什么不是“点了就打开完整界面”**：点地形那一排的“还有 4 个”，别的八类、图层、调整、资源库的每一个表单都跟着变，是点一处动了全局；而第九十二、九十三轮的“更多”“更多设置”、图层里原有的“更多底图”本来就是在原地展开。所以选在原地展开；全局的开关只在“偏好”里，入口的悬停和展开后的那一句都指向它。

### 数字键

核实了原来的排法：数字键是“这一类现在那一排上的第几个”（`toolsOf` 的下标）——所以正拿着“选生态的范围”（平时不在那一排上）时，“资源”从 3 变成 4。现在按 `keyTools(类, 世界)`：**这一类在这个世界里的全部工具**（工具表里的先后；世界里用不上的不占键——没有自定义场时的“涂自定义场”、“选生态的范围”）。同一个世界里一个键永远是同一个工具：

- 简单界面里地形露着画陆地、放岛、堆山，键是 1、2、4（3 是藏着的岛链）——写在每个工具的悬停里；
- 按藏着的工具的键照样换过去，它正拿着，所以就露在那一排上自己的位置；换走以后收回去；
- “资源”永远是自然的 3。

`tool-replay.json` 没有重录（那里录的是手势发出的命令，不经过这一排）。

## 2. 帮助（`Help.tsx`、`help-data.ts`、`help-search.ts`）

- **拆开**：字在 `help-data.ts`（`HELP_START`、`HELP_STEPS`、`HELP_KEYS`），怎么搜、现在这个工具看哪几条在 `help-search.ts`（不碰界面的部件，测试直接调），`Help.tsx` 只画、照旧导出 `HELP_START`。
- **搜索**：标题下面一个框，按字过滤“怎么开始”的四句、底部的工具（名字、类别、怎么用）、每一步的每一条、按键。几个词用空格隔开，都出现才算；不分大小写；步骤的标题对上时整步都算。工具那一行写着它是数字几、是不是平时收着（“地形 · 画岛链：拖一条线，沿线长出一串岛（数字键 3；平时在这一排末尾的‘还有 N 个’里）”）。没搜到：“没有找到‘X’。换个短一点的词试试，比如‘河’‘保存’‘撤销’”。
- **`?` 键**：搜索框不自己抢焦点——一打开就按 `?` 还是关上（第九十八轮定的，冒烟第十三段查着）。点进框里打 `?` 是打字（`keys.ts` 的 `isTyping` 原来就管着，核实过：冒烟第十四段里框里多了一个 `?`、帮助没关）。
- **现在这个工具**：有世界、不在新建向导里时，最上面一小块：这个工具自己的那一句、数字键，和最多六条有关的——先是讲这个工具的，再是讲这一类的，再是这一类的那一步里没单独标的。为此每一步可以写它讲哪几类（`cats`），每一条可以写它讲哪几个工具、哪几类（`on('…', 'river')`）；每个工具至少有一条（测试查着），为此补了十来条（画陆地、堆山、打碎、重画、自定义场、资源、删除河湖、选国家、领土、新建与合并国家），多了一步“文化与城市”。
- **讲简单 / 完整界面**：“工具”一步里五条（平时只露常用的、怎么一直露着、世界里有什么会自己露出来、数字键、改过的项照常露着），资源库一步里一条（首页）。
- 那一小块的标题不是 `h5`（是一块底色里的一行粗字）：第九十八轮的冒烟认帮助里第一个 `h5` 是“怎么开始”，没有动它。

## 3. 原地的一行解释、术语

先全应用搜了一遍这几个词出现在哪、旁边有没有一句话：

| 词 | 出现在哪 | 这一轮 |
| --- | --- | --- |
| 安全模式 | 顶上的一条“安全模式：脚本没有运行”；向导、形态编辑器“安全模式：缩略图不含脚本的效果”；打开时的问话“安全模式下脚本不运行” | 顶上那一条改成“安全模式：这个世界里的脚本这次没有运行，别的照常”（`SAFE_MODE_TEXT`）；另两处本来就说得清 |
| 自定义场 | “调整”最下面一段；“图层”里场的底图；工具“涂自定义场” | “调整”那一段第一行“自己起名的一层数值，如‘魔力’‘文明度’”（`FIELD_NOTE`），第二行怎么用；“图层”里看着一个场时写同一句；帮助里一条 |
| 脚本 | 生态“更多设置”里的“脚本”一段；形态编辑器；信任脚本的问话 | 生态那一段：“脚本是几行 JavaScript：自己定它长在哪里、什么颜色。不会写可以不管”（`SCRIPT_NOTE`）；形态编辑器原来有一句 |
| 融入 | 我的库首页卡片的“⋯”、拖卡片；涂生态的“自然融入” | 我的库首页（能拖卡片的地方）顶上一句（`ARRANGE_NOTE`）；“自然融入”在底部条上，放不下一行，照旧在悬停和帮助里 |
| 自然生成 | 生态页“长在哪里”；河、湖类型的字段；“水系 ⋯”列表里的“· 不自然生成” | 生态页原来有一行；河湖类型那个开关加了说明“关掉后只用在画的、选了它的上面”；`WATER_MANUAL_NOTE` 去掉了“自己出现” |
| 锁定 | 国家、城市、地标的档案；省份、河、地名的底部条 | 三种档案的开关下面各一行（`LOCK_NOTES`：“重新生成国家时，它的领土、档案都不动”）；底部条上的放不下，照旧在悬停里 |
| 时代 | 新建向导“库”一段；资源库首页最上面的卡片；生成的面板 | 向导里：“库定这个世界的时代（人口、国家怎么生成的一套规则）、文化和政体”（`ERA_NOTE`）；首页的卡片没加（卡片上那一行是这个时代的摘要） |

没做的：无人区、倾向、格局、派系、取值这些（资源库里各有字段的说明；底部条上的“无人区”只有悬停）。

**改掉的词**：

- “原文”→“外文名”（第八十一轮定的叫法，资源库里早就这样叫）：省份底部条、格的档案、国家 / 集团 / 城市 / 地标的档案、统治者展开的一行、图层里“中文 / 外文名 / 两者”（界面上的字在 `copy.ts` 的 `NAME_MODE_LABELS`，`core/name-display.ts` 没动）。`src/ui` 里 `grep 原文|比重` 的五十来处其余都是注释和标识符。
- “比重”：界面上只剩政体字段的一句说明（“只选有哪些，比重在国家档案里”→“各占多少在国家档案里”，在 `core/human/gov-kinds.ts` 的字段表里）。
- “维度”→“变量”：人口笔刷的“改一个变量”和两句悬停、“这个时代没有别的变量”。
- README 左上角一行（还写着“资源包”、七类工具）、开头一段、文档索引；使用说明里界面上的“原文”“比重”“上手说明”。

**“新建世界”**（第九十二轮留下的四种叫法）：定成——

- 你做的那个东西叫**世界**；新建它叫**新建世界**（“世界”菜单里以前是“新世界…”，现在是“新建世界…”，和向导的标题一样）；
- “地图”只留在两个固定的名字里：**这张地图**（资源库面板里指现在开着的这个世界）和**我的地图**（存在浏览器里的世界的列表），加上本义（地图上、整张地图）；
- 所以资源库里的“新建地图时选‘我的库’就带上”“只影响新地图”“新地图会用”改成“新建世界时……”“只影响新世界”“新世界会用”；“新世界”作名词照旧（“没保存的新世界”、默认的名字）。

**自救页**（第九十六轮留下的）：开头一句以前一律写“界面没能接着显示。请先导出文件，再重新载入。”，下面“你的世界”那一行又写“重新载入后接着做”“没有东西会丢”——两种说法。现在开头只说发生了什么（“界面没能接着显示。你的世界还在不在、先点哪个，看下面这一行。”），先导出还是直接重新载入只由那一行说（只有没存好的两种叫人先导出）。只改了 `crash-text.ts` 的一句，`rescue.ts` 没动。

## 4. 这一轮动到 `core/` 的两处

都是登记表里给人看的字（第九十三轮说的“给人看的那一层”），不参与计算、不进世界文件：

- `core/human/gov-kinds.ts`：政体“有哪些派系”的说明里“比重”→“各占多少”；
- `core/content/kinds.ts`：河、湖类型的“自然生成”加一句说明。

所以没有做测速对照，也没有跑逐字节对照。`src/state.ts` 多了一个常量 `OVERLAY_DEFAULTS`（“显示”里各个开关一打开页面时的样子，原来写在信号的初值里）。

## 5. 向导里“回到缩略图”

以前是 `向导.scrollIntoView({ block: 'start' })`：把向导的顶边贴到窗口顶上——能滚的那一层（`.modal-backdrop`）被滚到 30 像素（它上面的留白），看起来就是整个向导往上挪了一截。现在只滚那一层回到 0（`scroller.scrollTo({ top: 0 })`）。冒烟里量：展开“自定义…”、滚到底（1529 像素）、点它 → 向导的顶边 30 → 30 像素，页面、`.app` 都没有滚。

## 取舍

- **类别一类不藏**；每一类常用的最多三个。自然只剩“涂生态”一个——“拖动扩张”是第二种手势，“资源”是人文的事。
- **人口笔刷算常用**：三种模式不算简单，但“文化”一类只有三个工具，而且第九十八轮的冒烟要点它。
- **省份画笔、剪刀写的是“划分过省份才露”**，而应用里新建的世界都划分过——等于平时就在。规则留着：空白的世界里它们确实用不上。
- **“删除河湖”平时收着**：画了第一条河、放了第一个湖它就自己出来；选中一条河在“⋯”里也能删。
- **展开只记到关页面**：不为每一处各存一个偏好（任务书要的是一个偏好、一个键）；想长久就开“完整界面”。
- **搜索不抢焦点**：帮助一打开就能按 `?` 关上，比省一次点击要紧。
- **首页的卡片没有做“世界里有就露”**：每一种内容世界里都有（内置的库带来的），认不出哪些是“你的”；搜索、地图上点到直达、别的页面的链接照常到得了。
- **“调整”里不在默认值上的照常露着**：不然在完整界面里改过四季，切回来就找不到是谁改了气候。
