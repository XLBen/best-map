# 第二十六轮的设计

从开发说明里搬来（第四十一轮）。这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## 国家的等级、领土补齐与集团（第二十六轮）

生成的顺序成了 文化圈 → 国家 → **领土补齐** → **帝国、联邦、同盟** → 人口 → 国家的移民（`generate.ts` 用 `registerHumanStage` 把 `claims`、`blocs` 两步挂在 `countries` 后面）。两步都只在重新长国家时（`ctx.countries.mode === 'generate'`）运行，命令之后的整理里没有：手画的无主地之后不会被补上。

**等级与格局**（`countries.ts`）：
- 每国一个等级 `CountryMeta.tier`：`city` 城邦、`small` 小国、`medium` 中等、`large` 大国、`empire` 帝国，面积倍数 `COUNTRY_TIERS` = 0.12 / 0.4 / 1 / 3 / 9（`TIER_NAMES` 是中文名）。自己建的国家没有这一项，算 `medium`。
- 各等级占多少：时代的 `tiers`（`{ city, small, medium, large, empire }` 的权重；没写时 `DEFAULT_TIERS`）。格局 `countryRules.layout`（`'era' | 'mixed' | 'petty' | 'unified' | 'powers'`，`LAYOUT_NAMES`：按时代 / 混合 / 诸侯林立 / 大一统 / 列强并立）不是 `era` 时换成 `LAYOUT_TIERS` 里的比例；`'era'` 不记进 `countryRules`。`tierWeights(era, layout)` 给出生效的比例。命令：`generate_human` / `regenerate_human` 的 `countries.layout`，`generate_countries` / `regenerate_countries` 的 `layout`。
- 个数不随格局变：`plannedCountries(面积, averageCountryKm2(era, fragmentation))`，按“文化 × 陆块”（一个文化在每一块陆地上、邦联那一片以外）能住人的面积用最大余数法正好分完——别的大陆、大岛上住着人的地方有自己的国家，不靠隔海的国家去占；不到 6 格的小岛上的不分（别处都没有地方时才分）。界面的估计是 `estimateCountryCount(world, derived, era, fragmentation, keepLocked)`（同一个算法；联邦切出来的成员邦不算在里面）。
- 先按文化的倾向挑政体，再挑等级：权重 = 等级的比例 × 与政体的 `size` 相配的程度。面积预算 = 平均的国家 × 等级的倍数 ÷ 实际挑出的平均倍数 ×（0.7–1.3），不超过所有能住人的地方的 `MAX_SHARE`（12%，国家少的世界里帝国不吞掉大半），也不超过所在陆块能住人的地方。大的先挑起点，间距按预算的平方根；不放在被邦联那一片围住、不到预算一半的小角落里（别处都没有地方时才放）。
- 扩张分两遍。预算按能住人的干陆地算，别的干陆地（荒漠、山、苔原）算 `LOW_HAB_WEIGHT`（一半）。
  - 第一遍：各国长到预算就停（还没定下的格让给挨着的、没长满的国家）。
  - 第二遍：剩下能占的地方接着长，每国最多到预算的 `FREE_MUL`（4）倍、所有能住人的地方的 `MAX_FREE`（16%）；长满的同样把格让给没长满的邻国。快慢拉平（速度取四次方根），小国的范围放到平均的国家那么大：剩下的归近的，不是大国多占。在起点所在的陆块上可以翻过低于本国下限的山、荒漠（代价 3 倍）、冰川（6 倍）去占那边没人占的谷地，长完把翻过的格放掉（国家只占自己住得下的地方，贴着国境的那一圈由领土补齐补上）。再剩下的是无主地。
  - 下海：一步的代价 ×（1 + 2 × 紧凑）×（1 + 2 ×（1 − 靠海））×（1 + 6 × 游牧）——游牧的几乎不下海，靠海的政体最容易。游牧放宽的宜居度下限只在起点所在的陆块上，别的陆块按时代的下限。长完以后，不在起点的陆块上、超过 8 格、能住人的分量（面积 × 宜居度）不到本国 5% 的地方放掉成无主地（没人住的冰岛、荒岛不归隔海的国家；近海的小岛由领土补齐补上）。
  - 要“住满”的时代（下限不超过 0.02，如现代）：最后没长到的陆地归最近的国家（陆地、海都走，不限宜居度）。
- 邦联：时代的 `relations.confederation`（几片；小数部分是再多一片的可能）。国家不少于 10 个时，挑一个文化组（按能住人的面积），从它宜居度最高的地方往外圈出一片，约一个大国大（max(3, 0.4 × 成员数) 个平均国家，不超过这一组的一半、所有能住人的地方的五分之一）；撒 6–14 个成员（总个数的三成；剩下的至少一半给别的地方，不到 5 个不撒；占总个数里的几个）：中心是一个中等国家（皇帝的本领），别的是城邦、小国，这一片按等级的倍数分成各自的预算；起点一个个挑离已有的起点、离这一片的边都远的格。长的时候只有成员进那一片，成员也不出那一片去占能住人的地方，所以帝国是认得出的一整片。放进 `ctx.confederations`，下一步并成帝国。
- 附庸：最多两层（附庸的附庸）；邦联的成员不当别国的附庸。时代写了 `relations.subjects`（`vassal` 附庸、`protectorate` 保护国、`dominion` 自治领、`tributary` 朝贡国的权重）时按它记 `CountryMeta.subject`（`SUBJECT_NAMES`；省略为附庸）。历史里按种类写一句。`set_country` 的补丁多了 `subject`（`null` 恢复默认；没有宗主时报“先选宗主”，去掉宗主时跟着去掉）。

**领土补齐**（`claims.ts`）：只把无主的陆地写进 `causes.country`；锁定的国家当作邻国算，不往里加。
1. 无主的陆地连成的一块（湖不算）：挨着的陆地都属于同一国时整块归它（海岸不算缺口）；但超过 `SMALL_GAP` 格、与这一国共享的边不到海岸边数的 `ENCLOSED_COAST`（0.5）倍的（半岛的尖、窄地峡那一边）不算被围住，留给第 3 条。挨着两国以上的不填。
2. 不超过 `SMALL_GAP`（8）格的：挨着几国时归共享边界最长的那一国；四周是海的小岛归 `ISLET_STEPS`（3）格海路以内最近的国家。
3. 贴着国境的一圈：时代的 `unclaimed.bandKm`（古代 30、中世纪与奇幻 80、近现代 300；现代、科幻本来就住满）以内的无主格归最近的国家；山、荒漠、冰川都要（国与国之间的冰川山脊归两边），更远的极地冰盖、大漠深处仍然无主。
4. 还没有主的湖归湖岸上最多的那一国，再重算首都一带的人口倍数（`countryPopScale`）。

**碎岛**（`country-layers.ts`）：破碎度够 `ISLET_FRAG` 的海格按 `ISLET_STEPS` 格海路归最近的有主海岸的国家，写进 `derived.country`（编号），`derived.countryIslet` 记下这些格：1 是水面照旧是海，2 是水面也是这一国的领海。`causes.country` 仍然只记陆地。导出的 `countries.bmp` 里碎岛的陆地像素是国家的颜色。

**集团**（`blocs.ts`，`small.blocs: Bloc[]`）：`{ id, kind: 'empire' | 'federation' | 'alliance', name, orig?, nameLocked?, leader, members, color }`。一个国家最多在一个帝国或联邦里、一个同盟里；盟主总在成员里（排第一）。
- 生成按时代的 `relations`：帝国 = 邦联的成员，皇帝国是最大的；联邦 = `relations.federation` 个大国（`large` / `empire` 等级，面积的平方 × 联邦制的政体 4 倍挑），在最大的一块领土上从首都起按离得最远挑 4–12 个起点、按距离分（有省份时整省归一邦），原来的国家是首府所在的成员，别的是新国家；成员邦叫“地名 + 成员的称号”（锁定名字）；同盟 = `relations.alliances` 个，挑最大、彼此不结盟的国家当盟主，沿已有的同盟关系拉三层，再拉进挨着的、同一文化组的国家（一半），附庸跟着宗主、联邦整个进。
- 名字：盟主的地名 + `relations.titles` 的 `empire` / `federation` / `alliance` 里的一个（写法同政体的称号的一种写法，`{name}` 换成地名）；`member` 是成员邦的称号。没写时“帝国”“联邦”“同盟”“邦”。`autoBlocName(world, bloc, era?, others?)`：盟主的地名已经写在别的集团（`others`，省略为世界里的；生成时是这一次的）的名字里时（联邦的首府又是同盟的盟主），换成成员里下一个没用过的地名，都用过时照用盟主的。
- 命令 `set_bloc { id?, patch }`：`id` 省略是新建（`patch` 写 `kind` 与 `members`，`leader` 省略为面积最大的成员，同盟的颜色从 `ALLIANCE_COLORS` 里挑没用过的，帝国、联邦用盟主的颜色），`patch: null` 是删除，别的是改（`kind`、`name`（`''` 恢复自动）、`orig`、`leader`（不在成员里时加进去）、`members`、`color`）。加进一个集团的国家从同一类的别的集团里退出。只改小数据，`Dirty.Human`。
- 整理：`tidyCountries` 里调 `tidyBlocs`（去掉没了的成员、盟主不在了换成最大的成员并跟着换名字、空的去掉）；合并国家时成员里的 b 换成 a，拆分时分出的国家跟着进原来的国家所在的集团；`clearCountries` 去掉 `small.blocs`。
- 给界面的：`blocList`、`blocById`、`nextBlocId`、`blocsOf(world, id)`、`blocOf(world, id, kind?)`；`blocMapColors(world, kinds?)`（国家的编号 → 集团的颜色，不在集团里为 null，“同盟”模式用）；`blocCells(world, kinds?)`（每格的集团编号，−1 没有；片区名用）；`blocBorderGroups(world, kinds = ['empire'])`（帝国的外沿，布局同 `countryGroups`）；`federationColorOf(small)`。`countryMapColors` 里联邦的成员邦用联邦的颜色（第三个参数 `false` 时不换），附庸照旧变浅。

**城市等级**：`cityRankSchema` 多了 `perCountry`（0–1）：每国最多“城市数 × perCountry”座（向下取整），按人口取前几座，别的降到够得上的下一级（只管按比例定的，首都、陪都、点指定的不算）。内置的大城市 `minShare` 从 0.01 提到 0.02（核心先定的 0.03 让中世纪几乎没有大城市，界面那一步改成 0.02）、`perCountry` 0.16667（城市数的六分之一）。

**界面**（第二十六轮的界面部分）：
- **碎岛的着色**：`render/colors.ts` 的 `humanFlat` 在国家、同盟模式里给 `derived.countryIslet` 的格写 A = `ISLET_FLAT`（1，水面照旧是海）或 `ISLET_FLAT + 1`（2，水面也是领海）。这两个值本来淡得看不出，着色器（`renderer.ts` 取 `uFlat` 的地方）认出它们：陆地像素换成 `COUNTRY_ALPHA` 涂满，水面像素是 0 或 `SEA_CLAIM_ALPHA`（`provCell` 本来就把碎岛的陆地像素归那一格，所以一格里按像素的陆海分开）。`countryBorderGroups` 把水面是海的碎岛当作不归谁的海（不在海里绕着碎岛画国界）。“这里”（`Inspector.tsx` 的 `countryHere`）在碎岛上写国名，不写领海。
- **国界纹理的第二个值**：`countryBorderGroups(world, blocs)` 在国家模式（`cellLayers` 里 `o.mode === 'country'`）时把集团写进每格的第二个值：帝国是帝国的编号（`blocBorderGroups`），联邦是联邦的编号 + `FEDERATION_GROUP`（100000，`blocCells(world, ['federation'])`），别的陆地 0，海 −1。着色器：国界两边的第二个值同是一个联邦时近处那一圈浓淡 × 0.4、不画外面那一圈（成员之间的界线细而淡）；在帝国里（0 < 值 < `FEDERATION_GROUP`）的像素，3.5 像素以内四个方向都还是这个帝国、5 像素处有一个方向是别的陆地或别的帝国时，画一道浓淡 0.6 的细线——国界的里侧再一道，像双线；海（−1）不算，海岸上不画。
- **同盟模式**：`state.ts` 的 `ViewMode`、`MapKind` 多了 `bloc`（`parseMapKind` 认它）；`modeDef('bloc')` = `LAYER('bloc')`（同文化，片区名是 `bloc`）；`viewAvailable` 要有国家、有 `small.blocs`；`mapModes` 在“国家”后面、`humanViews` 在“国家”后面各多一项。删掉最后一个集团时（`defs/tools.ts` 里“世界里没有这一层了”的 effect）底图回到国家。`humanFlat(w, 'bloc')`：`blocMapColors` 的颜色（同盟优先，再是帝国、联邦），不在集团里的国家 `NO_BLOC` 灰色，无主地不涂，领海、碎岛同国家模式；`flatByGroup` 同国家模式。片区名 `regionDraws(w, 'bloc')`：`blocCells(w, BLOC_REGION_KINDS)` 上的 `regionLabels`，键 `region:bloc:编号`；按领土、集团、国家、陆海、中文 / 原文、网格缓存。指针：`blocHereText`（“集团 · 国名”），点到集团 `selectBloc`，不在集团里的国家 `selectCountry`。一国在同盟模式里算哪个集团统一用 `ui/blocs.ts` 的 `shownBloc`（`blocOf` 总是帝国、联邦在前，与颜色的先后不同）。图例 `blocLegend`：每个集团一行（成员的人数加起来），最后“不在其中”。
- **国家模式**：`countryDraws` 的结果里多了联邦的名字（`blocCells(w, ['federation'])` 上的 `regionLabels`，键 `region:bloc:编号`），与国名一起按面积排：联邦的名字最大、先排，缩小时成员邦的名字挤不下，放大了才在空处出现；缓存的键多了 `small.blocs`。国家的图例里联邦合成一行（联邦的名字、成员的人数加起来）。
- **缓存**：`set_bloc` 只换 `small.blocs`：`colorSignature` 多了一段集团（编号、种类、颜色、成员），着色、国界纹理跟着重算；`legendFor` 的键多了 `small.blocs`；`countryDraws`、`regionDraws('bloc')` 的键里有它。
- **档案**：`CountryArchive.tsx` 头上写等级（`TIER_NAMES`，没有等级的算中等国家）；颜色一行写“地图上用联邦的颜色”；外交里“从属”（`SUBJECT_NAMES`，没有宗主时禁用；`subjectCommand`：选附庸写 `null`）与“集团”（`BlocLine`：所在的集团的小块，点了 `selectBloc`，× 是 `leaveBlocCommand`——最后一个成员退出时删掉集团；一个下拉框，“加入”列 `joinableBlocs`，“新建”三种，`newBlocCommand(kind, 这一国)`）。集团的档案 `BlocArchive.tsx`（`sheet` 多了 `'bloc'`、`state.ts` 的 `selectedBloc`；集团删掉、撤销掉或换了世界时清掉、关上抽屉；抽屉的标题按种类“同盟档案”……）：名字与原文（`blocNamePatch`，空着恢复自动）、种类（`Seg`）、颜色、盟主、成员（× 退出、“加一国”）、定位（成员的全部陆地格）、删除（先问一句）。“国家 ⋯”的列表里附庸写从属的种类。
- **格局**：`LayoutPick`（`panels/countries.tsx`，一个下拉框，选项悬停写 `LAYOUT_HINTS`）在“国家 ⋯”的生成、重新生成里，也在生成人文的“国家”里（`panels/culture.tsx` 的 `CountryChoice`，向导与“文化 ⋯”共用）。`HumanChoice.countries.layout`（省略为 `era`）写进 `generate_human` 的 `countries.layout`（按时代时不写），`defaultChoice` 读 `countryRules.layout`；`generateCountriesCommand(f, layout)`、`regenerateCountriesCommand(w, f, keep, layout)`（与 `layoutOf(w)` 相同时不写；选回“按时代”时写 `'era'`）。个数的估计不变（格局不改个数）；会生成联邦的时代，滑块悬停的说明（`fragTitle`）加一句“联邦的成员邦另算”。
- **导出**：`countries.csv` 多三列 `tier`（自己建的国家为空）、`subject`（有宗主时；省略的是 `vassal`）、`blocs`（所在的集团的编号，分号隔开）；有国家时多一个 `blocs.csv`（`id, kind, name, orig, red, green, blue, leader, members`——成员分号隔开、盟主在前；没有集团时只有表头）；单独导出的“国家表”是这两个文件。
