# 第三十五轮的设计

从开发说明里搬来（第四十一轮）。这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## 大陆轮廓（第三十五轮）

第三十四轮的大陆还是“椭圆 + 半岛 + 扭曲”：偏圆胖（凸包亏缺区域 0.22、星球 0.31），两块大陆的海岸对不上，板块与大陆块各随机各的，大陆倾斜（第三十二轮）的方向与大陆的形状没有关系。第三十五轮在生成器里让大块的大陆裂开、漂移，板块跟着碎块走，另加三角形的半岛与块与块之间的地峡。都是逐点的（每格只看自己的位置与按种子建好的模型），所以“重新生成一片”照旧只重算圈里的格、缩略图与成品一致、陆地多少单调、“岛多少”不挪海岸。

**裂开并漂移的大陆块**（`core/outline.ts` 放共用的式子与常数；地区 `core/generate.ts`、星球 `core/planet-gen.ts` 的 `buildRifts`、`riftAt`）：
- **哪些块裂**：半径 ≥ 0.14 的母块（“一块大陆”的主块除外），各取一串固定的随机数（`mixSeed(seed, 106)`，前面的块成不成都不改后面的），一半抽到裂开；抽到的一半是红海一类（块中心处两半分开 D = 0.02–0.05）、一半是大西洋一类（D = 0.15–0.4）。
- **裂谷线**：块的局部坐标里一条抛物线（过中心附近、弯曲 kappa = ±0.8 / r）再加按漂移前的位置取的分形噪声（`WIGGLE`：幅度 0.035、频率 3.5、六层）：u(p) = 法向距离 + kappa·沿线距离² + 噪声。
- **两半绕同一个极转开**：极在裂谷线的延长线上（红海一类在块边附近：离中心 0.8–1.3 个半径，只裂开一半，越往极越窄；大西洋一类在 3–6 个半径以外，差不多是平移），+ 那一半转 +phi、− 那一半转 −phi，块中心处分开 D；离极不到 0.4 个极距时渐渐不转、过了极不转（不压出接缝）。星球上就是欧拉极旋转（Rodrigues 公式，极离块中心最多 90°）。
- **逐点的逆映射**（`riftAt`）：漂移后的一点 q 先按它在原来的裂谷线的哪一边（两半对称地转开，中线就是原来的线）定是哪一半，再转回去得到漂移前的位置 P。这一族块（母块与它的半岛）的场、缝合线、大陆的低频噪声（块的噪声、近地表的分形起伏、隆起与盆地、陡崖分段、凹陷、丘陵）都在 P 上取，所以两岸的海岸像拼图一样对得上。离这一族块远了（别的块占上风、或离开它的范围）渐渐回到 q 上取（`wN`），不出接缝。
- **切口**（`eHard`、`eSoft`）：往这一半里面量离切口 x（= ±u(P)）。定海陆的大陆场 c 至多 `eHard(x)`：x ≥ 0 一侧是 0.8 + 8x 的台阶（地壳高度约 +900 m：海平面在 −70 到 210 m、海岸噪声 ±180 m、近地表起伏都压不过它），外侧先是宽的大陆架（地壳高度 −420 到 −600 m，宽 min(0.03, 0.45·半缝宽)：海底的后处理把它当陆壳）、再是陆坡（min(0.012, 0.3·半缝宽)）、深海。所以海岸就在切口上。造山、基准面、丘陵用的“形状”场 cs 至多 `eSoft(x)`（从海岸的 0.02 往内陆缓缓抬起）：裂开的海岸是低平的被动边缘，往里 0.1–0.2 以内大陡崖至少有一半（`ReliefInput.esc`，`ESC_K` = 0.5：整段都有时沿海低地少了三个点，见下面“和地球比”）。缝不到半格时把切口往外挪（`closeGap`），不留一串单格的海；缝里与切口内侧 0.012 以内近地表的起伏压低（`reliefNear`）。
- **洋中脊**：缝里按漂移后离原来的裂谷线的 |u| 抬起洋中脊（半宽与板块的洋中脊相同），洋底的年龄就是 |u|，两侧对称。两半的板块之间不再按板块的平分线画洋中脊、裂谷（`sib`）。
- **不压到别的块上**（`riftClear`）：这一族块漂移前的格点（场 > −0.1，33 × 33）移过去以后，别的块的场 < −0.3、或者不比没移时大 0.02 以上；不行就把 D 乘 0.75 再试，方向试四个、取开得最大的；大西洋一类开不了时改成红海一类再试，还不行就不裂。“几块大陆”的块挨得近，抽到的约六成裂得开（30 个种子里大块的 28% 裂开）。试过开不了时按最窄的红海一类硬裂：几块大陆连成一块（区域 9 号种子最大的陆块占陆地 97%），星球上两格宽的缝两岸对不准。
- 穹隆（第三十二轮）跟着它所在的那一半走。

**板块跟着碎块走**（`fragmentPlates`）：落在碎块中间（漂移后这一族的场 > 0.4）的随机板块去掉，两半的重心各放一个板块（权重 0.035），速度是漂移的方向（地区：绕极转的速度方向；星球：同一根欧拉轴、一正一反），比一般的板块快（0.9–1.2）：前缘因此是汇聚的安第斯式大陆边缘，裂开的那一岸是被动的，第三十二轮的大陆倾斜把河引向裂开的那一岸。碎块边上的板块留着（与以前一样有块内的交界、山带）。试过把碎块上的板块全去掉：碎块上没有了块内的山带与高原，区域 2000 m 以上 11% → 9%、高原指数 1.1% → 0.85%。

**三角形的半岛**：四成的半岛（`mixSeed(seed, 107)`，半岛的位置、大小不变）沿长轴往外收窄：宽度从 1 收到 1 − tri（tri = 0.7–0.9），整体加宽 1.25 倍（`triWidth`）。

**地峡**（`buildIsthmi`）：“几块大陆”“一块大陆”“破碎大陆”“内海”每张图 1–2 处（`mixSeed(seed, 108)`）：候选是没裂开的母块与裂开的两半（漂移后），两两沿连线走：从两块场 ≥ 0.2 的地方起、中间隔着海、长 0.04–0.4 的，按长短挑；两端再往块里伸 0.06，中点往一侧弯（长度的 0.25–0.5），16 段的二次贝塞尔折线，半宽 0.012–0.018（星球 0.015–0.022）。不把太多块连成一块：本来就挨着的块（中间没有海、场重叠）先算一块（并查集），连起来的块加起来不过所有块的四成。中线上大陆场是 0.8（一定是陆地）、到半宽处 0、再往外 −3·超出的距离（窄的岛架）；不加大陆的噪声，近地表的起伏压低七成，裂谷不切断它。星球上按方向量距离（扭曲有沿半径的分量）。地峡只在原来的噪声里有：“重新生成一片”圈到地峡上时那一片另一套噪声里没有地峡，可能断开。

**都是逐点、按种子的**：裂开、地峡都在建模型时定好（按种子、类型，与格数无关），采样每格只看自己的位置；`blockField`（造岛弧、火山锥、板块栅格的上下盘、“对面是不是大陆”）按漂移后的位置、不加弯曲噪声。重新生成一片的格用同一个漂移（另一套噪声的弯曲）。星球形态的布局脚本加的块不裂。

**统计**（`core/stats.ts` 的 `landShape`，`tools/realism.ts` 的 `outlineStats`、`riftCoastMatch`）：
- 凸包亏缺：大陆（面积 ≥ 陆地 3%、至少 100 格的陆块）1 − 面积 / 凸包面积，按面积加权；凸包按格心（星球投到陆块中心的切平面上，心射投影）再往外扩半个格距。
- 半岛指数：开运算（往里缩 3 步、再往外长 3 步）去掉的那部分占大陆的比例。
- 地峡：扭曲后离地峡中线不到 0.3 个半宽的格（至少 3 格）九成以上是陆地算留下来了；有地峡的种子的比例。
- 两岸还原漂移后的距离：海岸线（陆格与海格之间的边上按陆度插值的过零点）上漂移前在这一族块里面（场 ≥ 0.25）、离切口不到 0.012 的点，按漂移前的位置分两半，只比两半沿裂谷线都有海岸的那一段；每点到另一半最近的点的平均距离（两个方向再平均）÷ D，每处裂开一个数。星球上漂移前的位置按方向比（投回球面：扭曲有沿半径的分量，转动不改它）。

六个种子的平均很飘（一个种子的最长流路 ÷ 直径在 0.4–1.4 之间），所以区域另跑了 12 个种子（`--only region --raster 0 --seeds 1-12`，02b7adf → 这一轮）：200 m 以下 28.4% → 28.6%、2000 m 以上 12.4% → 10.8%、最大 / 前五流域 5.9 / 20.4% → 5.3 / 19.2%、最长流路 ÷ 直径 0.78 → 0.75、L/√A 1.95 → 1.93、内流区 8.7% → 8.0%、湖面 1.98% → 1.86%、高原 1.52% → 1.59%、低平地 14.9% → 14.1%、低处大干流两旁 59.4 → 61.4 m、分汊 43.0% → 43.1%、裂谷湖长宽比 3.9 → 3.2。

- **变好的**：大陆不再圆胖（凸包亏缺区域 0.22 → 0.34、星球 0.31 → 0.36，在地球的非洲与欧亚之间），半岛多了；2000 m 以上、最大与前五流域都更近地球；裂开的两岸对得上（两岸距离只有 D 的 7–8%）。
- **最长流路 ÷ 陆块直径变低（0.91 → 0.80、0.92 → 0.84）**：直径按出口所在的陆块算，地峡把两块大陆连成一块，直径变大了，河却不过地峡（南美的亚马孙按地球的算法是除以南美的直径，不是美洲）。12 个种子不加地峡时 0.79、第三十四轮 0.78。
- **L/√A 没有变好**（计划说新的轮廓可能有帮助）：约 1.9 / 2.0，与第三十二到三十四轮一样。裂开让大陆变窄，倾斜把河引向裂开的一岸，但流域照样被裂开的两岸、地峡、半岛分成一块块，干流不比以前长；试过把倾斜加强（800 → 1000 m）或放远（0.2 → 0.28）：L/√A 1.93 / 1.94，低平地少了 4–6 个点、低处大干流两旁高出 69 / 73 m，不划算，没改。
- **区域内流区、高原、200 m 以下**：6 个种子 8.3% → 6.8%、1.12% → 0.94%、28.3% → 30.1%，12 个种子 8.7% → 8.0%、1.52% → 1.59%、28.4% → 28.6%，在种子的抖动以内。
- **大陡崖的强弱**（`ESC_K`）：裂开的海岸往里整段都有大陡崖时（12 个种子）200 m 以下 25.7%、低平地 11.7%、低处大干流两旁 64.8 m；不加时 30.7%、16.7%、57.3 m，最长流路 ÷ 直径 0.70；一半时这几项与第三十四轮差不多，取一半。
- **区域的裂谷湖**：陆上的裂谷湖只在三个种子里有（共 6 个），长宽比 3.7（第三十四轮靠一个 9.0 的湖凑到 5.8；12 个种子 3.9 → 3.2），慢测试区域的这一项放宽到 > 3；低处大干流两旁 60.2 m（12 个种子 59.4 → 61.4），放宽到 < 62。
- **板块**：碎块中间的随机板块去掉以后碎块上没有了块内的交界，山带、高原少了；碎块边上的留着、碎块的板块走得快一些（0.9–1.2），2000 m 以上、高原与第三十四轮差不多（试过的几种：全去掉 11.4% → 8.8%、0.85%；场 > 0.4 才去掉、速度不变时 10.8%、1.25%、最长流路 ÷ 直径 0.85；都改时 11.2%、1.20%、1.02，区域 6 个种子）。
