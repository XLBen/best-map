# 第二十三轮的设计

从开发说明里搬来（第四十一轮）。这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## 国家与政体（第二十三轮）

人文的第三批：领土按格画（可以有无主地），一个陆地省只属于一个国家，每国一份档案（名字、颜色、旗帜、首都、政体、主流文化与兼容的文化组、派系、外交、统治者、建国年份、历史）。生成的顺序是 文化圈 → **国家** → 人口 → **国家的移民**。政体只是“生成的倾向 + 说明”，不带游戏数值；派系由时代定义，影响力由人口构成大致算出。都只读自然的推导，不改地形（`core/human/`）。

**两种内容**（`human/government.ts` 的格式，`human/gov-kinds.ts` 登记；`store: 'content'`，命令 `set_content`，改了重算到 `human`；内置的在 `core/packs/governments/`）：

| 种类 id | 全称 | 资源包的段 | 世界里 | 内置的 |
|---|---|---|---|---|
| `government` | 政体 | `governments` | `small.content.government` | `BUILTIN_GOVERNMENTS` |
| `faction` | 派系 | `factions` | `small.content.faction` | `BUILTIN_FACTIONS` |

内置的不是总在的：在资源库里启用，或者生成国家时自动复制进来（`countries.ts` 的 `ensureGovContent`：时代的 `governments` / `factions` 列着的内置项；没列时是 `eras` 里写了这个时代的；世界里一个这个时代的政体都没有、内置的也没有时，复制全部内置的政体，保证生成得出来）。这个时代能用哪些：`eraGovernments(small, era)` / `eraFactions(small, era)`（时代列了的、世界里有的；没列时是世界里 `eras` 写了这个时代或不限时代的；再没有时是世界里全部的——时代还没有自己的政体、派系时借用别的时代的）。派系同样：内置的里一个这个时代的都没有、世界里也没有时复制全部内置的。

**政体**（`governmentSchema`）：

```json
{
  "id": "feudal-monarchy",
  "name": "封建君主制",
  "category": ["monarchy"],
  "description": "国王把土地分封给贵族……",
  "color": "#9a4b3c",
  "title": {
    "default": { "zh": "王国", "orig": "Kingdom of {name}" },
    "steppe": { "zh": "汗国", "orig": "{name} Khanate" },
    "eastern": { "zh": "国" }
  },
  "rulerTitle": { "default": "国王", "steppe": "可汗" },
  "eras": ["medieval"],
  "weight": 3,
  "size": 1, "expansion": 0.3, "coastal": 0, "urbanization": 1, "cohesion": 0.5, "vassals": 0.45, "nomadic": 0,
  "emblems": ["crown", "lion", "tower"],
  "layouts": ["cross", "tricolor-v"]
}
```

- `category`：类别（几个标签，1–8 个，每个不超过 16 字）。建议用英文 id：`monarchy` 君主制、`republic` 共和制、`theocracy` 神权、`tribal` 部落、`federation` 联邦、`empire` 帝国、`oligarchy` 寡头、`nomadic` 游牧、`dictatorship` 独裁、`democracy` 民主、`communist`、`fascist`、`corporate`、`magocracy`（`CATEGORY_NAMES` 有中文名，`categoryName(c)` 不认识的照写）。派系的基础影响力、旗帜默认的纹章按它。
- `title`：国家的称号。写法：一个字符串（`"王国"`）、`{zh, orig?}`（`orig` 是原文的写法，`{name}` 换成国名地名部分的原文：`"Kingdom of {name}"`、`"{name} Khanate"`）、或按文化换说法的表（键是**文化 id、文化组 id 或 `default`**，先看文化、再看文化组、最后 `default`，都没有时取第一项；值是前两种写法之一）。中文里写了 `{name}` 时换进去（`"大{name}朝"`），没写时接在后面（“X王国”）。`pickTitle(title, culture)`、`titled(base, title)`。
- `rulerTitle`：统治者的称号，写法同 `title`（只用中文）。省略时档案里没有称号。
- `eras`：只在这些时代里有（省略时不限）。`weight`：被挑中的多少（省略为 1）。
- 生成的倾向（都有默认值）：`size` 国土的相对大小（0.05–10，1 平均；帝国 3、城邦 0.15）；`expansion` 扩张性（0–1：越大越容易越过文化的边界，境内的异族越多，人口一步后还往异族的地方掺主流文化的人）；`coastal` 偏海岸（0–1：起点挑海边，往内陆长的代价 × (1 + 3·coastal)）；`urbanization` 城市化（0–5：首都一带的人口倍数，第二十四轮放城市也用）；`cohesion` 紧凑（0–1：下海的代价 × (1 + 3·cohesion)，越远越难长）；`vassals` 收附庸的可能（0–1）；`nomadic` 游牧（0–1：能占宜居度低于时代下限的地方，下限 × (1 − nomadic)）。
- `emblems` / `layouts`：旗帜偏好的纹章、样式（`FLAG_EMBLEMS`、`FLAG_LAYOUTS` 里的 id；省略时按类别）。

**派系**（`factionSchema`）：

```json
{
  "id": "merchants", "name": "商人", "color": "#c9a227", "description": "行会与商家……", "eras": ["medieval"],
  "base": { "republic": 1.4, "oligarchy": 1, "monarchy": 0.35, "default": 0.3 },
  "drivers": [{ "coastal": true, "weight": 0.8 }, { "dimension": "religion", "value": "sun-faith", "weight": 0.5 }]
}
```

- `base`：政体的类别 → 基础影响力（0–10）。国家的政体有几个类别写在这里时取平均，一个都没写时用 `default`（再没有为 0）。
- `drivers`：来自人口的部分（最多 16 条），每条 = `weight`（−10–10）× 这部分人占国家人口的比例。这部分人：`dimension` + `value`（某一维取某个值，如 `religion` = `sun-faith`）、`culture`、`cultureGroup`、`primary: true`（主流文化）、`minority: true`（不在兼容文化组里的人）、`coastal: true`（住在海边的格）；写了几项时取比例最小的那一项。
- 影响力（`countryFactions(world, id)`）：每个这个时代的派系 max(0, 基础 + Σ 来源)，再归一（加起来是 1，三位小数）。档案里自己定过（`set_country {factions}`）时照用定的。

**时代多的几项**（`eraSchema`，都可以不写）：`governments` / `factions`（能用的 id，见上）；`countryKm2`（“统一 ↔ 分裂”在正中时一个国家平均占多少 km² **能住人的**陆地，省略为 `COUNTRY_KM2` = 160 万；地球大小的中世纪星球上约 60–90 个国家）；`years`（`[最早, 现在]`，建国年份在这里面，省略为 `[500, 1000]`）。已有的 `unclaimed.minHabitability`（宜居度低于它的格不归国家，游牧的政体放宽）与 `seaClaimKm`（领海）现在起作用。

**文化多的一项**：`tendencies.government`（与别的维度同一种写法：`[["feudal-monarchy", 3], "theocracy"]`）——这个文化的国家更可能是哪些政体；写了时没写到的政体 × 0.15，没写时按政体的 `weight`。

**地名风格可以多写两类**（都可以不写）：`country`（国名的地名部分）、`person`（人名，统治者用）。没写时：音译式拼一个词根（原文首字母大写，中文是音译）；模板式国名用 `region` 的写法（避开“地区、之地、地方、道、一带”结尾的），人名从词表里取两个一两个字的词（`human/country-names.ts` 的 `countryBase`、`personName`）。

**写内置的政体与派系**（给写内容的人）：

1. 放进 `core/packs/governments/<名字>.json`，写 `{ "governments": [...], "factions": [...] }`（一般一个时代一个文件；几个时代共用的政体写一次，`eras` 里写上几个时代；同一个 id 只算先列的文件里的那一个），在 `core/packs/governments/index.ts` 的 `FILES` 里加一行（资源库里按这个先后列出）。时代里用 `governments` / `factions` 列出 id。
2. id 用小写字母、数字、连字符；名字用通用的政治学叫法，不超过 20 个字；说明自己写、一两句，不搬游戏文本，不带游戏数值。
3. 每个时代 5–13 种政体、3–7 个派系，时代的 `governments` / `factions` 都列出来（测试查：至少 5 种、3 个，列着的都在 `eras` 里写了这个时代，每个内置项都有时代在用）。
4. 类别只用 `CATEGORY_NAMES` 里有中文名的那 14 个（派系的 `base` 也按它们写；不认识的类别界面上照写英文）。几个类别取平均：想让某个派系在这种政体里强，就少写几个类别（贵族共和国只写 `oligarchy`，免得商人借 `republic` 压过贵族）。
5. 称号：都写 `default`，再按文化组、文化换说法——中文的称号（草原的“汗国”、中东的“苏丹国”“哈里发国”、东亚的“朝”“国”、汐见人的“幕府”、兽人的“大部落”、矮人的“氏族王国”、异星集群的“巢群”“菌网”），原文按那种语言（`Royaume de {name}`、`Königreich {name}`、`Regnum {name}`、`{name} Khanate`、`Sultanate of {name}`）。按文化 id 写的先于文化组。不合这个文化的政体，默认的称号写平常的（苏丹制对西欧的文化是“王国”，武家政权对别的文化是“摄政国”）。统治者的称号同样按文化换（可汗、罗阇、埃米尔、沙皇、将军、山王）。
6. 倾向的数字：`size` 帝国 2.4–3.5、城邦 0.15–0.2、商业共和国 0.35；`coastal` 商业共和国、自由城邦、殖民帝国 0.7–0.9；`nomadic` 游牧的 0.85–1，部落 0.5，别的 0–0.15；`cohesion` 是越远越难长：城邦、精灵、矮人 0.6–0.9，一般的 0.25–0.45，游牧、殖民帝国、星际联邦 0.1–0.15（现代的低一些，宜居的地方才长得满）；`weight` 按这个时代里常见的多少，只该某些文化用的（游牧汗国、苏丹制、武家政权、蜂巢意志）写得小（0.15–0.3），由文化的倾向抬上去。共用的政体（几个时代都有的）的 `weight` 也是共用的：一个时代里不该常见的就不共用（绝对君主制不进现代）。
7. 文化的 `tendencies.government` 写在文化组的文件里（组里的文化照抄），一张表里写下这个组在各个时代的政体（每个时代只认它有的）；写了某个时代的就至少写两种，不然那个时代这一组的国家全是同一种（测试查）。权重要盖过政体的 `weight`：`weight` 小的（游牧汗国 0.3）要写到 15–20 才成为这一组的主流。个别文化自己写一份（汐见人的武家政权、巴迪亚人的游牧、达里安人的帝国、齿轮侏儒与余烬提夫林的法师统治），写的是整份（照抄组的再改几项）。
8. 时代的 `countryKm2`：青铜与古典 45 万（再加上 `unclaimed.minHabitability` 高，小国林立、大片无主）、中世纪与近世 150 万、近现代 120 万、现代 60 万（地球大小的星球上约 190 个国家）、奇幻 130 万、科幻 90 万；`years` 写那个时代的年份。
9. `countries.test.ts` 用内置的中世纪与西欧、东亚、草原三组生成，记着金标准：改了中世纪的时代、这几组文化、中世纪的政体与派系的数据就要重录那两组哈希（`RECORDED`，同 `population.test.ts`）；`governments-builtin.test.ts` 查全部内置的政体与派系（见下）。

- 派系的来源：青铜与古典按宗教（河谷诸神、城邦众神、圣火教、祖灵信仰）、海边、少数群体；近现代按民族认同（帝国认同 → 保守派、公民国族 → 自由派与工商界、本族与泛族认同 → 激进派、教门认同 → 教会）；现代每个派系是意识形态光谱上相邻的几种（革命左翼 = 无政府主义、革命社会主义、威权社会主义；民族主义派 = 威权民族、极端民族、君主主义……，权重 3.5–4，所以派系的影响力大致就是国内意识形态的构成）；奇幻按种族与神祇（法师 ← 精灵、侏儒、提夫林、秘法之眼；氏族长老 ← 兽人、矮人、地精、龙裔）；科幻按“派系”那一维（联邦派 → 联邦主义者、企业联合 → 财团……）与物种。
- 文化的倾向（摘要）：草原在青铜与古典是游牧联盟、部落联盟，中世纪是游牧汗国；地中海是城邦、寡头共和制、商业共和国；中东是神王制、神庙国家、苏丹制、神权（哈里发国）、现代的神权共和国；东亚是早期王国、帝国、现代的社会主义共和国与一党制；北欧是酋邦、选举君主制、君主立宪；东欧是部落联盟、公国、贵族共和国、沙皇国；中美、安第斯是神王制、早期帝国、总统共和制；奇幻的种族各用自己的（精灵议会、氏族王国、兽人部众、龙主统治、自由城邦）；科幻的晶岩、孢林、甲巢诸族多是蜂巢意志，甲巢也常是军事政府，潮汐诸族多是星际联邦（潮汐联邦）。
- 按各时代默认的文化组在 1.2 万格的地区（陆地约 3100 万 km²）/ 2 万格的星球（约 1.96 亿 km²）上生成：青铜与古典 36 / 253 国（干陆地有国家的约六成，宜居度低于 0.25 的大多无主）、中世纪 18 / 86、近现代 26 / 118、现代 47 / 251（地区上九成）、奇幻 19 / 101、科幻 29 / 159。
- `governments-builtin.test.ts` 查：格式；类别都有中文名；说明一两句、不超过 50 字、不用“真的 / 直接 / 其实 / 系统 / 一下 / 真正”；纹章、旗帜样式认得；称号的键是文化、文化组或 `default`，都有 `default`，原文都有 `{name}`；每个时代的政体、派系（个数、名字不重复、色差：政体 > 12、派系 > 18）、`countryKm2`、`years`；派系的来源认得；文化的政体倾向都是内置的、在这个文化能用的时代里有；每个时代按默认生成：只用这个时代的政体与派系，国名、统治者的称号按文化换说法，建国年份在 `years` 里，至少 4 种政体；青铜与古典比中世纪国家多、无主地多，现代比中世纪国家多、干陆地八成五以上有国家；草原多游牧的政体、奇幻的种族多用自己的政体、异星种族多是蜂巢意志（三个种子合起来数）；确定性。

**世界里的数据**（`world.ts`）：

- `causes.country`（Int32，每格的国家编号，−1 无主）：只记陆地（湖面也算）；海不记（领海是推导）。生成国家时才建，撤销到那之前时去掉（`UndoRecord.dropArrays`），进撤销、检查点、快照。删除国家、删除人文、新建世界时填 −1（数组留着）。
- `small.countries`：编号（1 起）→ `CountryMeta`；`small.nextCountry`：下一个编号。生成过国家才有。
- `small.human.countryRules`：`{fragmentation, seed}`——“统一 ↔ 分裂”（0 统一：国家平均大 8 倍；1 分裂：小 8 倍；0.5 按时代的 `countryKm2`，`sizeFactor(f)` = 8^(1 − 2f)）与种子。有它才算“有国家”。
- `CountryMeta`：

- 旗帜（`human/flags.ts`）：`layout` 是 `FLAG_LAYOUTS`（`plain bicolor-h bicolor-v tricolor-h tricolor-v cross nordic saltire canton chevron quartered border diagonal stripes`，`LAYOUT_COLORS` 是每种要几种颜色），`colors` 1–4 种（底色在前，少了用底色），`emblem` 是 `FLAG_EMBLEMS`（`star sun moon crown cross circle tower tree sword eagle lion wheel mountain wave`）。`makeFlag(seed, 国家的颜色, {categories, layouts, emblems})` 生成（纹章的颜色与底色分得开），`flagSvg(flag, w?, h?)` 画成 SVG 字符串（界面、导出共用）。
- 推导：`derived.country`（Uint16，每格的国家编号 = `countryList` 的下标 + 1，0 无主；陆地按 `causes.country`，海按时代的 `seaClaimKm`：从海岸往外按 km 走，离谁家的海岸近、不超过这么远的海归谁，离无主的海岸近的不归谁）。只在有国家时有；领土、陆海、国家的编号、领海都没变时照用上一份。`COUNTRY_DERIVED`；不进金标准的 `digestWorld`（没有国家的世界没有它）。

**生成**（`human/countries.ts`，两步：`countries` 在人口之前、`country-mix` 在人口之后，`humanStages()` 是 `['cultures', 'countries', 'population', 'country-mix']`；`GenContext.countries` 是 `CountryPlan {mode: generate | keep, rules, keepLocked}`，没有时这两步什么都不做，与第二十二轮逐值相同）：

1. **几个国家**：能住人的干陆地（宜居度 ≥ 时代的下限、不是锁定的国家的）面积 ÷（`countryKm2` × `sizeFactor`），最多 `MAX_COUNTRIES` = 512 个；按各文化能住人的面积（km² × 宜居度）分给文化，分到 0.4 个以上的至少一个。
2. **政体与起点**：每个文化按 `govWeights`（政体的 `weight` × 文化的 `tendencies.government`）挑够数的政体，大的先挑起点：本文化的地盘里宜居度 × (1 + 0.35·噪声) × 海岸（偏海岸的政体在海边 × (1 + 2·coastal)，内陆 × (1 − 0.6·coastal)）最高、离已有的起点不近于 0.6·√(文化的面积 / 个数) km 的格（挑不出时放宽）。
3. **往外长**：各国从起点按代价同时长（一个 Dijkstra，每格归先到的），走一条边的代价 = 文化圈的那一套（`cultures.ts` 的 `edgeCosts`）× 进别的文化（同组 × (1 + 0.6·(1 − expansion))，别的组 × (1 + 2.5·(1 − expansion))）× 内陆（× (1 + 3·coastal)）× 下海（× (1 + 3·cohesion)）÷ 强弱（√size × 0.85–1.15）× 越远越难（1 + cohesion · 已走的 / (2R)，R = √(平均面积 × size / π)），超过 20R 不长。宜居度低于下限 × (1 − nomadic)（最低 0.002，冰盖谁都不占）的干陆地不进；海能穿过、不归国家；锁定的国家的格不进。
4. **整理**：湖（连成一片的湖面）归湖岸上格数最多的那一国（没有时无主）；不连着首都、小于 max(3 格, 这国的两成)、挨着别国的小块并给接壤最多的邻国（邻国按自己的下限占不了的格成无主地）。
5. **档案**：编号接着 `nextCountry`；主流文化 = 起点的文化，兼容的文化组 = 主流的组 + 国土里能住人的面积占三成以上的组；颜色 = 主流文化的颜色按序号挪色相、深浅（与已用的不重）；旗帜、名字（主流文化的风格起地名，避开已有的国名，接政体的称号）、统治者（人名 + 称号）、建国年份（`years` 里，偏近）。
6. **外交**（只在新长出的国家之间；邻国 = 陆上接壤或隔一格海）：附庸——从小到大看，旁边大 3 倍以上、自己不是附庸的国家按它的 `vassals` ×（同组 1、别的 0.5）×（自己的 size ≤ 1 时 1、否则 0.5）的概率收下（没有附庸链）；同盟、敌对——亲近 = 同一个文化 2、同组 1、兼容的组有重的 0.5、别的 −1，同一类政体再 +0.5；亲近 ≥ 1 时三成结盟（各不超过 3 个），≤ 0 时三成半敌对（各不超过 2 个）。
7. **历史**：“{年份} 年，{文化}人建立{国名}。”＋“后来成为{宗主}的附庸。”／“此后向外扩张，境内也住着{异族}人。”（扩张性 ≥ 0.6、有占一成以上的不兼容文化）／“靠海上的贸易立国。”（偏海岸 ≥ 0.6）＋“与{…}结盟。”“与{…}不和。”（`historyText`）。
8. **人口**（人口一步之前）：`ctx.popScale` = 1 + 1.2 × 城市化 × e^(−到首都的距离 / R)，R = max(两倍格距, 0.15 × √国土面积)（只在国土里、6R 以内）。**国家的移民**（人口一步之后，`country-mix`）：扩张性 0.06 以上的国家，占多数的文化组不兼容的有人的格掺进 0.35 × 扩张性 的主流文化的典型群体（官吏、移民），手改过的格不动。
- `mode: keep`（重新生成人文、挪发源地、不换国家时）：用现有的领土，只按它调人口（首都一带、移民）。
- 锁定的国家（`keepLocked`）：领土、档案都留着；外交里指向重新生成掉的国家的去掉。

**省份跟着国界**（`provinces.ts`）：一个陆地省（陆地、无人区、湖省）只属于一个国家（无主也算一个）；海省不跟着国界（领海按格推导）。`countryKeys(world, pland)`（按格分是陆地的格是它的国家，海是 −2；没有国家时为 null，什么都不变）：
- 自动划分（`partition`：起点的间隔、生长、小省并入）与补格（`fillUnassigned`：修补、湖省的整理）都不跨国界。
- `fitProvincesToCountries(world)`：跨国界的省里格数最多的那个国家留着这个省，别的国家在这个省里的格按连成的块：小块（不到目标大小的四分之一）并进挨着的、同一个国家、同一类、没锁定、只属于这个国家的省里接壤最多的那个，别的成新省（编号接着往后，按格起名，名字由命令的 `provinceNames` 记下）。锁定的省照样切（锁定只管自动重划）。只看原因，执行、重放一样，不用另记修补。改了领土的命令、生成国家、划分省份之后都调它。
- 涂省份（`assign_province`）涂进已有的陆地省：这些格跟着这个省换国家；新建的省按国界切开。并省（`merge_province`）：并进来的格跟着 `into` 的国家。这样改了国家的这两条重算到 `Human`（国家的一层要重算）。
- 重新生成国家后省份只切不并：要整齐时重新划分省份。

**命令**（`Dirty.Human`：只重算人文的几层与名字；撤销记 `country`、`province`，生成的几条另记人口的四个数组）：
- `generate_human {…, countries?: {fragmentation?, seed?}}`：写了 `countries` 就同时生成国家（`fragmentation` 省略 0.5、`seed` 省略为人文的种子）；不写时没有国家（已有的去掉）。历史“生成人文“中世纪” · 3 个文化组 · 4.0 亿 · 14 个国家”。
- `regenerate_human {…, countries?}`：有国家时用现有的领土；写了 `countries` 时国家也重新长（锁定的留着）。`move_hearth` 同前者。
- `generate_countries {fragmentation?, seed?}`：生成国家（已有时整个换掉，锁定的也不留），参数从默认起；人口按国家重新分（手改过的格不动，等于带国家的 `regenerate_human`）。“生成国家 · 14 个”。没有人文时报错。
- `regenerate_countries {fragmentation?, seed?, keepLocked?}`：按记着的参数重新生成，写了的几项换掉；`keepLocked` 省略为 true。“重新生成国家 · 14 个”。
- `remove_countries {}`：去掉国家（人口不动）。“删除国家”。`remove_human`、`set_worldgen` 的新世界也去掉国家。
- `paint_country {cells, country: id | null}`：领土笔刷，只画陆地（湖面也算），null 是无主。“领土“X” · 36 格”“无主地 · 36 格”（格数是真改了的）。
- `new_country {cells?, name?, orig?, culture?, government?, color?, flag?}`：新建（档案自动生成：主流文化 = 这些格里人最多的文化，政体 = 时代里 `weight` 最大的，首都 = 人最多的格；写了名字时 `nameLocked`）。可以没有领土。“新建国家“X” · 12 格”。
- `merge_countries {a, b}`：b 并进 a（领土、兼容的文化组，指向 b 的外交改指 a）。“合并国家“B” → “A””。
- `split_country {id, cells?}`：cells（这个国家里的格）成新国家（同样的文化、政体、兼容的组）；不写时按离得最远的两格分成两半，没有首都的那一半成新国家。“拆分国家“X” · 分出“Y””。
- `set_country {id, patch}`：`patch` 的每一项都可以不写——`name`（'' 恢复自动；`orig` 跟着 `name`）、`color`、`flag`（null 按种子重新生成）、`government`（没改过名字时换称号）、`primaryCulture`（没改过名字时按新文化的风格重起地名；它的组加进兼容的组）、`acceptedGroups`（主流的组总在）、`factions`（null 恢复自动）、`overlord`（null 不再是附庸；不能绕成圈）、`allies` / `rivals`（整份换掉，两边都改，同盟与敌对互斥）、`ruler {name, orig?, title?}`、`founded`、`history`、`locked`。“国家“X” · 政体、改名”。
- `remove_country {id}`：领土成无主地，外交里去掉。“删除国家“X””。
- `move_capital {id, cell | null}`：首都挪到这国的一格（锁定）；null 恢复自动。“挪动首都 · “X””。第二十七轮起界面上从城市档案（“设为首都”）、格的档案（“在这里建首都”：每步之后的 `tidyCities` 在首都格上补一座城）、国家档案（恢复自动）发出，没有单独的工具。
- 每条之后整理（`tidyCountries`）：首都不在领土里了换成人最多的格（没有人时离中心最近的，不再锁定；没有领土时没有首都），外交里指向没了的国家的去掉、同盟敌对两边补齐。

**改地形以后的修补**（`country-edit.ts` 的 `repairCountries`，在 `commands.ts` 的 `applyTerrain` 里、修补省份之前，只看原因，不用另记）：变成海的格不再归哪国；新长出的陆地从挨着的旧陆地按步数往外，归最近那一格的国家（挨着的是无主地就无主；四周全是海的新岛无主）。别处、手改的不动；要整体重来时重新生成国家。

- **地图**（第二十五轮起是地图模式，见“地图模式与指针”）：国家模式里 `ColorOptions.borders` 也开着（省界）、`countryBorders`；`renderer.provinceAlpha` 0.45（省界淡）；国家底图 `flatByGroup`（水面的像素只取水面格：领海是一圈淡色）。叠加层的 `countries` 是 `map/political.ts` 的 `countryDraws(w, nameMode)`（每国 `{key: 'country:编号', lines: nameLines, path, area}`，面积按格的平均面积 × 主体格数、平铺图上除以纬度的余弦；按领土、档案、陆海、中文 / 原文缓存）；自然的地名只留 `POLITICAL_TYPES`（海、湾、海峡、湖、山脉与自己的）。导出整张地图同样（`map/export.ts` 的 `cleanOverlay`）。
- **着色**（`render/colors.ts`）：`HumanFlatMode` 多了 `country`：陆地按 `derived.country` 的编号取 `countryMapColors`（alpha `COUNTRY_ALPHA` 215，透出晕渲），领海 `SEA_CLAIM_ALPHA` 70，湖、不归谁的海不涂；`countryBorderGroups`：陆地是编号（无主 0），领海是编号 + 65536，不归谁的海 −1（core 的 `countryGroups` 不分陆海，海岸上会多画一道国界）；`colorSignature` 带上 `countryMapColors`。
- **渲染器**：第二张分组纹理 `uCountry`（`CellLayers.countryGroup`，第 13 个纹理单元）：合成时按省份同样取格（`provAt`），左右上下 1.5 像素一圈浓（0.82）、3 像素一圈淡（0.3），海上的一半；`countryEdge`：两边都 ≥ 0、不同、同是陆地或同是海才画。缩小到一格不到一个像素时淡到 0.55。投影的着色器里同样把偏移换成 `uDX` / `uDY`。省界多了浓淡 `uProvAlpha`（`Renderer.provinceAlpha`，进合成的键）。
- **国名的排版**（`render/overlay.ts` 的 `placeCountries`，`placeLabels` 里最先排，按主体大小从大到小）：中线 5 点展开跨接缝、`smoothPath`（Catmull-Rom，每段 4 点）、逐点 `toScreen`（投影时背面的不标）；领土在屏幕上的粗细 = 面积 ÷ 中线长；字号 = min(64, 粗细 × 0.36, 中线的八成 ÷ 字宽)，不到 10 像素不标；`layoutAlong` 字距拉开铺满中线的八成（最多 1.8 个字宽），每个字按切线的方向转；两者时原文一行在下（0.45 倍字号），拉丁字母写成大写（`countryLineText`）。每个字一个框，和已排的国名重叠的不标，别的地名按这些框避让；国名的框不给点击命中。中线、每个字在 1 像素字号时的宽按 `CountryLabelDraw` 对象缓存（`countryMetrics`：重排时不设字体、不量字）。画的时候 `drawGlyphs` 先描边、再填字。
- **这里与格的档案**：`Inspector.tsx` 的 `hereLine` 最前面写国名或“无主地”（海上写“X领海”）；`ArchiveBox.tsx` 的 `CountryLine`（钉住时国名是按钮，`selectCountry` 打开档案）。
- **资源库**：`repo.ts` 的 `GOV_KINDS`（政体、派系下面有“生成国家… / 重新生成…”，打开“国家 ⋯”）；通用编辑器认出政体的 `title`、`rulerTitle`（`fields.ts` 的 `isTitleField`：`json`、没有 `of`、键是这两个）换成 `TitleEditor`：一行一种（键、中文、原文；统治者称号没有原文），`titleRows` / `titleValue` 互换，只有 `default` 一行时存回最简单的写法，空着中文的行先留在框里不存。
- **速度**（13.92 万格、157 国的星球，1280×820）：平移、缩放每帧与地理模式相同（约 6–7 ms，合成多出的国界取样在测量的抖动之内）；国名重排约 1 ms，排好的版面每帧画约 4 ms。

**导出**（`export.ts` 的 `countryFiles`，只在有国家时有）：`countries.bmp`（国家自己的颜色；海、湖用 terrain.bmp 的颜色，无主的陆地是白色，领海是国家的颜色与海的颜色各一半）、`countries.csv`（`id, name, orig, red, green, blue, government, culture, capital, population, area_km2, overlord`；capital 是格的编号）；`provinces_summary.csv` 最后加一列 `country`（省份所属国家的编号，无主为空）。README.txt 多两行。没有国家的世界这些文件、列都没有，别的文件逐位不变。
