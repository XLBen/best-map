# 第九十八轮的设计：第一次打开一键开始、重新生成前的确认

这一轮改了什么见 [更新记录](../../更新记录.md)。前提和前几轮一样：用户是不懂系统的新手，结果要可以预料。两件事：第一次打开时不用往下翻两屏、挑一张就能开始；各处的“重新生成”不再有的不问就做、有的总问——有手改的东西会被换掉时才问，问的话里写着数。

生成的结果逐值不变：金标准、摘要、着色器的哈希、界面的快照、`raster-identity` 一个都没有重录。世界文件的格式没变（`DOC_VERSION` 还是 22），IndexedDB 的库还是第 8 版；localStorage 多一项 `map2.wizard.custom`（“自定义…”展开过没有）。没有动引擎的计算、`src/render/`、计算 Worker 的消息。

## 1. 新建向导的第一屏（`src/ui/Wizard.tsx`）

以前一上来是六节（选一种世界、多大、放在星球哪里、地形的五个滑块、选一个库、人文），缩略图在两屏以下。现在从上到下：

1. 标题“新建世界”，右边“帮助”（没有世界时顶栏的“更多”是灰的，见第 2 节）和关闭；
2. 留着的旧世界（`BackupBanner`）、“上次的世界已自动保存 · 继续上次的世界”——和以前一样在最上面；
3. “一块地区 / 整个星球”；
4. 一句“挑一张开始”，右边“换一批”（以前叫“换一组”）和“自定义…”；
5. 六张缩略图；
6. “自定义…”收着时一行小字：现在用的：群岛之海 · 一片海域 · 中世纪与近世 · 带国家和城市；
7. 生成过了 1 秒时的步名、进度条、“取消”（第九十七轮的 `BusyLine`），和新建有关的那一句（见下）；
8. “自定义…”展开时的几段：世界的种类 / 星球的种类、多大、放在星球的哪里、地形、库、人文。

### 留在外面的、收进去的

- **留在外面：“一块地区 / 整个星球”**。它决定的是做什么东西（一张地图还是一颗星球），缩略图整个不一样，是第一次来的人最可能想换的一样；它只有两个选项、一行，不把缩略图往下挤。
- **留在外面：“换一批”**。不满意这六张时最常做的事，和缩略图是一回事。
- **别的都收进“自定义…”**：世界的种类、大小、位置要先懂“群岛之海”“一片海域”“放在星球的哪里”是什么意思才选得了；地形的滑块、库与文化组、人文的开关更是。不选时用的是什么写在那一行小字里——没选不等于没有。
- 展开在原地（缩略图下面），不另开弹窗；**缩略图一直在上面**：改了下面的，上面的六张跟着重画，最后一行有“回到缩略图”。没有把展开的几段放回缩略图上面：那样展开以后又是老样子，挑一张要翻两屏。
- 展开过就记在这台机器上（`src/ui/wizard-prefs.ts`，写法同 `packs/lib-prefs.ts`），下次打开向导还是展开的。
- 几段的小标题去掉了序号（“1. 选一种世界”→“世界的种类”）：不再是一步一步往下走的。
- “自定义…”带省略号：[ui-design.md](../ui-design.md) 说省略号只用在会打开弹窗的按钮上，这里是在原地展开——按任务书定的字写的，没有改规矩；按钮展开着时是 `.open`（按下的底色）。

量到的（无头 Chrome，`npm run smoke` 的第十三段）：1280×800 和 1024×700 两种窗口里，六张缩略图、“自定义…”、“帮助”都在窗口里，最下面一张缩略图的底边在 497 像素，弹窗没有滚过。

### 默认值不变

什么都不选时的选择、点一张发出去的设置和命令，从组件里搬到了 `src/ui/domain/wizardChoice.ts`（纯函数）：`defaultWizardChoice`、`wizardWorld`（点缩略图）、`wizardCommands`（形态编辑器里“用它新建”也用）、`wizardSummary`（那一行小字）。组件里只剩状态和画法。

- `src/ui/domain/wizard-choice.test.ts`：默认的选择、三个种子，发出去的设置和命令的摘要等于在第九十七轮（`a08664b`）的代码上记下的（草稿目录的 `wizard-base98.mts` 对着 `git archive a08664b` 的拷贝，照那时 `Wizard.tsx` 里的写法拼出来；同一个脚本对着现在的代码跑，三个摘要相同）；另一条把那几行原样写在测试里逐字比。世界是设置和命令的确定的函数（金标准钉着），所以世界逐值相同。
- 冒烟：点第一张 → 世界；再开向导、展开“自定义…”、什么都不改、点同一张 → 每一个类型数组连同小数据逐字节相同。

### 向导里的那一句（`.wizard-note`）

第九十七轮：顶上的提示条被向导挡着，所以向导底下把它照搬一遍——于是和新建无关的话（上一笔排着没做成的“这一步没做”之类）也出现在向导里。现在提示带一个记号：`showToast(text, error, 'open')`，`toast` 里是 `about: 'open'`。打上记号的只有：

| 哪里 | 说的是 |
| --- | --- |
| `state/open.ts` | 向导里新建到一半取消了（“已取消”）；启动时打开上次的世界取消了；世界文件不是这一版的 |
| `state/worker-host.ts` 的 `handle`（新建、打开的回复） | 没能生成、没能打开的原因 |
| `engineReset`，说的是 `STOPPED_WORLD` 时 | 已取消，回到了原来的世界 |
| `thumbnail` | 缩略图没画出来的原因（形态的脚本出错……）。点了一张以后排着的几张被丢掉时回的“这一步没做：世界已换”**不再说**（以前弹在顶上、被向导照搬的就是它） |

向导只写 `about === 'open'` 的。“已取消，世界回到了这一步之前”、脚本超时、导出……都不带，不出现在向导里（`src/state/stop.test.ts` 里几处对 `toast` 的断言正好分得出这两种）。

## 2. 帮助：没有世界时也能开，`?` 键

- 以前只有“更多 → 上手说明”一个入口，而没有世界时“更多”是灰的：第一次打开、只有向导时开不了。现在向导的标题右边一直有“帮助”（`ModalHead` 多一个 `extra`：标题右边、关闭之前的一个小按钮；别的弹窗的标题栏结构不变）。
- **`?` 键开关帮助**（`shell/keys.ts` 的 `isHelpKey`）：写在 Esc 之后、“向导 / 帮助 / 弹窗开着时别的键都不管”那一句之前，所以没有世界、向导开着时也行；全角的“？”也算；带 ⌘、Ctrl、Alt 的不算；按住不放只算一次。**正在输入框、文本域、下拉、可编辑的地方打字时是打字**（用的是原有的 `isTyping`，这时不拦这个键）。问话框开着时到不了这里（`Ask.tsx` 在捕获阶段先拦下了所有的键，原来就是）。和现有的键不冲突：以前 `?`、`/` 都没有用。
- 名字：对用户只叫“帮助”（以前“上手说明”）——“更多”里的按钮、弹窗的标题、顶栏的悬停、使用说明都改了。
- 帮助最上面多一段“怎么开始”（四句：挑一张缩略图开始 → 用底部的工具画 → 改动自动保存在这个浏览器里 → 想留一份点“世界 → 保存”或导出世界文件），下面是原来的 8 步（小标题“一步一步”）和按键表（加了“帮助 · ?”）。帮助的大改（搜索、按当前工具排）是第九十九轮的事。

## 3. 重新生成：有手改会被换掉时才问

### 以前

| 哪里 | 以前 |
| --- | --- |
| “文化 ⋯ → 重新生成”“换库、文化组… → 重新生成” | 不问。换了库时手改过人口的格全没了，只有一行小字 |
| “国家 ⋯ → 重新生成” | 不问。没锁定的国家（改过名字、颜色、边界的）全换掉 |
| “城市 ⋯ → 重新生成” | 不问 |
| “省份 ⋯ → 划分省份 / 换一种划分”、多选“重新划分”、“重划”画笔 | 不问。手改过的省份（没锁定的）全换掉 |
| 资源库面板底下“改了 N 项 · 重新生成”、一项顶上“在地图上”的按钮、“添加并重新生成” | 不问；手改过国家、省份时写一行“手改过的国家会被换掉”（没有数） |
| 拖发源地 | 不问 |
| “删除人文”“删除国家”“删除城市…” | 总问，但只说“都删除，可以撤销” |

### 现在

都走 `src/ui/domain/regen-ask.ts` 的 `execRegen(cmd, busy)`：先数（`core/regen-loss.ts` 的 `regenLoss(world, cmd, 命令记录)`，纯函数），**数出来是空的直接做**（之后有“撤销”）；不是空的问一次：

> **重新生成**
> 会换掉你手改过的 334 格人口、2 个国家手画的边界。可以撤销。
> 〔先不〕〔重新生成〕

按钮写动作（省份的是“重新划分”，拖发源地的是“挪动”）。资源库里的两处（“在地图上”的按钮、“添加并重新生成”）经 `packs/row-actions.ts` 的 `runTrusted`，问在那里。问话框里主要的按钮在最右边（`choices` 里写在前面的那个，`shell/Ask.tsx`）；以前“删除人文”“删除国家”“删除城市”三处把主要的按钮写在了后面，画出来在左边，这次一起改对了。

重新生成本来就留着的不算“会被换掉”、不问，但按钮下面写一行让人知道（以前只在按钮的悬停里；`copy.ts` 的 `REGEN_KEEPS`）：文化“手改过的格、拖过的发源地、国家的领土不动”，国家“锁定的国家、手改过人口的格不动”，城市“锁定的、自己放的、画的不动”；省份的那一行（“规则相同，划分相同；锁定的省份不变”）原来就有。

## 4. 顺带查的：重放后第一条命令里记的省名少两个

第九十七轮发现、基线上就有：一份“新建（加内容 + 造陆地）→ 加时代 → 生成人文 → 划省份”的世界文件，`Engine.fromDoc` 重放后再 `toDoc()`，第一条命令里记的省名（`provinceNames`）少两个。查清了（脚本和输出在草稿目录，`replay98.mts`、`sweep98.mts`、`check98.mts`、`patch98.mts`、`raster98.mts`）：

- **世界本身不变**。2000 格、种子 4 的那个世界逐项比了两万多项（全部原因数组、51 个推导数组、小数据的每个键的 JSON、`worldDigest`），重放出来的和原来的一样；故意改一个省名、一格高程、一格省份，三处都查得出。
- **只在第一次重放时少**：存了再开、再存再开四轮，世界每一轮都相同，文件只在第一轮变（482 个省名 → 480 个），第二轮起逐字相同。不会让省名悄悄变。
- **少掉的是什么**：新建时划出来、各 3 格的两个陆地省，推导算好以后这 6 格全是湖面，湖省整理（`fixLakeProvinces`）把它们并进新的湖省、把这两个省删了。第一次执行时“记省名”在“湖省整理”之前（那时还不知道湖在哪），所以记下了它们；重放、重做时整理在记省名之前就做了（`settleApply`），记的时候它们已经不在。命令里多记的那两个名字重放时写上去两行之后就随省一起删了——删掉它们或者换成乱写的再重放，世界逐项相同。
- **普遍吗**：60 组（2000 / 4000 格 × 种子 1–6 × 五种世界）里 16 组第一轮文件会变，世界变的 0 组，第二轮起还在变的 0 组；少掉的编号每一例都正好是那一步湖省整理删掉的那几个。
- **实际的后果**（都不丢数据）：按命令的字逐条比的三处（检查点合不合用 `checkpointFits`、`Engine.fromCheckpoint`、自动保存是不是接着写 `continues`）会把“第一次记的”和“重放后的”当成不同——读代码推出来的最坏情况是某一次打开不用检查点而重放（慢一点），两个页面时可能多留一份其实相同的“留着的旧世界”。没有在浏览器里跑出来过。
- **没有改**。让第一次执行记的就等于重放记的，只要在 `core/engine-fixes.ts` 的 `fixLakeProvinces` 里把整理删掉的省从这一步的 `provinceNames`、`provinceOrig` 里去掉（十几行，补丁在草稿目录的 `patch98.diff`；运行时模拟 60 组，三份文件逐字相同、世界逐项相同）。但它要重录 `core/raster-identity.test.ts` 里星球的 `world.json` 那两项（命令记录的字变了；世界的 82 项不变）——这一轮的规矩是摘要一个都不重录，而且世界本身没有问题，所以只写明结论，留给以后单独的一轮。

## 取舍

- **数不出来的不问**。没有记号、命令记录里也认不出的手改（见“没做的”）不会让它问。宁可少问，不为了保险每次都问——每次都问，人就不看了。
- **数的是会被换掉的，不是会变的**。重新生成以后几乎什么都会变（那是它的本意）；问的只是“你亲手做的、这一次留不住的”。
- **第一次“生成”也走同一条路**：还没有国家时点“生成国家”、没有人文时点“生成人文”，也可能换掉东西（跟着重算的自动城市上写的简介；没有人文时自己放的地标——生成人文连城市地标一起生成时地标整个换掉），所以也先数；平常数出来是零，不问。
- **拖发源地也会问**：拖完松手才问有点别扭，但它确实会换掉自动的城市上写的简介；没写过的人不会遇到。
- **“重划”画笔**同样是松手以后问（涂到的省里有手改过的时）。
- **帮助叫“帮助”**，不留“上手说明”这个词：两个入口（向导上、“更多”里）要是一个叫法。
- **向导里的“帮助”是一个小按钮**，没有在第一屏上直接写怎么开始：第一屏只有一件事（挑一张）。

## 没做的、要知道的

- **数不出来的手改**（不会问）：
  - 国家重新生成时**集团**（帝国、联邦、同盟）里自己建的、改过的：只留成员都锁定的，别的没了——没有数它（生成的集团也带着“改过名字”的记号，分不出）；
  - 一个国家手改以后锁定、重新生成过一次（它留着）、再解锁：再重新生成时它不在“上一次重新生成之后的手改”里，不数（世界里没有“这个国家手改过”的记号）；
  - 涂成无主地的格，生成时归的那一国是锁定的：那一国不算被换掉，这几格也不数；
  - 没有命令记录时（主线程手上还没有：不该发生）只按世界里的记号数，改国名、换颜色、改省名认不出；
  - 手改过人口、后来成了湖面的格：`keepManual` 时引擎只留干的陆地上的，这几格不留，也没有数。
- **国家档案里手写的备注**算“留着”，其实是按编号留：没有锁定的国家时重新生成的编号从 1 起，原来 3 号国家的备注到了新的 3 号国家头上（第八十五轮的做法，没有动）；新的国家比原来少时，多出来的编号上的备注就没了。
- **自动的城市上写的简介会被换掉**是引擎原有的规矩（改名字、等级、所属才算“改过”）。这一轮只是数出来、问一句；没有改成“写过简介的也留着”——那会让已有的世界文件重放出不一样的结果。
- **第 4 节的那件事没有修**（见那里）。
- **帮助**只加了最上面一段和一个键；搜索、按当前工具排没有做（第九十九轮）。
- **窄窗口**（900 px 以下、手机）里的第一屏没有看：缩略图一排三张会很小。触屏是第一百轮的事。
- **没有用眼睛看过的界面**见交回来的报告。
