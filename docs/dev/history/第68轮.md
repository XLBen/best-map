# 第六十八轮的设计

这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。接着第六十七轮（[第67轮](第67轮.md)）：列表上的“从别的库加”从一个平铺的下拉改成右栏里能多选的窗口，上级页面的下拉一起改。

## 为什么改

第六十七轮的“从别的库加”是 `PageList.tsx` 里的 `RefPicker`（选项来自 `pick-other.ts` 的 `otherLibOptions`，选了 `addOther` 直接加）。在应用里看到：

- 宗教页里 63 项混在一起，来自 5 个库，不分段；每项下面写英文 id（`theravada`）。
- 只能选一项，选了就加；看不到会连带加什么，也不能“添加并重新生成”。
- 这个世界用不了的项（缺变量、缺文化组）直接不列，用户不知道为什么没有。
- 弹框比 380 px 的面板宽 4 px，面板出横向滚动条。
- 上级页面“加派系”“加文化”的下拉里也混着别的库的项，问题一样。

用户定的：点了在右边拉开一个能多选的窗口；用不了的**灰着列出来写原因**（不藏）；上级页面一起改。

## 做法：复用第六十七轮的一套

右栏不是新写的一套勾选，是第六十七轮“看库就是添加”换了个入口：

| 用的 | 做什么 |
| --- | --- |
| `pick-store.ts` | 勾选照旧按库记；打开右栏时 `setPickDest` 设成左栏这一份 |
| `pick-view.ts` 的 `pickView`、`lookOf`、`pressRow` | 一个库的勾选、每行的状态、点了做什么 |
| `pick-look.ts` 的 `rowLook` | 每行的状态只有这一个函数（没有另写） |
| `PickBox.tsx` | 每行的勾，灰行点了把要的一起勾上、几选一的小菜单；多一个可选的 `look`（调用方算好的样子） |
| `LibBasket.tsx` | 清单；多一个可选的 `other`：“加到”写死、不带“去看看”、`onto` |
| `pick-add.ts` 的 `addPicked` | 多一个 `onto` |
| `pages.ts` 的 `listPage` | 那个库自己列表的分段（宗教按组、文化按文化组） |
| `lib-keys.ts` | 上下键在 `.lo-pane` 的行之间走；Esc 先清搜索再收起 |
| `lib-pick.css` | 两栏、窄窗口覆盖照用 `.lp-side` 那一套 |

新的只有两个文件：

- `src/ui/packs/other-view.ts`（纯逻辑，可测）：`otherLibs`（别的库，各写可加几项、已勾几项；不含目的地自己，读进来的文件也列，这一种一项都没有、也没勾东西的不列）、`pickFrom`（先看 `defaultFrom` 给的上次用的库，它没有这种内容时第一个有的）、`otherSections`（那个库里这一种的行，按 `listPage` 的分段，只留这一种的行，不写 id）、`otherLook`（`rowLook` 之上两处：已有的写“本世界已有”“这个库已有”；上级放不下的灰着写“放不到“X”下面”，`picked` 照旧，勾着的还能取消）、`otherDetail`（点名字展开：说明、只勾它时还会一起加的）、`ontoOf`（这个库勾的这一种里放得下这个上级的）、`hasOther`（按钮出不出）。
- `src/ui/packs/LibOther.tsx`：右栏的组件。

`panel-store.ts` 的 `PanelState` 多一个 `other`（哪一种、变量、标题、`onto`，加上打开时左栏是哪一页 `at`）：`toggleOther`（再点一次同一个按钮收起；打开时设目的地）、`closeOther`；`closeSide` 先收它；`set` 里换了页面（`at` 对不上）就去掉，回到原来那一页也不再出来；`setSource` 本来就清掉；`openRoute` 在能勾的库里打开一项时收起它（右栏换成那一项）。`libWide` 把它算进去（提示条、底部条让开）。

开着时右栏画 `LibOther`，不画 `LibSide`；`side` 留在状态里，收起后底下的那一项还在（我的库里点开一项、在那一项的页面上点“从别的库加”，收起后回到那一项）。

## 上级页面：一次放几项

`core/packs/closure.ts` 的 `ImportOnto` 由一个 `child` 改成 `children: ContentRef[]`。`ontoEdit` 改成 `ontoEdits`：逐个链上，同一项改了几次（派系写在政体的 `factions` 上，每链一个改一次政体）接着上一次改过的改，最后每项一条——世界里每项一条 `set_content`（政体只写一次，两个派系都在），库里每项一次 `replaced`。链不上的（这一步没加进来）跳过，同以前。

`LibOther` 每次画时用 `ontoOf` 算 `children`（勾的、`role: 'pick'`、这一种、放得下），交给 `LibBasket` 的“添加 N 项”“添加并重新生成…”和 ⌘回车。加到世界是一个 batch，一次撤销全撤；加到库是一次 `setPack`。

上级页面的下拉（`PageChildren.tsx` 的 `RefPicker`）只留这一份自己的项；旁边一个“从别的库加”（别的库里有这一种才出），打开同一个右栏，标题写“从别的库加 · 派系 → 加到“君主制”下面”。

## 取舍

- **灰的列出来**：第六十五轮起下拉里灰的不列（选了加不进来）。现在是能勾的窗口，灰的行和库里的列表一样能点（圈里加号把要的一起勾上），所以列出来写原因。
- **一次只加当前这个库的**：和第六十七轮一样。换“来自”的库勾的留着（下拉写“已勾 N”），清单只是现在这个库的。几个库一起加要把清单改成跨库的，这一轮不做。
- **已勾 N 写这个库全部种类的**：清单加的是这个库全部勾的，下拉写一样的数，不会对不上。
- **展开的“一起加”**：只勾这一项时的清单（`importPreview` 只给它一个），不是现在勾选下的；灰的项只勾它时加不进来，展开写原因。
- **加完右栏不关**：可以接着勾；提示条不带“去看看”（左边就是），新加的行高亮几秒（`flashRows` 的 hl），长列表里滚到第一行（走查时改的，原来只闪一下，加到组的末尾时看不到）。
- **只列这一种**：`listPage` 在上级的列表上还会列“不属于政体的派系”这类融入的项，右栏里只留这一种。
- **`.ref-pop` 不超出**：`RefPicker` 打开时量外面最近一层会滚动的（面板的 `.lp-body`），右边放不下时加 `.end` 靠右对齐，`max-width` 不超过它。别处的下拉也不再出横向滚动条。

## 去掉的

`pick-other.ts` 的 `otherLibOptions`、`addOther`、`OntoRef`；`PageList.tsx` 里 `FromOtherLib` 的 `RefPicker`；`PageChildren.tsx` 下拉里的 `others`。`pick-view.test.ts` 里“下拉里别的库的”“选了直接加到我的库”两条搬到 `other-view.test.ts`（数、灰的、放不下、加到我的库一步撤销、撤销条写点的那一项、不带“去看看”）。

## 测试

- `other-view.test.ts`（新，7 条）：不列目的地自己；可加的数就是能勾的行数，已勾的数；已有的写“这个库已有”“本世界已有”；本世界里灰的社会主义共和国列出来写“需要意识形态”、能解；上级页面打开的放不下的灰着写原因、勾着的还能取消，`ontoOf` 只放放得下的；换“来自”的库勾的还在；右栏开关（再点收起、换来源收起、两栏、目的地是左栏这一份）；上级页面勾两个宗教加到我的库，两个都放到组下面，一次撤销全撤，提示条不带“去看看”。
- `pick-add.test.ts`：别的库里两个能直接加的派系放到世界的一个政体下面，一个 batch，一次撤销回到原样，重放逐值相同。
- `closure.test.ts`：`children` 两个时加到库（政体的 `factions` 接在原来的后面）、加到世界（政体只写一条，撤销回到原样）。

金标准、r29 摘要、着色器都没重录；生成没动。改的只是界面和添加（添加的命令只在用户点“添加”时才有），没有动画法（`overlay-ab` 不用跑）。

测速（`node tools/bench-median.mjs 1 --against 3215fd6 --`，区域、星球各一次）：加工各步只有噪音，一次里有快有慢（区域 erod +6%、lake +6%、hotRelief +8%，星球同几步 -14%、-1%、+1%；星球 tempBrush +11%，区域同一步 -7%；撤销几毫秒的步骤 ±数十 %）。生成、编辑的代码没动（`closure.ts` 的改动只在点“添加”时走），不再细测。

全部测试：204 个文件、2393 个，都过（`--maxWorkers=2`）；`npx tsc --noEmit`、`npm run build` 都过。

## 走查（127.0.0.1:5196，1024 px 与 800 px）

- 本世界 › 宗教 › 从别的库加：右栏按库、按组分段，没有英文 id，面板没有横向滚动条；“来自”列青铜与古典、中世纪与近世、近现代、现代、奇幻（科幻没有宗教这一维的取值，不列；原来的下拉不分维度，把科幻的种族、意识形态也混进宗教页）。
- 勾两个、换到现代再换回来：还勾着，下拉写“已勾 2”；点名字展开说明；“添加并重新生成人文”按加了什么起名。
- 添加 2 项：右栏不关，两行变“本世界已有”，清单清空。
- 政体 › 部落酋邦 › 派系 › 从别的库加：标题“→ 加到“部落酋邦”下面”，勾教士、市民添加，两个都在部落酋邦下面；提示条“撤销”一次两个都没了。
- 灰的写原因：中世纪的天朝“需要汉”、伊克塔“需要伊斯兰教”，科幻的蜂巢意志“需要甲壳族或孢生族”，近现代的几个“需要民族认同”；点天朝的灰勾，汉（文化组）一起勾上，写“为了天朝加的”。
- 800 px：右栏盖在左栏上，有“返回”；Esc 先清搜索，再收起。

走查时改的两处：
- 面板变宽时提示条在 1024 px 宽的窗口里被挤成一行两三个字（`.app.lib-wide .notices` 是 `left` 定位，宽度按右边剩下的算）：加 `width: max-content`，最宽仍是 `min(100% - 768px, 440px)`。
- 加完新行只闪 1.2 秒，加到组的末尾时在视野外：改成高亮几秒并滚过去。
