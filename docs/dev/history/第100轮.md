# 第一百轮的设计：触摸与平板

这一轮改了什么见 [更新记录](../../更新记录.md)。前提和前几轮一样：用户是对系统完全无知的新手，界面像 Procreate，结果要可以预料。以前地图上的输入只当一个指针处理（鼠标），没有 `pointercancel`，样式里没有粗指针的写法，Shift、Alt、右键、F、Tab 做的事在屏幕上没有按钮。这一轮：**手指和笔在地图上能画、能移动缩放；没有键盘做不了的事都有按钮；平板上可点的东西够大、不溢出。鼠标、触控板、键盘的行为一项没变。**

生成的结果逐值不变：金标准、摘要、着色器的哈希、界面的快照（`tool-replay.json`）、`raster-identity` 一个都没有重录。世界文件的格式没变（`DOC_VERSION` 还是 22），IndexedDB 的库还是第 8 版；localStorage 多一个键 `map2.touch`（用过笔没有、两个偏好）。只动了界面和输入：`core/`、`src/worker*.ts`、`src/sandbox.ts`、`src/render/` 没有动，所以没有测速、没有跑逐字节对照。

## 1. 地图上的手势

### 三个文件

- `src/ui/map/touch.ts`：手势怎么判定——**纯的状态机**（`TouchGestures`）。不碰 DOM、时钟、工具、镜头：进去的是手指 / 笔的按下、移动、抬起、取消和“到点了”（`tick(t)`），出去的是一串要做的事（`TouchAct`：`hover`、`leave`、`draw-start / move / end / cancel`、`tap`、`pin`、`pan-start / move / end`、`pinch-start / move / end`）。阈值都是这个文件里有名字的常量。
- `src/ui/map/touch-wire.ts`：把这些事接到工具和镜头上。用的都是鼠标那一条路已有的做法（`startPan`、`panTo`、`endPan`、`zoomAt`、离开、吸取），由 `input.ts` 递进来（`TouchHost`）；状态机要等的那两种时间（等够了开始画、长按）由它上定时器。
- `src/ui/map/input.ts`：只分事件。`pointerType` 是 `touch` / `pen` 的交给上面两个；没有 `pointerType`、是 `mouse` 的走原来的路。为了让两边共用，原样搬出了三个函数：`panTo`（拖着平移到这里）、`endPan`（平移收尾）、`pickAt` / `wantsPick`（吸取）。新接了 `pointercancel`。

鼠标不经过状态机。每个鼠标事件多做的只有：读一次 `touch.busy`、看一眼 `pointerType`、读一次屏幕上的 Shift / Alt 开关（`held.peek()`）。

### 规则

| 手势 | 结果 |
| --- | --- |
| 一根手指，拿着拖的工具（画笔、放岛、画河……） | 用工具：和鼠标左键一样 |
| 一根手指，拿着点的工具（指针、选省份、选国家……） | 点一下是工具的点击；拖开是平移地图（鼠标也是这样） |
| 两根手指 | 平移和捏合缩放，同时进行；两指的中点下面那一点跟着中点走 |
| 画到一半第二根手指落下 | 这一笔**不算**（工具的 `cancel()`，和 Esc 同一个入口：不发命令、预览去掉），改成平移缩放 |
| 两指里抬起一根 | 平移缩放到此为止；剩下的那根不拿来画。**全部手指抬起以后才回到工具**（中途再落下一根凑成两根，接着平移缩放） |
| 长按 | 手指这时不是在画（拿着点的工具，或开了“手指只移动地图”）时，按住不动半秒 = 右键点一下：钉住“这里” |
| `pointercancel`（系统手势、来电、切应用） | 当作取消：画着的不算、平移和两指收尾，不卡在“按着” |
| 笔 | 永远是用工具，落下就开始（不等） |
| 笔落着、刚抬起时落下的手指 | 不算（手掌），到它抬起为止 |
| 手指画着时笔落下 | 手指的那一笔不算，笔接着画 |

**长按和“按住不动地画”冲突怎么定的**：按住画笔停一下是确切的预览（“手停一下，地图上就是松手后的样子”），这个不能让。所以长按只在手指不是在画的时候算——一句话：**拿着点选的工具时按住不动半秒钉住“这里”；拿着画笔时按住是预览，要钉住先点右上角的“指针”**。指针工具本来点一下就钉住；选省份、选国家这样的工具点一下是选中、长按是钉住。帮助的“触摸”一段写的就是这一句。

**第二根手指多半来得很快**：手指落下后先等 `TOOL_DELAY_MS` 才把它交给拖的工具。在这之内第二根落下，工具一下都没碰——捏合不会先闪一下画笔，画河的“分一股出去”这样的模式也不会被一次取消清掉。等的时候挪开了（超过 `DRAW_SLOP_PX`）或抬起了（点一下），马上交给工具，不等满；起笔的位置还是落下的地方，一点不丢。笔不等。

**没有悬停**：手指按下时先补一次“鼠标移到这里”（`move(p, false)`），工具的预览照常有（画笔圈、这是哪个省）；发源地这样“停在东西上才是拖的工具”的也靠这一下定。抬起、取消以后和鼠标离开地图一样（`leave`）：不留一个停在最后位置的预览圈。拖底部条的滑块时“在最后停的地方预览”照旧（`lastPointer` 留着）。工具的那句话（“堆山 约 +600 m”）手指按着时写在手指上面（下面会被手指挡住）。

**短促的误触**怎么处理的：(1) 两指手势里先落下的那一根不交给工具（等的那一会儿），已经交了的取消；(2) 笔落着、刚抬起 `PALM_GUARD_MS` 之内落下的手指不算；(3) 画着时第二个触点落下就取消这一笔。**没有**做“很短的一下不算”：放岛、点一个点、选省份都是很短的一下，分不开；也没有按触点的大小认手掌（各家设备报的数不一样，认错了手指就画不了）。所以单独的一次手掌轻触，拿着画笔时还是会留下一个点——可以撤销；用笔的人开“手指只移动地图”就没有这回事。

### 阈值（`touch.ts`）

| 常量 | 值 | 是什么 |
| --- | --- | --- |
| `TOOL_DELAY_MS` | 80 毫秒 | 一根手指落下后等这么久才交给拖的工具 |
| `DRAW_SLOP_PX` | 4 像素 | 等的时候挪动超过它就开始画 |
| `TAP_SLOP_PX` | 10 像素 | 手指挪动不超过它算没动（点一下、长按）；点的工具拖过了它是平移。鼠标是 5 |
| `PEN_SLOP_PX` | 5 像素 | 笔的，和鼠标一样 |
| `LONG_PRESS_MS` | 500 毫秒 | 按住不动这么久是长按 |
| `PALM_GUARD_MS` | 300 毫秒 | 笔抬起后这么久之内落下的手指不算 |
| `PINCH_MIN_PX` | 12 像素 | 两指靠得比这近时不算缩放（只平移） |

这些数是按常见的做法定的，**没有在真的平板上调过**。

### 两指平移缩放怎么算的

每一下 `pinch-move`：先 `panTo(中点)`（开始时记下的那一点跟着中点走——球形投影下是 `rotateToAnchor` 把那一点转到手指下，和鼠标拖着转同一个做法），再 `zoomAt(中点, 这一下的倍数)`（那一点不动），然后从这里重新 `startPan`（镜头变了，起点重记）。单元测试里量：一块地区、球形投影下，两指中点下面的那一点在平移 + 缩放之后还在中点下面（差不到 10⁻⁵ 个地图单位）。

iPad 的 Safari 两根手指落在屏幕上时还会发 `gesturestart / gesturechange`（原来给触控板的捏合用的）：手势进行中不再理它，免得缩放两遍。这一条是照着 Safari 的行为推的，没有在 iPad 上验证。

### 笔

- 检测到用过笔（`pointerType === 'pen'` 按下过一次，记在 `map2.touch`）以后，“更多 → 偏好”里多出两个开关，默认都关：
  - **手指只移动地图**：手指不画——一指拖是平移、两指缩放、长按钉住；笔照常画。点选的工具手指照常点（不然拿着指针时手指什么都做不了）。没用过笔的设备上这个偏好不起作用（开不了它，也就不会被“手指不画了又没有笔”困住）。
  - **笔的压力影响力度**：开着时 `Pointer.pressure` 才有值；画笔把这一笔里按得最重的那一下（不低于 `PRESSURE_MIN` = 0.1）乘到力度上。接了的画笔：堆山 / 压低、冷暖、干湿。鼠标、手指、没开时乘的是 1（逐位不变，`tool-replay.json` 没有重录）。
- 笔的悬停（没落着的移动）和鼠标的移动走同一条路。
- **压力只在单元测试里走过**（手造的事件）：没有真的笔，无头 Chrome 的触摸也没有笔。

屏幕上的 Shift / Alt 是一种做法：工具表里写 `mods: { shift: { label, title } }`（没有别的按钮做得到时才写），底部条第二行就多一个开关；开着时地图上的每一下都当作按着那个键（`held`，`input.ts` 的 `pointerOf` 把它并进去——鼠标也一样，开关是界面上的状态），换工具就关上。画笔的“Shift 反过来”没有做成开关：模式选择本来就在。`touch-ui.test.ts` 钉着：工具的那一句里提到 Shift 的都对得上模式选择或开关，提到 Alt 的都是吸取、都有吸管。

## 4. 平板上的布局

样式在 `src/ui/shell/touch.css`，三部分：

1. **浏览器自己的手势**：`.app` 上 `touch-action: manipulation`（不要双击放大；捏合放大整页留着——没有用 `user-scalable=no`，看不清小字的人用得上；地图上的捏合是缩放地图，`.map-overlay` 本来就是 `touch-action: none`）、去掉点按时的灰块；有触摸屏时（`any-pointer: coarse`）`overscroll-behavior: none`（下拉刷新、回弹不带着整页走），面板、弹窗滚到头不带着后面的滚；粗指针时界面上的字不让长按选中、不弹系统菜单（输入框、出错的原话照常）。`index.html` 没有动。
2. **补的那几样东西的样子**（看全图、“显示界面”、底部条最下面那一句、屏幕太窄的那一句）。
3. **`@media (pointer: coarse)`**：
   - 控件的两档高度 `--h-sm`、`--h-md` 都放到 44——按钮、列表行、顶栏、底部条的工具、面板头上的关闭都是按这两个量定的；写死了更小的几种（`button.small`、`select.small`、分段选择、链接样的按钮、面板头上 24 像素的关闭、框、下拉、取色的框、勾选的一行、折叠的标题，资源库里列表的一行、一段的标题、面包屑、分组的小标题）另放到 44；按钮最窄 44。这些是照着冒烟里量出来的“比 44 小的”一条一条补的：量过的地方见第 5 节，没量过的面板里可能还有漏的。
   - 滑块：能按的那一条高 44（按在这一条上哪里都算，本来就是指针事件 + 捕获），把手画成 28；右边能点开打字的数 44×44。开关的轨道画大一号。
   - 底部条高了：它从窗口底边往上占了多高写进 `.app` 的 `--bar-clear`（`shell/bottom-bar.ts` 的 `trackBarClear`，和顶栏的 `--top-clear` 一样），资源库面板停在它上面（以前写死 84 像素）。
   - 竖着的平板（粗指针、宽不到 900）：顶栏只剩图标时手指没有悬停可看——字写在图标下面；右下角的“这里”抬到底部条上面。
   - 底部条一排放不下时**折行**（定的是折行，不横向滚：`.bb-row` 本来就是 `flex-wrap`）；再多就自己滚，不伸到屏幕外面。顶栏的一组放不下时也折行。
   - 安全区：顶栏、底部条、左右下角的几样、弹窗那一层都加了 `env(safe-area-inset-*)`。现在的页面没有 `viewport-fit=cover`，浏览器自己把页面放在安全区里，这些量是 0；将来做成全屏的应用时它们才有数。

**桌面一个像素都不变**怎么验的：第九十九轮的源码（`git archive 76db745`）另打包一份，和现在的各在无头 Chrome 里（1280×800、鼠标、`#demo` 的世界）截同样的 21 张——一打开、九类工具、指针、鼠标停在地图上的画笔圈、四个弹出面板（图层、更多、世界、调整）、资源库、量距离、只看地图、1024×700、800×700——PNG 逐字节比：**21 张都相同**。新建向导那一张没截到（脚本停在“保存当前世界”的问话上），帮助没有截（它有意多了一段“触摸”、“按键”里两行多了“触控板”三个字）。这是一次性的核对，脚本没有进仓库。

**还靠悬停的**（手指看不到）：

- 底部条上各个选项、按钮的 `title`（“自然融入”是什么、“锁定走向”是什么、吸管橡皮擦的那一句）——一行放不下；帮助里搜得到一部分。
- 顶栏按钮的 `title`（“资源库：文化、政体、生态……”“撤销 画陆地 · 1953 格”）、“世界”旁“没保存”记号的原因（点它打开菜单，第一行写着）。
- “还有 N 个”的 `title` 里藏着的是哪几个——点了就露出来，不用看。
- 图层里各个底图、开关的 `title`，资源库里行上小标记的 `title`。
- 鼠标停在按钮上的地图预览（省份的“对半分开”“重新划分”、河的“从这里往下删除”悬停时先画给你看）——手指只有点下去。

不靠悬停的：工具做什么（底部条最下面一行）、藏着什么（展开）、术语的那一行（第九十九轮）、字段的说明（字段下面一行）、每一段何时生效的标记。

**手机**（宽不到 600）不是目标：打开时最上面说一句“屏幕太窄，有些地方会挤在一起。建议用平板或电脑”，8 秒后自己收起、也能点 × 关（它盖着顶栏的一行）；不拦着用。

## 5. 帮助、冒烟

- 帮助多一段“触摸”（`help-data.ts` 的 `HELP_TOUCH`，八行）：触摸设备上排在“按键”前面，鼠标下排在后面；搜得到（搜“触摸”“手指”出整段）。“按键”里“双指滑动 / 捏合”前面加了“触控板”（和手指分开）。
- `npm run smoke` 第十五段（`tools/smoke-touch.mjs`，`--only 15`）：另开一个存储是空的浏览器环境，`Emulation.setDeviceMetricsOverride`（768×1024、`mobile: true`）+ `Emulation.setTouchEmulationEnabled`，触摸都用 `Input.dispatchTouchEvent`。走的：向导第一屏 → 手指点一张建世界 → 量大小、手指拖滑块 → 两种朝向下的布局和五个面板（图层、更多、世界、资源库首页、帮助）→ 竖着时再往里：“调整”、地形的“⋯”、资源库里文化的列表和一种文化的页面、国家的档案 → 一指画 → 两指捏、平移 → 看全图 → 画到一半第二指落下 → `touchCancel` → 长按 → “多选”开关 → 问话框、向导（收着、展开“自定义…”）→ 宽 390。
  - **量大小的办法**：页面上每一样看得见、点得着的东西（`button`、`[role=button|slider|switch]`、`a[href]`、`select`、`input`、`textarea`、`label.check`、`.item`、`summary`；包在 `label` 里的框按那一圈 `label` 算）的包围盒，宽、高有一边不到 44 就列出来。量过的：向导（收着、展开）、顶栏、底部条（地形、省份）、左右下角的按钮、上面那些面板和弹窗。**没量的**：别的类的“⋯”、选“哪一种”的列表、资源库里别的种类的页面和挑选的模式、生态编辑器、“我的地图”“管理库”“留着的旧世界”的弹窗、星球形态编辑器、城市和集团的档案。
  - **核实过的**：无头 Chrome 里开了触摸模拟，`(pointer: coarse)` 成立、`(hover: hover)` 不成立，`navigator.maxTouchPoints` 是 5——粗指针的样式是真的生效了量的。
  - **量过才知道的**：`Input.dispatchTouchEvent` 的 `touchEnd` 里列的是**抬起的**那几根（空的是全部抬起），不是剩下的；第一版写反了，“抬起一根、剩下的接着动”那一步其实在重新捏合。

## 取舍

- **两指点一下不是撤销**（Procreate 是）：没有做。误触的代价是丢一步，而顶栏上撤销就在手边。
- **长按不在画笔下生效**：见上。
- **补的按钮只在触摸设备上露**：任务书要桌面不变；带触摸屏的笔记本用手指点过一次才露（那以后按钮还是桌面的大小——44 像素只跟着主要的指针）。
- **没有用 `user-scalable=no`**：整页的捏合放大留着。地图上不会误触（`touch-action: none`），面板上捏了是放大界面。
- **折行，不横向滚**：底部条横向滚的话，露在外面的半个按钮看不出后面还有；折行一眼看得全。
- **偏好没有进 `map2.prefs`**：`content-ui.test.ts` 逐项钉着那一份的形状；另用一个键，没有动已有的测试。

## 没做的、要知道的

- **真的平板、真的笔都没有试过**。手势只在两处走过：单元测试（手造的指针事件、假的时钟）和无头 Chrome 的触摸模拟（合成的触点：没有手掌、没有压力、没有系统手势、没有 Safari）。阈值没有在真机上调过。
- **笔**：`pointerType === 'pen'` 的整条路（落下就画、手掌不算、两个偏好、压力）只在单元测试里；无头 Chrome 的调试协议发不了笔的触点。
- **iPad 的 Safari**：`gesturestart` 那一处是推的；`touch-action`、`-webkit-touch-callout`、屏幕键盘弹出时的布局（`100%` 高的页面被键盘顶上去）都没有看。
- **悬停时的地图预览**（省份的“对半分开”等）手指看不到，没有补。
- **资源库里拖卡片**（融入）、档案里拖着换先后：以前就是指针事件，这一轮没有在触摸下试。
- **带触摸屏的笔记本**：用手指点过以后补的按钮会露，但大小还是桌面的。
- **单独一次手掌轻触**在画笔下还是会留一个点（见“短促的误触”）。
- **两指转动地图**没有（地图不转）。三指、双击手势都没有。
- **手机**只是不坏：顶栏、底部条折成好几行，地图剩得很少。
- 第九十八轮留下的“重放后第一条命令里记的省名少两个”还是没有修。
