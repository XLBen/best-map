# 第七十六轮的设计

这一轮改了什么见 [更新记录](../../更新记录.md)。[第七十一轮](第71轮.md)把大类地物的类型字改成了生态的名字（荒漠、苔原、冰盖、沼泽湿地），
起出来的名字没改，因为要重录 `biome-legacy` 等摘要。用户定了：名字也改，重录那几项。

## 改了什么

只改“中文·默认”地名风格（`core/packs/names/zh-default.json`）的三条模板，权重、先后不变：

| 大类 | 以前 | 现在 |
| --- | --- | --- |
| desert | `{dry}{color}沙漠` | `{dry}{color}荒漠` |
| tundra | `{cold}{nature}冻原` | `{cold}{nature}苔原` |
| icecap | `{cold}{nature}冰原` | `{cold}{nature}冰盖` |

同一大类里本来就有的 `{color}{cold}荒漠`、`{color}{cold}冰盖` 不动。别的 90 套地名风格不动：
`ja-kanji` 的砂漠 / 凍原 / 氷原、`ko-hanja` 的沙漠 / 冻原 / 冰原（带韩文读音表）是那种语言自己的词；外文地名风格里的“沙漠”“荒漠”是两个不同的词的译名。
沼泽湿地那一类的模板（某某泽、某某沼）本来就不叫“沼泽”，不改。

模板只换字，挑模板的随机数不变；起名不查重名到字，所以别的名字一个没变。

## 核对：两边的世界只差这三个字

两个临时测试在第七十五轮的代码（574c123）和这一轮上各导出同样的十五个世界，逐个比较。十五个世界是：

- 一块地区、星球（`speed-identity` 的设置）；
- 金标准那组操作的前两步（4 万格，生成、划省份）和同样做法的星球（3 万格）；
- 大陆世界在中世纪、现代、奇幻下生成人文；
- `r29` 的六种设置（古典到科幻，带国家、城市）和它们共用的没有人文的世界；
- `features.test` 的 6000 格小星球。

导出的是：所有类型数组的摘要、每个地物（key、类型、名字、格的摘要），以及整个小数据（JSON）。

比较的规则是：两边的字符串不同时，把旧的里沙漠 → 荒漠、冻原 → 苔原、冰原 → 冰盖，必须正好等于新的。别的任何不同都算错。结果：

- 别的不同 0 处；
- 每个世界的小数据里只有那三条模板不同；
- 地名：金标准那组 3 个（沙赤沙漠 → 沙赤荒漠……），星球 7 个，`features.test` 的大陆世界 6 个（旱青沙漠 → 旱青荒漠、冰雷冻原 → 冰雷苔原、霜月冰原 → 霜月冰盖……），key 都不变；
- 生成过人文的世界，有人住的地方地名跟着各文化的地名风格起；没人住的荒漠、苔原、冰盖还按“中文·默认”起，所以古典、近现代、现代、科幻各变了 2–5 个，中世纪、奇幻没有。

## 重录了什么

全量测试改模板后有 26 个不同（有的测试停在第一处不同，换上后又报了后面的几项，`r29` 用 `R29_RECORD=1` 重录、只有 features 变了），都在下面。新值是测试报的值，按“旧值 → 新值”逐个替换，没有手写。

| 文件 | 项 | 为什么 |
| --- | --- | --- |
| `golden-hashes.json` | features | 地名 |
| `golden-full.json` | region、planet 的 small、derived.features | 小数据里的地名风格、地名 |
| `biome-legacy-digests.json` | golden.features、golden-full 的 small / derived.features、r29 的 nature、modern、modern:again 的 features，libraries 的 content | 同上；冻结的参照代码没动 |
| `human/r29-digests.json` | 没有人文的、古典、近现代、现代、科幻（含再生成国家的）的 features | 地名 |
| `packs/libraries-digests.json` | 六个库的 content | 小数据里的地名风格 |
| `r31-digests.json`（`speed-identity`） | 地区、星球每一步整个世界的摘要 | 小数据里的地名风格 |
| `human/class-only-digests.json`（`class-ground`） | 地区、星球每一步整个世界的摘要 | 同上 |
| `solver-identity.test.ts` | 各项的 world | 同上 |
| `ocean-plane.test.ts` | `R45_CURRENTS0` | 同上 |
| `rivers.test.ts` | features | 地名 |
| `features.test.ts` | `kv(continents())` | 地名 |
| `raster-identity.test.ts` | 星球的 `features.csv`（两个）、`world.json`（四个） | 地名、世界里的地名风格；地区没有荒漠、苔原、冰盖的地物，`features.csv` 不变 |

没动的：

- 地形、气候、生态、河、省份、国家的各层；
- 着色器的哈希、栅格化的图片与别的表格；
- `tool-replay.json`、快照。

测试个数不变。
