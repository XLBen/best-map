# 第八十一轮的设计

这一轮改了什么见 [更新记录](../../更新记录.md)。用户说资源库里改东西又绕又反直觉。这一轮只改界面：生成的结果逐值不变，
金标准、摘要、快照、着色器的哈希一个都没有重录（没有去掉字段：重复的那一项只是在页面上不列，见“重复的两项”），世界文件的格式没变（`DOC_VERSION` 不动）。

## 问题在哪里

1. **四种“什么时候用上”，看不出来**：生态松手就重算；时代、文化、政体、等级、格局、城市等级要面板顶上的“重新生成…”（只在看本世界时出现）；
   省份划分不在里面，它的“大小”一段叫人回到“省份 ⋯”点“划分省份”，“湖”一段又是马上整理；在我的库、内置的库里改永远不影响世界，只写在帮助里。
2. **再打开回到只读的库**：面板记着上次看的那一份，常常是内置的库，表单全灰，最显眼的按钮是“复制成我的库”。
3. **单位、说明藏在悬停里**：领海 km、国家大小 km²、划进国家 km、成片大小只写在 `title`；只有典型高度写了 `unit`。几个名字是行话：集中程度、文化的倒向、多见、基础分量、强势程度、原文。
4. **数是框**：上下限、步子超过 2000 格就成了 `<input type=number>`（人口密度 0.001–10000、国家大小 1000–1e9、各组占多少 0–1000、倾向的权重）；城市化率写 0.10。
5. **国家等级的比例**是五个写着“比例”的框。
6. **路很深**：改国家大小要资源库 → 时代卡片 → 时代页 → 展开“国家” → 打字 → 重新生成，五到七步；新建向导、“文化 ⋯”里没有入口。
7. **重复的两项**：国家等级的“多见”（时代没写比例时用）和时代的“国家等级的比例”；国家格局自己的“多少”和时代里每种格局的“多少”。
8. **一件事几种叫法**：比重、在组里占多少、多少、比例、多见、权重、基础分量、强势程度、稀有度；复制成我的库、存回我的库、存进资源库、装进资源库……、从本世界存进资源库……；时代 / 时代规则；维度 / 变量；移出本世界 / 删除 / 清理；“收起（Esc）”“在地图上看”这两个违了文字的规矩。
9. **一行上的标记堆起来**：本世界改过、和库不同、默认、在用、变淡，加上四种勾。
10. **挑选和改混在一起**：看别的库时每一行都有勾，勾了面板变成两栏带清单，“从别的库加”又开一栏。
11. **两个撤销**：⌘Z 看“最后点的是不是面板里”，顶栏的撤销总是世界的。
12. **帮助**里资源库一步有二十来条。

## 改了什么

### 一条“改了 N 项 · 重新生成”（`regen.ts`、`RegenBar.tsx`、`src/regen-track.ts`）

用户定的：只有一条，放在面板底下（不随列表滚），只在看本世界时出现。

- 省份划分也算：和上次划分时的规则比（`size`、`varied`、`wasteland`、`seaByDistance`、`riverCost`、`ridgeCost`；名字、说明、`lakeMode` 不算——“湖”改了马上整理）。
  重新生成是“省份 ⋯”的“划分省份”同一条命令 `generate_provinces`（世界的种子，规则没变时划出来一样）。`RegenTrack` 多记一样 `provinces`（`generate_provinces` 算重新划分；重新划分一片是手改）。
- 几样一起要时一步：一个 batch，先划分省份（国家按省份长），再重新生成人文 / 国家 / 城市，和以前同一条命令。
- 条上写会重做什么：“会重做省份、国家、人口、城市；锁定的不动”（`regenNeed` 的 `what`）。不默默换掉手改的：`RegenTrack` 跟着撤销的先后记 `hand`——上次生成之后手改过国家
  （涂领土、新建、合并、分开、改名、集团、挪首都）、省份（划进、合并、分开、剪刀、改名、重新划分一片）的，条上另写一句“手改过的国家、省份会被换掉”（`warn`）。
  人文的重新生成留着手改过的格、城市留着自己放的，不算。重新生成过那一样就不再写。
- 从资源库添加的“添加并重新生成…”不变（`addedNeed` 不算省份，照旧在清单底下写一句）。
- 改了马上变的一段标题旁写“即时”（`InstantMark.tsx`）：本世界的生态（编辑器顶上）、省份划分的“湖”（`page-segments.ts` 的 `instant`；“湖与海”拆成“湖”，近海小远洋大挪到“大小”）。
- 看的不是本世界时顶上一行（`LibPanel.tsx` 的 `SourceBanner`）：我的库“改这里不影响当前世界”；只读的库“这是“X”，只能看”，一项的页面上旁边是“在本世界打开”（本世界有这一项）或“添加到本世界…”（进入挑选、这一项勾好，`pickThis`），别的页面“回到本世界”。

### 打开总是本世界（`panel-store.ts` 的 `startOf`）

不带请求打开（顶栏、“世界”菜单）：有世界时总是本世界，上次看的就是本世界时回到那一页；没有世界时照旧回到上次看的（没开过时默认的库）。别处带请求打开（“编辑生态类型…”、缺内容的“从资源库添加…”）照旧。

### 字段：单位、说明、滑块（`fields.ts`、`ContentEditor.tsx`、各个 `*-kinds.ts`）

- 说明从悬停挪到字段下面一行灰字（`.ed-hint`）。全部字段的说明都不超过 20 个字（新的测试查着，二十来条长的改短了，长的解释留在格局页面的模块提示和使用说明里）。
- 单位写在 `unit`：人/km²、km²、km（领海、划进国家、成片大小）、格（省份大小）、m（典型高度、高度范围）；`%` 表示存的是 0–1，写成百分之几（城市化率、游牧、资源的比例）。滑块右边写“120,000 km²”“10%”（`valueText`）。
- 都是滑块：不超过 2000 格的照旧等间距；范围很大、下限不小于 0 的按对数（`logScale`）——停的地方是两位有效数字的数（每十倍 90 个：1.0、1.1……9.9，加上两头），
  位置按对数算（两位有效数字的格在每十倍里疏密不一，按格数算会偏，测试查一半的位置在几何平均附近）；下限是 0 时最左边一小段是 0。值 → 位置 → 值，停得到的数原样回来（测试查着三种范围的每一个数）；
  内置时代写的人口密度（0.5、2、12、30……）都停得到。有负数又很宽的放粗步子到 2000 格。没写上下限的（规则的条件、年份）还是框：它们是条件，不是“调多少”。
  滑块不能打字：`Slider` 本来就不支持，只用方向键走一步（单步是位置的 6%）。
- 倾向的表每个取值的“多少”是按对数的小滑块（0–1000）。
- 改名：集中程度 → 聚居，文化的倒向 → 按文化分国，多见 / 比重 / 在组里占多少 / 基础分量 / 权重 → 多少，强势程度 → 强弱，稀有度 → 比例（真的是百分比），派系里“这部分人的比例乘以它”的权重 → 倍数，原文 → 外文名 / 外文写法，人口的维度 / 维度 → 变量。只改了字段表的 `label`、`hint`，存的键不变。
- 时代页上没有名字的图标按钮补了 `aria-label`（删除、打开这一项、不写、更多、关闭……）。

### 国家等级的比例：一条色条（`components/ShareBar.tsx`、`share-bar.ts`）

不认识世界的控件：几段（名字、颜色按先后轮流 `--share-0…5`），拖两段之间的分界只改这两段、和不变，夹在左右两个分界之间；拖时只是草稿（数跟着变），松手交出去一次；方向键挪 1%。
交出去的是百分之几，按 0.1 取整，差的补在最大的一段上，和正好是 100。时代整个不写比例时按各等级自己的“多少”画（`refItem`），第一次拖就写进时代。拖到 0 的等级不出现（和以前写 0 一样）。

### 生成设置（`gen-settings.ts`、`PageGen.tsx`）

本世界首页最上面一张卡片（写“国家 X 万 km² · 人口 N 人/km² · 省 N 格”），打开一页：国家大小、人口密度、城市化率（字段表里的那三个，单位、滑块同一份）、国家等级的比例（色条）、省份大小；下面链到时代、省份划分的其余几项。
改的是本世界的时代、省份划分，和它们自己的页面同一条命令（`worldItemCommand`；历史里写“改国家大小”，测试比过命令只差 `label`）。改了以后底下的那一条照常出现。

入口：“文化 ⋯”的时代一段（新加）、“国家 ⋯”（`EraRulesNote`：世界里有这个时代时按钮从“时代”换成“生成设置”；换了库、世界里还没有那个时代时照旧开库里的时代）、“省份 ⋯”（“生成设置”“省份划分”两个按钮）、新建向导。
向导里选了最简单、能预料的一种：“选一个库”那一步一个开关“建好后打开生成设置”（默认关），建好后面板开到这一页；向导里不另放这几个滑块（还没有世界，改的是谁说不清）。

“文化 ⋯”的总人口滑块下面一行写“默认按人口密度 N 人/km²；改密度在生成设置”，生成设置的人口密度下面写“‘文化 ⋯’的总人口按它算”。

### 重复的两项

查了六个内置库：每个时代都写了全部五级的比例，所以等级自己的“多少”（以前叫“多见”）只在自己做的、没写比例的时代里用到。它在页面上不列（`page-segments.ts` 的 `HIDDEN`），数据照旧留着，
时代没写比例时色条按它画。没有去掉字段，所以不用重录摘要、不用加版本。
格局自己的“多少”不能藏：每个时代的附庸格局（朝贡、封建附庸、保护国、附属国、星际附庸……）都没写多少，用的就是格局自己的。说明改成“时代里没写时用它”。

### 叫法统一（`packs/copy.ts`、`docs/dev/ui-design.md` 的表）

- 存：一项、几项、读进来的文件都叫“存到我的库”；整个内置的库复制一份叫“复制成我的库”，只在右上角“⋯”里（一项的页面、列表上不再放）；存成文件叫“导出文件”。
- 删除：本世界的一项“删除”（悬停写“从本世界删除；自己做的存到我的库”，历史里“删除文化“X””），“清理没用到的”叫“删除没用到的”；上级页面里把一项拿出去（不删）还叫“移出”。
- “时代规则”都叫“时代”；“维度”都叫“变量”（取值不变）；“收起（Esc）”→“关闭（Esc）”；生态编辑器的“在地图上看”（换底图）→“看底图”。
- 资源库面板新加的字都在 `src/ui/packs/copy.ts`。

### 一行最多一个标记（`page-marks.ts` 的 `oneMark`）

默认 / 在用先，其次和库不同，最后本世界改过；变淡是样子，不算标记。勾只在挑选时有。

### 从别的库挑是一种模式（`panel-store.ts`、`pick-view.ts` 的 `pickMode` / `shownPick`）

右上角“从别的库添加…”（列表上的同一个按钮直接开到那个库的这一种）进入，标题写“从 [库 ▾] 挑选”，右上角“完成”；不在这个模式时看库只是看，没有勾、没有右栏。
挑选时换库还在挑选，切到本世界就结束；“完成”回到原来那一份，勾了还没加的先问（添加 N 项 / 先不加 / 取消），先不加的勾都记着；首页按 Esc 也是完成。
勾选、闭包、添加的逻辑（`pick-store.ts`、`pick-look.ts`、`pick-add.ts`、`closure.ts`）一行没改，组件不再直接用 `pickView`，用 `shownPick`。
上级页面里的“从别的库添加…”照旧在右栏开一栏（`LibOther.tsx`）：它要把勾的放到这个上级下面，挑选的模式里没有“上级”。

### 一个撤销（`pages.ts` 的 `undoTarget`、`panel-store.ts` 的 `undoHere` / `undoState`、`TopBar.tsx`、`shell/keys.ts`）

只看面板看的是哪一份：面板关着、看本世界——世界（本世界里改一项本来就是世界的命令）；看我的库——这个库自己的；看内置的库、读进来的文件——不能撤销（免得看不见的世界变了）。
顶栏的撤销、重做和 ⌘Z 走同一条，悬停写撤销哪一步（世界的看历史，库的看 `libEdits.undoLabel`）。面板上自己的撤销按钮去掉了（只留一处，像 Procreate）。

### 帮助

资源库一步收成五条（`Help.tsx`），细节在使用说明。

## 速度

只改界面。面板照旧是 memo 的（第七十九轮的 `useMemo` 的 ctx、顶上一行 memo 都留着，看的不是本世界时的那一行也是 memo）；`regenNeed` 多比一次省份划分（几个数）。
对数的刻度按字段算一次停的地方（最大的国家大小约 540 个），滑块拖动时二分查找。

## 测试

新的 `src/ui/packs/lib-easy.test.ts`：重新生成的条（省份划分算、湖不算、和国家一起是一步先划分省份、写会重做什么、手改过的写出来、重新生成后不再写）、打开总是本世界（`startOf`）、
对数滑块的值 → 位置 → 值、单位和百分比的写法、每个有上下限的数都是滑块、说明不超过 20 个字、色条和不变且松手交一次、生成设置和那一项的页面同一条命令、一行一个标记、内置的时代都写了比例。
改了的：`pick-view.test.ts` 的两栏（要先进入挑选，完成回到我的库）、`undoTarget` 不再看点在哪里、改名的几处字。`tool-replay.json` 没变。

## 合并时改的

- **改国家大小却不重做国家**：时代改了算“重新生成人文”，而只重新生成人文时国家的领土不动，所以国家大小、领海、等级比例、格局、按文化分国、集团的称号、国境外划进国家这几项改了等于白改（这是以前就有的，生成设置把国家大小摆到最前面才显出来）。现在时代里这几项变了，条上写“会重做人口、文化、国家、城市”，一步重新生成人文和国家（`regen.ts` 的 `ERA_COUNTRY_KEYS`；测试：区域上国家大小改成 1/8，国家多了）。预览里 6.5 万 → 2.8 万 km²：12 国 → 63 国。
- **色条看不见**：新组件的类名 `.share-bar` 和第二十二轮人文里那一条小的占比条重名，后面那条规则把高度压成 0。新组件改叫 `.ratio-*`。
- 生成设置里人口密度下面那一句改成“总人口 = 人口密度 × 陆地面积”（原来那句像是在说城市化率）。
