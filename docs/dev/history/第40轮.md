# 第四十轮的设计

从开发说明里搬来（第四十一轮）。这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## 叠加层与排版提速（第四十轮）

用户说选国家图层时还是卡，别的图层也看一看。第三十九轮管的是 GPU 合成与换模式，这一轮管主线程上的 2D 叠加层（地名、国名、城市、道路、风、比例尺……）、排版、片区名、风的流线与国家的档案。原则同上一轮：屏幕、导出逐像素相同，只省白做的工作。

**白做了什么**：
- 鼠标每动一下（`map/input.ts` 的 `onMove`）都 `requestDraw`：整帧重画，叠加层清空后把国名、地名（每个字描边、填字两遍）、城市图标、道路、风、省名、纬度、比例尺全部重画，只有河是缓存的位图。同一格里动、预览一点没变也一样。
- 排地名的避让逐个比全部已放的框（国名 `boxes.some`、地名、山峰的三角），国家模式里先放上千个城市的框；每个地名都设一次 `ctx.font`（设一次要解析一遍字体名）。
- 悬停的地名在版面的键里：在地名上移过就整张重排。转球时版面的键里有 `lon0`、`lat0`：转动的每一帧都重排。
- 片区名（`map/political.ts`）按中文 / 原文与国家的档案缓存几何：换中文 / 原文、改名都要整个重算（地区 21–41 毫秒），在那一帧里同步算；第一次切到要它的模式也是。`listOf`（`core/human/era.ts`、`government.ts`）没有这一种时每次给新的空数组，按列表对象认的缓存次次错过。
- 风、洋流的流线每帧重新描；缩放到新的一档，看得见的块在这一帧里同步算；块的缓存只涨不减。
- 选国家：档案（`CountryArchive.tsx`）带 `key={m.id}`，换一国整个抽屉卸掉重建；每次渲染用 `localeCompare(…, 'zh')` 排全部国家（每比一次按语言建一次排序器）；`vassalsOf` 每次扫全部国家（一层层往下找时 O(n²)）；列表每一行每次重新生成旗的 SVG；选国家、选集团几次写信号各通知一次。
- 省份、地名的高亮（`map/highlights.ts`）每帧扫一遍全部格、复制一遍格。

### 鼠标移动：预览没变就不重画

`ToolHandler.moveKey(p)`（`tools/api.ts`，可选）：鼠标移动（没按着）时 `preview()` 只随这个键变，在 `move(p)` 之后调。`map/input.ts` 记下上一次移动的工具、键与鼠标下的地名；下一次三样都相同（键逐项 `===`）时不 `requestDraw`，只调 `hintAt(p)` 把鼠标旁的那句话挪到新的位置（`MapView` 的 `hintAt`：同一句话、新的坐标，与 `drawFrame` 算出来的相同）。按着、拖滑块时照旧每次重画；别的手势（按下、松手、离开、缩放、镜头动了 `refreshPointer`）之后作废。键的约定：要包括 `preview()` 用到的鼠标的一切。
- 指针：在不在地图上、鼠标下的城市（`hot`）、“这里”的格、描格的格与陆水；
- 选国家、合并国家：画面上的格；
- 选省：画面上的省、⇧。
别的工具（画笔圈跟着鼠标、量距离……）没有键，照旧每次重画。

### 叠加层：什么都没变时不画

`drawOverlay` 分成三段（`overlayParts`：`under` 河与标记、风、洋流、经纬、道路；`shapes` 工具的图形；`over` 省名、地名、比例尺；投影时 `overlay-proj.ts` 的 `projectedParts` 同样三段），依次画在同一张画布上就是原来的命令。导出（`st.frame`）、移动中照原样直接画。屏幕上停稳时（`drawScreen`）：
- **静态的键**（`staticKey`）：世界、路径、镜头（含投影的朝向）、画布的大小与 dpr、开始时画布上的 `textBaseline`（省名不设它，照用经纬网或上一帧的地名、比例尺留下的，所以进键）、选项里除了图形以外的全部（`FIELD_KIND` 表：每加一项选项要写明进不进键，不写编译不过；每帧新建、内容相同的省名数组按元素比、地名类型的 Set 按内容、纬度按数、画风按 `mapStyleKey`）、字体加载的次数、自定义点的小图解码了几张（`settle-draw.ts` 的 `settleImageEpoch`）、风与洋流空闲时算好了几批（`wind.ts` 的 `windEpoch`）。
- 键与图形（`sameShapes`：每帧新建的图形按每一项比，点、格、流量逐个比）都与上一次画的相同：**什么都不画**，画布上就是上一帧（逐像素相同），返回上一次的地名框。鼠标在地图上动、预览没变时（见上）连这一帧都没有；跨了格、预览没变的叠加层（指针、选国家在国家模式里）走这里。
- 别的时候照原样直接画。新画布的 `textBaseline` 是 `alphabetic`，第一帧以后变成 `middle`：键里有它，所以新画布、镜头停下以后的头两帧照原样画，之后才跳过。

**为什么不贴缓存**：第一版把底下、上面两段画进离屏画布，只有图形变了时贴回来、只画图形。在无头 Chrome 里逐字节对照：
- 底下一段画进一张同样大的画布、再按 `copy`（或在清空的画布上按 source-over）贴回来，与直接画在叠加层上逐字节相同；只有道路、只有地名的两种画面贴缓存的帧也逐字节相同（按软件画）；
- 道路、地名都有的画面，贴缓存的帧按软件画时仍与直接画差几万字节（找了几轮没找到原因）；按显卡画（SwiftShader）时，旧的代码自己同样的命令重画一遍（中间多画一个画面外的圈）读回来就差几万到二十几万字节——画布按整帧的命令决定怎样光栅化，分开画的几段与一次画完的本来就不一定相同。
所以只有图形变了时照原样整张画（主线程约 0.3–1.2 毫秒，与原来相同），不用离屏画布，屏幕逐像素相同。

### 排地名

- **按格子查避让**：`placeLabels` 建一个 `BoxIndex`（`settle-draw.ts`，48 像素的格子），国名、城市、地名、山峰的三角都按它查、放好的框同时放进 `boxes` 与它（两边始终是同一批框）。结果与逐个比相同：两个框重叠时必有一点同在两框里，那一点所在的格两框都占着；坐标不是有限数或一个框跨的格太多（> 64 格）的放进 `wide` 逐个比，查的框是这样的时逐个比全部。
- **只在量字时设字体**：字宽缓存里没有这个字才设 `ctx.font`（国名、城市早就这样）；画的时候每个地名自己设。
- **悬停**：`layoutHover`：悬停、选中的地名只有是一个地名或山峰、并且不是本来就“用户自己的”（圈的地区、改过的名字）或是删掉的时，才进版面的键；悬停国名、城市、自己的地名时版面不重排（排出来与不悬停相同：`mine` 与“删掉的照样标”只对那一个地名起作用），悬停的样子（描边的颜色）由静态的那一层按 `hoverLabel` 重画。悬停一个普通的地名照旧重排（它排到最前，别的地名让它，原来就是这样）。
- **转球**：等面积、球形投影里转动、缩放的一次手势（移动中、还没停稳过；停稳画一次地名 `gesture` 加一）沿用这次手势第一帧排好的版面（多排了一圈边距），地名、图标按记下的锚点（地图坐标与排的时候的屏幕位置）挪到现在的位置，国名的每个字按排的时候落在地图上的点（`worldAt`）重新投影，转到背面的不画；缩放超过 1.3 倍、版面的键（不含朝向）变了时重排；停稳的那一帧照原样重排。移动中的样子与原来不同（原来每帧重排），停稳的一帧相同。
- 山峰三角的分格（`grid`）不再每加一个复制一次数组。
- `?perf` 记 `layout`（这一帧排地名的毫秒数）。

### 片区名：几何与字分开

`map/political.ts`：几何（每一片的中线、屏幕上的大小：`regionLabels`，地区约 20–40 毫秒）按种类各留一份（`geoMemo`），键只有每格的编号、陆海、网格与编号的个数（国家：领土、陆海、网格、国家的编号；集团：领土、每格的国家、陆海、网格、集团的编号 / 种类 / 成员、国家的编号；文化、文化组、每一维：编码数组（每一维另带是第几维）、名字表的长度、陆海、网格）；配字（名字、中文 / 原文）另按几何、名字表（国家、集团、取值的对象）、中文 / 原文记下（`drawMemo`，同样的给同一个数组，地名的版面不必重排）。改名、换中文 / 原文只重新配字。
- **空闲时算**：`regionDraws(w, src, nm, lazy)`：屏幕上（`MapView` 给 `requestDraw`）这一种的几何一份都没算过（第一次切到这个模式）时，排进 `requestIdleCallback`（没有时 `setTimeout`），这一帧给 null（先不写片区名），算好了调 `lazy` 重画；以前算过、只是输入变了的（编辑以后）照旧当场算，免得片区名闪一下。导出、测试不给 `lazy`，当场算。
- 结果与第三十九轮相同（测试留着原来的 `political.ts` 对照）。
- `core/human/era.ts`、`government.ts` 的 `listOf`：没有这一种时给同一个空数组（同 `settle-content.ts`）。

### 风与洋流

`wind.ts`：块按场的数组缓存，最多 `TILE_CAP` = 384 块，取到的挪到最后，满了扔最前面的。屏幕上（`OverlayState.lazy`，`MapView` 给 `requestDraw`）缓存里没有的块不在这一帧里算：排进队，空闲时一块块地算（每段约 6 毫秒），全算好了 `windEpoch` 加一、调 `lazy`。算好之前：上一次画全了的那一档（按场与季节记下）看得见的块都在缓存里时先画它，否则只画已经算好了的块（第一次打开风向时那一帧什么都不画）。算法、随机数与当场算的逐点相同（测试：空闲时算好后画出来的与当场算的相同）。镜头、季节、场都没变时叠加层不画，也就不重描（键里有 `windEpoch`）；只有图形变了、移动中照旧整张描（与原来相同）。

### 选国家

- 档案去掉 `key={m.id}`：换一国只重画变了的地方。按国家重置的状态：名字、原文、各个字的框照旧跟着值走（`useEffect`）；历史这一段照旧按国家重建（`key={m.id}`：打着字换国家时，没提交的字在卸下时写进原来那一国）；派系的拖到一半的值另加按 `m.id` 清掉。
- 中文排序：`countries.ts` 的 `ZH`（一个 `Intl.Collator('zh')`，比较的结果与 `localeCompare(…, 'zh')` 相同）、`countriesByName`（按国家的对象缓存排好的国家）；档案的外交、领土，集团的档案、城市的档案、能加入的集团都用它。
- `vassalsOf`：按国家的对象建一次“宗主 → 附庸”（顺序同 `Object.values`），给一份副本。
- 列表（`panels/countries.tsx`）：旗的 SVG 按旗的对象与大小缓存（`flagHtml`）；每一行是 `memo` 的组件，档案、统计、政体名、宗主、选没选中都没变时不重画（点的时候按当时的世界）。
- `selectCountry`、`selectBloc`、指针的点击里几次写信号合成一个 `batch`。

### 其他

- 选中的省、地名的高亮按选中的与省份数组、地名数组记下，每帧不再扫一遍全部格。
- 投影时的省名、道路：镜头与选项都没变时整个叠加层不画，也就不再逐个投影。
- `?perf` 新的几项：`overlayStatic`（静态的变了、照原样画的毫秒数）、`overlayDynamic`（只有图形变了、照原样画）、`layout`；`notes` 里 `overlay:skip`（什么都不画）、`overlay:shapes`、`overlay:direct`、`overlay:motion`。
- 2D 画布的上下文丢了又恢复（`contextrestored`）时静态的那一层作废、重画。

**已知限制**：静态的键一变（镜头停下、悬停换了普通的地名、世界变了）或工具的图形变了（画笔圈、悬停的城市圈跟着鼠标）照旧整张重画、重新光栅化；新画布与镜头停下后的头两帧照原样画（画布留下的 `textBaseline` 在键里）；只有指针、选国家、合并国家、选省四个工具有 `moveKey`，别的工具每次移动照旧重画；转球的手势里沿用版面（转进来的地名停稳后才排上，字的方向是排的时候的）；风向的新一档在空闲时算，算好之前画上一档或只画算好的块；片区名第一次切到那个模式时晚一帧出现；投影的转动、缩放、移动中照旧每帧直接画叠加层。
