# 第五十九轮的设计

这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

用户要的：资源库改成本世界在左边、别的库从右上角来；一个库是一个可以编辑的东西；每个文件的关系要清楚，“而不是丢一个类似文件夹的东西”。用户是新手，界面像 Procreate 和手机设置。

## 面板

左上角一个窄的面板（380 px），标题是下拉：本世界 / 内置的库 / 我的库 / + 新建一个库。**切换以后界面完全一样**：所有的页面都从“看哪一份”（`SourceRef`）和世界、资源库（`PageCtx`）算出来，本世界和库只差 `itemsOf` 和只读。

层层点进去：首页 → 列表 → 这一项的页面，左上角返回，Esc 也是返回。路线是一个栈（`Route[]`）。这一层没了（撤销了新建、库删了）时 `liveStack` 从不在的那一层截断，所以不会有“这一项找不到”的空白页。

**逻辑都在 `src/ui/packs/pages.ts`**（首页有哪些卡片、怎么点进去、面包屑、一项的页面有哪些段、只读与否、这一项能做什么、引用点到哪里、⌘Z 撤销哪一边），组件只画。`page-layout.ts` 是首页的排法，`page-segments.ts` 是每种内容的分段。

### 首页

按计划的草图：最上面时代规则，下面五段。时代的**每一维一张卡片**（“宗教 7 组”），不是一张“取值”：点进去只看这一维，按取值组分段，段的标题点了去那一组。“变量”点进去是时代规则的那一段。

第六十轮的路：`homePage` 收一张“卡片 → 上级”的表（`Inside`），归到别的卡片下面的不单独列，上级写“含文化、地名风格”。这一轮这张表是空的，测试查了传进去的样子。卡片的归属将来由库的 `arrange` 决定，页面不用改。

### 一项的页面

几段可折叠的卡片（`segmentsOf`），收起时标题旁写一句（`segmentBrief`，引用写名字）。**表单还是 `FieldsBox`**，只是每一段给一部分字段；`FieldsBox` 多一个 `scope`：`when` 指的字段可能在别的段（地名风格的“写法”），改的时候按整张表算。

**id 不在页面上**：改了 id 别的内容就找不到它了；新建、复制的 id 自动起。测试查着：每种内容除了 id，每个字段在且只在一段里。

**引用能点过去**：`RefGo` 这个 context，面板给一个函数（`refRoute`）：这一份里有它就到它的页面，没有不能点。维度到时代规则的变量那一段，条件里的 `river:x` 到河的页面。用 `<a>`：只读的表单是 `<fieldset disabled>`，里面的 `button` 都不能点，`a` 能。

替用户定的：**写了范围的数画成滑块**（`sliderScale`：有 `min`、`max`、`step`，不超过 2000 格），用户说过控件是连续的；第 58 轮的典型高度就是这个。范围太大的（人口密度 0.001–10000、比重 0–1000）还是框。这也改了旧面板的 `FieldsBox`，旧面板已经不挂了。

### 入口

资源库按钮和所有别处的入口（`openLibraryFor`、缺内容的提示、“示例生态…”、“城市 ⋯”、“新类型…”）都开新面板。`RepoPanel` 不挂了，文件和测试留到第 63 轮。“从资源库添加…”开世界用的库、只列不在本世界的（`hideOn`）。

右上角“导入”先走现有的 `openPackImport`，第 61 轮做新窗口。从本世界存进资源库、整理本世界、资源包在“⋯”里（第 62 轮会动）。

## 自动保存

松开滑块、打完字（`Draft` 本来就是失去焦点才提交）就存，没有“用到本世界”“存进资源库”两个按钮了：看哪一份改的就是哪一份。

- 有错的留在页面上（草稿），下面写“要改”，改好才存。
- 本世界：一条命令（`worldItemCommand`），世界的撤销栈，大星球上连着改几项时排队（`queueWorld`，和河湖类型的编辑同一个做法）。生态的命令按字段，去掉的写 `null`（`speciesPatch`）。
- 我的库：见下一节。
- 只读的库 `commitItem` 直接返回 `readonly`，表单也不能动：两层。

⌘Z：`undoTarget`。面板开着、看我的库、**最后点的是面板里**：撤销这个库；别的都是世界。看内置的库时点了面板再 ⌘Z 什么都不做，免得看不见的世界变了。这是替用户定的：只按“看哪一份”的话，开着面板画一笔再 ⌘Z 会撤销库。

## 写库

`src/library-edit.ts`。以前改一项（`editMineList`）：读存储、六个库全部 `parsePack`、克隆这个库、改、这个库再 `parsePack`、写整个库、再读一遍六个库。

现在：

- **校验**只查这一项（`itemErrors`）。
- **内存**：包是不改动的数据，改一项只换这一项到树根这条路（`mapNode`），别的小包是同一个对象。同一项在几个小包里每一处都换。
- **撤销**记改之前、改之后两个树根，几乎不占地方，每个库一个栈，切走不丢，和世界分开。
- **存**分两步：
  1. 改一项马上写进**日志**（localStorage，同步，只有改过的那几项）。刷新页面、关掉页面不丢，下次读库时 `adopt` 补上（每一项照样查格式，不合格式的不补）。
  2. 整个库晚一点才写 IndexedDB：停手 4 秒、关面板、切换库、`pagehide`。写完去掉日志；写的中间又改了，日志留着。
- 记不成“这一项换成这样”的（加、删、换先后、改库名）马上写整个库。日志写不进去（隐私模式、超过 1 MB）时 200 ms 后写整个库。

为什么日志不用 IndexedDB：它是异步的，刷新的瞬间写不写得进去没保证，这正是要防的那个窗口。localStorage 同步，放的又只有改过的几项。

**版本**：`Stored.rev` 每写一次变大。读存储时同一版不再 `parsePack`（`parsedPack`）；我的库写进去的那一份记为查过（`rememberParsed`），每一项改的时候查过了。存着的比内存里新（别处换掉了这个包：存进资源库、导入、别的页面）就放弃内存里的和撤销。`removePack` 通知编辑器（`forget`），没写的不会把删掉的库写回来。

打开面板不再每次读存储（读六个库要在主线程上解开约 9 MB），只读第一次。

## 复制成我的库

`copiedPack`：新的键、新的名字，内容和原来的库**共用同一份对象**，改的时候才换（上面那条路），所以复制是瞬间的，内存不多占。存进 IndexedDB 时是展开的（约 1.8 MB 一个库）。复制之后还在同一页。

`worldPartsOf` 以前按键写死 `fantasy`，现在看小包在不在（`biomes`、`rivers`、`lakes`）。测试：奇幻的副本新建世界加的生态、河湖、内容和内置奇幻逐条相同，只差来源。`DEFAULT_WORLD_PACKS` 写成字面量：它在模块载入时算，那时内置的树还没拼。

## 生态与水系

地理里一张卡片，里面是生态、河、湖、总表（`waterTable`）。总表纵列生态，横行水系，普通河、普通湖也是一行。

**同一份数据**：`core/water-table.ts` 拆成 `waterCellEdit`、`waterBlockEdit`（算出一处改动 `WaterEdit`）和 `waterEditCommand`（世界里是命令）。`setWaterAllowed`、`setWaterBlock` 照旧导出，给出的命令和以前一样。库里 `applyToLibrary` 把同一个改动落到那一项上。总表、生态页（`SpeciesWaterForm`，生态抽屉也是它）、河湖页都走 `commitWaterCell`。

世界里点一格要算一会儿：勾先变（`useOptimistic`），世界换了去掉。

第 57 轮的坑：

- 奇幻的六种河规则写在脚本里，每格都勾着。表上写“规则”两个字，悬停和表下一句写“先看规则，规则说是的再按这里的勾一格一格看”；河页写现在按什么出现（`waterRuleNote`）。
- 不自然生成的写“不自然”。
- 河的条件没有大小，湖有：字段表本来就对（`whenField`），测试查着。
- 断流的说明留在 `SpeciesWaterForm` 里，生态页、抽屉一样。

字段表补了几处：河、湖的画法写中文（`RIVER_STYLE_LABEL`），湖以前没有画法这个字段；生态、河、湖、岛有 `blank`（新建）；“自然生成”写了 `default: true`，省略时开关是开着的（和引擎一样）。

## 顺手解决的

- **底部条“类型：X”**：河页“出现在哪些地形”一段写“一条河可以分段不同；地图底部写的类型是占一半以上的那一种，没有时写普通河”。
- **“本世界加的”组重开时重新勾上**：取消的组比重写 0（`retireGroups`），和第 50 轮“0 就不参与”同一个意思；再勾上时 `reviveGroups` 去掉。只取消了它时人口不重算，只记这一笔（`regenerateWith`）。
- **两个季节**：图层面板的“季节”下面写一句（`copy.ts` 的 `SEASON_NOTE`）。
- **典型高度**：地形类别第一段，滑块，无头 Chrome 里拖过：2400 → 4500，世界里改了，页面写“改过”，能撤销。
