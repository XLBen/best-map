# 第三十七轮的设计

从开发说明里搬来（第四十一轮）。这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## 描格（第三十七轮）

指针描出鼠标下的格、钉住的格描边（第二十五轮的指针、“指针描格”）原来走高亮纹理：一层只描边（alpha 字节 128）的高亮，着色器的“高亮与轮廓”按像素扭曲后的格 `id` 与相邻像素的 `idAt(uvW + hx)` 比。指针给的是 `DisplayCell.here`（与这一点同类的格，按 `causes.land` 分陆海，湖算陆地），两者在海岸、峡湾、岛礁、沙坝的像素上不同，结果描出来的线跨进海里、切过陆地、对不上湖岸，有时鼠标都不在框里（测试里这样的像素占 2.5–4%）。这一轮改成跟着画面上的陆海描。

**规则**（“描格的格”）：
- 像素 p 的格 F(p) = 省份的规则（GPU 的 `provCell`、CPU 的 `provinceCell`）不按剪刀切线换格：画成水面（海、湖：画面的海岸值 < 0）的像素取到陆地格时依次试没扭曲的最近格、0.6 / 1.2 格两圈各 8 点，取第一个水面格，都不是时 −1；画成陆地的像素取到水面格时试 0.3 / 0.6 格两圈，取第一个陆地格，破碎的水面格（碎岛）就是那一格，都不是时取 `landCellOf`（最近的陆地省的格）。
- 小湖群的像素（地形层写成 `SPECK_MARK`）算它扭曲后那一格（`idAt(uvW)` / `cell`）的陆地：小湖在框里，不另描。
- 描出的范围 R(c, 陆/水) = {p : F(p) = c，且 p 画成的陆或水与鼠标处相同}。鼠标在陆上描这一格的陆地部分，在水上描水面部分；湖面描到画出来的湖岸；碎岛上描这一格的几块小岛，旁边的水上描水面、小岛处留洞；峡湾深处 F = −1 的水面不描（卡片照旧写“这里”）。
- 不按切线换格：钉住、悬停说的是一格，切线只管省份。

**GPU**（`src/render/renderer.ts`）：
- `provRule(name, pick)` 是 `provCell` 与 `focusCell` 共用的模子，`provCell` 的 `pick` 是 `seamCell(…, uv)`，`focusCell` 原样取格（`provCell` 的源码一字不变）。`FOCUS_GLSL` 另有 `focusAt(uv, uvW)`：照 `provAt`，每个取样按自己的场景像素判陆海；返回 格号 · 2 + 陆 1 / 水 0，没有格时 −1。
- uniform：`uFocus`（ivec2：鼠标下的格、钉住的格，各是 格号 · 2 + 陆 1 / 水 0，−1 不描）、`uFocusC[2]`（格心与半径，地图单位）、`uFocusSphere`（整个星球 1）。`nearFocus` 先按到格心的远近排除：一块地区按平面距离，整个星球按球面上的弦长（地图单位的 1 合 π 弧度；按经度差乘 cos 纬度的写法在两极的格上不对：极点那一格在等距圆柱上横跨整个经度）。半径 `FOCUS_REACH` = 3.2 格。
- 画在“高亮与轮廓”之后、地图外的背景之前：中心与上下左右各 1 个像素（`ex`、`ey`；投影里是 `uDX` / `uDY`）各算一次 `focusAt`，在 R 里而有一个相邻像素不在的是里面一道白（0.9），不在 R 里而有一个相邻像素在的是外面一道深色衬边（0.42）：线居中约 2 像素，浅色的平原、雪地上也看得清。浓淡 ÷ `uPxScale`，与高亮的轮廓一样。
- 平面、星球、投影三个合成着色器都有（投影由星球的替换出来：`mustAll` 的 `toScene` 从 6 处变成 7 处，`ex`、`ey` 两处 `must` 换成 `uDX`、`uDY`）。
- `renderer.setFocus(hover, pinned)`：`CellFocus | null`，格号超出网格的不描；`focusKey` 在停稳合成的 `composeKey` 与投影的合成键里。

**CPU**（`core/display.ts`）：`DisplayCell.focus: CellFocus`（`{cell, land}`）：`provinceCell(world, f.coast, null, x, y, cell, near, water, f.frag)`，小湖群 `{cell, land: true}`；没有切线时就是 `province`。`here`、`province` 不变。

**界面**：
- `tools/api.ts`：`Preview.focus`；`focusOf(w, p)`（`shown.focus`，没有 `shown` 时是 `cell` 与格的陆海，湖算水面）；`pinTarget(w, p)`（描格的格与 `'land' | 'water'`；格为 −1 时钉 `here`、`part` 为 null）。
- `tools/pointer.ts`：悬停时 `preview()` 给 `focus`（格为 −1 时 null；停在城市、地标、点上时没有）；点一下 `pinCell(pin.cell, pin.part)`。右键钉住（`map/input.ts`）同样用 `pinTarget`。
- `state.ts`：`pinnedPart`；`pinCell(cell, part)`，`pinCell(-1)` 一起清掉（收起卡片、取消钉住、新建或打开世界、网格变小）。
- `map/highlights.ts` 去掉了 `cellOutline`、`pinLayers`（高亮的键里也没有钉住的格了）；别的工具的高亮（画笔描格等）照旧走高亮纹理。
- `MapView` 每帧 `renderer.setFocus(preview.focus, pinnedFocus(w))`（指针工具开着、鼠标在地图上、不在城市等标记上时才有悬停的那一格；钉住的格任何工具下都有）；导出的干净画面与 `cleanState` 都是 `setFocus(null, null)`。

**测试**：见“测试”的“描格”。着色器在无头 Chrome（SwiftShader）里编译、链接过平面、星球、投影与去掉花纹的四份。

**速度**：只改画法。`displayCellAt` 只在悬停时调，有切线时多算一次 `provinceCell`。合成里离两格格心 3.2 格以外的像素只多两次距离判断；以内的多五次 `focusAt`（每次最多 17 次取格），只在鼠标所在的那一小片。
