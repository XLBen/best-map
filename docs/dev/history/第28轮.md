从开发说明里搬来（第四十一轮）。这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## 资源库与本世界（第二十八轮）

做法照 Blender 素材库的“追加”、Figma 的团队库：资源库（`src/library.ts` 的包 + 各种类的 `builtin()`）里是全部内容，世界里只放添加进来的，工具里只列本世界的。

- **用在哪里**（`core/content/usage.ts`）：`ContentKind.usage(world, id) → {count, label, cells?} | null`，`registerUsage()` 在 `content/kinds.ts` 的最后用 `updateKind` 挂上（不改各种类自己的登记）。
  - 放在 `small.content` 的种类只按原因与小状态数，重放结果不变：文化（有人的格（`popGroup`/`popShare`）、主流文化是它的国家、发源地、生成时点名的、自动快照里有它）、文化组（属于它的文化、这一组有人的格、兼容它的国家、生成时选的、发源地）、取值（有人的格、自动快照）、时代（`human.era`）、政体（国家，定位给领土）、派系（国家写了影响力的）、地名风格（文化、地名、省份；世界默认不算，停用默认时 `disableRowCommand` 一起换回内置中文）、城市等级 / 地标类型 / 点的类型（定了等级的城市、地标、点）、地形类别 / 资源（画成它的格）。
  - 以前的种类在界面里还按推导数：生态（`dominant` 是它的格、涂了它的约束）、河 / 湖的种类（`derived.riverType` / `lakeType` 是它的格、选了它的画的河、湖）、岛的种类（`causes.islandType` 是它的格）。
- **引擎也拦**：`commands.ts` 的 `setContent` 停用（`item: null`）时查 `usageOf(kind, {small, causes}, id)`，有在用的抛 `CommandError`（“文化“瓦尔蒙人”还在用（952 格有这种文化的人），先把用到它的地方改掉”）。不查的：总在的内置项（去掉改过的那一份是换回内置的）、有 `afterSet` 的种类（地形类别、资源：画成它的格本来就跟着恢复自动，只在资源库里拦）。以前的种类的删除命令（`remove_species`、`remove_river_type`……）照旧，它们会把用到它的地方变回普通的；资源库里一样按 `usage` 拦。
- **新世界只带用得上的**：生态是 `DEFAULT_SPECIES` 的 13 种、没有河湖的种类（本来就是）；“水体类型”里的奇幻示例按钮去掉了，换成“从资源库添加…”。生成人文时 `ensureHumanContent` 照旧从内置的复制，最后一步 `pruneHumanContent`（`core/human/prune.ts`，在 `generateHuman` 里，命令的一部分，重放一样）去掉与内置一模一样、没用到的：不是 `human.era` 的时代；没人、也不是这个时代每一维能用的取值；没人、不是国家的主流文化、没有发源地、生成时没点名的文化；没选、没有留下的文化、没有国家兼容、没有发源地的文化组；去掉的文化用的、别处都没用到（`styleInUse`、留下的文化）的内置地名风格。自己做的、改过的总留着。政体、派系不动（时代的那一组是档案里能选的）。人口、领土的原因数组不变（推导的文化编号按留下的重排）；人文的几个金标准没有变。
- **界面**（`src/ui/packs/repo.ts`、`RepoPanel.tsx`）：
  - 筛选 `REPO_FILTERS`：全部 / 本世界（`on`）/ 不在本世界（`off`）/ 内置 / 资源包（`imported`）/ 我的；卡片写来源（`SOURCE_LABEL`）和“在本世界”。
  - `addCommand(row, world)`（不在本世界、能添加时是 `enableRowCommand`）、`removeCommand(row, world)`（在本世界、能动、`rowUsage` 为空时是 `disableRowCommand`，包成“移出本世界：……”一整步）；`rowUsage` 按世界对象记着（`WeakMap`），卡片写“有 N 处在用：……”和“定位”（`camera.ts` 的 `focusOn`）。`toggleCommand` 照旧（预览、测试用）。
  - `saveableItem`（只有 `source: 'world'` 的：本世界做的、改过的）→ `saveItem` 存进“我的资源”；`itemPack(row)` 单独一项的资源包（生态带上 `fieldsOf` 的场）→ 导出文件；`canDeleteFromLibrary`（只有 `mine`）→ `library.ts` 的 `removeItem(包的键, 段名, id)`（删到空时整个包删掉）。
  - 选择器：`TypePicker` 多了 `library`（种类 id）：最后一项“从资源库添加…”（`openLibraryFor(kind)`：打开资源库、筛到 `off`），`onNew` 可以不给；不是 `TypePicker` 的（国家档案的政体、主流文化，群体的下拉）下面放 `LibraryLink`。国家档案的政体是时代的那一组再加本世界别的（`governmentChoices`）。
  - 生成人文的选择（`src/ui/human.ts`）：`choiceLists(small, scope, lib)`——`library`（新建向导、第一次生成）列内置的 + 资源包、我的资源里的 + 世界里的；`world`（重新生成）只列本世界的，`HumanChoices scope="world"` 下面有“从资源库添加…”。`eraChoices` / `groupChoices` / `cultureChoices` 多了 `lib`；`chooseEra` 的 `lists` 让默认的组只从列着的里挑。选了资源包里的时代、文化组时 `importCommands` 先 `set_content`（地名风格 → 时代 → 文化组 → 包里这一组的文化），`generateCommand(c, small, lib)` 和生成合成一整步。
  - 从本世界存进资源库（`PackDialog.tsx` 的 `ExportView`）：`exportSections(world)` 按 `repoKinds()` 每一种的 `fromWorld` 列出（人文的几种也在），`exportPicks` 给 `packFromWorld` 每一段的勾选，`packEmpty` 看每一段；资源包的内容（`PackContents`）也按登记表列。
