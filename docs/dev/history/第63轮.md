## 前几轮记下的

- **`addCommand`、`packAddCommand`**：删。`PageItem` 的“添加到本世界”第 59 轮接的是 `addCommand`（没有闭包，会留下找不到的引用），这一轮才发现，改成和列表一样走 `addRows`。
- **`restoreCommand`、`builtinOriginal`、`status.modified`**：`restoreCommand` 删（“用库里的版本”代替）。`status.modified` 留：看内置的库时，世界里改过的那一项要算“在本世界”，不然写“添加”，点了多一个 `id-2`。`builtinOriginal` 只留判断（`rows.ts` 的 `builtinChanged`），只有内置的库的行要算；世界里的行不再算（“和库不同”已经写了）。
- **`tidyWorld`**：新面板在用，留在 `tidy.ts`。
- **`removeUnused`、`packRemoveRefs`**：删。第 62 轮说过：它们算上生态、河湖，和清理的规则不一样。
- **`unusedContent`**：留。`engine.planTidy` 没写 `only` 时、`tidy_content` 没写 `items` 时还在用（都在计算 Worker 里），第 62 轮的 `cleanable` 测试拿它对照。删它要动 Worker，这一轮不动。

`core/` 一行都没改，所以引擎的结果和速度不可能变。

## 档案里换政体（第 61 轮留的）

`addFromLibrary` 改走 `importPreview` + `importCommand`，这样不再自己找派系。

- **带上**：政体列的派系（第 53 轮就有）、限谁用的文化组（比重 0，不参与生成）；写到世界里没有的内容，能去的引用去掉。
- **不带变量（替用户定的）**：先算一遍要加哪些变量，把它们放进 `off` 再算。第 61 轮说过：换一个国家的政体不该动所有人的人口。写到那个变量的来源去掉，要变量走“导入”。
- **带不了**（去不掉的引用找不到、放不下）：`id` 是 `null`，`governmentCommand` 返回 `null`，点了不做。内置的库里没有这种情况，只有写坏的文件可能。
- **同 id、内容不同的派系**：以前“世界里有这个 id 就用世界的”，现在和导入一样改名为 `id-2`。世界里改过这个派系的人换政体时会多一份；取舍：和导入窗口一个规则，结果可以预料。

测试 `countries-ui`：`only` 的组、变量不加、派系都在、没有新的找不到的引用、两次撤销回到原样。

## 走入口时发现的

都是无头 Chrome 真的点出来的，测试之前没有覆盖：

1. **“查看”之后弹窗还盖着面板**（第 59 轮起）：旧的 `openRepo` 会关 `packDialog`，新的 `openLibrary` 不关。资源包的“查看”、已安装的“查看”都是这样；从导入窗口“装进资源库…”来的还盖着导入窗口。加 `PackDialog.viewLibrary`。
2. **“从资源库添加…”开到空列表**：开世界用的库，它里面的都在本世界了就只写“都在本世界了”。水体类型的“从资源库添加…”悬停写着“奇幻的示例都在那里”，点开却是中世纪。`openTarget` 改成：世界用的库里没有还没加的，就开第一个还有的库。“示例生态…”原来有自己的一段（`biomePackEntry`），去掉，走同一条路。没有一个库还有时还是写“都在本世界了”（岛）。
3. **导入窗口读大文件**：旧面板查 `file.size`，新窗口漏了（`readPack` 只在读进内存之后查）。`chooseFile` 补上。

没了的功能：**旧面板的鼠标停着预览**（停在“添加”“移出”“设为默认”上地图先画出来）。第 59 轮新面板没有做，使用说明一直还写着，这一轮把这句去掉。没有补，要的话是单独一轮。

## 坑

- **导入时去掉了引用的项，清理时算“改过”**：闭包加进来的政体（去掉了这个世界没有的文化组的换说法）和库里不完全一样，`isBuiltinSame` 是假，清理、移出时存进“来自《世界名》”。不丢东西，只是库里多一份。第 62 轮的 `trimmed` 只用在“和库不同”的标记上，要改就是 `worthKeeping` 也认它，但那在 `tidy` 的回复之后，要拿到来源的库。没改。
- **`lp-row` 的旧拖动**（第 60 轮记的）还是 HTML5 的，和 `page-drag.ts` 两套，这一轮没合。
- **列表里的行不走 `removeCommand` 的预览**：鼠标停着预览没了（上面写了）。
- **`rowsOf` 按世界对象记着**：测试里同一个 `eng.world` 改了之后读的是旧的，所以测试直接调 `libraryRows`、`worldRows`。
- **`.lib-panel` 多了毛玻璃**：`.repo` 那一组玻璃样式（毛玻璃、细边、阴影）第 59 轮以来没给新面板，这一轮换过来，和别的浮层一样。样子变了一点，走查时留意。
