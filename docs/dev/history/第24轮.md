# 第二十四轮的设计

从开发说明里搬来（第四十一轮）。这一轮改了什么见 [更新记录](../../更新记录.md)；现在的文件见 [开发说明](../../开发说明.md) 与 docs/dev/ 下的各篇。

## 城市、道路、地标、自定义点（第二十四轮）

人文的第四批：城市按人口自动放（一格最多一座，数量按时代的城市化率，等级按占本国人口的比例），道路按地形的难走程度连城市（大道、小路），地标分自然的（按地形找）与人造的（按文化、时代、政体放），自定义点自己定类型和图标、可以当作城市（陪都）。存进世界的只有“在哪、是不是自动的、自己改过的几项”；名字、等级、所属、人口、建城年份、简介都按世界现算，所以改了人口、国界、地名风格之后跟着变，自己定过的不变。都只读自然的推导，不改地形（`core/human/`）。

**三种内容**（`human/settle-types.ts` 的格式，`human/settle-content.ts` 世界里的列表，`human/settle-kinds.ts` 登记；`store: 'content'`，命令 `set_content`，`dirty` 是 `none`——城市、地标是现算的，不用重算推导；内置的在 `core/packs/settlements/`，**总在世界里**（像内置的地形类别：不用启用、不能停用，`small.content` 里同 id 的一项换掉内置的那一份，停用它换回内置的；别的 id 排在后面）：

| 种类 id | 全称 | 资源包的段 | 世界里的列表 | 内置的 |
|---|---|---|---|---|
| `cityRank` | 城市等级 | `cityRanks` | `worldCityRanks(small)` | `BUILTIN_RANKS`（`ranks.json`） |
| `landmarkType` | 地标类型 | `landmarkTypes` | `worldLandmarkTypes(small)` | `BUILTIN_LANDMARK_TYPES`（`landmarks.json`） |
| `pointType` | 自定义点的类型 | `pointTypes` | `worldPointTypes(small)` | `BUILTIN_POINT_TYPES`（`points.json`） |

**城市等级**（`cityRankSchema`）：

```json
{ "id": "big", "name": "大城市", "icon": "double-ring", "level": 3, "minShare": 0.02, "perCountry": 0.16667, "minPop": 50000, "label": 1.15, "capital": false, "major": true, "color": "#…", "description": "…" }
```

- `icon`：界面按它画（内置的四种 `star` 星、`double-ring` 双圈、`circle` 大圆、`dot` 点；自己写的界面不认识时画圆）。`label`：标注的字号倍数（1 是普通城市）。
- `level`：越大越重要（列表的先后、缩小时先显示哪几级、`major` 省略时首都与 level ≥ 3 的连大道）。
- 自动的等级：首都用写了 `capital` 的那一级（`capitalRank`）；别的城市在 `minShare ≤ 占本国人口的比例` 且 `minPop ≤ 人数` 的几级里取 level 最大的，都够不上时取 level 最小的（`rankFor(ranks, share, pop)`）。写了 `perCountry` 的一级（第二十六轮）每国最多“城市数 × perCountry”座，按人口取前几座，别的降到够得上的下一级。
- 内置 4 种：首都（星，`capital`）、大城市（双圈，占本国人口 2% 以上，每国最多城市数的六分之一；第二十六轮以前是 1%、不限）、城市（大圆，0.4% 以上）、村镇（点）。

**地标类型**（`landmarkTypeSchema`）：

```json
{ "id": "temple", "name": "神庙", "category": "manmade", "icon": "temple", "color": "#…", "description": "供奉神灵的大庙。",
  "eras": ["antiquity", "medieval", "fantasy"], "cultureGroups": ["eastern"], "governments": ["theocracy"],
  "place": "capital", "per": "country", "count": 1, "chance": 0.35,
  "label": { "default": { "zh": "{city}神庙", "orig": "Temple of {city}" }, "eastern": "{city}大寺" }, "manual": false }
```

- `category`：`natural`（自然的，写 `detector`）或 `manmade`（人造的，按 `eras`、`cultureGroups`（国家主流文化的组）、`governments`（国家政体的类别）筛，省略的不限；没有人文时不放人造的）。
- `detector`（`LANDMARK_DETECTORS`）：`peak` 名山（山脉的主峰——地物里的山峰——在前，再是别的山峰格，按海拔）、`volcano` 火山（带 volcanic 标签的山峰与山脉的最高处）、`waterfall` 瀑布（河的一格到下游一格落差 ≥ 150 m 且 ≥ 1.5 m/km，按 落差 × log(1 + 流量 / 河的门槛)）、`canyon` 峡谷（流量 ≥ 两倍门槛的河格，两侧最高的两个不是河的邻格的平均比它高 ≥ 350 m，按 高差 × √log(1 + 流量 / 门槛)）、`oasis` 绿洲（荒漠（生态的地形 desert；第二十七轮起只看生态）里有河或挨着湖、至少 3 个荒漠邻格的格）。
- `place`（`LANDMARK_PLACES`，人造的放在哪）：`capital` 首都旁的一格、`big-city` 最大的非首都大城市旁、`city` 随便一座城市旁、`coast` 海边的城市旁（没有时海边人多的格）、`mountain` 最高的 24 格里按海拔² 挑、`river` 河谷（河格旁边高出最多 × log 流量的前 12 格）、`desert`、`forest`（森林、林地、丛林）、`border` 国界上（挨着游牧、部落政体的国家的格 × 5）、`wild` 没有城市管着的格（按宜居度）、`any`。都不放在城市、别的地标的格上。
- `per` / `count` / `chance`：`country` 是每个国家 `count` 个（小数部分按可能），每个按 `chance` 的可能放；`world` 是整个世界每 5000 格陆地 `count` 个（自然的总按这个算，有候选时至少一个；同类之间隔开 0.5·√(陆地面积 / 个数)）。
- `label`：名字的写法，格式同政体的称号（一个字符串、`{zh, orig?}`、或按文化 id / 文化组 id / `default` 换说法，按地标那一格人口里占多数的文化、没有时所属国家的主流文化）。词：`{city}` 最近的城市、`{country}` 国名的地名部分、`{river}` 这一格或旁边的河、`{range}` 山脉、`{peak}` 山峰（主峰用地物的名字，否则格的小地名）、`{lake}` 湖、`{place}` 这一格的小地名、`{culture}` 文化名；找不到时用 `{place}`。原文：写法有 `orig` 且用到的词都有原文时才有；写法只是一个词（`"{peak}"`）时用那个词的原文。
- `manual`：不自动放（只能自己加）。
- 内置的（中世纪的世界里能见到的打勾）：自然 5 种（名山、火山、瀑布、峡谷、绿洲）；人造 15 种——神庙 ✓、金字塔（古代，中东、非洲、中美、安第斯）、长城 ✓（古代、中世纪的东亚，国界上）、王陵 ✓（君主制、帝国）、城堡 ✓（中世纪、奇幻，国界上）、修道院 ✓（山里）、灯塔 ✓、圣地 ✓（神权政体）、大学、纪念碑（近现代、现代）、大坝（近现代起）、法师塔（奇幻）、太空港、生态穹顶（科幻）、遗迹 ✓（整个世界）。

**自定义点的类型**（`pointTypeSchema`）：

```json
{ "id": "second-capital", "name": "陪都", "icon": "star-outline", "image": "data:image/png;base64,…", "color": "#c9a227", "description": "…", "actsAsCity": { "capital": true, "rank": "big" } }
```

- `icon`：内置图标的名字（`pin star-outline fort swords anchor pick shrine tent chest`）；`image`：上传的小图（`data:image/png|jpeg|webp|svg+xml;base64,…`，不超过 32000 字）——有 `image` 时界面用它。
- `actsAsCity`：当作城市。这种点挂在一座城市上（`attachedCity`）时，那座城市 `secondCapital`（`capital: true` 时，档案里写“陪都”、国家的首都里有它）、按 `rank`（省略时：算首都的用首都那一级）显示；没挂在城市上时这个点自己当一座城市（`cityList` 里 `point: true`，id 是点的编号，人口按它管着的格算）。
- 内置 9 种：标记、陪都（当作首都）、要塞、古战场、港口、矿场、圣地、营地、宝藏。

**世界里的数据**（`world.ts`，都在 `small` 里：撤销、检查点、快照照小数据走；用到时才有，没用过的世界一项都不多）：

```ts
small.cities: Record<id, CityMeta>      // { id, cell, auto?, name?, orig?, salt?, rank?, country?, founded?, description?, notes?, locked? }
small.roads: Record<id, RoadMeta>       // { id, kind: 'major' | 'minor' | 自己写的, cells: number[], auto?, from?, to?, name?, note? }
small.landmarks: Record<id, LandmarkMeta> // { id, type, cell, auto?, name?, orig?, salt?, description?, locked? }
small.points: Record<id, PointMeta>     // { id, type, cell, x?, y?, name, note?, attachedCity? }
small.nextSettlement                    // 下一个编号（四种共用，1 起）
small.settlementRules                   // { seed, roads, landmarks }：生成过才有
```

- `CityMeta`：`auto` 是自动放的（重新生成时换掉；自己放的、自己改过名字 / 等级 / 所属的没有它）；`name` / `orig` 只在自己起了名字时有（没有时按当地的风格现起，`salt` 是“换一个”）；`rank` 只在自己定了等级时有；`country` 只在自己定了所属时有（没有时按所在格的领土）；`founded`、`description` 没写时自动；`locked` 锁定（重新生成时留着，所在的格变成海时挪到最近的陆地）。
- `RoadMeta.cells`：一串前后相邻的陆地格。`from` / `to` 是两头的城市（自动的：起点、终点的城市；画的：两头的格上有城市时记下）。一条自动的路只存新修的那一段，走在已有道路上的那段不重复存（同一条边只在一条路里）。`auto`：自动的（重新生成时换掉；画的、改过走向或种类的没有它）。
- `PointMeta`：`x`、`y` 是精确的位置（地图坐标，省略时在格心）；`name` 总有（省略时用类型的名字）。

**城市的生成**（`human/settlements.ts` 的 `placeCities`）：
1. 个数：每个国家（无主地也算一份，少一半）按 `CITY_RATE`（1/30）× √(城市化率 / 0.1) ×（0.5 × 有人的格数 + 0.5 × 全世界有人的格数 × 人口的比例），至少一座（有人的国家）；全世界最多 `MAX_CITIES` = 4000。留着的（锁定的、自己放的）算在里面。
2. 首都：每个国家的首都格先放一座。
3. 别的：在本国有人的干的陆地里按 人口 × 有河 1.6 × 挨着海 1.4 × 挨着湖 1.2 × e^(0.25·噪声)（波长 300 km）从高到低挑，与已有的城市隔开 0.6·√(本国能住人的面积 / 个数)（至少 1.6 格距）；挑不够时间隔 × 0.7 再挑（最多 4 遍，最后只要不同格）。
4. 只看原因（人口、领土、首都）与自然的推导（河、海岸），所以执行、重放一样。

**现算的**（`cityTable(world)`，按城市、点、国家的首都与政体、人口、领土、内容缓存；命令里用不缓存的 `computeCityTable`）：
- 管着的格：从每座城市（和当作城市的点）同时往外按 km 走，只走同一个国家（所在格的领土）的干的陆地，最远 4 格距（`CATCH_CELLS`）。
- 人口：一个国家里城市人口的总数 = 城市化率 × 城市管着的格的人口；按 管着的人口^1.15 ×（首都 × 1.8 × √政体的城市化）分给各城市，不超过管着的人口的 95%。占本国人口的比例 = 城市的人口 ÷ 这个国家的总人口（无主的城市按无主地的总人口）。
- 首都：城市所属国家的 `capitalCell` 就是它的格。陪都：挂着“当作首都”的点。
- 等级：自己定的 → 首都、陪都（点的 `rank`）→ 按比例（`rankFor`）。
- 名字：自己起的 → 按 `styleFor(world, {cell})` 的风格起（风格写了 `city` 类用它，否则 `province`、再否则 `spot`；情境标签 coastal、river、mountain、cold；种子“世界种子:city:编号:盐”，风格不是世界默认时加风格 id）；自动起的重名时，重要的先占，后面的换一个。
- 排序：等级的 level 大的在前，再按人口、编号。

**道路的生成**（`human/roads.ts` 的 `generateRoads`）：
1. 代价（`roadCosts`）：走一条边 = km × 两格的通行难度（起伏 × 植被，`cellMovement`）的平均 × (1 + 高低差 / 300) × 过河（进有河的格 × 2.2、顺着河谷两格都有河 × 0.85）；两格都在已有道路上时 × 0.4（大道）/ 0.6（小路）。海、湖走不了。
2. 大道：每块干的陆地上，首都与大城市（`isMajorRank`）按直线距离连成 Gabriel 图（先取每个点最近的 8 个当候选）→ 最小生成树，再补上生成树上绕得太远（超过直线的 2.2 倍）的边；按短的先走，每条用 A*（`RoadSearch.astar`：估计是直线 km × 最便宜的通行难度 × 0.55，只在两头的直线距离 × 1.6 + 4 格距的椭圆里找）。
3. 小路：别的城市按重要的先，各自用 Dijkstra 走到最近的已有道路或已经连上的城市（`RoadSearch.nearest`）；一块陆地上还没有路时最重要的城市做起点。所以同一块陆地上的城市都连得上。
4. 存：一条路走过已有道路的那几段不存，只存新修的（`commit`）。

**命令**（都是 `Dirty.None`：只改小数据；要推导的用 `ensureDerived`，重放一样；撤销记小数据）：
- `generate_human {…, settlements?: {seed?, roads?, landmarks?}}`：写了 `settlements` 就在生成人文的最后一步（写好 `small.human`、人口、国家之后）放城市，`roads`、`landmarks` 省略为 true（`seed` 省略为人文的种子）。没写时没有城市与道路（已有的去掉，地标、自定义点留着）。历史“生成人文“中世纪” · 3 个文化组 · 4.0 亿 · 13 个国家 · 171 座城市”。
- `regenerate_human`、`move_hearth`、`generate_countries`、`regenerate_countries`：有 `settlementRules` 时按它重新放自动的城市、道路、地标（锁定的、自己放的、画的留着）。`remove_human`：城市、道路去掉（地标、自定义点留着）。`set_worldgen` 的新世界：全部去掉。
- `generate_settlements {seed?, roads?, landmarks?}`：一起生成，全部换掉（写了的几项换掉记着的参数）；`regenerate_settlements {同上}`：只换自动的。“生成城市与地标 · 171 座城市 · 147 条道路 · 41 个地标”。没有人文时只放自然的地标。
- `remove_settlements {cities?, roads?, landmarks?, points?}`：去掉几种（城市连同道路）。“删除城市、道路”。
- `generate_cities {seed?}`（全部换掉）/ `regenerate_cities {seed?, keepLocked?}`（自己放的留着；`keepLocked` 省略为 true）：有道路时自动的道路跟着重连（画的留着）。没有人文时报错。“生成城市 · 171 座”。
- `add_city {cell, name?, orig?, rank?}`（陆地、这一格没有城市）“新建城市“X””；`remove_city {id}`（连着它的自动道路一起删、挂着它的点不再挂着）“删除城市“X””；`move_city {id, cell}`（是首都时首都跟着挪到同一个国家的新格、锁定首都；连着它的道路从新的格重走到另一头，走不到的删掉）“挪动城市“X””；`set_city {id, patch}`：`name`（'' 恢复自动；`orig` 跟着 `name`）、`reroll: true`（换一个自动的名字）、`rank`（null 恢复自动）、`country`（null 恢复按领土）、`founded`、`description`、`notes`（null 去掉）、`locked`。改了名字、等级、所属的自动城市不再是自动的。“城市“X” · 改名、等级”。
- `generate_roads {}`（全部换掉）/ `regenerate_roads {}`（画的、改过的留着）“生成道路 · 147 条”；`add_road {cells, kind?（省略为 minor）, name?}`（至少两格、都在陆地上、前后相邻）“画道路 · 约 120 km”；`edit_road {id, cells, from?, to?}`（`cells` 换掉 `[from, to]`（含两头的下标）那一段，省略时整条换掉；换完要前后相邻；改过的不再是自动的）“改道路 · 约 120 km”；`remove_road {id}`“删除道路”；`set_road {id, patch: {kind?, name?: string | null, note?: string | null}}`“道路 · 大道”。
- `generate_landmarks {keepManual?}`（省略为 true：自己放的、锁定的留着）“生成地标 · 41 个”；`add_landmark {type, cell, name?, orig?, description?}`（陆地）“新建地标“X””；`remove_landmark {id}`；`move_landmark {id, cell}`；`set_landmark {id, patch: {type?, name?（'' 恢复自动）, orig?, description?: string | null, locked?}}`。
- `add_point {type, cell, x?, y?, name?, note?, attachedCity?: id | null}`（`attachedCity` 省略时：类型当作城市、这一格有城市时挂上它）“新建点“X””；`remove_point {id}`；`move_point {id, cell, x?, y?}`（挂着的城市不在新的格时按新的格重新挂）；`set_point {id, patch: {type?, name?, note?: string | null, attachedCity?: id | null}}`。
- **每步之后的整理**（`tidyCities`，有城市时在 `applyCommand` 里每条命令之后）：每个国家的首都格上都有一座城市（没有时补一座自动的——挪了首都、新建国家之后）；挂着、连着没了的城市的点与道路去掉那一项。
- **改地形以后**（`applyTerrain` 里、修补国家之后，只看原因）：变成海的格上的城市、地标删掉（锁定的挪到最近的陆地）；道路上变成海的格断开，断开后不到两格的那段去掉。

**给界面的**（都从 `core/human` 导出）：
- `cityList(world)`：`CityInfo[]`（重要的在前）——`{id, point?, cell, x, y, name, orig?, customName, rank: CityRank（icon、label、level）, rankAuto, autoRank, country: 编号 | null, countryAuto, capital, secondCapital, population, share, auto, locked}`。缩小时按 `rank.level` 只画首都、大城市。`cityTable(world)` 另有 `byId`、`owner`（每格归哪座城市管：`list` 的下标）、`countryPop`。`cityAt(world, cell)`、`hasCities(world)`、`cityName(world, meta)`。
- `cityArchive(world, id)`：`CityInfo` 加 `rankName, countryName?, cultures（管着的格里的文化，前 6 个，share 是占比）, founded, foundedAuto, description, descriptionAuto, notes?, elevation, terrainClass?, coastal, river, province, provinceName?, roads（连着的道路条数）`。自动的建城年份：首都是建国那年，别的在建国年份前 200 年到时代的“现在”之间；自动的简介：“X是Y的首都，位于河畔，人口约 N。”
- `roadPaths(world)`：`RoadPath[]`（大道在前）——`{id, kind, auto, from?, to?, name?, points: 格心连成的折线（地图坐标，星球上沿路连续展开）, km}`。`smoothRoad(points, rounds?)` 是画的时候平滑（Chaikin，两端不动）。大道放大缩小都画，小路放大时才画（界面定）。
- 画路、改走向（像改河一样用控制点）：`traceRoad(world, pts)`（画的一笔 → 一串相邻的格；走到海里时 `{blocked}`）、`routeRoad(S, a, b)`（两格之间按地形找路，已有的道路算便宜）、`roadHandles(world, road, tol?)`（控制点：格心折线化简后留下的点在 `cells` 里的下标，含两头）、`dragRoadHandle(S, road, handles, j, [x, y], route = true)`（拖第 j 个控制点：它两边到前后控制点的两段重走，`route` 时按地形、否则按直线；返回新的整条 `cells`，发 `edit_road {id, cells}`）、`spliceRoad(cells, mid, from?, to?)`。`S = settleInputs(world, world.derived)`。
- `landmarkList(world)` / `landmarkArchive(world, id)`：`LandmarkInfo {id, type, typeName, category, icon, color?, cell, x, y, name, orig?, customName, description?（自己写的，没有时类型的说明）, auto, locked, country, elevation}`；`landmarkName(world, meta)`；`detectLandmarks(S, detector)`（候选的格与分数，从高到低）。
- `pointList(world)`：`PointInfo {id, type, typeName, icon?, image?, color, cell, x, y, name, note?, attachedCity?, actsAsCity, capital}`。
- `countryStats` / `allCountryStats` 多了 `cities`（城市的个数）与 `capitals`（首都、陪都的城市编号，首都在前；当作城市的点没挂在城市上时是点的编号）；`countryCities(world)`。
- `cellArchive(world, cell)` 多了 `city?: {id, name, orig?, rank, rankName, icon, capital, secondCapital, population}`、`landmarks?: {id, type, typeName, name, orig?}[]`、`points?: {id, type, typeName, name}[]`。
- 内容：`worldCityRanks / worldLandmarkTypes / worldPointTypes / cityRankById / landmarkTypeById / pointTypeById / capitalRank / rankFor / isMajorRank`、`BUILTIN_RANKS / BUILTIN_LANDMARK_TYPES / BUILTIN_POINT_TYPES`、`LANDMARK_DETECTORS / LANDMARK_PLACES`、`ROAD_KINDS`、`MAX_CITIES`；生成：`generateSettlements(world, d, {rules, fresh})`、`settlementRules(world, patch)`。表与档案全文（导出用，也从 `core/human` 导出）：`citiesCsv / roadsCsv / roadsGeojson / landmarksCsv / pointsCsv / archiveMarkdown / archiveJson`、`hasSettlements(world)`、`cellLatLon(world, x, y)`。
