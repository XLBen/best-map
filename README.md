# 架空世界编辑器（map_2）

给写架空世界的作者用的地图工具：几秒钟生成一片像真实世界的海陆，然后自己放岛、画陆地、涂生态、画河、划省份，名字自动起好，最后导出成游戏能用的位图与表格。气候、河流、植被按物理规则推导，你改了一处，下游、下风向会跟着变。

```bash
npm install
npm run dev        # 开发服务器，默认 http://localhost:5173（.claude/launch.json 里用 5191）
npm test           # 全部测试（181 个）
npm run test:fast  # 改代码时常跑的那部分（跳过最慢的几个文件）
npm run golden     # 只跑金标准：提速、重构后结果必须逐值不变
npx tsx tools/generate.ts --seed 3 --out out/seed3   # 命令行批量生成并导出
npx tsx tools/hash.ts                                 # 各层结果的哈希，用来核对 Node 与浏览器是否逐值一致
npx tsx tools/bench.ts --globe                        # 整个星球（10 万格）各步的耗时
```

## 五分钟上手

界面学的是 Procreate：地图铺满全屏，按钮浮在上面，每一类调节只有一个固定的位置。

| 位置 | 放什么 |
|---|---|
| 左上角 | **世界**（新世界、打开、保存）· **操作**（导出、历史、上手说明、偏好）· **调整**（整个世界的滑块）· 撤销、重做 |
| 右上角 | **地形 · 气候 · 自然 · 水系 · 省份 · 地名** 六类工具：点一类只是换到这一类（换到它上次用的工具），不弹出东西挡地图，也不换底图。然后是 **图层**（底图、画风、地名、河流、边界、比例尺、纬度刻度、参考图）和 **生态**（要涂的生态、生态类型编辑） |
| 底部工具条 | 第一行：这一类的全部工具（图标 + 两三个字，悬停时说怎么用），末尾的“⋯”是这一类的更多设置（省份的划分规则、文字包与全部地名……）。第二行：当前工具的设置——“半径 ━━●━━ 420 km”这样带名字、数值一直写着的横滑块（用不上的不显示），以及模式（画陆地/画海、岛的种类与“换个形状”、自然融入/强制、更冷/更暖……）；选中的省份、地名也在这里改 |
| 顶部中间 | 改完后的一句话 + 撤销；放岛、岛链再加“换个形状”（替换刚放的那个）。鼠标旁只写一行结果（“陆地 +804 格”“火山岛 · 190 km”），没有结果时不说话 |
| 右下角 | “这里”：鼠标下是什么（就是地图上画出来的那一格：海岸、弯曲的省界、剪刀切线旁都不会读错），点开看为什么 |
| 左下角 | 比例尺；旁边的尺子是量距离 |

1. **新建世界**：左上角“世界”→“新世界…”，先选“一块地区”还是“整个星球”（整个星球见下一节）。一块地区：选世界类型（群岛之海、一块大陆、几块大陆、破碎大陆、内海、空白海洋）、大小（一片群岛约 1500 km ～ 半个星球约 1.8 万 km），再选**放在星球的哪里**：一条从北极到南极的竖条上画着热带、亚热带、温带、寒带、极地，地图的南北范围是上面一个可以拖动的窗（高度由大小决定），旁边写着“北纬 19° — 北纬 73°，包括亚热带、温带、寒带、极地”。一张图本来就从南到北跨好几个气候带，靠海、山上也各不一样；这一步只是选地图在星球上的位置（四个快捷按钮是常用的位置）。最后从 6 张缩略图里挑一张，缩略图跟着位置变。之后每次打开页面会自动接着上次的世界。
2. **地形**：画陆地 / 海、放岛（火山岛、大陆岛、低平岛、珊瑚岛）、画岛链、堆山 / 压低、重画这一片，以及**恢复原样**：涂到的地方，画过的陆地、海、山和放的岛都退回生成时的样子（中间全收回，边上渐变），预览里直接画出恢复后的海岸线。画陆地时底部可以选“圈一片”：按住画一个圈，松手后圈里变成陆地（或海），边上照样是自然的海岸。最小的笔刷正好一格，悬停时描出会涂到的格。岛的大小是连续的：点一下用底部滑块的大小，按住往外拖就拖多大。手里有草图的话，在“图层 → 参考图”里导入，半透明地铺在地图上照着描。
3. **气候与自然**：“气候”里有冷暖（底部选更冷 / 更暖）、干湿（更湿 / 更干）、擦掉冷暖干湿的改动、涂自定义场。涂完顶部写“变冷 917 格，最多 −4 °C”，地图闪出气温变了的地方。“自然”里右上角“生态”选一种生态去涂（也可以按住 Alt 在地图上吸取），底部是“自然融入”（系统调这里的冷暖干湿，让它真的长出来，周围平滑过渡，范围由“过渡”滑块决定）或“强制”；还有拖动扩张、岛屿特有生态、擦除。“编辑生态类型”在右边的抽屉里：每种生态是气候图上的一个色块，拖动、拉伸就能改它喜欢的冷暖干湿，可以一边调一边看地图。
4. **整个世界**：“调整”里拖“陆地多少、岛多少、山多高、海岸曲折”，地图上先画出将来的海岸线（与结果逐格相同），松手才计算、算的时候也不闪回旧的海岸；**地图在星球上的位置**（整张图往南或往北挪，下面写着现在跨哪几个气候带）、冷暖、干湿、四季、河流多少等也在这里，每一下都能撤销。“图层”里打开“纬度刻度”，左边每 10° 一格，回归线、极圈用虚线标出。
5. **水、省份、地名**：“水系”点一下起一条河，按住拖出路线。河不会交叉：路线碰到别的河就停在那里汇进去，提示里写着“→ 汇入赤江 · 230 km”。从一条河上按住往外拖是让它改道，会变干的旧河道画成红色虚线。底部的“大小”选小河到大河（水沿河道一路加进来，越往下越宽）。放湖和放岛一样能拖出大小。“省份”选省份（在底部条改名、改类型、锁定、对半分开）、省份画笔、剪刀（画的线就是切口，线没画到省界外会自动延长，切成几块就是几个省）、合并、重新划分一片；底部“省份着色”换成按省份上色的底图，“⋯”里是自动划分的规则。“地名”里点名字就能改名、换一个、锁定；**圈地名**：画一个圈，圈住的地方成为一个地区、平原、山地、森林、沙漠或海域（按地形猜，可以改），名字按文字包自动起，也可以直接打字；**放地名**：点一下放一个城镇、渡口、海角这样的点状地名。“⋯”里是全部地名和文字包。
6. **导出**：左上角“操作”里导出游戏文件包（.zip）或当前画面的 PNG；世界文件在“世界”里保存、打开。

操作：触控板双指滑动平移、捏合缩放；鼠标滚轮缩放，右键或空格加拖动平移（只需点一下的工具里左键拖也是平移）；`=` `-` 缩放；F 看全图；`[` `]` 调底部第一个滑块（半径、大小），`{` `}` 调力度；R 换个形状；按住 Alt 点一下吸取生态或省份；数字键切换这一类的工具；⌘Z 撤销，加 Shift 重做；Tab 隐藏界面只看地图；M 量距离（点几个点量出总长和步行天数，Backspace 删掉最后一点）；Esc 关面板、取消正在画的、退出量距离。滚轮是缩放还是平移会自动分辨，分辨不准时在“操作 → 偏好”里改。

## 整个星球

新建世界时选“整个星球”，整颗星球平铺成一张图（经纬度等距，像常见的世界地图）：
- **类型**：像地球（几块大陆）、一块超大陆、破碎大陆、群岛星球、海洋星球（只有火山岛露出海面）、空白星球。
- **大小**：小（半径约 3,400 km）、类地（6,371 km）、大（9,500 km）。大小只改变 km，同一颗星球放大缩小。
- **精细**：约 10 万格，类地星球每格约 75 km。缩略图用 4,000 格，与成品的陆海一致。

看地图：
- 一直往左或往右拖，会绕星球一圈回到原处，接缝看不出来。上下边是南北极，拖到两极就停住。
- 两极附近像普通世界地图那样被横向拉宽：画笔、岛在图上是横向拉长的，在星球上是真实大小。
- “图层”里的“纬度刻度”在星球上叫**经纬网**：每 30° 一条线，回归线、极圈用虚线。比例尺写明是哪个纬度的比例（“1,000 km · 北纬 45°”）。
- 右下角“这里”写着经纬度，海上写洋流的方向和冷暖，陆地上写洋流让这里暖了或凉了多少。

**洋流**（只有整个星球有）：
- 大陆东岸外是向极的暖流，更暖更湿；低纬度的大陆西岸外是向赤道的寒流和冷水上涌，凉而干，像南美、非洲西岸的沙漠；高纬度的西岸比同纬度的东岸暖，像西欧；赤道上大洋东部有冷水舌。
- “图层 → 洋流”画出流线：暖流偏橙、寒流偏蓝。“调整 → 洋流强弱”：0 是没有洋流，2 是加倍。
- 这是按风带和海岸位置估算的简化模型：环流强度来自 Sverdrup 平衡，大洋西侧收成窄而强的边界流，再加上顺风偏转的风吹流；海面温度顺着海流输送，约 1,000–2,000 km 内回到平衡。

工具：
- 所有工具在接缝两边、两极附近都照常用；画笔、重画、放岛按球面上的真实距离。
- 圈一片、圈地名不能绕着极点画：会提示“绕着极点了”，松手不生效。
- 量距离沿球面上最短的弧线量，线也画成弧线。
- “调整”里没有“地图在星球上的位置”和“地图外面是海”，多了“洋流强弱”。

导出：2:1 的经纬度等距图，左右两边接得上；`features.csv` 里是真实的经纬度。

## 结果可以预料

该随机的地方随机（新世界的格局、海岸与地形的细节、岛的轮廓、自动起的名字），全部由种子决定：同样的操作做两遍，结果一样。想要不一样，就点明确的按钮——“换一组”“换个形状”“换个排列”“重画这一片”“换一种划分”“换一个”。

不该随机的地方，按下面几条规则，每条都有测试：

1. **所见即所得**：每个工具动手前或动手时都显示确切的预览，松手后的结果与预览逐格一致。放岛直接画出岛将来的海岸线并写出直径（直径就是海岸线的大小，放出来的岛平均就这么大），小礁也一样；画河显示整条河道；画河的提示写明最后流到哪（入海、流进湖里、汇入哪条河），改道时把会变干的旧河道画成红色虚线；放湖显示湖面；画陆地、圈一片、岛链画出将来真实的海岸线（不再是绿色、蓝色的格子）；拖动扩张显示将长出的格；剪刀用不同颜色显示切成的每一块，自动延长的部分画成虚线；恢复原样画出恢复后的海岸线；重画这一片停一下就画出重画后的海岸线和山的高低变化，什么都不会变时点了不算；圈地名高亮圈住的格并写出类型和面积；重新划分显示会被重做的省份；“调整”里拖陆地多少、岛多少、山多高、海岸曲折时画出将来的海岸线；涂生态、冷暖干湿、擦除、自定义场按住停一下，拖“调整”里气候、河流的滑块、拖生态色块时停一下，地图上就是松手后的样子（变了的格描边，涂不成的格画红色斜线），松手时直接用算好的结果。新建向导的缩略图是粗略版，看不到很小的岛。
2. **画陆地**：画笔中间 70% 一定变成陆地，只有边缘一圈由海岸噪声决定湾和岬；画笔外一格不变。圈一片也一样：圈里离边远的地方一定变成陆地，只有圈的边上一窄条由海岸噪声决定。
3. **影响局部、变化看得见**：编辑只影响画到的地方和物理上必然受影响的下游、下风向。每次编辑后变化的格会闪几秒，顶部一句话说清改了什么（“陆地 +800 格，44 格生态变了，1 处河道变了”），旁边就是撤销。高程迭代固定轮数，所以在一块大陆上的改动不会让别的大陆的地形变一点点。
4. **滑块是连续的**：“陆地多少”就是升降海平面，陆地多时原来的陆地一格不少；“岛多少”只增减火山岛；“山多高”只缩放造山带。你画的陆地、放的岛都会保留。岛、湖、画笔的大小和力度也都是连续的，不再只有几档。
5. **放岛的形状跟着鼠标走**：岛的形状只取决于种类、大小和形状编号，与位置无关，所以悬停时轮廓跟着鼠标移动而不变形，拖大拖小是同一个岛等比例缩放。放下一个后自动换下一个形状（悬停时看得到）；不满意就点提示条上的“换个形状”，原地换一个。旧存档里“小 · 中 · 大”的岛照旧按原来的形状重放。
6. **缩略图即成品**：生成器的随机都按地图上的位置取，与格数无关：4000 格的缩略图与 4 万格的成品陆海一致率 ≥ 90%。
7. **涂到的就是**：“自然融入”涂到的格要么长成这种生态，要么当场画上红色斜线，并在“没涂成”里用人话说明原因（“太冷：这里年均 13 °C，它要 22 °C 以上”），可以一键强制。绝不默默地改成别的。
8. **自动划分也稳定**：同样的规则划出来的省份相同；重新划分一片只动被涂到一大半的省份，别处的编号、名字、格子都不变；改陆地只修补变了陆海的格；锁定的省份始终不动。
9. **名字不乱跳**：名字跟着要素里一个固定的“锚点格”走——在海里放个岛、把岛画大一点，只要那一格还在，名字就不变。改过的名字之后也一直跟着这个地方。
10. **河不交叉、不截走别的河**：画的河碰到别的河就汇入，那条河照旧流到原来的入海口；改道不能接回自己的上游（水会绕成圈），预览当场变红说明。旧存档里画的河照旧逐值重放。

## 地形是怎么来的

先造“地壳高度”，再定海平面：
- 大陆块带域扭曲和多尺度分形起伏，低处被淹成内海和海湾；外侧是宽窄不一的大陆架、陆坡和深海；
- 板块边界上有洋中脊、海沟、裂谷，造山带分段、有平行的次级山脉和高原；
- 火山锥（热点岛链、岛弧、海山）高度取重尾分布，所以岛的大小自然呈幂律（少数大岛、许多小岛）；
- 海平面按目标陆地比例取分位数；陆地 = 高度 + 海岸噪声 × 破碎度 > 0，屏幕和导出都用同一个海岸噪声画格以下的海岸细节；
- 高程是抬升与河流下切的稳态（stream power），所以山有树枝状的河谷和支脉。

## 生态

每种生态在气候图上是一个矩形（年均温 × 湿润程度），外面自动留一圈过渡；另外可以勾选条件：只长在海边 / 河边 / 高山 / 平地 / 低洼积水处，雨季在夏天 / 冬天。两种生态都能长的地方，“强势程度”高的占上风。更精细的条件在“高级”里：对任意一项（海拔、坡度、流量、纬度、自定义场……）给一条梯形耐受曲线。默认的 13 种生态接近地球（Whittaker 生物群系图）。

“自然融入”时，系统在温度 ±15 °C、降水 ×12 的范围内反推出让涂的生态成为主导的最小修正，用格图上的调和插值把修正平滑地扩散到周围，再重算水文与植被，所以河流和你涂的生态始终自洽。

岛屿特有生态：点一个岛（大陆不行），以岛上最多的那种生态为底，建一种只长在这个岛上的近亲：喜欢的冷暖干湿、条件照抄，强势程度只高一丝，颜色略微偏一点，名字是“岛名 + 底生态名”。所以岛上原来是这种生态的地方换成特有的版本，冰原、湿地等别的生态不变，岛外也不会出现。再点同一个岛只会提示已经有了；提示条上有“编辑”。

## 省份

自动划分的规则：大小（小 · 中 · 大）；按地形调整大小（平原、河谷、海岸省份小，山地、荒漠大）；冰原、深漠、高山合成无人区；大湖单独成省；近海的海域小、远洋的大。边界尽量贴着河与山脊。省份类型有陆地、无人区、湖、海域。名字从文字包里按省内地形取字。

## 文字包（地名）

名字由文字包生成，是一个 JSON 文件，可以在“地名”模式里导出、修改、导入：

```json
{
  "id": "my-pack",
  "name": "我的文字包",
  "lists": {
    "color": ["青", "白", "赤"],
    "cold": ["霜", "雪", "冰"],
    "animal": ["鹤", "鹿"]
  },
  "types": {
    "island": {
      "patterns": [{ "p": "{color}{animal}岛", "w": 3 }, { "p": "{animal}屿" }],
      "byTag": { "cold": [{ "p": "{cold}{animal}岛" }] }
    }
  }
}
```

- `lists`：词表。模板里的 `{词表名}` 换成该词表里的一个词（同一个名字里尽量不重复用字）。
- `types`：每种地貌一组模板，`w` 是权重（默认 1）。地貌类型有 `continent island archipelago peninsula ocean sea bay strait lake river range peak plateau plain basin desert forest tundra icecap wetland province`，以及用户圈的地区 `region` 和放的点状地名 `spot`（圈的平原、山地、森林、沙漠、海域分别用 `plain range forest desert sea` 的模板）；没写的类型退回 `island` 的模板，没写 `region`、`spot` 的旧文字包用 `province` 的模板。
- `byTag`：要素带某个情境标签时，有 65% 的机会改用这里的模板。标签有 `cold hot dry wet high large small volcanic`；省份另有 `coastal river mountain sea waste`（无人区）；点状地名另有 `coastal river mountain sea`。
- 导入时会检查模板里用到的词表是否都存在；可以用它做英文或某种架空语言的包。
- 名字由“文字包 + 类型 + 锚点格 + 世界种子”确定，换文字包后所有自动名字一起换，你改过的名字不变。

## 速度（第七轮的优化）

第七轮没有加功能，只让程序更快、更稳。结果全部逐值不变：`core/golden-full.test.ts` 对一组较长的操作后整个世界（每一个数组、地物、省份）按字节记下哈希，地区与星球各一组；每一项提速还有自己的“新旧算法逐位相同”测试。

用起来的变化：
- **撤销、重做是瞬间的**：最近几步（地区 3 步、星球 2 步）的结果都存着，直接换回来，不再重算。
- **只改冷暖干湿快了约 4–5 倍**：气候里和地形有关的那部分（风、水汽输送图、洋流）按内容缓存，地形没变就不重算。
- **重新打开上次的世界**：每次自动保存时，引擎的完整状态也存一份（检查点），打开时直接恢复，不必从头重放（打包后的程序里才有；星球上约 5 秒对照约 18 秒）。
- **自动保存不会再悄悄停掉**：改存 IndexedDB、只写变了的命令（以前存在 localStorage，画多了会超过约 5 MB 的上限，之后不再保存）。旧的自动保存第一次打开时自动搬过来。
- **算的时候照样能画**：画笔类的工具，以及放岛、岛链、圈一片、放湖，可以在前面的编辑还在算时接着用，松手后按顺序执行，各是一步，结果与一步一步等着做相同；排队中的那几步一直显示松手时的样子，直到结果换上，鼠标旁写着“排队中：前面还有 2 步”。画河、剪刀、合并要按算好的世界来，新建、打开、导出时也一样，按下会提示“还在计算上一步”，不再默默忽略；“换个形状”要等排队的几步算完。
- **停一下就是松手后的样子**：涂生态、冷暖干湿时按住停一下，地图按算好的将来的世界画出生态颜色、雪、河、地名（“温带阔叶林 · 38 格会变 · 6 格没涂成”），接着画也不跳回原样；拖“调整”里的河流多少、整体冷暖、四季、地图在星球上的位置等也一样。松手时直接采用，颜色不跳。大星球上一次要算很久的，不再自动预览，只说“松手后约 N 秒出结果”。
- **省份先看再做**：重新划分一片时涂着停一下，地图上就画出新的省界和省名（“重划 2 个省 → 5 个”）；鼠标停在“对半分开”“按新规则重新划分”“换一种划分”上，先看到新的省界，点下去照样一下就做、可以撤销。合并时锁定的省标红、点了不合并；不相邻的两省也能合并（提醒“合并后是一省两块”）；涂省会把别的省涂断时也提醒。
- **画了等于没画（比如在陆地上画陆地）**：提示“没有变化”，不重算、不进历史。
- **画河改道**：松手时直接用算好的确切预览，不再算第二遍。
- **新建向导**：缩略图一张一张出来，第一张不到半秒。
- **导出**：放到单独的线程里，期间照样能看、能改地图；顶部显示进度，可以取消；栅格化快了约 1.4–3 倍。
- **画面**：改完后的闪烁不再每帧重画整张图；平移、缩放时着色器不算看不见的细节（每帧快约 15–50%；画面除海岸线上极少数像素的舍入外逐像素一致）。

## 导出

游戏文件包（.zip）里有：`heightmap.bmp`（8 位）与 `heightmap16.png`（16 位）、`provinces.bmp` + `definition.csv`、`provinces_summary.csv`（含省份类型）、`terrain.bmp`、`biomes.bmp`、`rivers.bmp`、`features.csv`（地名表：类型、名字、面积、在图上的像素坐标与经纬度，含自己圈的地区和放的地名）和 `world.json`。位图与屏幕用同一套格以下的海岸、自然弯曲的边界和平滑的河道，所以导出的图和屏幕上看到的一致。

生态的花纹（闪光、裂纹、斑驳、脉络、斑点、条纹）、发光和颜色脚本算出的颜色只画在屏幕上和导出的 PNG 画面里，新建向导的缩略图按拉远时的平均色画。`biomes.bmp`、`terrain.bmp` 照旧是每种生态一种颜色的分类图：游戏要的是“这一格是什么”，不是画出来的样子，这是有意的。

## 文件结构

- `core/`：纯计算，不依赖 DOM，Node 与浏览器共用
  - `mesh.ts` 网格（平面、球面两种）；`sphere.ts` 球面网格（斐波那契撒点、球面 Delaunay、显示用的三角网、最近格）；`geo.ts` 整个星球的几何（经度绕回、球面距离、大圆、球面上的圆）；`generate.ts` 随机世界（地壳高度、板块、火山锥）；`planet-gen.ts` 整个星球的生成器（球面上的板块、大陆块、热点岛链）；`terrain.ts` 组合地形、画笔、放岛、岛链；`elevation.ts` 抬升-侵蚀稳态与湖
  - `climate.ts` 日照温度、风带季风、水汽输运；`planet-climate.ts` 整个星球的气候；`sphere-flow.ts` 球面上的输送（绕星球一圈的风带不剪断）；`ocean.ts` 简化洋流与海面温度；`hydrology.ts` 填洼汇流、湖、径流；`rivers.ts` 河流折线
  - `species.ts` 生态类型（色块 + 条件 + 耐受曲线）；`vegetation.ts` 适宜度 / 竞争 / 扩散；`constraints.ts` 涂生态的反推与“没涂成”的原因；`endemic.ts` 岛屿特有生态；`biome-look.ts` 生态在地图上的样子（颜色脚本、花纹与发光的算式，屏幕与缩略图共用）
  - `features.ts` 地理要素识别，用户圈的地名区块也在这里变成地名；`names.ts` + `packs/zh.json` 文字包命名
  - `provinces.ts` 省份规则、划分、局部重划、修补；`select.ts` 画笔、拖动扩张、画河的路线（汇入、改道、会变干的河段）、圈一片、剪刀沿线切省
  - `commands.ts` 命令（zod 校验、撤销记录）；`engine.ts` 流水线、历史（撤销只从那一步影响到的那一层重算）、文档
  - `subcell.ts` 格以下的细节（屏幕与导出共用）；`export.ts` 导出；`thumbnail.ts` 向导缩略图；`presets.ts` 世界大小、星球上的纬度带
  - `testing/fixtures.ts` 测试共用的世界模板（建一次，每个测试拿一份副本）
  - 测试：`*.test.ts`，其中 `golden-full.test.ts`（整个世界按字节逐值不变）、`undo-cache.test.ts`（撤销缓存与重算一致）、`checkpoint.test.ts`（检查点恢复与重放一致）、`replay-names.test.ts`（重放后省名不变），以及各项提速的新旧对照（`rng-kernel`、`mesh-build`、`reroll-incremental`、`flow-order`、`provinces-naming`、`features-cache`、`climate-cache`、`routing-identity`、`raster-identity`、`solver-identity`）是第七轮加的；`erase-cut.test.ts`（恢复原样、剪刀、最小笔刷、星球位置）、`regions.test.ts`（圈地名、放地名）、`undo.test.ts`（撤销与从头重放逐值一致）是第五轮加的；`golden.test.ts`（一块地区的结果逐值不变）、`sphere.test.ts`、`planet.test.ts`、`planet-climate.test.ts`、`ocean.test.ts`、`geo.test.ts` 是第六轮（整个星球）加的
- `src/`：界面。`worker.ts` 在 Web Worker 里跑引擎（只改了名字、省份时只把这些发回主线程；写、读检查点）；`export-worker.ts` 导出用的单独 Worker；`idb.ts` IndexedDB（自动保存、检查点、参考图）；`render/` 是 WebGL 渲染（`renderer.ts`）、着色（`colors.ts`）、矢量叠加（`overlay.ts`）与风向流线（`wind.ts`）；`ui/` 里：
  - `defs/` 是注册表：`tools.ts`（每个工具的图标、名字、底部条上的滑块与选项、吸取、换个形状）、`adjustments.ts`（“调整”里的滑块）、`layers.ts`（“图层”里的底图与开关）。加一个工具、参数或底图只要加一条声明，顶栏、底部工具条、面板都由它们生成
  - `shell/` 是浮在地图上的外壳：顶栏、弹出面板、底部工具条（`ContextBar.tsx`，量距离时换成量出来的数；横滑块的换算在 `sliders.ts`）、提示条、右下角“这里”、左下角的尺子、右边的抽屉、键盘
  - `panels/` 是弹出面板的内容；`tools.ts` 是地图工具（预览与命令）；`Wizard.tsx` 新建向导，`ClimateChart.tsx` 生态类型编辑器，`Inspector.tsx` “这里是什么”
- `tools/`：`generate.ts` 批量导出，`bench.ts` 计时，`hash.ts` 各层哈希，`terrain-stats.ts` 地形统计，`preview-terrain.ts` 地形预览图

## 已知限制

- 耗时（Node 里实测，第七轮前 → 后；浏览器里多约 0.05–0.1 秒的传输与重画）：

  | 操作 | 一块地区（4 万格） | 整个星球（10 万格） |
  |---|---|---|
  | 改海陆（真改了海陆的一笔） | 0.75 → 0.48 秒 | 2.4 → 1.75 秒 |
  | 只改冷暖干湿 | 0.37 → 0.08 秒 | 1.24 → 0.22 秒 |
  | 撤销、重做 | 约 0.7 秒 → 几毫秒 | 约 2.2 秒 → 十几毫秒 |
  | 重画这一片 | 0.9 → 0.33 秒 | 4.7 → 1.4 秒 |
  | 新建 | 1.5 → 1.2 秒（网格另快约 3 倍） | 5.2 → 3.2 秒 |
  | 重新打开（重放；有检查点时更快） | 2.5 → 0.95 秒 | 9.9 → 3.8 秒 |

  改名、圈地名、改省份及其撤销约 10–20 毫秒；悬停、涂画时每帧约 1–2 毫秒。导出宽 4096 的图约十几秒（地区）到半分钟（星球），期间照样能用。
- 撤销只存最近几步的结果（地区 3 步、星球 2 步，每步约 11 / 27 MB），再往前撤销还是要重算；排队的笔画各算一遍，画得很快时要等它们一笔一笔算完。检查点只在打包后的程序里用（开发服务器里照旧重放）。
- 一块地区：地图是星球上的一块，东西不相接，“地图在星球上的位置”只能整体南北挪，南北跨度由建世界时的大小决定。最多约 4 万格（放大到最大时一格约 64 像素）。
- 整个星球只有平铺图，没有地球仪；两极附近按平铺世界地图的样子被拉宽；圈一片、圈地名不能绕着极点画。
- 气候是简化的过程模型，不是 GCM：洋流只有整个星球有，而且是全年平均的表层流（没有深层洋流、海冰、厄尔尼诺这类年际变化）；季风只按大尺度海陆分布估计。一块地区的地图还没有洋流。
- 导出的 `terrain.bmp`、`rivers.bmp` 用的是通用配色，导入具体游戏前需要按其调色板重新映射（见导出包里的 README）。
- 改道时“会变干的旧河道”是估算：没算改道后地势跟着变的部分，极少数格可能和结果不同。新河道下切后，上游的水有时会直接流进路线的第二格。
- 量距离量的是直线（整个星球上是大圆弧），一段一段相加，步行天数按每天 30 km 算，不绕山、不绕海。
- 参考图只能“保持比例放在中间”或“拉伸铺满”，还不能单独移动、缩放；它只存在这个浏览器里。
- 人文内容（城镇、文化、国家）和省份的上级层级、自定义属性还没做；“放地名”只是一个带名字的点。

## 旧存档的变化（第七轮）

没有变化：旧存档照旧逐值重放（与第六轮的程序逐值相同）。两处新的记录方式：
- 新存档的命令里记下了当时新起的省名（可选字段 `provinceNames`），重新打开后省名与当时一字不差。以前重放时起名用的是还没算到那一步的推导，约 1% 的省名会与当时不同；旧存档没有这项记录，照旧重放。
- 自动保存从 localStorage 搬到了 IndexedDB（第一次打开时自动搬过去）；另存一份检查点，打开时直接恢复。

## 旧存档的变化（第六轮）

没有变化：一块地区的世界和所有旧存档逐值不变（`core/golden.test.ts` 锁住各层结果的哈希，屏幕截图的哈希改前改后也一致）。整个星球的存档写成第 3 版，旧版本的程序打不开它（会提示文件版本不对），不会把它当成平面地图去重放。

## 旧存档的变化（第五轮）

旧存档照旧逐条重放，下面几处和以前打开时不一样：

- **零星的小湖没了**：只有一两格的自然洼地（高程平滑留下的小坑）不再算湖，水照常流过，荒漠里不再有零星的蓝点。附近的流量、生态因此略有变化；高程、陆海、省份、你放的湖都不变。
- **“调整”里先后改了几项的存档**：以前改一项星球参数（比如“整体冷暖”）会把之前改过的其他几项（比如“四季分明”）悄悄重置回默认值，这是个 bug；现在每一项都保留你拖到的值，所以这类存档重放后的气候是你当时设的样子。省份的自动划分规则也有同样的修正。
