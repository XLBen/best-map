# 架空世界编辑器（map_2）

给写架空世界的作者用的地图工具：几秒钟生成一片像真实世界的海陆，然后自己放岛、画陆地、涂生态、画河、划省份，名字自动起好，最后导出成游戏能用的位图与表格。气候、河流、植被按物理规则推导，你改了一处，下游、下风向会跟着变。想要水晶丛林、血河、双子大陆这样的奇幻设定，可以给生态、河流类型、星球形态写一小段脚本，打包成资源包给别人用。

**一键开启**：先装 [Node.js](https://nodejs.org)（LTS 版），然后双击 Mac 上的 `启动-Mac.command`、Windows 上的 `启动-Windows.bat`。第一次会先联网装需要的组件（一两分钟），再打包一次（代码没变时以后不再打包），之后浏览器自动打开 http://localhost:5191 （打包好的程序，比开发服务器快，打开上次的世界直接从检查点恢复）。地图已经开着时再双击只是打开浏览器。用完关掉那个黑色窗口就停止。世界自动保存在浏览器里、按地址分开，所以地址固定是 5191；重要的世界请用“世界 → 保存”另存一份文件。**第九轮起不再兼容以前的存档**：第九轮以前保存的世界文件、浏览器里的自动保存都打不开了（打开时提示“这是旧版本的世界，打不开”），请新建。Mac 第一次若提示“无法打开”：右键 → 打开。

```bash
npm install
npm run dev        # 开发服务器，默认 http://localhost:5173（.claude/launch.json 里用 5191）
npm test           # 全部测试（79 个文件、779 个）
npm run test:fast  # 改代码时常跑的那部分（跳过最慢的几个文件）
npm run golden     # 只跑金标准：提速、重构后结果必须逐值不变
npx tsx tools/generate.ts --seed 3 --out out/seed3   # 命令行批量生成并导出
npx tsx tools/hash.ts                                 # 各层结果的哈希，用来核对 Node 与浏览器是否逐值一致
npx tsx tools/bench.ts --globe                        # 整个星球（10 万格）各步的耗时
```

## 五分钟上手

界面学的是 Procreate：地图铺满全屏，按钮浮在上面，每一类调节只有一个固定的位置。

| 位置 | 放什么 |
|---|---|
| 左上角 | **世界**（新世界、打开、保存）· **操作**（导出、历史、上手说明、偏好）· **调整**（整个世界的滑块）· 撤销、重做 |
| 右上角 | **地形 · 气候 · 自然 · 水系 · 省份 · 地名** 六类工具：点一类只是换到这一类（换到它上次用的工具），不弹出东西挡地图，也不换底图。然后是 **图层**（底图、画风、地名、河流、边界、比例尺、纬度刻度、参考图）和 **生态**（要涂的生态、生态类型编辑） |
| 底部工具条 | 第一行：这一类的全部工具（图标 + 两三个字，悬停时说怎么用），末尾的“⋯”是这一类的更多设置（省份的划分规则、文字包与全部地名……）。第二行：当前工具的设置——“半径 ━━●━━ 420 km”这样带名字、数值一直写着的横滑块（用不上的不显示），以及模式（画陆地/画海、岛的种类与“换个形状”、自然融入/强制、更冷/更暖……）；选中的省份、地名也在这里改 |
| 顶部中间 | 改完后的一句话 + 撤销；放岛、岛链再加“换个形状”（替换刚放的那个）。鼠标旁只写一行结果（“陆地 +804 格”“火山岛 · 190 km”），没有结果时不说话 |
| 右下角 | “这里”：鼠标下是什么（就是地图上画出来的那一格：海岸、弯曲的省界、剪刀切线旁都不会读错），点开看为什么 |
| 左下角 | 比例尺；旁边的尺子是量距离 |

1. **新建世界**：左上角“世界”→“新世界…”，先选“一块地区”还是“整个星球”（整个星球见下一节）。一块地区：选世界类型（群岛之海、一块大陆、几块大陆、破碎大陆、内海、空白海洋）、大小（一片群岛约 1500 km ～ 半个星球约 1.8 万 km），再选**放在星球的哪里**：一条从北极到南极的竖条上画着热带、亚热带、温带、寒带、极地，地图的南北范围是上面一个可以拖动的窗（高度由大小决定），旁边写着“北纬 19° — 北纬 73°，包括亚热带、温带、寒带、极地”。一张图本来就从南到北跨好几个气候带，靠海、山上也各不一样；这一步只是选地图在星球上的位置（四个快捷按钮是常用的位置）。最后从 6 张缩略图里挑一张，缩略图跟着位置变。之后每次打开页面会自动接着上次的世界。
2. **地形**：画陆地 / 海、放岛（火山岛、大陆岛、低平岛、珊瑚岛，以及只占一格的**小礁**）、画岛链、堆山 / 压低、重画这一片，以及**恢复原样**：涂到的地方，画过的陆地、海、山和放的岛都退回生成时的样子（中间全收回，边上渐变），预览里直接画出恢复后的海岸线。画陆地时底部可以选“圈一片”：按住画一个圈，松手后圈里变成陆地（或海），边上照样是自然的海岸。最小的笔刷正好一格，悬停时描出会涂到的格；最小的岛约一格。岛的大小是连续的：点一下用底部滑块的大小，按住往外拖就拖多大。手里有草图的话，在“图层 → 参考图”里导入，半透明地铺在地图上照着描。
3. **气候与自然**：“气候”里有冷暖（底部选更冷 / 更暖）、干湿（更湿 / 更干）、擦掉冷暖干湿的改动、涂自定义场。涂完顶部写“变冷 917 格，最多 −4 °C”，地图闪出气温变了的地方。“自然”里右上角“生态”选一种生态去涂（也可以按住 Alt 在地图上吸取），底部是“自然融入”（系统调这里的冷暖干湿，让它真的长出来，周围平滑过渡，范围由“过渡”滑块决定）或“强制”；还有拖动扩张、岛屿特有生态、擦除。“编辑生态类型”在右边的抽屉里：每种生态是气候图上的一个色块，拖动、拉伸就能改它喜欢的冷暖干湿，可以一边调一边看地图；每种生态下面收起的“高级：图案、效果与脚本”能加花纹、发光、对周围的影响、侵占和脚本，“添加示例生态…”加上内置的奇幻生态。
4. **整个世界**：“调整”里拖“陆地多少、岛多少、山多高、海岸曲折”，地图上先画出将来的海岸线（与结果逐格相同），松手才计算、算的时候也不闪回旧的海岸；**地图在星球上的位置**（整张图往南或往北挪，下面写着现在跨哪几个气候带）、冷暖、干湿、四季、河流多少、**山挡风**（高山让风拐弯，0 是风直接翻过山）等也在这里，每一下都能撤销。“图层”里打开“纬度刻度”，左边每 10° 一格，回归线、极圈用虚线标出。
5. **水、省份、地名**：“水系”画河有两种走向（底部“走向”）。**顺地势**：点一下起一条河，按住拖出路线，碰到别的河就停在那里汇进去，提示里写着“→ 汇入赤江 · 230 km”；从一条河上按住往外拖是让它改道，会变干的旧河道画成红色虚线。**自定义走向**：按住画出河道，河完全照着画的线走，穿山时只挖出一道河床（旁边的山、山名、气候都不变）；进海、进湖就到头，多画的部分灰色、不要；从海或湖往陆地上画会自动倒过来（从河口往上游画）；画到陆地上可以选“画完接着流”或“画完就消失”；穿过别的河时红色标出会变干的河段，松手后底部问“截走它 / 到这里汇入 / 取消”（回车、Esc，按住 Shift 松手直接截走）；画到一条河上时在第一次碰到它的地方汇入（斜着画过去先擦过它一两格也不会被当成截走、绕圈）。**接着别的河画**：从一条画的河的终点（在终点消失的河的终点、“画完接着流”的河画的线的末端）起笔是往下游接长这条河（还是同一条河，名字、大小、类型照旧，消失的终点换成这一笔的终点）；从一条河中间起笔是改道，底部先问“从这里改道：「赤江」下游约 300 km 会变干 / 改道 / 取消”；从画的河的源头起笔先问“重画整条「赤江」/ 取消”；鼠标停在起笔的地方时就写着会怎样。横穿一条在终点消失的河的终点也算穿过它，截走后它不再消失。新河抢走旁边自然小河的集水区时，提示里写“旁边的小河会并进来（N 格）”。新画的河都会自动起名（排在原有地名之后，不会抢走别的地名）。**点一下已有的河就选中它**：底部改名字、“大小”（这条河一共多少水，最左边是顺其自然），“⋯”里是粗细（只改画法和导出）、终点、删掉；在选中的画的河上按住拖是重画这一段，名字、大小照旧。选中自然的河可以“固定这条河”（走向固定下来，名字和颜色不变）或“从这里往下去掉”。“水系 ⋯”里是河流列表：画过的河和有名字的自然大河，每条的大小、长度、流到哪，有一段在海里、没按画的走、水被截走了会标出来，点一行就选中。底部的“大小”选新河的大小（水沿河道一路加进来，越往下越宽）。放湖和放岛一样能拖出大小。“省份”选省份（在底部条改名、标成无人区、锁定、对半分开）、省份画笔、剪刀（画的线就是切口，线没画到省界外会自动延长，切成几块就是几个省）、合并、重新划分一片；底部“省份着色”换成按省份上色的底图，“⋯”里是自动划分的规则。“地名”里点名字就能改名、换一个、锁定；**圈地名**：画一个圈，圈住的地方成为一个地区、平原、山地、森林、沙漠或海域（按地形猜，可以改），名字按文字包自动起，也可以直接打字；**放地名**：点一下放一个城镇、渡口、海角这样的点状地名。“⋯”里是全部地名和文字包。
6. **导出与资源包**：左上角“操作”里导出游戏文件包（.zip）或当前画面的 PNG；世界文件在“世界”里保存、打开；做好的生态、河流类型、湖泊类型、星球形态在“世界 → 资源包…”里导入、导出、用到这个世界。

操作：触控板双指滑动平移、捏合缩放；鼠标滚轮缩放，右键或空格加拖动平移（只需点一下的工具里左键拖也是平移）；`=` `-` 缩放；F 看全图；`[` `]` 调底部第一个滑块（半径、大小），`{` `}` 调力度；R 换个形状；按住 Alt 点一下吸取生态或省份；数字键切换这一类的工具；⌘Z 撤销，加 Shift 重做；Tab 隐藏界面只看地图；M 量距离（点几个点量出总长和步行天数，Backspace 删掉最后一点）；Esc 关面板、取消正在画的、退出量距离。滚轮是缩放还是平移会自动分辨，分辨不准时在“操作 → 偏好”里改。

## 整个星球

新建世界时选“整个星球”，整颗星球平铺成一张图（经纬度等距，像常见的世界地图）：
- **类型**：像地球（几块大陆）、一块超大陆、破碎大陆、群岛星球、海洋星球（只有火山岛露出海面）、空白星球。
- **星球形态**：类型下面还有几张形态的卡片：内置的双子大陆、环形内海、极地大陆，和资源库里装的（带脚本的标着“脚本”）。卡片上的“编辑…”打开形态编辑器：名字、一句话说明、从哪种星球改起，陆地多少、岛多少、板块数、大陆块数、大陆大小、山脉宽窄几个滑块，收起的“脚本”里可以写布局脚本（加大陆块、加岛）和地形脚本（改每一格的高度、山、丘陵、岩性；可以选“在原来的地形上改”或“完全由脚本决定”）。右边的缩略图停半秒就按改过的样子重画，脚本出错写在它下面，“换个种子”看另一颗。改内置的、导入的形态改的是一份副本；“存进资源库”存进“我的资源”（没改过的不再存一份），“用它新建”直接建世界。脚本算得太久被停下时，缩略图下面说一声，改了脚本才再算（每停一次世界都要从记录里恢复一遍）。从世界导出、存进资源库替换“我的资源”时，里面存的星球形态留着。“自己做一个…”从空白的开始。
- **换形态**：建好的星球上，“调整 → 地形”里有一行“星球形态：双子大陆 [换…]”。选一个，地图上先画出换了之后的样子（多出的陆地淡黄，会变成海的画斜线，写着“会多出 1,234 格陆地、少掉 567 格”），点“换成它”才换，一步，可以撤销；画过的陆地、放的岛照样叠在新的地形上，陆地多少、岛多少照现在的（调过的，或新建时定下的），不用形态里写的。安全模式下形态里的脚本不运行，预览里也没有它们的效果。
- **大小**：小（半径约 3,400 km）、类地（6,371 km）、大（9,500 km）。大小只改变 km，同一颗星球放大缩小。
- **精细**：约 10 万格，类地星球每格约 75 km。缩略图用 4,000 格，与成品的陆海一致。

看地图：
- 一直往左或往右拖，会绕星球一圈回到原处，接缝看不出来。上下边是南北极，拖到两极就停住。
- 两极附近像普通世界地图那样被横向拉宽：画笔、岛在图上是横向拉长的，在星球上是真实大小。
- “图层”里的“纬度刻度”在星球上叫**经纬网**：每 30° 一条线，回归线、极圈用虚线。比例尺写明是哪个纬度的比例（“1,000 km · 北纬 45°”）。
- 右下角“这里”写着经纬度，海上写洋流的方向和冷暖，陆地上写洋流让这里暖了或凉了多少。

**洋流**（只有整个星球有）：
- 大陆东岸外是向极的暖流，更暖更湿；低纬度的大陆西岸外是向赤道的寒流和冷水上涌，凉而干，像南美、非洲西岸的沙漠；高纬度的西岸比同纬度的东岸暖，像西欧；赤道上大洋东部有冷水舌。
- “图层 → 洋流”画出流线：暖流偏橙、寒流偏蓝。“调整 → 洋流强弱”：0 是没有洋流，2 是加倍。
- 这是按风带和海岸位置估算的简化模型：环流强度来自 Sverdrup 平衡，大洋西侧收成窄而强的边界流，再加上顺风偏转的风吹流；海面温度顺着海流输送，约 1,000–2,000 km 内回到平衡。

工具：
- 所有工具在接缝两边、两极附近都照常用；画笔、重画、放岛按球面上的真实距离。
- 圈一片、圈地名不能绕着极点画：会提示“绕着极点了”，松手不生效。
- 量距离沿球面上最短的弧线量，线也画成弧线。
- “调整”里没有“地图在星球上的位置”和“地图外面是海”，多了“洋流强弱”。

导出：2:1 的经纬度等距图，左右两边接得上；`features.csv` 里是真实的经纬度。

## 结果可以预料

该随机的地方随机（新世界的格局、海岸与地形的细节、岛的轮廓、自动起的名字），全部由种子决定：同样的操作做两遍，结果一样。想要不一样，就点明确的按钮——“换一组”“换个形状”“换个排列”“重画这一片”“换一种划分”“换一个”。

不该随机的地方，按下面几条规则，每条都有测试：

1. **所见即所得**：每个工具动手前或动手时都显示确切的预览，松手后的结果与预览逐格一致（每一类都有“预览 = 执行结果”的测试）：
   - **地形**：放岛（含小礁）、岛链、画陆地 / 海、圈一片、恢复原样、放湖直接画出将来真实的海岸线（不再是绿色、蓝色的格子）；放岛写出直径（直径就是海岸线的大小，放出来的岛平均就这么大）。重画这一片停一下就画出重画后的海岸线和山的高低变化，什么都不会变时点了不算。堆山、压低写出“约 +600 m”，预览的深浅跟着力度变。“调整”里拖陆地多少、岛多少、山多高、海岸曲折时画出将来的海岸线，松手后算的期间也不闪回旧的海岸。
   - **气候与生态**：涂生态、冷暖干湿、擦除、自定义场、拖动扩张按住停一下，地图上就是松手后的样子（变了的格描边，涂不成的格画红色斜线，写着“38 格会变 · 6 格没涂成”），接着画也不跳回原样，松手时直接用算好的结果；拖“调整”里气候、河流、山挡风的滑块、拖生态色块时停一下也一样。
   - **水系**：画河显示的就是松手后的河（同一套画法，越往下越宽），提示写明最后流到哪（入海、流进湖里、汇入哪条河）；停一下换成确切的流量、名字、会变干（红色）和新出现的河段；改道时把会变干的旧河道画成红色虚线。放湖显示湖面，贴着海放不住时当场拦下。删除河湖停一下标出真正会变干的河段。
   - **省份**：剪刀、涂省、合并拖动时直接画出将来真实的省界（新的几块是它们将来的颜色），剪刀切出的边就是画的线；重新划分涂着停一下，画出新的省界和省名；鼠标停在“对半分开”“按新规则重新划分”“换一种划分”上，先画出新的省界；锁定的省合并不了当场标红，不相邻、会把别的省涂断时黄色提醒。
   - **地名、“这里”**：圈地名高亮圈住的格并写出类型和面积；右下角“这里”、Alt 吸取、点选读的都是地图上画出来的那一格（海岸、弯曲的省界、切线旁都不会读错）。
   - **资源包、星球形态、脚本**：用资源包、换星球形态先在地图上看（会变成新生态的格、会多出少掉的陆地），“用上”“换成它”直接采用算好的结果；脚本框停一下就真的用到地图上；拖花纹、发光的滑块时地图立即跟着变。
   - **排队时也一样**：前面的编辑还在算时接着画，排队中的那几步一直显示松手时的样子，直到结果换上。
   - **还不是确切的**：新建向导的缩略图是粗略版，看不到很小的岛；放岛、画陆地时新陆地的颜色、高程在结果出来之前是估计的；大星球上一次要算很久的预览不自动算，只说“松手后约 N 秒出结果”。下面“还能怎样更所见即所得”里有完整的清单。
2. **画陆地**：画笔中间 70% 一定变成陆地，只有边缘一圈由海岸噪声决定湾和岬；画笔外一格不变。圈一片也一样：圈里离边远的地方一定变成陆地，只有圈的边上一窄条由海岸噪声决定。
3. **影响局部、变化看得见**：编辑只影响画到的地方和物理上必然受影响的下游、下风向。每次编辑后变化的格会闪几秒，顶部一句话说清改了什么（“陆地 +800 格，44 格生态变了，1 处河道变了”），旁边就是撤销。高程迭代固定轮数，所以在一块大陆上的改动不会让别的大陆的地形变一点点。
4. **滑块是连续的**：“陆地多少”就是升降海平面，陆地多时原来的陆地一格不少；“岛多少”只增减火山岛；“山多高”只缩放造山带。你画的陆地、放的岛都会保留。岛、湖、画笔的大小和力度也都是连续的，不再只有几档。
5. **放岛的形状跟着鼠标走**：岛的形状只取决于种类、大小和形状编号，与位置无关，所以悬停时轮廓跟着鼠标移动而不变形，拖大拖小是同一个岛等比例缩放。放下一个后自动换下一个形状（悬停时看得到）；不满意就点提示条上的“换个形状”，原地换一个。
6. **缩略图即成品**：生成器的随机都按地图上的位置取，与格数无关：4000 格的缩略图与 4 万格的成品陆海一致率 ≥ 90%。
7. **涂到的就是**：“自然融入”涂到的格要么长成这种生态，要么当场画上红色斜线，并在“没涂成”里用人话说明原因（“太冷：这里年均 13 °C，它要 22 °C 以上”），可以一键强制。绝不默默地改成别的。
8. **自动划分也稳定**：同样的规则划出来的省份相同；重新划分一片只动被涂到一大半的省份，别处的编号、名字、格子都不变；改陆地只修补变了陆海的格；锁定的省份始终不动。
9. **名字不乱跳**：名字跟着要素里一个固定的“锚点格”走——在海里放个岛、把岛画大一点，只要那一格还在，名字就不变。在一片森林里涂别的生态，涂出来的那片另起名字，森林的名字留在没涂的地方。新种类的地名（涂出来的生态区、画的河、带类型的河）排在原有地名之后才起，不会抢走别处的名字。改过的名字之后也一直跟着这个地方，永远不自动变。
10. **河不会悄悄截走别的河**：顺地势画的河碰到别的河就汇入，那条河照旧流到原来的入海口；自定义走向的河穿过别的河时，先标出会变干的河段，松手后问你“截走它 / 到这里汇入 / 取消”。改道不能接回自己的上游（水会绕成圈），预览当场变红说明。
11. **脚本出错不挡你**：脚本出错、算出不是数的值，这一次按没有脚本处理，顶部说明是第几行；算太久的脚本会被停下，世界退回这一步之前的样子。画笔、撤销、打开世界绝不因为脚本出错而失败。

## 地形是怎么来的

先造“地壳高度”，再定海平面：
- 大陆块带域扭曲和多尺度分形起伏，低处被淹成内海和海湾；外侧是宽窄不一的大陆架、陆坡和深海；
- 板块边界上有洋中脊、海沟、裂谷，造山带分段、有平行的次级山脉和高原；
- 火山锥（热点岛链、岛弧、海山）高度取重尾分布，所以岛的大小自然呈幂律（少数大岛、许多小岛）；
- 海平面按目标陆地比例取分位数；陆地 = 高度 + 海岸噪声 × 破碎度 > 0，屏幕和导出都用同一个海岸噪声画格以下的海岸细节；
- 高程是抬升与河流下切的稳态（stream power），所以山有树枝状的河谷和支脉。

## 生态

每种生态在气候图上是一个矩形（年均温 × 湿润程度），外面自动留一圈过渡；另外可以勾选条件：只长在海边 / 河边 / 高山 / 平地 / 低洼积水处，雨季在夏天 / 冬天。两种生态都能长的地方，“强势程度”高的占上风。更精细的条件在“高级”里：对任意一项（海拔、坡度、流量、纬度、自定义场……）给一条梯形耐受曲线。默认的 13 种生态接近地球（Whittaker 生物群系图）。

“自然融入”时，系统在温度 ±15 °C、降水 ×12 的范围内反推出让涂的生态成为主导的最小修正，用格图上的调和插值把修正平滑地扩散到周围，再重算水文与植被，所以河流和你涂的生态始终自洽。

**涂出来的生态区有自己的名字**：涂上的生态与周围原来的生态不同、连成 8 格以上、并且真的长成了，这一片就成为一个地物，自己起名；周围原来那片的名字留在没涂的地方，标注也放在它自己的格上，不会压在新涂的那片上。属于森林、沙漠、冻原这些大类的生态按大类起名（“某某林”“某某沙漠”），草原、稀树草原、灌丛按自己的模板（“某某草原”），自己做的生态起的名字里带着生态的名字（写了地名设定的按它的模板，见下）。同一种生态往外涂，名字不变；把一整片都涂成别的，才换名字。圈地名新圈的地区默认“自动”类型：圈完再把这里涂成沙漠，它就变成沙漠；选过类型的不再自动变。

**“高级：图案、效果与脚本”**（生态抽屉里每种生态下面，收起着）：
- **图案**：闪光、裂纹、斑驳、脉络、斑点、条纹，第二种颜色、明显程度、大小，外加发光和发光的颜色。拖滑块时地图立即跟着变；拉远时花纹淡成平均色，整个星球上没有接缝。只改外观不重算。
- **对周围的影响**：让周围变暖变冷、变湿变干，离它越远越弱，到“范围”的边上为 0（见下面“河流类型与对周围的影响”）。
- **侵占**：选几种别的生态，在它们适宜的地方，这种生态更容易占上风（比如示例里的虫群占领区侵占森林）。
- **地名**：类型名（地图上这一片叫什么，比如“晶林”）和起名模板。
- **脚本**：“长在哪里”“颜色”两个脚本框，见下面“脚本”。

生态自带地名设定（“高级”里的类型名、起名模板，比如示例包里水晶丛林的“晶林”）时，自然长成的一大片（8 格以上，每种最多 10 片）也有自己的地名，不只是涂出来的那些；名字在原有的地名都起好之后才起，不会抢走原有地物的名字，只改别处时也不会变。没有地名设定的生态照旧，只用内置生态的世界地名一点不变。

岛屿特有生态：点一个岛（大陆不行），以岛上最多的那种生态为底，建一种只长在这个岛上的近亲：喜欢的冷暖干湿、条件照抄，强势程度只高一丝，颜色略微偏一点，名字是“岛名 + 底生态名”。所以岛上原来是这种生态的地方换成特有的版本，冰原、湿地等别的生态不变，岛外也不会出现。再点同一个岛只会提示已经有了；提示条上有“编辑”。

## 省份

自动划分的规则：大小（小 · 中 · 大）；按地形调整大小（平原、河谷、海岸省份小，山地、荒漠大）；冰原、深漠、高山合成无人区；大湖单独成省；近海的海域小、远洋的大。边界尽量贴着河与山脊。名字从文字包里按省内地形取字。

省份有陆地、海域两种，另外有两种特别的：
- **无人区**：陆地省份底部条上的一个开关。意思是没人住的地方（冰原、深漠、高山）：导出到游戏时算作不可进入的荒地（`provinces_summary.csv` 的类型一列），地图上画灰色斜线，省名灰色。它不改地形和生态。
- **湖省**：自动划分时一大片湖单独成的省，导出时算作湖，省名蓝色；底部条上只标“湖省”。湖后来被删掉、干了时写“湖省 · 这里已没有湖”，旁边有“改回陆地”。

省份工具里，无人区的斜线压在选中的高亮之上，随时看得见；“⋯”里有图例。

**剪刀**：拖动时地图上就是切开后真实的省界，新的几块是它们将来的颜色；切出几块后红线隐去，只留两端的小点（自动延长的部分画成虚线）。线只有在一端所在的省里走了一段（至少两格、线长的四分之一）才往那一端延长，所以从邻省外画到另一边的邻省外，只切开中间的省。切开后，切线旁（两边各约 1.25 格）的像素按“在线的哪一边”分省，屏幕上和导出的 `provinces.bmp` 一样，切口就是画的线；点选、合并、吸取在切线旁也按显示出来的那一边算。之后把两块合并回去、重新划分了这里，这条切线就不起作用了。

## 文字包（地名）

名字由文字包生成，是一个 JSON 文件，可以在“地名”模式里导出、修改、导入：

```json
{
  "id": "my-pack",
  "name": "我的文字包",
  "lists": {
    "color": ["青", "白", "赤"],
    "cold": ["霜", "雪", "冰"],
    "animal": ["鹤", "鹿"]
  },
  "types": {
    "island": {
      "patterns": [{ "p": "{color}{animal}岛", "w": 3 }, { "p": "{animal}屿" }],
      "byTag": { "cold": [{ "p": "{cold}{animal}岛" }] }
    }
  }
}
```

- `lists`：词表。模板里的 `{词表名}` 换成该词表里的一个词（同一个名字里尽量不重复用字）。
- `types`：每种地貌一组模板，`w` 是权重（默认 1）。地貌类型有 `continent island archipelago peninsula ocean sea bay strait lake river range peak plateau plain basin desert forest tundra icecap wetland province`，用户圈的地区 `region` 和放的点状地名 `spot`（圈的平原、山地、森林、沙漠、海域分别用 `plain range forest desert sea` 的模板），以及涂出来的生态区 `biome`（温带草原、稀树草原、灌丛另有 `biome.steppe`、`biome.savanna`、`biome.shrubland`；模板里的 `{__species}` 换成生态的名字）；没写的类型退回 `island` 的模板，没写 `region`、`spot` 的旧文字包用 `province` 的模板，没写 `biome` 的用内置包的。
- `byTag`：要素带某个情境标签时，有 65% 的机会改用这里的模板。标签有 `cold hot dry wet high large small volcanic`；省份另有 `coastal river mountain sea waste`（无人区）；点状地名另有 `coastal river mountain sea`。
- 导入时会检查模板里用到的词表是否都存在；可以用它做英文或某种架空语言的包。
- 名字由“文字包 + 类型 + 锚点格 + 世界种子”确定，换文字包后所有自动名字一起换，你改过的名字不变。

## 脚本

生态、河流类型、星球形态都可以带一小段脚本，用的是完整的 JavaScript：

| 写在哪里 | 脚本 | 返回什么 |
|---|---|---|
| 生态抽屉 → 一种生态 → “高级：图案、效果与脚本” | 长在哪里 | 0–1，乘进适宜度（0 就不长） |
| 同上 | 颜色 | `[r, g, b]` 或 `'#rrggbb'`：这种生态在这一格画成什么颜色 |
| “水系 ⋯ → 水体类型” → 河 / 湖 → 编辑 | 哪些自然的河（湖）是这一种 | `true` / `false`，每条河、每个湖只算一次 |
| 新建向导 → 星球形态卡片的“编辑…” | 布局 | 不用返回，调 `addBlock({lat, lon, size})`、`addIsland(…)` 加大陆块、加岛 |
| 同上 | 地形 | 新的高度，或 `{height, mountains, hills, rock}` 里要改的几项 |

**写法**：一段函数体，最后 `return` 结果。变量有中文、英文两套名字，写哪个都行，比如 `海拔` / `elevation`、`年均温` / `tMean`、`离河` / `riverDist`：

```js
// 海拔 1500 米以上才长，越高越多
return smoothstep(1500, 2500, 海拔);
```

- **变量**（框下面的“变量和例子…”里有全部的中文说明，和几段点一下就能用的例子）：
  - 气候：年均温、最热月、最冷月、降水、湿润、四季、大陆性、风向；
  - 地形：海拔、坡度、抬升、岩性、湖、离海岸；
  - 水：流量、湿度、汇水、是河、离河（河流类型的规则另有河长、源头海拔）；
  - 位置：经度、纬度、地图上的坐标、这一格的面积；
  - 你用画笔改过的冷暖、干湿；世界的种子、星球半径、日照、水汽、河流门槛。
  - 没有省份：改省份不会重算生态，给了反而会对不上。
- **辅助函数**：`noise`、`fbm`、`fbmAt`（这一格处的噪声，整个星球上没有接缝）、`rand()`（每格固定的随机数）、`smoothstep`、`clamp`、`mix`、`mixColor`、`field('场名')`（自定义场）、`river('类型')`（离这种河多近）、`hasRiver('类型')`。
- **结果必须每次都一样**：`Math.random`、`Date`、`performance` 不能用（随机数用 `rand()`），也不能在格与格之间记东西、`import`、`console`。提交前就会指出来。

**边写边看**：框里停 600 毫秒、检查通过后就真的用到地图上；同一次修改只算一步撤销。写错时框下面一行红字，比如“第 3 行：没有变量 tMeen（是不是 tMean？）”，地图保留上一次好的结果；在地图上算的时候才出的错写成“地图上有一处…（点这里去看）”，点了镜头移过去。有 `while`、`for(;;)` 这类循环的脚本，打字停下时先不用，离开框时才用。

**出错**：语法错误在提交时就拒绝，世界不变。运行时出错、算出不是数的值，这一次按“没有这段脚本”处理（长在哪里按 1、用本来的颜色、河不算这一种、地形不改），顶部一条不挡操作的提示“「X」的脚本出错了，暂时按没有脚本处理（第 3 行…）”，带“编辑”。

**卡住**：一段脚本算了 1.5 秒以上，顶部显示“正在运行「X」的脚本…”和“停下”；4 秒没有动静就判定卡住（电脑睡眠不算），自动停下，用存着的记录把世界恢复到这一步之前（这一步没做，重做记录清空）。恢复时又卡住，就用安全模式打开。整个页面都卡死了的话，下次打开时先问“上次打开这个世界时程序停止了响应。用安全模式打开吗？”。

**安全模式**：这个世界里的脚本都不运行（带脚本的生态、河流类型、星球形态照旧在，只是按没有脚本算），顶部横幅写着原因，有“再试一次”（重新打开，脚本照常运行）和“查看脚本”。自动保存记着安全模式，刷新后照样是安全模式。

**信任**：打开别人的世界文件、导入资源包、读自动保存时，有没见过的脚本就先问“信任这个世界里的脚本吗？”，列出每段脚本（谁的、哪一种、源码），可以“信任并打开”“不运行脚本打开”（安全模式）或取消。信任按脚本的内容（SHA-256）记在这个浏览器里，改一个字就要重新问。自己写的脚本、内置示例包、导入资源库时信任过的包不再问（“我的资源”里存的不算：那里的脚本可能来自别人的世界）。

**隔离与它的限度**：脚本只在单独的计算线程里跑，这个线程从 data: 地址打开（没有来源），也受页面的安全规则管。
- 挡住的：读不到这个浏览器里保存的其他世界、资源库、检查点（检查点由另一个只做存储、从不运行脚本的线程写）；不能连别的网站。
- 程序一开起来先自查三项（来源为空、打不开存档、页面规则管得到它），全过才在信任的问话里说“脚本在隔离的环境里运行，读不到你保存的其他世界，也不能联网”；有一项说不准就老实说“当前环境不能把脚本隔离运行：脚本能读到这个浏览器里保存的世界，也能联网”。在这个页面里隔离运行过以后，不会悄悄换成不隔离的线程。
- 挡不住的：脚本照样拿得到当前这个世界的数据（它本来就要在这上面算），写错了地图就是错的；能拖慢电脑、占内存（靠看门狗和安全模式兜底）；页面规则只许连这个程序自己的网址（同源），所以把程序放在网站上时，脚本最多能向这个网站本身发请求。隔离靠浏览器，不支持的浏览器上退回普通线程（问话里照实说）。所以只信任你信得过的人写的脚本。

## 资源包

资源包（`*.map2pack.json`）把几种生态、河流类型、星球形态和文字包放在一个文件里，在“世界 → 资源包…”里管理：

- **资源库**：装好的资源包都在这里。内置的“奇幻生态示例”总在、默认信任；“我的资源”是从自己的世界里导出、存进来的。删掉资源库里的包不影响用过它的世界。
- **导入**：只解析、检查，不运行任何脚本；列出内容（带色块）和要留意的问题（重复的 id、指向不存在的生态、场、河流类型或词表的引用）。包里有脚本时先问“信任这个资源包吗？”，可以展开看每一段脚本。不认识的部分直接报错，不悄悄丢掉。
- **用到这个世界**：左边一张卡片，勾选要用的项，地图上先画出用了之后的样子（会变的格描边，新生态的格淡淡涂上，写出“会有 1,234 格变成新生态”），点“用上”是一整步，可以撤销。世界里已有一模一样的跳过；同 id 不同内容的改名为 `id-2`（名字带上编号，比如“水晶丛林 2”），包里对它的引用一起改，花纹的种子不变。岛上特有的生态默认不勾。生态抽屉里的“添加示例生态…”也走这张卡片。
- **导出**：从当前世界勾选自己做的生态（内置的原样不用导出，岛上特有的不带）、河流类型、在用的星球形态、文字包，存成文件或存进资源库（同名的会替换，事先说一句）。存进资源库不会把脚本记为信任：没信任过的，以后用到世界时照样先问。
- 以前导出的生态文件、文字包照旧能导入（走同一条检查、信任的路）。
- **内置示例包“奇幻生态示例”**，照着改就能做自己的：
  - 5 种生态：**水晶丛林**（闪光加发光，一片一片地长，晶川两岸最多）、**死亡森林**（裂纹，离水越远越容易枯死，让周围变干，越高越灰白）、**虫群占领区**（斑驳，侵占森林和水晶丛林）、**神圣之地**（发光，在“圣地”自定义场上涂过的地方一定长，让周围变暖）、**血腥之地**（脉络，长在血河两岸；还没有血河时长在离河近的地方）。每种都有自己的地名设定（比如水晶丛林长成的一片叫“某某晶林”）；五种一起用上时，每种占陆地都不超过 8%。
  - 4 种河：**血河**（低地上的大河，实线）、**晶川**（从高山上冲下来的冷河，发光）、**冥河**（虚线，让两岸变冷变干，没有规则，只能自己画）、**熔岩河**（火山带里的河，发光，让两岸变热变干）。
  - 3 种星球形态：**双子大陆**（两块大陆隔着大洋相对，用布局脚本）、**环形内海**（一圈陆地环抱一片内海，不写代码）、**极地大陆**（两极各一块高耸的大陆，布局加地形脚本）。

格式：`{format: "map2-pack", version: 1, id, name, author?, description?, fields?, biomes?, riverTypes?, planetForms?, textPacks?}`。

## 河流类型与对周围的影响

- **河流类型**（“水系 ⋯ → 河流类型”）：名字、颜色（地图集风格可以另给一个）、画法（实线、虚线、双线、发光）、粗细、两岸的影响（范围、冷暖、干湿）、起名模板，以及“哪些自然的河是这一种”的脚本。内置示例有血河、晶川、冥河（只能自己画）、熔岩河。
- **每格是哪一种河**：选了类型的河（画的河、固定下来的河）先定下；然后每种类型的规则**每条河只算一次**——一条河是从源头顺着最大的上游往下、到汇入更大的河（或入海、入湖）为止，规则读到的海拔、坡度、气温是整条河的平均，流量是最大，位置是源头，所以一条河不会一段是一段不是；最后往下游传：上游的水不少于这一格的一半时跟着上游，所以流进更大的河就停了。选了“普通的河”的河不按规则变。
- **选类型**：画河时在底部条上选新河是哪一种；选中一条河时也能换。给自然的河选类型会把它固定下来（一步），名字照旧。
- **两岸**：离这种河多近（0–1，河上为 1，范围以外为 0）在生态的条件里是“靠近某种河”，脚本里是 `river('id')`，`hasRiver('id')` 说地图上有没有这种河。
- **名字**：按规则成了某种河、或者画的时候选了类型的河，用那种河的起名模板（第二轮起名，不抢原有的地名）。
- **对周围的影响**：生态的“变暖变冷、变湿变干”、河的两岸影响，在第一遍算出生态、河之后按它们的位置算一次（每种源头一次距离，越远越弱，到范围为 0；合计最多 ±15 °C、降水 ×e^±2.5），之后的求解（自然融入会把影响补回来）和最后一遍都在加了影响的气候上算。没有这种影响的世界照原来的算法，逐值不变。“这里”写明“受「神圣之地」影响：这里暖了 1.8 °C”。
- 只改河流类型的颜色、画法、粗细不重算，只重画；改名字、模板只重新起名；改规则、两岸从水文起重算。

### 湖泊类型（第九轮）

湖和河是同一套：“水系 ⋯ → 水体类型”分“河 / 湖”两栏，用同一个编辑器。
- **湖泊类型**：名字、颜色（地图集风格可以另给一个）、画法（实色、发光、干湖底）、湖岸的影响、起名模板、“哪些自然的湖是这一种”的脚本。内置示例有血池、晶湖、冥湖（只能自己选）、熔岩湖。
- **一个湖**是连着的湖面加上干涸的湖底。放的湖、自然的湖自己选的类型说了算；剩下的湖每种类型的规则**每个湖只算一次**（海拔、气温是整个湖的平均，另有 `湖面积`、`入湖水量`、`干湖`、`放的湖`、`常年有水`），所以一个湖整片是同一种。
- **选中一个湖**：用“放湖”点一下湖就选中，底部条上是名字（换一个）、“这个湖：X ▾”、大小（放的湖）、删掉。给自然的湖选类型不用把它固定下来。
- **湖岸**：离这种湖多近在生态的条件里是“靠近某种湖”（`lake:id`），脚本里是 `nearLake('id')`、`hasLake('id')`。
- **类型按钮**：底部条上一直在——画河、放湖时写“新画的河：X ▾”“新放的湖：X ▾”，选中一条河、一个湖时写“这条河：X ▾”“这个湖：X ▾”；列表最后一项“新建类型…”新建一种、用上它，并打开它的设置。

## 第八轮：自定义河道、脚本与资源包、所见即所得

这一轮照你列的要求分四批做：修问题和手感、自定义河道、深一层的所见即所得、脚本与资源包。下面是用起来的变化，细节在上面各节。

**修好的问题**
- **生态名字跟着涂的生态走**：以前把针叶林涂成雨林、在森林中间涂一块沙漠，名字都不变，旧森林的名字还正好压在新沙漠上；草原、稀树草原和自己做的生态没有名字。现在涂出来的一片有自己的名字，原来那片的名字留在没涂的地方（见“生态”）。
- **更小的岛、小礁、更小的画笔**：
  - 火山岛、大陆岛、低平岛最小约 1 格（以前至少约 8 格，类地星球上像台湾那么大）；珊瑚岛的环要大一点才看得出，不变。
  - 新的**小礁**（放岛的种类里选）：只占一格，画出来约半格大，海岸曲折怎么调都还在。岛链有自己的种类和大小，放岛选了小礁不影响岛链。
  - 所有画笔最小 0.4 格，不到半格时只涂鼠标下那一格（省份画笔、重划也一样）；“重画这一片”最小 1.2 格，保证点了一定有变化；新放的湖最小只淹一格；过渡、新河的“大小”也能调得更小。
- **省份的无人区、湖省说清楚**：去掉了意思不明的“陆地 / 无人区 / 湖”三选一，换成“无人区”开关和只读的“湖省”标记，地图上看得见（见“省份”）。
- **剪刀切出的边就是画的线**：以前省界是格子边再加自然弯曲，离画的线最远将近一格（放大后约 40 像素），从邻省外画过去还常把邻省也切开。现在拖动时就画出真实的省界，切口就是画的线，屏幕和导出一致（见“省份”）。
- **山挡风**：以前风只由纬度、海陆决定，永远直接翻过山。现在高山挡得住的风会拐弯：迎风坡的风顺着山走（北半球向左拐），背风坡风小雨少；离山远的地方风一点不变，洋流照旧。降水、雨影、生态都跟着新的风变。
  - “调整”里有“山挡风”滑块：0 是风直接翻过山，1 和地球差不多，最大 2。“这里”多了“夏 / 冬风向”，比如“西南风（中）”。
  - 新建的世界默认是 1（打开）。
  - 代价：改地形时每次多算约 10–40 毫秒；只改冷暖干湿照旧不重算风。
- **放湖不白放**：湖碰到海时松手就拦下（“离海太近，留不住水：往内陆挪一点”），拖出的大小留着，历史里不再多一个不存在的湖。

**自定义河道，管理每一条河**（怎么用见“五分钟上手”第 5 步）
- **自定义走向**：河完全照着画的线走，不再碰到河就停（以前在地区上画一条 1000 km 的直线，八成多会中途被截断）。进海、进湖就到头；可以从河口往上游画；终点在陆地上可以“画完接着流”或“画完就消失”。
- **只挖一道河床**：以前画一条河会把沿途的山削低（最高峰 8,800 m 能变成 3,700 m，几百格地形跟着变）。现在新画的河（两种走向都是）只把河道那几格挖成一路往下的河床，旁边的山、山名、气候都不变，而且快好几倍。
- **截走前先问**：穿过别的河时先标出会变干的河段，松手后问“截走它 / 到这里汇入 / 取消”。
- **点河选中**：画河时点一下已有的河就选中它，不用另换工具：改名字、大小、粗细、终点，重画一段，或者删掉。自然的河可以“固定这条河”（以后改地形也不挪，名字照旧）或“从这里往下去掉”。
- **河流列表**（“水系 ⋯”里，不会自己弹出）：每条河的大小、长度、流到哪，有一段在海里、没按画的走、水被截走了会标出来；点一行就选中并定位。
- **画的河有名字**：新画的河自动起名，同一条河只标一次；固定一条自然的河沿用它原来的名字。

**所见即所得**（每种预览保证什么，见“结果可以预料”第 1 条）
- **幽灵海岸**：画陆地、圈一片、放岛（含小礁）、岛链、恢复原样、放湖、“调整”里的地形滑块，预览都直接画出将来真实的海岸线（以前画的是绿色、蓝色的格子，与结果差 18–59%，现在差不到 0.5%）。
- **停一下就是松手后的样子**：涂生态、冷暖干湿时按住停一下，拖“调整”里的气候、河流、山挡风滑块时停一下，地图按算好的将来的世界画出生态颜色、雪、河、地名（“温带阔叶林 · 38 格会变 · 6 格没涂成”），接着画也不跳回原样；松手时直接采用，颜色不跳。大星球上一次要算很久的不自动预览，只说“松手后约 N 秒出结果”。
- **省份先看再做**：重新划分一片时涂着停一下，就画出新的省界和省名（“重划 2 个省 → 5 个”）；鼠标停在“对半分开”“按新规则重新划分”“换一种划分”上先看新的省界，点下去照样一下就做。合并时锁定的省当场标红；不相邻的两省也能合并（提醒“合并后是一省两块”）；涂省会把别的省涂断时也提醒。
- **“这里”读画出来的那一格**：悬停卡片、Alt 吸取、选省读的都是屏幕上画的那一格（以前在海岸、弯曲的省界旁约 7% 的位置读错）。
- **排队**：放岛、岛链、圈一片、放湖也能像画笔一样，在前面的编辑还在算时接着用；排队中的那几步一直显示松手时的样子，鼠标旁写着“排队中：前面还有 2 步”。画河、剪刀、合并照旧等前面算完（它们要按算好的世界来）。
- **手感**：触控板平移、缩放、看全图之后画笔圈立即跟手；画陆地 / 海的画笔里多一圈细实线（圈里一定变）；空闲悬停只显示圈；“力度”“疏密”拖动时预览的深浅跟着变，并写出变化量（“堆山 约 +600 m”“间距约 X km”）；改完的闪烁 1.2 秒、慢慢淡出，切省、合并、涂省也闪；自己圈的、放的、改过的地名总显示；省界拉远时按省的大小淡出，不再一下子消失；导出的图片不带高亮、闪烁和预览。

**脚本、资源包与新的类型**
- **脚本**：生态（长在哪里、颜色）、河流类型（哪些自然的河是这一种）、星球形态（布局、地形）都能写完整的 JavaScript，变量有中文名；出错按没有脚本处理，卡住会被停下；有安全模式、信任和隔离（见“脚本”）。
- **生态的新本事**：花纹（闪光、裂纹、斑驳、脉络、斑点、条纹）与发光、对周围冷暖干湿的影响、侵占别的生态、自己的地名设定（见“生态”）。
- **河流类型**：名字、颜色、画法（实线、虚线、双线、发光）、两岸的冷暖干湿、起名模板，以及“哪些自然的河是这一种”的规则，一条河整条要么是要么不是（见“河流类型与对周围的影响”）。
- **星球形态**：新建整个星球时选形态卡片，“编辑…”里调滑块、写脚本、看实时缩略图；建好的星球在“调整 → 地形”里换形态，先看多出、少掉的陆地（见“整个星球”）。
- **资源包**：把生态、河流类型、星球形态、文字包装进一个文件，导入时先检查、问信任，“用到这个世界”先看后用、一步可撤销，也能从世界导出（见“资源包”）。
- **内置奇幻示例包**：5 种生态（水晶丛林、死亡森林、虫群占领区、神圣之地、血腥之地）、4 种河（血河、晶川、冥河、熔岩河）、3 种星球形态（双子大陆、环形内海、极地大陆），见“资源包”。

| 1 | **新建向导的缩略图看不到很小的岛**：缩略图只有 4,000 格，约一半的小岛画不出来。可以在选中一张后用 1.2 万格重算那一张 | 中 | 低 |
| 2 | **撤销前悬停看会回到什么样**（历史面板里悬停某一步也一样）：最近几步的结果本来就存着，换上来画就行；更早的要重算 | 中 | 中低 |
| 3 | **起名预览**：放地名、圈地名之前就看到会叫什么 | 低 | 低 |
| 4 | **岛屿特有生态的确切预览**：点之前看到岛上哪些格会换成特有的生态（用同一套“停一下”的预览） | 低 | 低 |
| 5 | **屏幕与导出的 `provinces.bmp`、`biomes.bmp` 在海岸像素上规则不一致**：海岸线上窄窄一圈，导出图里个别像素归到岸的另一边。要统一规则，`raster-identity` 得重录 | 中 | 中 |
| 6 | **整张地图按屏幕的样子导出图片**：现在“当前画面的 PNG”只导出看得到的那一块；`biomes.bmp` 每格一种颜色，屏幕上是按比例混色加花纹 | 中 | 中 |
| 7 | **脚本先在临时线程里试跑**：现在有循环的脚本要离开框才用到地图上；导入资源包时不先逐段试跑（✓ / ✗ 和出错的行），要用到世界上才知道 | 中低 | 中 |
| 8 | **放岛、画陆地、堆山时预览确切的高程和生态**：现在只有海岸线是确切的，新陆地的颜色、高程在结果出来之前是估计的。要整套重算，大星球上一次要几秒 | 中 | 高 |

## 速度（第七轮的优化）

第七轮没有加功能，只让程序更快、更稳。结果全部逐值不变：`core/golden-full.test.ts` 对一组较长的操作后整个世界（每一个数组、地物、省份）按字节记下哈希，地区与星球各一组；每一项提速还有自己的“新旧算法逐位相同”测试。

用起来的变化：
- **撤销、重做是瞬间的**：最近几步（地区 3 步、星球 2 步）的结果都存着，直接换回来，不再重算。
- **只改冷暖干湿快了约 4–5 倍**：气候里和地形有关的那部分（风、水汽输送图、洋流）按内容缓存，地形没变就不重算。
- **重新打开上次的世界**：每次自动保存时，引擎的完整状态也存一份（检查点），打开时直接恢复，不必从头重放；世界的网格也存一份，不必再建（第九轮起开发服务器里也有检查点，版本号是引擎文件的内容哈希；星球上刷新页面约 1 秒）。
- **自动保存不会再悄悄停掉**：改存 IndexedDB、只写变了的命令（以前存在 localStorage，画多了会超过约 5 MB 的上限，之后不再保存）。旧的自动保存第一次打开时自动搬过来。
- **算的时候照样能画**：画笔类的工具可以在前一笔还在算时接着画，松手后按顺序执行，各是一步，结果与一步一步等着做相同（第八轮扩展到放岛、岛链、圈一片、放湖，排队中照样显示松手时的样子）。要按算好的世界来的工具（画河、剪刀、合并），以及新建、打开、导出，按下会提示“还在计算上一步”，不再默默忽略；“换个形状”要等排队的几步算完。
- **画了等于没画（比如在陆地上画陆地）**：提示“没有变化”，不重算、不进历史。
- **画河改道**：松手时直接用算好的确切预览，不再算第二遍。
- **新建向导**：缩略图一张一张出来，第一张不到半秒。
- **导出**：放到单独的线程里，期间照样能看、能改地图；顶部显示进度，可以取消；栅格化快了约 1.4–3 倍。
- **画面**：改完后的闪烁不再每帧重画整张图；平移、缩放时着色器不算看不见的细节（每帧快约 15–50%；画面除海岸线上极少数像素的舍入外逐像素一致）。

## 导出

游戏文件包（.zip）里有：`heightmap.bmp`（8 位）与 `heightmap16.png`（16 位）、`provinces.bmp` + `definition.csv`、`provinces_summary.csv`（含省份类型）、`terrain.bmp`、`biomes.bmp`、`rivers.bmp`、`features.csv`（地名表：类型、名字、面积、在图上的像素坐标与经纬度，含自己圈的地区和放的地名）和 `world.json`。位图与屏幕用同一套格以下的海岸、自然弯曲的边界和平滑的河道，所以导出的图和屏幕上看到的一致（海岸线上的个别像素除外，见“已知限制”）。剪刀切过的地方，`provinces.bmp` 按切线分省，与屏幕相同（哪个很小的省因此一个像素都分不到时，碰到它的切线就不用了，并提示一句）；画的河照画的线画，乘上粗细。`provinces_summary.csv` 的类型一列写着陆地、无人区、湖、海域。

生态的花纹（闪光、裂纹、斑驳、脉络、斑点、条纹）、发光和颜色脚本算出的颜色画在屏幕上和当前画面的 PNG 里；新建向导的缩略图也有，花纹按拉远时的平均色画。`biomes.bmp`、`terrain.bmp` 照旧是每种生态一种颜色的分类图：游戏要知道的是“这一格是什么”，不是它画出来的样子，所以有意不画进去。河流类型的颜色、画法也一样，只在屏幕和 PNG 上，`rivers.bmp` 照旧按流量分级。

## 已知限制

- 耗时（Node 里实测，第七轮前 → 后；浏览器里多约 0.05–0.1 秒的传输与重画）：

  | 操作 | 一块地区（4 万格） | 整个星球（10 万格） |
  |---|---|---|
  | 改海陆（真改了海陆的一笔） | 0.75 → 0.48 秒 | 2.4 → 1.75 秒 |
  | 只改冷暖干湿 | 0.37 → 0.08 秒 | 1.24 → 0.22 秒 |
  | 撤销、重做 | 约 0.7 秒 → 几毫秒 | 约 2.2 秒 → 十几毫秒 |
  | 重画这一片 | 0.9 → 0.33 秒 | 4.7 → 1.4 秒 |
  | 新建 | 1.5 → 1.2 秒（网格另快约 3 倍） | 5.2 → 3.2 秒 |
  | 重新打开（重放；有检查点时更快） | 2.5 → 0.95 秒 | 9.9 → 3.8 秒 |

  改名、圈地名、改省份及其撤销约 10–20 毫秒；悬停、涂画时每帧约 1–2 毫秒。导出宽 4096 的图约十几秒（地区）到半分钟（星球），期间照样能用。
- 撤销只存最近几步的结果（第九轮起地区 8 步、星球 6 步，相同的数组几步共用，合计不超过 200 MB），再往前撤销还是要重算；排队的笔画各算一遍，画得很快时要等它们一笔一笔算完。星球上一次确切预览要几秒：第九轮起它在阶段之间可以停下（接着画、松手执行别的命令时不再等它算完）。
- 一块地区：地图是星球上的一块，东西不相接，“地图在星球上的位置”只能整体南北挪，南北跨度由建世界时的大小决定。最多约 4 万格（放大到最大时一格约 64 像素）。
- 整个星球只有平铺图，没有地球仪；两极附近按平铺世界地图的样子被拉宽；圈一片、圈地名不能绕着极点画。
- 气候是简化的过程模型，不是 GCM：洋流只有整个星球有，而且是全年平均的表层流（没有深层洋流、海冰、厄尔尼诺这类年际变化）；季风只按大尺度海陆分布估计。一块地区的地图还没有洋流。
- 导出的 `terrain.bmp`、`rivers.bmp` 用的是通用配色，导入具体游戏前需要按其调色板重新映射（见导出包里的 README）。
- 画河拖动的时候，“会变干的河段”先是估算（没算改道后地势跟着变的部分），停一下才换成确切的；松手用的是确切的。
- 还不是所见即所得的几处（先做哪个、各要多少功夫见“还能怎样更所见即所得”）：
  - 海岸线上窄窄一圈像素，屏幕和导出的 `provinces.bmp`、`biomes.bmp` 规则还不一样，个别像素在导出图里归到岸的另一边；
  - 新建向导的缩略图看不到很小的岛；
  - “当前画面的 PNG”只导出看得到的那一块；
  - 撤销之前不能先悬停看会回到什么样；
  - 放岛、画陆地时只有海岸线是确切的，新陆地的高程、生态颜色要等结果出来才对；
  - 放地名、圈地名之前看不到会叫什么；点“岛屿特有生态”之前看不到哪些格会换。
- 脚本（见“脚本”）：
  - 隔离靠浏览器：不支持的浏览器上脚本在普通线程里跑，能读到这个浏览器里保存的世界、能联网（信任的问话里会照实说）。隔离时页面规则仍许连这个程序自己的网址（同源）；脚本照样能拖慢电脑、占内存。所以只信任信得过的人写的脚本。
  - 有循环的脚本要离开脚本框才用到地图上；导入资源包时不先逐段试跑，用到世界上才知道哪段出错。星球形态的脚本出错时，提示条上没有“编辑”。
  - 花纹、发光的着色器在个别显卡上编译不过时，地图照常画、只是不带花纹和发光，不会另外提示。
  - 整个星球（10 万格）上用了内置示例包以后，要重算生态的编辑约慢一倍（多算脚本和对周围的影响）。

- 人文内容（城镇、文化、国家）和省份的上级层级、自定义属性还没做；“放地名”只是一个带名字的点。
