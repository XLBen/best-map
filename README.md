# 架空世界编辑器（map_2）

给写架空世界的作者用的地图工具：几秒钟生成一片像真实世界的海陆（一块地区或整个星球），然后自己放岛、画陆地、涂生态、画河、划省份，名字自动起好，最后导出成整张地图的图片，或游戏能用的位图与表格。气候、河流、植被按物理规则推导，你改了一处，下游、下风向会跟着变。想要水晶丛林、血河、双子大陆这样的奇幻设定，可以给生态、河湖类型、星球形态写一小段脚本，打包成资源包给别人用。

## 一键开启

1. 先装 [Node.js](https://nodejs.org)（LTS 版）。
2. 双击 Mac 上的 `启动-Mac.command`、Windows 上的 `启动-Windows.bat`。Mac 第一次若提示“无法打开”：右键 → 打开。
3. 第一次会先联网装需要的组件（一两分钟），再打包一次（代码没变时以后不再打包），之后浏览器自动打开 http://localhost:5191 （打包好的程序，比开发服务器快，打开上次的世界直接从检查点恢复）。地图已经开着时再双击只是打开浏览器。用完关掉那个黑色窗口就停止。

**保存**：世界自动保存在浏览器里、按地址分开，所以地址固定是 5191。按 ⌘S（Windows 用 Ctrl+S）起个名字存进“世界 → 我的地图”（可以存很多个）；重要的世界再用“世界 → 导出世界文件”另存一份文件，换电脑、清浏览器数据时靠它。

**不兼容旧存档**：第九轮以前保存的世界文件、浏览器里的自动保存都打不开了（打开时提示“这是旧版本的世界，打不开”），请新建。

## 五分钟上手

界面学的是 Procreate：地图铺满全屏，按钮浮在上面，每一类调节只有一个固定的位置。

| 位置 | 放什么 |
|---|---|
| 左上角 | **世界**（新世界、我的地图、保存、导出世界文件、资源包）· **操作**（导出、历史、上手说明、偏好）· **调整**（整个世界的滑块）· 撤销、重做 |
| 右上角 | **地形 · 气候 · 自然 · 水系 · 省份 · 地名** 六类工具，然后是 **图层** 和 **生态** |
| 底部工具条 | 第一行：这一类的全部工具，末尾“⋯”是更多设置。第二行：这个工具做什么、它的滑块和模式；选中的省份、地名、河、湖也在这里改 |
| 顶部中间 | 改完后的一句话 + 撤销 |
| 右下角 | “这里”：鼠标下是什么，点开看为什么 |
| 左下角 | 比例尺；旁边的尺子是量距离 |

1. **新建世界**：“世界 → 新世界…”，选“一块地区”（类型、大小、放在星球的哪里）或“整个星球”（类型、形态、大小），从缩略图里挑一张。
2. **地形**：画陆地 / 海、放岛（按住拖出大小）、岛链、堆山 / 压低、重画这一片、恢复原样。松手前就画出将来真实的海岸线。
3. **气候与自然**：涂冷暖干湿；右上角“生态”选一种去涂，“自然融入”让它真的长出来，涂不成的格画红斜线并说明原因。
4. **整个世界**：“调整”里拖陆地多少、岛多少、山多高、冷暖、干湿、河流多少、山挡风……每一下都能撤销。
5. **水、省份、地名**：画河（顺地势，或完全照着画的线走），点一下河、湖就选中它；省份可以剪、合并、重新划分；地名可以改、圈一片起名、放一个点。
6. **保存与导出**：⌘S 存进“我的地图”；“操作 → 导出”里导出整张地图的 PNG、当前画面的 PNG 或游戏文件包（.zip）。

常用键：触控板双指平移、捏合缩放；F 看全图；`[` `]` 调大小；⌘Z 撤销；⌘S 保存；Tab 只看地图；M 量距离；Esc 取消。全部见使用说明。

## 开发

```bash
npm install
npm run dev        # 开发服务器，默认 http://localhost:5173（.claude/launch.json 里用 5191）
npm test           # 全部测试（99 个文件、945 个）
npm run test:fast  # 改代码时常跑的那部分（跳过最慢的几个文件）
npm run golden     # 只跑金标准：提速、重构后结果必须逐值不变
npm run build      # 查类型后打包
npx tsx tools/generate.ts --seed 3 --out out/seed3   # 命令行批量生成并导出
npx tsx tools/hash.ts                                 # 各层结果的哈希，核对 Node 与浏览器是否逐值一致
npx tsx tools/bench.ts --globe                        # 整个星球（10 万格）各步的耗时
```

更多见 [开发说明](docs/开发说明.md)。
